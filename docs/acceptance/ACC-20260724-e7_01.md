## 3. 兩個特別驗證（獨立 probe，非測試檔）

### 3.1 `parse_quoted` 未終止字串 bug（含 `"\` 結尾）

以獨立 probe 直餵下列輸入，全部**正確拒絕並定位到行**、無崩潰、無靜默接受：

| 輸入 | 結果 |
|---|---|
| `k: "\`（開引號 + 單一反斜線後即行尾，懸空反斜線） | `ok=FALSE line=2`「引號字串格式錯誤（未終止或未知轉義）」 |
| `k: "\"`（反斜線轉義掉結尾引號 → 未終止） | `ok=FALSE line=2` 同上 |
| `k: "abc`（一般未終止） | `ok=FALSE line=2` 同上 |
| `parse_scalar("\"\\")`（懸空反斜線 token） | 回傳 `false`（不動 out） |
| `parse_scalar("\"a\\\\b\"")`（合法轉義 `"a\\b"`） | 回傳 `true`，值長度 3、首字 `a` —— 正常路徑未被誤傷 |

**結論：實作者宣稱修過的懸空反斜線/未終止字串 bug 確實已修好**——`parse_quoted` 於 `i+1 >= size`
即回 false（懸空反斜線）、掃完仍 `!closed` 回 false（未終止）；合法轉義不受影響。

### 3.2 `1.10` minor 不被當數字塌成 `1.1`

- `parse("format_version: 1.10")` → `ok=FALSE line=0`「format_version 不相容（本實作支援上限為 1.0）」
  ——minor=10 > 支援上限 0，正確判為不相容。
- 直接以相容規則證明 minor 真為 10 而非塌成 1：
  - `is_format_compatible({1,10},{1,10}) = true`（expect true）
  - `is_format_compatible({1,10},{1,1})  = false`（expect false）
  - 若 minor 曾塌成 1，第二式將為 true；實得 false，**證明 minor 保留為 10**。

**結論：`1.10` 由 `parse_version` 以字串切分 + `stoi("10")` 取得 minor=10，未經 `double`，不塌成 1.1。已驗證正確。**

## 4. 審查發現

### 4.1 [Minor / 非阻斷 / 建議加固] 越界數值字面值會漏出 `std::out_of_range`

`numeric_token()` 接受任意長度數字串後呼叫 `std::stod`；`parse_version()` 呼叫 `std::stoi`。
兩者對**超出型別範圍**的輸入會拋 `std::out_of_range`，而 `parse()` 只 catch `ParseFail`，
故該例外**逸出 `parse()`**，與 `CHG-20260724-e7_01.md` 所述「對外介面仍為無例外的 ParseResult」
契約不符，亦不符 NFR-04「錯誤定位到行」（逸出的是無行號的標準例外）。

獨立 probe 實測：

| 輸入 | 現況 |
|---|---|
| `n: 999999999999999999999999999999999`（超大整數） | `ok=TRUE`（`stod` 收下為 inf 級 double，未報錯——可接受但非整數語意） |
| `n: 1e999999`（超大指數） | **逸出 `std::out_of_range`（stod）** |
| `format_version: 999999999999999.0`（超大 major） | **逸出 `std::out_of_range`（stoi）** |
| `format_version: 1.999999999999999`（超大 minor） | **逸出 `std::out_of_range`（stoi）** |

- **影響評估**：僅由**數值越界的畸形輸入**觸發；任何良構設定、以及相容版本（major=1、minor≤上限）
  的 `format_version` 皆不可能越界，故**不影響已列驗收面、37 測試、兩項特別驗證與正常運作**。
- **建議加固（後續單元或 hotfix）**：於 `numeric_token` / `parse_version` 以 `try{stod/stoi}catch(...)`
  轉為帶行號的 `ParseError`（或先做位數/範圍預檢），以完全兌現「無例外 ParseResult」與 NFR-04。
- **判定**：屬邊界穩健性缺口，**非阻斷**；不推翻本次 pass，但列為明確追蹤項。
