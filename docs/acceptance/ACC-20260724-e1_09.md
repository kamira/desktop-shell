## 語意正確性覆核 — pass

逐項對 `edge_snapping.cpp` 與測試比對：

- **四邊吸附**：`best_snap_axis` 逐軸考量螢幕起始邊 `0 - lo`（水平左 / 垂直上）與末端邊
  `extent - hi`（水平右 / 垂直下）。測試 `SnapRect.SnapsToEachScreenEdge` 對 1000×800 容器四邊
  逐一驗證（左緣 10→0、右緣距 5→左緣 900、上緣 8→0、下緣距 10→上緣 700），四邊皆正確。
- **閾值相對化 + 邊界含等於**：判定距離 = `threshold · 對應容器邊長`（逐軸）。`consider` lambda
  以 `a <= best_abs`（初始 best_abs = thr）接受首個候選，故 `|delta| == thr` 剛好吸附；
  `> thr` 不吸。測試 `ThresholdBoundaryInAndOut` 實證距 20（=閾值）吸、距 21 不吸、位置原樣。
- **多目標選最近 + 同距螢幕優先**：`consider` 於 found 後改用嚴格 `a < best_abs` 取代，平手保留
  先到者；螢幕候選先於 surface 候選加入，故同距螢幕勝（符合 CHG 設計）。測試
  `MultipleTargetsPicksNearestEdge`（near 左緣距 40、far 左緣距 10 → 選 far 1050）正確。
- **吸 surface 邊（對齊 + 相鄰）**：每 target 考量 左-左 / 右-右 / 左-右 / 右-左 四候選（後二為邊靠邊

- **遠離不吸附**：`FarAwayDoesNotSnap`（置中 500,500）→ `snapped()==false`、位置原樣。正確。
- **與 E1-08 拖曳整合**：`snap_surface` 讀 `DraggableSurface::live_position`（拖曳中實時位置）為被吸附
