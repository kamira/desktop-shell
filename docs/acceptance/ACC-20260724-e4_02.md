## 3. NFR-02（無絕對座標 / 無數字 z-order）覆核

逐欄位獨立確認渲染描述 `ImageRenderModel` 不含任何螢幕像素座標或疊放層級：

- **目標**：`ds::kernel::SurfaceId`（= `std::string`，源自上游 E1-24 `null_backend.hpp`）——
  **具名字串**，非數字 handle / index。`set_target("")` 空名回 `Invalid`（`image_element.cpp:98`）。
- **裁切**：`CropRect{x,y,width,height}` 為**正規化比例 [0,1]**（占來源分數），非螢幕像素。
  合法性檢查 `valid_crop`（`image_element.cpp:18`）要求有限、寬高 > 0、起點 >= 0、
  `x+width`/`y+height <= 1`。
- **縮放模式**：具名列舉 `ScaleMode{Fill,Fit,Stretch,Center,Tile}`，非數字係數。
- **透明度**：沿用上游 `AlphaProfile.opacity`（比例 [0,1]），非座標 / 非 z-order。
- **固有尺寸**：`ImageDimensions{width,height}` 為**影像自身資料**（來源像素尺寸），非螢幕擺放位置。
- grep（`z_order|zorder|z-index|screen_x|screen_y|abs_x|pixel_x` 等）在程式碼本體零命中；
  僅註解出現「不含螢幕 (x,y)」「非數字 handle」等否定敘述。

本單元不提供任何 (x,y) 螢幕位置或疊放層級欄位。**通過。**

## 4. 縮放 / 裁切 / 透明度覆核

- **縮放模式**：五模式（Fill=cover、Fit=contain、Stretch=拉伸、Center=原尺寸置中、Tile=平鋪）
  以列舉表達且語意清楚；預設 `Fit`；`set_scale_mode` 恆合法回 `Ok` 並反映於 `render_model`。
- **裁切**：預設 `full()`={0,0,1,1}；合法正規化裁切被接受；**越界**（負起點、溢出右/下、寬高本身
  > 1）、**退化**（零 / 負寬高）、**非有限**（NaN/Inf）一律回 `Invalid` 且**不套用**
  （`InvalidCropDoesNotMutateExisting` 與 probe P2 皆守衛「不部分套用」）；`clear_crop` 回 full。
- **透明度**：預設 opacity=1.0（完全不透明）；範圍內設值成功；**超界自動 clamp** 至 [0,1]
  （1.7→1.0、-0.4→0.0）；**非有限值**（NaN/Inf/-Inf）回 `Invalid` 且不靜默改值（probe P4 守衛
  -Inf 拒絕後保留前值）。邊界 0.0/1.0 與 -0.0 正確接受（probe P3）。

無效來源 / 零尺寸 / 空目標 / 越界裁切 / 非有限不透明度**一律報錯不靜默且不部分套用**——設計、
