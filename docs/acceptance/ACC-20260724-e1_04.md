- **圓角矩形**：界框外先剔除；`corner_radius` `std::clamp` 至 `min(w,h)/2`（過大為退化 stadium，

  閉合；邊界先以 `on_segment`（共線容差 1e-6 + 界框）判定，落在任一邊上一律命中。✔
- **path NonZero**：標準環繞數（`is_left` 向上 / 向下穿越 +1/−1），`wn != 0` 為內；邊界同樣先
  `on_segment` 含入。✔ 兩填充規則**確有實質差異**（見 §9 probe 之 pentagram 中心）。
- **枚舉窮舉**：`contains` / `is_valid` / `layer_rank` 之 `switch` 對 `ShapeKind` / `SurfaceLayer`

## 7. alpha 命中覆核

- 有效判定順序：先 `hit_test`（無效→Invalid 早退）→ `HitPolicy::Transparent` 之 surface **永不命中**
  （命中穿透，Ok/false）→ 幾何未命中→ Ok/false → `Opaque` 忽略 alpha 通道（Ok/true）→ `PerPixel`
  取 oracle 值。
- PerPixel：未注入 oracle 視為 1.0；oracle 回**非有限值 → Invalid**（報錯不靜默）；否則
  `effective = clamp(alpha,0,1) × clamp(opacity,0,1)`，`threshold` 亦 clamp 至 [0,1]，
  `effective >= threshold` 方命中。透明處（低於門檻）不命中。
- 兩條穿透路徑分明：surface 級 `HitPolicy::Transparent`（整片穿透）與逐像素低 alpha（局部穿透）
  互補，`topmost_hit` 之「最高層透明處落到底層」情境專門覆蓋。
- **判定：alpha 命中通過。**
