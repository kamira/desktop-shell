## 語意正確性覆核 — pass

逐項對照六個擴充點的組裝與需求：

- **E7-01 宣告式 load_skin**：`load_skin(const ds::format::Value&)` 消費 E7-01 Map（通常
  `Document::root`），解讀 `layer` / `input` / `alpha{mode,opacity}` / `position{anchor,dx,dy}`
  四欄（皆選填、未知鍵忽略、缺者用預設）。不自造格式，完全消費 E7-01 `Value` 多型模型
  （`is_map`/`is_string`/`is_number`/`find`/`as_*`）。文字→`parse`→`Document.root`→`load_skin`
  路徑於測試 `LoadSkinFromParsedTextDocument` 實證。
- **E1-01 具名圖層**：`layers_.assign(id, layer)` 指派具名 `SurfaceLayer`（wallpaper/below-normal/
  normal/overlay/topmost），卸載時 `layers_.remove(id)`；`assigned_to_layer()` 透傳
  `layers_.contains(id)`。多 skin 共用同一注入 `LayerStack` 互不干擾（測試
  `MultipleSkinsShareLayerStackWithoutInterference` + `layers.size()` 驗證）。
- **E1-02 輸入策略**：具名 `InputStrategy`（interactive/capture/click-through/inert）經
  `input_ctl_.set_strategy`，並以純函式 `to_backend_policy` / `hit_result` 對映後端三態
  （測試逐一驗 ClickThrough→PassThrough/Transparent、Capture→Modal、Inert→Accepting/Solid）。
- **E1-03 alpha surface**：`create_alpha_surface(id, SurfaceProfile, AlphaProfile)` 建立支援
  per-pixel alpha 的具名 surface；opacity 於建立時 clamp。
- **E1-07 anchor 定位**：位置以九宮具名 `Anchor` + 正規化 `Offset{dx,dy}` 承載；具體像素只在
  `resolve_live`（委派 E1-08→E1-07 `resolve`）純佈局計算邊界出現，由呼叫端提供容器 / 元件尺寸
  （測試 `ResolveLiveProducesConcretePlacement`：container 100×100 / element 20×20 / Center →
  (40,40)）。
- **E1-08 拖曳 + 位置記憶**：`begin_drag`/`drag_to`/`end_drag`/`cancel_drag` 透傳 E1-08 並保留
  其精確碼（Ok/Invalid/NotDragging/AlreadyDragging）；pending/committed 分離
  （拖曳中 `live_position` 回 pending、`remembered_position` 回上次提交，end 才提交、cancel 還原）；
  `save_position` / `load_position` 以 E7-01 文字 round-trip（測試 `SaveAndLoadPositionRoundTrip`
  在全新 profile 上還原 anchor + 正規化 offset 逐值相符）。

- **載入全有或全無（中途失敗回滾）— pass**：`load_skin` 先在**暫存變數**上驗證全部四欄
  （任一欄型別 / 具名值不合法即回 `Invalid` 且**完全不改狀態**、不建立任何後端物件），驗證通過
  後才依序實體化 E1-03→E1-01→E1-02→E1-08；任一步失敗即呼叫 `teardown_backend_state()`
  （反向拆除：位置登錄→輸入策略→圖層指派→alpha surface，各步對未知 id 皆安全 no-op）並回對應
  具名結果，**不留殘留後端狀態**。全數成功才提交期望狀態至成員並轉 `Loaded`。解構安全：dtor
  若仍載入則強制 `unload()`（測試 `DestructorUnloadsWhileLoaded` 證實不留殘留）。
  回滾實證：`CaptureStrategyUnsupportedRollsBack`（alpha 可用但無 input.capture → set_strategy
  失敗 → 已建立的 alpha surface 與圖層指派全回滾，`has_surface==false`、`assigned_to_layer==false`）。

- **NFR-02（具名圖層 + anchor，無絕對座標 / 數字 z-order）— pass**：核心 API 位置型別全程為
  `AnchorSpec`（具名九宮 anchor + 正規化偏移）、圖層為具名 `SurfaceLayer`（附 `layer_name()`
  穩定字串如 `layer.overlay`）；具名結果 `SkinState` / `SkinStatus` 各附 `to_string()`。grep 未見
  像素座標欄位 / 數字 z-order；具體像素僅於 `resolve_live` 邊界由呼叫端尺寸推導。

- **NFR-03（能力閘控）— pass**：per-pixel alpha 經 `alpha_svc_.supported()`（=
  `backend.has("surface.per_pixel_alpha")`）前置閘門，能力不可用回 `Unsupported` 且**不建立任何
  surface**（測試 `LoadSkinUnsupportedWhenAlphaCapabilityUnavailable`：surface 未建、圖層未觸）；
  圖層指派閘於 `LayerAssign::RejectedNoCapability`→`Unsupported`+回滾；Capture 輸入策略閘於
  `set_strategy` 失敗（需 `input.capture` 能力）→`Unsupported`+回滾。失敗一律回滾、不留殘留、
  走降級路徑，無靜默。
