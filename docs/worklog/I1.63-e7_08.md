## 我要做什麼（動工前計畫）

一個版本遷移機制（`namespace ds::format`，C++17）：

- `Migration{from, to, transform}`：單一遷移步驟；`transform: Value -> Value` 純結構轉換（可為空）。
- `MigrationRegistry`：`register_migration`/`add`（驗步驟嚴格上升）、`has_path`、
  `migrate(root, current, target)` 與 `migrate(Document, target)`。
- `MigrateResult` + `MigrateStatus{Ok, NoPath, TooNew, Invalid}` + `MigrateError{status, message, from, target}`。
- 以步驟為有向邊、`FormatVersion` 為節點，BFS 找最短鏈；no-op（已最新）/ TooNew（過新）/
  NoPath（無鏈）明確報錯，不靜默。
- 補 `version_less`/`version_to_string`（E7-01 `FormatVersion` 僅有 `==`/`!=`，不改上游）。
- CMake：`target_link_libraries(e7_08 PUBLIC e7_01 e9_02)`。

參考已合併的 `engine/format/e7_01/`（`Value`/`FormatVersion`/`Document`/`ParseResult` 成功失敗二選一、
不靜默失敗）與 `engine/format/e7_07/`（消費上游、CMake 連上游樣板）。
