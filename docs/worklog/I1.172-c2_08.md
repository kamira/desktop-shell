## 組裝設計

`ds::widgets::NoteWidget`（`content/widgets/c2_08/note_widget.hpp/.cpp`）：

- 注入式相依（不擁有生命週期）：`KernelBackend&` + `LayerStack&`（轉交內部自持的 C1-01
  `SkinProfile base_`）+ `FontMetrics&`（轉交內部自持的 E4-15 `TextInputElement content_`）。
  两个子物件**分開持久化**——`base_` 的位置經其自身 `save_position`/`load_position`；
  `content_` 的內容經本單元新增的 `save()`/`load()`。
- **基底透傳（C1-01）**：`load_base` / `unload_base` / `is_base_loaded` / `base_state` / `id` /
  `place` / `begin_drag` / `drag_to` / `end_drag` / `cancel_drag` / `is_dragging`，皆一行委派
  `base_.*`，保留其精確結果碼（不重新包裝、不吞語意）。
- **編輯透傳（E4-15）**：`set_text` / `insert` / `backspace` / `erase_forward` / `text` /
  `length`，皆一行委派 `content_.*`；非法 UTF-8 透傳 `std::invalid_argument`（不吞）。
- **內容持久化（E7-12，本單元的組裝重點）**：
  - `load(serialized_text)`：`ds::format::parse` 解析；失敗 → `Invalid`。成功則取根 Map 的
    `text` 欄位——缺席視為空筆記（`Ok`，`set_text("")`）；存在但非字串 → `Invalid`（不改內容）；
    存在且為字串則 `try { content_.set_text(field->as_string()); } catch
    (std::invalid_argument&) { return Invalid; }`（攔截罕見的非法 UTF-8 字串欄位，轉譯為具名
    結果，維持「不靜默」但不讓例外穿透這個以字串進出的持久化 API）。
  - `save()`：`Value::map({{"text", Value::string(content_.text())}})` 經
    `ds::format::serialize(root, kSupportedFormat)`。空字串 / 多行 / 含引號 / 反斜線 / Tab
    皆由 E7-12 的字串引號化 + 轉義規則保證 round-trip（該規則已存在，本單元純消費，不重造）。
- **顯示透傳（E4-01，經 E4-15）**：`render_model()` 一行委派 `content_.render_model()`。
- 具名結果：`NoteStatus`（Ok / Invalid），附 `to_string()`（NFR-02，一致於 `SkinStatus` 風格）。
- 解構安全：無需額外處理——`base_` 成員的 `~SkinProfile()` 已自行處理「若仍載入則強制卸載」，
  `NoteWidget` 解構時各成員依宣告逆序析構即涵蓋。

無效輸入一律明確回具名結果，不靜默：`load()` 對「無法解析文字」/「`text` 型別錯」/「`text`
非法 UTF-8」皆回 `Invalid` 且不改動既有內容（全有或全無）；基底 / 編輯操作的既有精確結果碼
（`SkinStatus` / `DragStatus` / 例外）全數透傳，不改寫語意。
