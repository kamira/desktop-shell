## 我要做什麼（動工前計畫）

engine 層純數學工具，平台無關：

- `Easing`（`easing.hpp|cpp`）：一組緩動曲線靜態純函式，輸入 t∈[0,1]（先 clamp）回 eased 進度。
  linear + In/Out/InOut × {Quad, Cubic, Sine}，共 10 種；`EasingType` 列舉 + `apply(type,t)` 分派。
  未知列舉回退 linear，全部 `noexcept`。
- `Tween`（`tween.hpp|cpp`）：`{from, to, duration, easing}`，`at(time)` 純查詢絕對時間值、
  `advance(dt)` 增量推進求當前值；`progress` / `done` / `reset` / 存取器。time 夾到 [0,duration]，
  `duration<=0` 視為瞬間完成。value type = double。
- 不接真實時鐘、不綁繪製後端、無平台分支（無 `#ifdef` / win32 / cocoa）。確定性 → 可完全單元測試。
