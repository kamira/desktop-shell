## 我要做什麼（動工前計畫）

消費上游 E7-12（`serialize`）與其相依 E7-01（`Value` / `Document` / `parse`），
把「目前桌面佈局」擷取為抽象 `LayoutState`、序列化為宣告式格式存於**可注入的儲存後端**，
並支援多具名 profile 的存 / 取 / 列舉 / 刪除。相位 1（Mac / null 期）：純邏輯，
**無** `#ifdef` / win32 / cocoa / 真實檔案 I/O（儲存為記憶體後端）。

## 設計要點

- `LayoutState { vector<LayoutElement> }`；`LayoutElement { id, type, Value properties }`。
  位置 / 大小 / 設定全收進宣告式 `properties`（Value Map），使核心 API 面不出現絕對座標 /
  數字 z-order（NFR-02）。
- `serialize_layout` 走 E7-12 `serialize(root, kLayoutFormat)`；`deserialize_layout` 走 E7-01 `parse`。
- `LayoutStorage` 抽象後端（put/get/has/erase/names）+ `MemoryLayoutStorage`（`std::map`，字典序列舉）。
- `LayoutStore(LayoutStorage&)`：`save`（覆寫同名）/ `load` / `list` / `remove` / `contains`。
- 不靜默失敗：查無佈局、空名稱、解析 / 結構違反一律 throw `std::runtime_error`。
