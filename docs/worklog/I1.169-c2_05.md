## 我要做什麼（動工前計畫）

artifact 層組裝型 widget，掛載於注入的 C1-01 `SkinProfile&` 之上，內部自持一個 E4-02
`ImageElement` + widget 層維護的圖片清單（`vector<string>` 參照 + `vector<ImageDimensions>`
尺寸 + 目前索引）：

- `ImageWidget(SkinProfile& skin)`：建構子立即 `set_target(skin.id())` 綁定渲染目標（skin id
  不可變，僅需綁定一次）。
- `configure(const Value& definition)`：宣告式 Map，欄位 `images`（List，必填，每項
  `{ref, width, height}`）/ `fit`（選填具名縮放模式字串）。先整批驗證（結構 + 具名值合法性），
  全數通過才提交新清單、重置索引至第 0 張，委派 E4-02 `set_source`/`set_scale_mode`（不部分
  套用）。
- `set_image(std::size_t index)`：索引越界或清單為空 → `Invalid`（不改變目前所選）。
- `next()`：依序前進，抵尾循環繞回第 0 張；空清單或僅一張 → 安全 no-op。
- `image_count()`/`current_index()`/`fit_mode()`/`render_model()`：查詢與渲染輸出（委派
  E4-02）。`skin()`：唯讀存取所掛載的 C1-01 基底，供驗證組裝正確。
- 平台中立、無 `#ifdef` / win32 / cocoa；無真實影像解碼（沿用 E4-02 可注入 `ImageSource`
  抽象）；空清單（未 configure）時所有查詢 / 切換操作安全降級。
