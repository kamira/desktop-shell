## 組裝設計

`ds::profiles::PortraitProfile`（`content/profiles/c1_02/portrait_profile.hpp/.cpp`）：

- 注入式相依（不擁有生命週期）：`KernelBackend&`（E1-03 `AlphaSurfaceService` + E1-08
  `DraggableSurface` 共用同一後端）+ `LayerStack&`（可與其他 surface / profile 共用堆疊）。
  內部自持 `SurfaceSwitcher`（E4-06，純記憶體、無需後端）+ `RegionEventDispatcher`（E5-14，
  純記憶體、無需後端）+ 一份具名表情 → `ImageElement`（E4-02）的線性配對。
- **宣告式載入（E7-01）**：`load_portrait(Value)` 解讀 `layer` / `alpha{mode,opacity}` /
  `position{anchor,dx,dy}` / `expressions[{name,source,width,height,scale}]` /
  `initial_expression`，先**全數驗證**（型別 / 具名值 / 表情缺欄位 / 非正尺寸 / 重複表情 id /
  `initial_expression` 無匹配）不動任何狀態，再依序實體化：E1-03 建立 alpha surface
  （`Unsupported` 降級，不建立任何 surface）→ E1-01 指派圖層 → E1-08 登錄初始位置 → E4-06 +
  E4-02 登記表情（`ImageElement.target` 一律覆寫為本 profile 主要 surface）→ 切至
  `initial_expression` → E5-14 依目前表情固有尺寸整理命中 surface。任一步失敗即
  `teardown_backend_state()` 全數回滾（成員欄位 `layer_`/`alpha_`/`position_` 延後到最終成功
  才提交，避免中途失敗留下「已提交但未實體化」的不一致狀態——仿 C1-01 `SkinProfile` 慣例）。
- **具名表情切換（E4-06 + E4-02）**：`add_expression`/`switch_expression`/`remove_expression`
  純委派 `SurfaceSwitcher`（需已載入），內部另有無狀態閘控的 `*_impl` 版本供 `load_portrait`
  於實體化中段（尚未提交 `state_ = Loaded`）與已載入後的公開方法共用，避免重複驗證邏輯。
  切換 / 新增 / 移除表情皆呼叫 `refresh_hit_surface()` 依目前表情固有尺寸重建 E5-14 命中
  surface 的形狀（`Shape::Rect` 之 width/height 為元件本地固有尺寸，非螢幕座標，NFR-02）；
  尚無表情時退回 1x1 最小佔位形狀。
- **區域點擊（E5-14）**：`set_regions`/`on_region_click`/`unsubscribe_region_click`/
  `inject_click` 純委派 `RegionEventDispatcher`。
- **定位 / 拖曳 / 位置記憶（E1-08）**：`place`/`resolve_live`/`begin_drag`/`drag_to`/
  `end_drag`/`cancel_drag`/`is_dragging`/`save_position`/`load_position`，語意與 C1-01
  `SkinProfile` 對應方法一致（皆純委派 E1-08，保留其精確結果碼）。
- **解構安全**：`~PortraitProfile()` 若仍載入則強制 `unload()`，避免共用 `LayerStack` /
  後端上殘留指向已銷毀物件語意的條目。

無效操作一律明確回 false / 具名結果，不靜默：`load_portrait` 非 map / 型別錯 / 具名值無效 /
表情缺欄位 / 非正尺寸 / 重複表情 id / 無效縮放模式 / `initial_expression` 無匹配 / 空 id /
重複載入；未載入即操作（表情增刪切換、定位、拖曳）；能力不可用時載入（`Unsupported`）。
