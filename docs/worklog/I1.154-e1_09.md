## 我要做什麼（動工前計畫）

拖曳（承 E1-08）surface 時，邊緣靠近**螢幕邊**或**其他 surface 邊**到閾值內即**自動吸附對齊**，
吸附後位置以 E1-07 宣告式定位承載（NFR-02）：

- 純幾何核心 `snap_rect(dragged_rect, target_rects, container, config) -> SnapResult`：逐軸求「夠近
  且最近」的對齊（螢幕起 / 末端邊、各 target 的左-左 / 右-右 / 左-右 / 右-左），套用位移。
- 宣告式 `snap(dragged_spec, element, targets, container, config) -> AnchorSpec`：`resolve` 落地 →
  `snap_rect` → 再表達為 `AnchorSpec`（吸螢幕末端邊 → 末端錨 + 零偏移；其餘 → 起始錨 + 正規化偏移，
  round-trip 回同一矩形）。
- 閾值 `SnapConfig::threshold` = 容器尺寸正規化分數（逐軸乘邊長換算）；`from_spacing` 用 E1-07 具名間距；
  `to_screen` / `to_surfaces` 可分別開關。具名 `Edge` / `AxisSnap` + `screen_edge_of` 查詢（NFR-02）。
- E1-08 整合 `snap_surface`：讀 `DraggableSurface::live_position` 對實時位置吸附（含自己 → 略過、
  無實時位置目標 → 略過）；被吸附者無實時位置 → Invalid。
- 服務 `EdgeSnapping` 持一組 `SnapConfig`。結果碼 `SnapStatus`{Ok, Invalid}；無效輸入結構化回報、
  不靜默、不寫 out、不崩潰。

參考已合併的 E1-07（`AnchorSpec` / `resolve` / 邊緣對齊洞見、結果碼風格）與 E1-08（`live_position`
唯讀查詢、具名 SurfaceId、null 後端測試設置）。核心宣告式型別內不出現絕對像素座標；具體像素只在
`snap_rect` 的 `ResolvedPlacement` 邊界（呼叫端提供尺寸）出現。
