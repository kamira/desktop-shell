## 我要做什麼（動工前計畫）

以 **anchor（錨點）** 表達元件 / surface 定位，取代絕對像素座標（NFR-02 正解）：

- 九宮具名錨點 `Anchor`（TopLeft…BottomRight）→ 正規化分數 [0,1]²（`anchor_fraction`）。
- 相對偏移 `Offset{dx,dy}`（容器尺寸的正規化分數）+ 具名間距 `Spacing`（`spacing_fraction` /
  `Offset::from_spacing` / `inset_from` 依錨定邊決定內縮方向）。
- 宣告式 `AnchorSpec{anchor, offset}`；`resolve(spec, container, element)` 純佈局計算 →
  具體 `ResolvedPlacement`（角 / 邊錨點邊緣對齊、置中錨點置中；比例隨容器縮放）。
- `AnchorLayout`：承 E1-03 / E1-24 具名 `SurfaceId` 模型，把「具名 surface → 定位規格」配對並解析。
- 無效 anchor / 非有限 offset / 非有限或負尺寸 → `AnchorStatus::Invalid`，不靜默、不寫 out、不崩潰。

核心宣告式型別內不出現任何絕對像素座標；具體像素只在 `resolve()` 的輸入尺寸（呼叫端提供）與
輸出佈局（計算結果）出現。參考已合併的 E1-03 `AlphaSurfaceService`：沿用其結果碼風格
（Ok/Invalid）、具名 SurfaceId 記錄配對、「不靜默失敗」契約。
