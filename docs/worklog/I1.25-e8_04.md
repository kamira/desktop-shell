## engine 層 / 平台中立約束遵循

- 純邏輯：無 `#ifdef`、無系統呼叫、無真實後端、無平台分支 —— 換平台一行不動。
- **相位 1 刻意不用 dlopen / 動態庫**：模組是已連結的 C++ 物件；契約（validate →
  register → track → unload）與相位 2 一致，只換取得 Module 的方式。
- 不定義 manifest 格式（E9-02 職責）；本單元消費已解析的 `ds::package::Manifest`。

## 設計要點

- `HostEnvironment` 承載閘控事實：host 提供的能力（對 requires）+ 授予的權限（對 permissions）。
- `load` 流程：manifest（name 非空、format 相容）→ 重複載入偵測 → requires 閘控
  （缺項全列，明確拒絕）→ permissions 閘控 → 呼叫 `on_register`（try/catch 包覆）→
  跨模組能力衝突整批檢查 → 無衝突才整批提交（不部分提交）。
- `unload`：呼叫 `on_unload` 鉤子（鉤子例外被吞、不阻斷）→ 自共享能力表精準移除本模組
  能力 → 移除追蹤。卸載後可重載。
- 命名空間 `ds::ext`；契約版本 `contract_version()` = "e8_04/1.0.0"。

## 本機驗證方式

- 本機無 cmake/gtest。以 `g++ -std=c++17 -Wall -Wextra -Wpedantic` + scratchpad gtest 墊片

  `g++ -std=c++17 -Wall -Wextra -Wpedantic -I engine/script/e8_04 -I engine/package/e9_02 -I <shim> engine/script/e8_04/module_loader.cpp engine/package/e9_02/manifest.cpp tests/e8/test_e8_04.cpp <shim>/gtest_main.cpp -o test_e8_04_local && ./test_e8_04_local`
