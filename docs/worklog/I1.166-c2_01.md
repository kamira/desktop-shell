## 組裝設計

`ds::widgets::ClockWidget`（`content/widgets/c2_01/clock_widget.hpp/.cpp`）：

- 注入式相依（不擁有生命週期）：`SkinProfile&`（掛載基底，C1-01）+
  `shared_ptr<TimeSource>`（時間來源，E2-10，可為空代表「無時間來源」）+
  `const FontMetrics&`（排版度量，E4-01）。
- **宣告式設定（E7-01）**：`configure(Value)` 先把定義（Map）解讀為期望顯示樣式（暫存副本，
  嚴格驗證已知欄位型別 / 具名值——無效即 Invalid 且不改狀態），再檢查掛載基底是否已就緒
  （`base.is_loaded()`；未就緒 → Unsupported，不提交設定）。全數通過才提交樣式並轉
  Configured，隨即儘力做一次初次取樣（無時間來源不算失敗，僅 display 暫空）。
- **時間更新（E2-10）**：`tick()` 重新取樣注入時間來源（`civil_from_epoch_seconds
  (source->now_epoch_seconds())`）、格式化 `display_text_`、呼叫內部 `relayout()`
  （E4-01 `TextLayout`）。未 configure → NotConfigured；無時間來源 → Unsupported（既有顯示
  不動，不靜默但也不清空舊值——時間來源缺席不等於「時間未知」而抹除已知的上次讀值）。
- **重新排版（E4-01）**：`refresh()` 僅呼叫 `relayout()`（依目前 `display_text_` + 目前
  align/width 重跑 E4-01 排版），**不重新取樣時間**——與 `tick()` 語意區隔（tick=更新時間+
  排版，refresh=純排版重算）。目標具名 surface 綁定基底 `base.id()`（NFR-02 具名指涉，換角色
  掛載對象一行不動）。
- **時間格式化**：12/24 時制純算術轉換（`std::snprintf`），不呼叫任何 OS 時區 / wall-clock
  API；0 時 → 12 AM、12 時 → 12 PM（標準 12 小時制邊界）。

無效操作一律明確回具名結果，不靜默：未 configure 即 tick / refresh（NotConfigured）、定義非
map / 型別錯 / 具名值無效 / 空 id（Invalid，不改狀態）、掛載基底未載入 / 無時間來源
（Unsupported）。
