## 錯誤紀錄（錯誤 + 根因 + 解法）

- **錯誤**：初版把 `inverse()` 的回傳型別設計成 `Transform2D` 的巢狀 `struct Result { Transform2D matrix; ... }`。
  編譯報 `field has incomplete type 'Transform2D'`。
  **根因**：巢狀類別在外層類別尚未閉合前不可擁有一個「外層類別型別」的資料成員（外層此時為
  不完整型別）。此為真實錯誤，CI 一樣會紅。
  **解法**：將結果型別提升為命名空間層級 `struct InverseResult`，於 `Transform2D` 類別完整定義**之後**
  才完整定義（類別內僅前置宣告 + 方法回傳該型別）。修正後編譯通過。
- **插曲（本地工具，不影響 repo）**：scratchpad gtest 墊片原缺 `EXPECT_FLOAT_EQ`，補上一條以
  `near(a,b,1e-6)` 實作的巨集即通過。屬本地驗證墊片，不進 repo。
