## 我做了什麼

一個 sysinfo 指標提供者，把記憶體使用量（實體 + swap）透過 E2-01 `MetricProvider` 掛成指標
`memory.stats`（unit=""、range unbounded——欄位異質 bytes 與 %），並以 E2-02 頻率分級（預設
Normal）決定採樣。設計參照 E2-03/E2-12/E2-13 provider 範式（單一 metric + 固定欄位集為可列舉
實例，e2_13 風格）：

- **值模型** `MemoryStats`：`physical_total/used/available` + `swap_total/used` + `valid`（皆
  bytes）；`from_physical` 便利工廠（available=total-used 夾 >=0）；`usage_percent`＝used/total
  *100 夾 [0,100]（total==0→0）、`swap_usage_percent`（除零保護）。used 與 available 由來源
  分別給出，不臆造 `used+available==total`（真實 API 因 buffer/cache 而未必成立）。
- **記憶體來源**（注入式、平台中立）：抽象 `MemoryStatSource::read()→MemoryStats`（非 const，
  序列型取樣有副作用）；`NullMemoryStatSource` 以注入快照列表達——**固定值=一元素序列**、
  **序列**模擬時間推進（列盡持續回最後一份、空列回 unknown）。即規格「注入固定/序列」。
- **提供者** `MemoryProvider`：固定 6 欄位實例（實體總量／已用／可用／使用率 % + swap 總量／
  已用；變動欄位保留歷史環、靜態欄位無歷史）；`sample()` 更新（register 前 no-op）；
  `sampling_tier()` 供 add_demand。
- **絕不接真實記憶體 API**（無 host_statistics / sysctl / /proc/meminfo / mach / #ifdef /
  win32 / cocoa）；無讀值以 valid==false 誠實表達，不謊報 0（total==0 時使用率欄位亦未知）；
  消費者只走 E2-01 抽象介面。
