## 我要做什麼（動工前）

E11-01 是系統匣（system tray / menu bar）圖示與其右鍵選單的設定介面。相位 1（Mac / null 期）
且屬 platform 層 —— 對系統的操作**只寫介面 + null 後端**，絕對禁止真實平台後端與平台分支。

## 關鍵設計決策

- **選單邏輯與後端解耦**：對系統的唯一出口是 `TrayBackend` 抽象；選單項樹、點擊分派、
  勾選切換皆為純資料 / 邏輯，可完全以單元測試驗證，換平台後端一行不改。
- **可注入 + 工廠選派**：`SystemTray` 由外部注入 `unique_ptr<TrayBackend>` 與 `const CommandBus*`；
  `make_default_tray()` 相位 1 選派 `NullTrayBackend`，真實後端上線後只改工廠。
- **點擊經 E6-01 匯流排分派**：選單項綁具名命令 id，點擊時以 `CommandBus::dispatch` 觸發，
  不相依任何具體致動器；Checkbox 先切換勾選、再帶 `checked` 布林參數分派。
- **索引路徑定位巢狀項**：`{i, j, …}` 決定性定位子選單項；越界 / 穿越非子選單回 nullptr。
- **點擊邊界結構化**：InvalidPath / NotClickable / NoCommand / NoBus / Dispatched，絕不崩潰
  （未接匯流排、點分隔線 / 子選單 / 停用項皆安全回報）。
- **null 後端忠實記錄**：記憶體保存最後圖示 / 提示 / 選單 / 可見狀態並累計呼叫次數，供契約測試斷言一致。
