- **C1-04**（`content/profiles/c1_04/osd_overlay_profile.hpp`）：OSD 浮層 profile——
  `OsdOverlayProfile`：`show(message, ttl)` / `update(message)` / `dismiss()`，狀態機
  `OsdState{Hidden, Showing}`，組裝 E1-14（短暫生命週期）+ E1-01（具名頂層 Overlay
  歸屬）+ E1-02（輸入策略）。重複顯示 / 未顯示即更新或收起皆明確回 `false`，不靜默。
  本單元不重造顯隱狀態機，直接以參考持有一個既有 `OsdOverlayProfile` 實例當基底。
- **E4-01**（`engine/render/e4_01/text_layout.hpp`）：文字排版——`TextLayout::layout(
  text, constraints)` 依注入式 `FontMetrics`（相位 1 用 `FixedFontMetrics`）把 UTF-8
  文字排成 `LayoutResult`（`LineBox` + `Glyph`，全相對偏移，NFR-02）。空字串排版結果為
  空（無行、`size{0,0}`）；`'\n'` 分段為多行；`max_lines` 裁切設 `truncated=true`。

## 組裝設計

`ds::apps::ShortcutCheatSheetApp`（`apps/c4_01/shortcut_cheat_sheet.hpp/.cpp`）：

- 注入式相依：`OsdOverlayProfile&`（C1-04，不取得所有權，須比本物件活得久，沿用
  C4-02/C4-03 對上游元件以參考持有、不擁有生命週期的組裝相依風格）+
  `const FontMetrics&`（E4-01，同樣不取得所有權）。`TextLayout`（E4-01）以值持有為成員
  （內部僅存一個 `FontMetrics` 參考，建構成本低，避免每次排版重新建構）。
- **資料模型**：`ShortcutEntry{keys, description}`——純資料，`keys` 僅為顯示用字串，
  刻意不做任何鍵盤事件擷取 / 解析（相位 1 硬性約束：無真實鍵盤 hook；也呼應本單元的
  純資料 + 文字排版定位，不越界做輸入層）。
- **`load_shortcuts(entries)`**：先整批驗證（任一項目 `keys` 或 `description` 為空
  字串 → `Invalid`，不動既有清單——不留半份殘留，呼應其餘 C4 系列單元「失敗不部分套用」
  的一貫精神）；驗證通過才 `std::move` 覆蓋既有清單。空清單本身合法（`Ok`，清空既有
  內容），與 E4-01 對空字串排版結果為空的語意自然銜接，不需特殊分支。若面板目前顯示
  中，成功載入後呼叫內部 `refresh_if_showing()`（委派 `OsdOverlayProfile::update()`）
  即時刷新面板內容，呼叫端不需另外重新 `show()`。
- **`filter(query)`**：ASCII 小寫化後子字串比對鍵位或說明任一命中即可見（相位 1 刻意
  不做完整 Unicode 大小寫折疊，保持簡單）；空字串清除篩選（`visible_shortcuts()` 回全
  部）。同樣在面板顯示中時即時刷新內容——與 `load_shortcuts` 對稱，讓「篩選中即時看到
  結果」與「內容改變即時反映在已顯示的面板上」是同一機制（`refresh_if_showing()`）。
- **`display_text()` / `layout()`**：`display_text()` 把 `visible_shortcuts()` 逐筆組
  成 `"<keys>  -  <description>"`（純 ASCII 分隔符，避免多位元組分隔符的排版 / 編碼
  邊界情況），行間 `'\n'`。`layout(constraints = {})` 純函式委派 `TextLayout::layout()`
  ——刻意與面板是否顯示中脫鉤，讓排版本身可獨立驗證（不需要先 `show()` 才能檢查排版
  正確），也預留給未來相位的繪製層直接消費，不必等面板顯示狀態。
- **`show(ttl)` / `hide()`**：直接委派 `panel_.show(display_text(), ttl)` /
  `panel_.dismiss()`——完全信任 C1-04 既有語意（重複顯示回 `false`、`ttl==0` 委派
  E1-14 拒絕、未顯示即收起回 `false`），本層不重複判斷，維持組裝型單元「不重造下游已
  解決的問題」的一貫原則。

具名結果 `LoadStatus`（Ok / Invalid）附 `to_string()`（NFR-02）；`show`/`hide`/
`filter` 沿用 C1-04 既有的 `bool` 語意，不另造同義列舉。

無效操作一律明確回傳，不靜默：無效鍵位清單（整批拒絕）、面板已顯示中再次顯示、未顯示
即收起（皆委派 C1-04 既有判斷）。
