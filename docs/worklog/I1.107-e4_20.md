## 分層 / NFR 遵循

- module 層純邏輯：只產出渲染描述，不觸碰任何 OS / 繪圖 API。
- NFR-02（無絕對座標 / 無數字 z-order）：所有頂點 / 控制點皆為元件本地座標系 `Point{x,y}`，
  非螢幕像素；描邊寬度為本地單位；指令 / 頂點順序即連線順序，本單元不提供任何數字 z-order
  欄位。
- 不靜默失敗：無效路徑操作（未 `move_to` 先 `line_to`/`curve_to`/`close`；重複 `close`）回
  `VectorStatus::Invalid` 且不追加指令；退化形狀（零/負寬高矩形、零/負半徑圓、<3 頂點多邊形、
  零長度線段）回 `Invalid` 且不寫入輸出路徑；非有限值一律 `Invalid`，不靜默改成預設值。
- 無 `#ifdef _WIN32` / `win32` / `cocoa` 分支，不涉及任何後端。
- 消費上游不重造輪子：描邊 / 填色的顏色合成描述沿用 E1-03 `AlphaProfile`。
- 未動根 `CMakeLists.txt`、`units.json`、共用 `docs/structure/directory.md`——G4 以每單元獨立
  結構檔 `docs/structure/units/e4_20.md` 滿足。
