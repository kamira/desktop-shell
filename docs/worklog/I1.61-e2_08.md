## 做了什麼
把「網路流量」實作為 sysinfo 指標提供者，範式沿用已合併的 E2-03 CPU 負載（差分演算法 +
可注入來源抽象 + null/假來源 + 差分轉接器 + `MetricProvider` 提供者），只是面向改為網路：
- 每網路介面的 **上傳/下載速率**（bytes/sec，由累積計數差分：兩份累積 rx/tx 位元組 + 時戳
  → 除時間差）、**累積收發位元組**、**收發封包數**，並支援**多介面**。
- 以 **E2-01** `MetricProvider` 暴露為六個指標（rx/tx 速率、rx/tx 位元組、rx/tx 封包），
  各以每介面為可列舉實例；以 **E2-02** `SamplingTier` 決定採樣節奏（預設 Normal）。
- 差分抽成獨立可測自由函式 `rate_from_delta` / `traffic_from_delta` /
  `traffic_from_snapshot`。首次差分速率誠實回 invalid（累積首份即有效）；無讀值誠實 invalid。

## 相位 1 平台中立性
無 `#ifdef` / `win32` / `cocoa` / `getifaddrs` / `/proc/net/dev` / mach / 任何真實網路 API；
僅注入式 `NullNetworkStatSource`（直接流量）與 `NullNetCounterSource`（累積計數序列）+
`DifferencingNetworkStatSource`（差分轉接）。真實後端留待相位 2，屆時提供者一行不動。
