## 設計要點

- `ThemeData { name, ds::format::Value attributes, Composition components }`：顏色/樣式/資源全收進
  宣告式 `attributes`(Value Map)，使核心 API 面不出現絕對座標 / 數字 z-order(NFR-02)。
- `ThemeManager`：`register_theme`(空名/重複拒絕)、`set_theme`(upsert，更新當前主題時自動通知)、
  `switch_to`(未知失敗不改狀態、同名 no-op、真變更才通知)、`current`/`current_name`(無當前 throw)、
  `has_theme`/`find_theme`/`list_themes`/`size`、`on_theme_change`(多回呼依序觸發)。
- `theme_from_document(name, doc)`：attributes = `doc.root`；橋接 E7-07 熱重載。
- 不靜默失敗：查無主題 → failure(帶原因) 或 throw std::runtime_error；空名稱 → failure。
