## 我要做什麼（動工前計畫）

消費 E7-01 契約（`Value` / `Document` / `parse`），提供與領域無關的階層式項目樹，供啟動器選單樹、
對話本、清單等共用，不自造格式模型。相位 1（Mac / null 期）：純邏輯，**不得**出現
`#ifdef` / win32 / cocoa / 真實後端。

設計（C++17，`namespace ds::format`）：

- `Item`：`id` / `label` / `value`（附帶酬載，任意 `Value`）/ 有序 `children`（遞迴）；
  查詢 `is_leaf` / `child_count` / `size` / `depth`；程式化 `set_label` / `set_value` /
  `add_child`；`operator==`。
- 尋址：`find(id)`（前序、含自身、const/非 const）/ `contains`。id 唯一。
- 遍歷：`for_each_preorder(root, visit(node, depth))`。
- 建構：`build_item(Value / Document)` / `build_forest(list)`；每項目 = Map，保留鍵僅
  `id`/`label`/`value`/`children`，其餘鍵報錯。契約違反回傳帶可定位訊息的 `BuildError`
  （`ItemResult` / `ForestResult`），承 E7-01 NFR-04「不靜默失敗」。

`target_link_libraries(e7_13 PUBLIC e7_01)`。無平台分支，相位 2 換後端一行不動。
