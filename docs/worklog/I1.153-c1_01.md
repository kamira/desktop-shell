## 組裝設計

`ds::profiles::SkinProfile`（`content/profiles/c1_01/skin_profile.hpp/.cpp`）：

- 注入式相依（不擁有生命週期）：`KernelBackend&`（surface 宿主）+ `LayerStack&`（E1-01，可共用）。
  內部自持 `AlphaSurfaceService` / `InputStrategyController` / `DraggableSurface`，三者**皆以同一
  注入後端建構**（建構子 init-list 確保），杜絕「不同服務綁不同後端」的組裝陷阱。作為多個具體
  skin 的共用基底：具體 skin 可持有本物件並附加自身資產 / 行為。
- **宣告式載入（E7-01）**：`load_skin(Value)` 先把宣告式定義（Map）解讀為期望狀態（暫存副本，
  嚴格驗證已知欄位型別 / 具名值——無效即 Invalid 且不改狀態），再依序實體化 **E1-03 建立 alpha
  surface → E1-01 指派具名圖層 → E1-02 設定輸入策略 → E1-08 登錄初始位置**；任一步失敗即
  `teardown_backend_state()` 回滾（全有或全無）。能力閘控（NFR-03）：`supported()==false` 前置
  回 Unsupported（不建立任何 surface）；圖層 `RejectedNoCapability` / Capture `set_strategy`
  失敗 → 回滾 + Unsupported。全數成功才提交期望狀態至成員並轉 Loaded。
- **定位（E1-07 / E1-08）**：`place(AnchorSpec)` = `set_position`；`resolve_live` 委派 E1-08 →
  E1-07 純佈局計算。具體像素僅在此計算邊界出現（NFR-02）。
- **拖曳（E1-08）**：`begin_drag` / `drag_to` / `end_drag` / `cancel_drag` 直接委派並回傳原生
  `DragStatus`（保留 NotDragging / AlreadyDragging 精確碼）；未載入時 begin/place 回 Invalid、
  其餘回 NotDragging。
- **位置記憶（E1-08 → E7-01）**：`save_position()` = `serialize_positions()`（本物件的 E1-08
  服務僅追蹤本 skin，故輸出僅含本 skin）；`load_position(text)` = `load_positions`（純資料回填，
  不經後端閘控，可在 load_skin 前先做 → 支援「先還原記憶、後實體化」流程）。
- **解構安全**：dtor 若仍 Loaded 則 `unload()`，不留殘留於共用後端 / 圖層堆疊。

無效操作一律明確回具名結果，不靜默：未載入即 place / drag、重複 load_skin（AlreadyLoaded）、
定義非 map / 型別錯 / 具名值無效 / 空 id、能力不可用時載入（Unsupported）、拖曳中 place。
