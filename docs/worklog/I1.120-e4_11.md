## 我要做什麼（動工前計畫）

module 層純邏輯，消費上游 E4-01（排版）與 E4-09（動畫驅動源）：

- `TypewriterElement`（`typewriter_element.hpp|cpp`）：持有完整 UTF-8 文字（解碼為碼位序列）
  與一個以碼位計數的「已顯示進度」（累計 double，取整數部分對外回報）。
- `set_text`：以 E4-01 `decode_utf8` 驗證 UTF-8 合法性，重建 UTF-8 位元組邊界表（供
  `render_model` 切前綴子字串），並重設進度歸零。非法 UTF-8 → `std::invalid_argument`。
- `set_speed`：每 tick 顯示幾個字元（可小數）。非正 / 非有限 → `std::invalid_argument`。
- `advance(dt)`：進度累計 `+= speed * dt`，夾在 `[0, total_count()]`；完成後再呼叫安全
  no-op。
- `attach(AnimationDriver&)`：對 `driver.add()` 的薄封裝，讓其每次脈衝自動呼叫
  `advance(frame.dt)`，回傳 `AnimationId`。
- `render_model()`：切出「已顯示前綴」子字串，委派 `TextLayout::layout()` 排版，回傳
  `LayoutResult`（NFR-02 相對佈局，未新增絕對座標 / 數字 z-order）。
- `is_complete()` / `reset()` / `visible_count()` / `total_count()`：查詢與控制介面。
- 平台中立、無 `#ifdef` / win32 / cocoa；時間全注入式，不接真實時鐘 / 計時器 / 繪製後端。
