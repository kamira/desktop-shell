## 我要做什麼（動工前）

E1-23 是「分層失敗的手動降級路徑」：當上游 E1-01 `LayerStack` 的分層能力不可用
（`has(kernel.surface) == false`，經 E1-21）或指派操作本身失敗（`assign()` 回非
Ok/Moved）時，提供一條**明確的手動降級路徑**——退回到較簡單的呈現（單層扁平化、
無 overlay），由呼叫端可選擇降級策略，且降級發生與否、原因清楚可見回報（不靜默）。

計畫產出（全部落在鎖定範圍內）：

1. `src/kernel/e1_23/layer_fallback.hpp`
   - `FallbackReason`：`None` / `CapabilityUnavailable` / `AssignRejected` / `StrategyForced`。
   - `FallbackStrategy`：可注入策略介面，`layered_available()`（預設委由 `has()`）與
     `flatten_target()`（預設 `SurfaceLayer::Normal`）。
   - `LayerFallbackResult`：`{ degraded, reason, assign_result, effective_layer }`。
   - `LayerFallback`：`try_layered()`（先試分層、失敗自動降級）、`fallback_flatten()`
     （直接手動降級）、`set_strategy()` / `strategy()`、`degrade_reason()` / `last_degraded()`。
2. `src/kernel/e1_23/layer_fallback.cpp`：上述介面的實作，純記憶體邏輯。
3. `src/kernel/e1_23/CMakeLists.txt`：依 BUILD.md 樣板，`add_library(e1_23 ...)` +
   `target_link_libraries(e1_23 PUBLIC e1_01 e1_21)` + `test_e1_23` executable + `add_test`。
4. `tests/e1/test_e1_23.cpp`：gtest，涵蓋分層可用正常路徑、能力不可用降級、assign 失敗
   （非能力問題）降級、降級原因可見回報、可注入降級策略、多層降級、能力恢復後回正常。
5. `docs/changes/CHG-20260724-e1_23.md`、本 worklog。

## 設計決策記錄

- **`LayerFallback` 不持有 `LayerStack`，每次操作以參數傳入**：降級決策應反映「當下」
  的能力狀態，不應綁死在建構當下的能力矩陣（`CapabilityMatrix` 本身是不可變快照，
  E1-01/E1-21 都沒有「原地更新能力」的介面）。這個設計讓「能力恢復後回正常」可以
  用同一個 `LayerFallback` 實例、換一個能力可用的 `LayerStack` 來驗證，貼近真實情境
  （例如換到有真實後端的平台）。
- **`fallback_flatten()` 直接呼叫時，降級原因依當下能力狀態如實回報**（`CapabilityUnavailable`
  或 `StrategyForced`），不因為是「手動」呼叫就一律標記同一原因——降級原因的可見性
  優先於呼叫路徑的區分。
- **能力矩陣完全不可用時，扁平化的 `assign()` 本身也可能被拒**（`RejectedNoCapability`）：
  這是忠實反映 `LayerStack::assign()` 的既有閘控語意（該閘控涵蓋所有圖層，不只特定
  一層），而非 E1-23 刻意繞過上游的能力閘控。此時 `LayerFallbackResult.assign_result`
  如實記錄「試過但寫不進去」，`degraded=true` 與 `reason` 仍清楚可見——降級決策本身
  沒有失敗，失敗的是底層寫入，兩者分開回報。

## 本機驗證方式

本機無 cmake、無 gtest。正式 gtest/CMake 檔照 BUILD.md 寫好給 CI（ubuntu-latest）。
本地以 g++ -std=c++17 -Wall -Wextra 搭配一個最小 gtest.h 墊片（scratchpad，不進 repo）
編譯**未經改動的**上游 `src/kernel/e1_01/layer_stack.cpp`、`src/kernel/e1_21/capability_matrix.cpp`、
`src/kernel/backend/null/null_backend.cpp`（e1_01 標頭相依）+ 本單元 `layer_fallback.cpp` +
`tests/e1/test_e1_23.cpp`，單一命令、全絕對路徑、無 cd/重導：

```
g++ -std=c++17 -Wall -Wextra \
  -I <repo>/src/kernel/e1_23 -I <repo>/src/kernel/e1_01 -I <repo>/src/kernel/e1_21 \
  -I <repo>/src/kernel/backend/null -I <scratchpad> \
  <repo>/tests/e1/test_e1_23.cpp <repo>/src/kernel/e1_23/layer_fallback.cpp \
  <repo>/src/kernel/e1_01/layer_stack.cpp <repo>/src/kernel/e1_21/capability_matrix.cpp \
  <repo>/src/kernel/backend/null/null_backend.cpp -o <scratchpad>/test_e1_23_local \
  && <scratchpad>/test_e1_23_local
```
