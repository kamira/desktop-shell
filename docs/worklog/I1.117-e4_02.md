## 分層 / NFR 遵循

- module 層純邏輯：只產出渲染描述，不觸碰任何 OS / 繪圖 API / 影像解碼函式庫。
- 相位 1 不解碼：以**可注入 `ImageSource` 抽象**（提供固有尺寸 + 具名參照或假資料）解耦；提供
  `MemoryImageSource`（固定假資料）與 `NullImageSource`（恆無效）兩個具體實作。
- NFR-02（無絕對座標 / 無數字 z-order）：目標以具名 `SurfaceId`（字串）指涉；裁切為正規化比例
  [0,1]；縮放為具名列舉；透明度為比例；本單元無任何 (x,y) 螢幕位置或疊放層級欄位。
- 不靜默失敗：無效來源（`valid()==false`）/ 零尺寸 / 越界 / 退化 / 非有限裁切 / 空目標名 / 非有限
  不透明度一律回 `ImageStatus::Invalid`，不套用、不部分套用（既有有效狀態不被破壞）。
- 消費上游不重造輪子：透明度沿用 E1-03 `AlphaProfile.opacity`；並透過其標頭取得
  `ds::kernel::SurfaceId`。
- 無 `#ifdef _WIN32` / `win32` / `cocoa` 分支，不涉及任何後端，不連結 libpng/libjpeg。
- 未動根 `CMakeLists.txt`、`units.json`、共用 `docs/structure/directory.md`——G4 以每單元獨立
  結構檔 `docs/structure/units/e4_02.md` 滿足。
