## 我要做什麼（動工前）

E5-04 是「心跳事件」（engine 層 / 事件 / 承重 3x）：週期性心跳 / 計時觸發，供閒置動畫、
定時輪詢等消費者按固定間隔取得脈衝。engine 層要求平台中立純邏輯，**不綁真實 OS 計時器**：
時間以「邏輯時間 / tick」計，由呼叫端注入推進，因此可完全以單元測試驗證。

計畫產出（全部落在鎖定範圍內）：

1. `engine/events/e5_04/heartbeat_source.hpp`
   - `Tick`、`SubscriptionId`（0 保留無效）、`HeartbeatEvent`{ id, interval, now, count }、`HeartbeatCallback`。
   - `HeartbeatSource`：`subscribe(interval, cb)` / `unsubscribe(id)` / `advance(dt)` / `tick()` /
     `now()` / `subscription_count()`；平台中立、不含平台分支。
2. `engine/events/e5_04/heartbeat_source.cpp`
   - 累計式到期（餘量保留、單次跨多間隔多觸發）；兩階段派發（結算後統一觸發，回呼中改動訂閱安全）。
3. `engine/events/e5_04/CMakeLists.txt`：依 BUILD.md 樣板，library + `test_e5_04` + `add_test`。
4. `tests/e5/test_e5_04.cpp`：gtest，涵蓋未到不觸發、到即觸發、累計、多觸發、取消後不觸發等。

## 分層 / 平台中立遵循

- engine 層純邏輯：時間由呼叫端注入（`advance`/`tick`），不綁真實計時器。
- 無 `#ifdef _WIN32` / `win32` / `cocoa` 分支，不涉及任何後端。
