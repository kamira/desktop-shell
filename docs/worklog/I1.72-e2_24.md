## 做了什麼
把「Wi-Fi 狀態」實作為 sysinfo 指標提供者，範式沿用已合併的 E2-03 CPU 負載 / E2-08 網路流量
（可注入來源抽象 + null / 假來源 + `MetricProvider` 提供者），面向改為 Wi-Fi 連線狀態：
- **七個面向指標**，各以單一 Wi-Fi 介面（`wifi0`）為可列舉實例：`wifi.connected`（bounded
  [0,1]、含 "Connected"/"Disconnected" 文字）、`wifi.ssid`（文字表述）、`wifi.rssi`（dBm、
  bounded[-100,0]）、`wifi.signal`（%、bounded[0,100]）、`wifi.rate`（Mbps）、`wifi.channel`
  （頻道 + 頻段文字）、`wifi.security`（安全類型 ordinal + 文字）。
- 以 **E2-01** `MetricProvider` 暴露、以 **E2-02** `SamplingTier` 決定採樣節奏（預設 Normal）。
- **無差分**：Wi-Fi 狀態是直接讀的瞬時快照（不同於 CPU / 網路的累積計數差分）；`WifiSource::
  sample()` 每次直接回一份 `WifiStatus`。訊號百分比由 `rssi_to_percent`（獨立可測純算術，夾
  [0,100]）換算。
- 誠實語意：整體無讀值 → 全面向 invalid；**未連線** → 「是否已連線」有效（值=未連線），
  連線相依面向（SSID/RSSI/訊號/速率/頻道/安全）誠實未知，不謊報 0。
- 歷史：數值面向（RSSI/訊號/速率/頻道/connected）推入歷史鋪時序；categorical（ssid/
  security）只設值不污染歷史。

## 相位 1 平台中立性
無 `#ifdef` / `win32` / `cocoa` / CoreWLAN / `CWInterface` / `CWWiFiClient` / `airport` /
任何真實 Wi-Fi API；僅注入式 `NullWifiSource`（可注入固定一份或整條序列，序列即模擬連線
變動 / 掉線，列盡回最後一份，預設無讀值）。真實後端留待相位 2，屆時另實作 `WifiSource`，
提供者一行不動。
