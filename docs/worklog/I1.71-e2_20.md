## 做了什麼
在 `modules/sysinfo/e2_20/` 新增網路連通性指標提供者，透過 E2-01 `MetricProvider` 掛上五個
指標（online / reachable / latency / loss / dns），由 E2-02 頻率分級決定採樣節奏。相位 1
（Mac/null 期）**不接任何真實網路探測**，改以可注入的 `ConnectivitySource` 抽象 + null/假
來源（固定 / 序列），無讀值誠實 invalid。

## 設計決策
- **指標形狀**：online 為整體連通性 → **單一實例**（"internet"）；reachable / latency /
  loss / dns 為**逐探測目標**（多目標）→ 每目標一個可列舉實例，共用同一組目標（首見序）。
- **誠實 invalid 顆粒度**：連通性各面向可各自無讀值（如可達但尚未量到延遲），故
  `ConnectivityTarget` 每面向各帶 valid 旗標；`ConnectivitySample` 另有整體 valid（整份
  無讀值）與 online_valid（online 面向未判定）。無讀值不推入歷史、不謊報 0。
- **純算術抽出**：`loss_pct_from_counts` 與 `online_from_targets` 為獨立可測自由函式。
- **null 來源雙用法**：內部一律以序列表達；固定用法 = 單元素序列（重複回同一份），序列
  用法 = 逐份推進、列盡回最後一份。滿足規格「注入固定/序列」。
- 範式對齊 E2-08：`ensure_target` 動態新增實例（unique_ptr 持有，既有參照不失效）、
  `apply(to_history)` 統一初建 / 採集路徑、消失目標設未知不縮減。
