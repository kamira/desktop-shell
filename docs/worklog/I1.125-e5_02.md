- `HoverEvent` struct：`{ kind, surface, point }`（`surface`/`point` 直接沿用
  E1-04 的 `ds::kernel::SurfaceId` / `ds::kernel::LocalPoint`，不重複定義型別）。

- `HoverTracker`：
  - `add_surface(HitSurface)` / `remove_surface(id)`：登記 / 移除參與命中測試的
    surface（`ds::kernel::HitSurface`，直接沿用 E1-04 型別）。
  - `inject_move(point)`：以 `ds::kernel::HitTester::topmost_hit` 判定命中，依前次
    懸停狀態分派 Enter（先前無懸停或換了 surface）/ Leave（離開舊 surface，含移到
    無命中處）/ Move（同 surface 內移動，不重發 Enter）；hit-test 回 `Invalid` 時
    回傳 false、不改狀態、不分派（報錯不靜默）。
  - `current_hover(out)`：查詢目前懸停的 surface。
  - `subscribe` / `unsubscribe`：分派前取訂閱快照，回呼中改動訂閱安全；空 listener
    拒收。

命中判定完全委由上游 E1-04，本單元只做「命中結果 → 懸停狀態轉換 → 事件分派」，
不重新實作任何幾何邏輯。相位 2 換真實滑鼠 / 視窗系統後端時，介面與分派語意一行不動，
真實後端只需在 OS 滑鼠移動回呼到達時呼叫既有 `inject_move()` 路徑。
