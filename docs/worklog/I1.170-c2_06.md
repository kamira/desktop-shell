## 我要做什麼（動工前計畫）

artifact 層組裝型 widget，掛載於注入的 C1-01 `SkinProfile&` 之上，內部自持一個 E4-07
`FrameAnimationElement`：

- `AnimationWidget(SkinProfile& skin)`：建構子立即 `set_target(skin.id())` 綁定渲染目標
  （skin id 不可變，僅需綁定一次）。
- `configure(const Value& definition)`：宣告式 Map，欄位 `frames`（List，必填，每項
  `{ref, width, height}`）/ `fps`（選填 Number > 0）/ `loop`（選填 Bool）。先整批驗證（結構 +
  具名值合法性），全數通過才建構 `MemoryImageSource` 序列並委派 E4-07 `set_frames` /
  `set_fps` / `set_loop`（不部分套用）。
- `play()`/`pause()`/`is_playing()`/`advance(Tick)`/`reset()`/`current_frame()`/
  `frame_count()`/`fps()`/`loop()`/`is_finished()`/`render_model()`：皆為 E4-07 對應介面的
  薄封裝。
- `skin()`：唯讀存取所掛載的 C1-01 基底，供驗證組裝正確。
- 平台中立、無 `#ifdef` / win32 / cocoa；時間全注入式，不接真實時鐘 / 計時器 / 繪製後端；
  空幀（未 configure）時所有查詢 / 播放操作安全降級。
