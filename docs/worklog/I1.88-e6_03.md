## 關鍵設計決策

- **委派上游、不重造輪子**：條件求值全交 E7-05 `Evaluator`（含 `VariableScope`）；分派全交
  E6-01 `CommandBus`。本單元只做「求值→真值橋接→分派」的編排。
- **求值失敗不靜默**：語法錯誤 / 未定義變數 / 非布林結果一律回 `ConditionError`（帶訊息 +
  欄位），絕不當成 false 悄悄跳過（NFR-04 精神）。三態 `ConditionalOutcome`
  （Dispatched / Skipped / ConditionError）互斥，呼叫端不需再猜。
- **真值橋接最小明確**：Bool→原值、Number→非零為真，其餘型別（Null/String/List/Map）判為
  型別錯誤，不臆測真假。
- **去抖 vs 節流語意分離**：
  - `Debouncer`（尾緣 / 合併）：`trigger(tick)` 只登記 / 刷新待決放行（回 false），
    `advance(tick)` 過靜默視窗才釋放單一次。連續觸發合併成一次。
  - `Throttler`（前緣 / 頻率限制）：`trigger(tick)` 即時決策放行，距上次放行滿 interval 才再放行；
    `advance(tick)` 純推進時鐘（推進足夠後下一次 trigger 便放行）。
- **注入式邏輯時鐘**：`Tick = int64`，單調（倒退夾住），完全無 wall-clock / thread，可決定性測試。
