## 目標

把文字字串依「可注入字型度量 + 排版約束」排版成一組「行/字符的渲染描述」（相對佈局）。
相位 1 不做真實字型光柵化；字型度量以注入式 `FontMetrics` 抽象，真實引擎留待相位 2。

## 步驟

1. 讀 `docs/backlog/BUILD.md`、上游 E1-03（`alpha_surface.hpp` 的 `SurfaceId` 具名 surface 模型）、
   參考 `modules/elements/e4_03` 的 render_model 描述風格與 CHG / 結構檔慣例。
2. 設計 `ds::render` 乾淨 API：`FontMetrics` 抽象 + `FixedFontMetrics`、`TextLayout::layout/measure`、
   `LayoutConstraints`、`LayoutResult{lines[], glyphs[]}`。位置全採相對偏移 + 具名 surface（NFR-02）。
3. 實作排版：嚴格 UTF-8 解碼 → 硬換行切段 → 詞界貪婪換行 → max_lines 裁切 → 省略號 → 對齊
   → 攤平為 LineBox/Glyph。無效輸入 / 壞度量明確擲 `std::invalid_argument`（不靜默）。
4. 寫 CMakeLists（`add_library(e4_01)` + `PUBLIC e1_03` + `test_e4_01` + `add_test`）。
5. 寫 26 個 gtest 案例，涵蓋測量 / 換行 / 對齊 / 省略 / 行高 / 空字串 / 可注入度量 / 無效輸入 /
   LayoutResult 內容 / NFR-02 相對佈局 / UTF-8 邊界。
6. 本機以 `g++ -std=c++17 -Wall -Wextra` 連上游 e1_03 / e1_21 / backend_null `.cpp` + scratchpad
   gtest 墊片編譯連結並執行。
