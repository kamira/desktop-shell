## 我要做什麼（動工前）

E5-09 是「機率排程器」（engine 層 / 子系統 events / low）：以機率在時間推進中偶發觸發事件，
供桌面角色的隨機行為（如隨機閒置動作）。engine 層要求平台中立純邏輯，且**RNG 必須可注入 / 可替換、
不用全域 rand**，以確保測試決定性可重現。時間推進委派已合併的 E5-04 `HeartbeatSource`。

   評估、每次抽一亂數、u<p 觸發）/ cancel / advance / tick / now / task_count / set_random_source；
   時間推進委派 E5-04 心跳（每任務掛一心跳訂閱）。
3. `engine/events/e5_09/CMakeLists.txt`：依 BUILD.md 樣板，library + `PUBLIC e5_04` + `test_e5_09` + `add_test`。
4. `tests/e5/test_e5_09.cpp`：gtest，涵蓋決定性重現、機率分佈、多排程、取消、夾限、事件內容、替換來源等。

## 錯誤紀錄（錯誤 + 根因 + 解法）

- 撰寫 `probabilistic_scheduler.hpp` 時誤留一行占位 `#include <cstaddr>`（不存在的標頭）。
  根因：編輯過程的暫時占位未清。解法：移除該行，僅保留必要標頭（heartbeat_source.hpp / random_source.hpp /
  cstddef / cstdint / functional / memory / unordered_map）。
- 既有 scratchpad 墊片缺 `EXPECT_NEAR` 且無 main runner。解法：在自控的 scratchpad 子目錄另寫一份含
  `EXPECT_NEAR` 與 main 的完整墊片（不進 repo），不覆蓋他人既有墊片。
- schedule 需要把「任務 id」傳進心跳回呼，但 id 由 subscribe 回傳後才知（雞生蛋）。解法：回呼改讀
  `HeartbeatEvent.id`（即心跳訂閱 id，也就是我方回傳的任務 id），毋須事先捕獲 id。
