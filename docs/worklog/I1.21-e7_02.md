## 我要做什麼（動工前計畫）

一個變數作用域 / 表 + 把文件（Value 節點樹 / Document）內的 `${name}` 引用替換為變數值。
消費 E7-01 的型別模型，不重造輪子。未定義變數要明確回報（NFR-04 精神，不靜默）。

設計（C++17，`namespace ds::format`）：

- `VariableScope`：名稱→`Value` 有序表、鍵唯一、可帶父作用域（`find`/`has` 上溯父鏈、子層遮蔽）。
- 引用語法 `${name}`：整串單一引用保留變數值原生型別；內嵌引用以字串呈現替換；
  `$$` 跳脫為字面 `$`。巢狀引用遞迴求值；循環引用以「求值中」堆疊偵測並回報。
- 錯誤模型對齊 E7-01 `ParseResult`：`ResolveError{message, variable}` + `ResolveResult`（Value）/
  `DocumentResolveResult`（Document）。遞迴內部以受控例外承載、於 `resolve()` 邊界捕捉轉 failure。
- `resolve(Value)` / `resolve(Document)` 遞迴進入 List / Map（**鍵不替換**）；Document 版本欄位原樣保留。
- CMake：`target_link_libraries(e7_02 PUBLIC e7_01)`。

參考已合併的 `engine/format/e7_01/`：沿用其 `Value` 工廠 / 存取、`ParseResult` 二選一結果風格、
「不靜默失敗、錯誤帶定位資訊」的契約，並推廣為變數層的 `ResolveResult` / `ResolveError`。
