## 我要做什麼（動工前計畫）

engine 層平台中立純邏輯：鍵盤按鍵事件 + 文字輸入提交事件的訂閱 / 派發介面。
不綁真實 OS 鍵盤——事件由呼叫端 / 測試注入。以**具名鍵**表達（非平台掃描碼）。

設計（C++17，`namespace ds::events`）：

- `Key` enum class：具名鍵（字母 / 數字 / 編輯 / 導覽 / F1–F12 / 修飾鍵），未知映 `Unknown`。
- `Modifier` 位元遮罩（Shift/Control/Alt/Meta）+ `|` `&` `|=` 運算子 + `has_modifier()` 查詢。
- `KeyEvent{ key, modifiers, action }`，`KeyAction`＝Press/Release。
- `TextInputEvent{ text }`：提交文字（如就地輸入框 commit），平台中立 UTF-8、可為空。
- `KeyboardInputSource`：兩條獨立頻道（按鍵 / 文字），`subscribe_key` / `subscribe_text` /
  `unsubscribe`（共用 id 空間，自動判別頻道）+ `inject_*` / `submit_text` 派發。
  分派前取快照確保回呼中訂閱 / 取消訂閱安全；依訂閱順序分派。

參考已合併的 `engine/events/e5_04/`（engine 層 plain class 樣式）與
`src/events/e5_08/`（訂閱 / 快照分派契約）。
