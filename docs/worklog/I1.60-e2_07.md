## 我做了什麼

一個 sysinfo 指標提供者，把磁碟 IO 指標透過 E2-01 `MetricProvider` 掛成**五個**指標——
`disk.io.read_bytes`/`write_bytes`（unit "B/s"）、`disk.io.read_iops`/`write_iops`（"IOPS"）、
`disk.io.queue`（unit ""，佇列深度），皆 range=`at_least(0)`（上無界）——每個以**每顆磁碟**
為可列舉實例，並以 E2-02 頻率分級（預設 Normal）決定採樣。設計刻意分離、易組合：

- **值模型**：`DiskIoCounters`（累積 read/write bytes、累積 read/write ops + 瞬時
  queue_depth）、`DiskIoSnapshot`（身分 + 計數）、`DiskIoSample`（時間戳 + 全磁碟快照）、
  `DiskIoRates`（已差分四速率 + 瞬時佇列）、`DiskIoReading` / `DiskIoUsageSample`（列舉輸出
  + valid）。
- **差分演算法**（自由函式，獨立可測）：`counter_rate`＝currΔ/dt（防 dt<=0 / 計數重置）；
  `rates_from_delta`＝四速率 + 佇列瞬時原樣帶出；`usage_from_delta`＝dt 為兩份時間戳差、
  每磁碟以共同數對齊。**吞吐率/IOPS 有量綱，差分需時間差**（與 CPU tick 比率不同）。
- **累積計數來源與速率來源分層，皆注入式、平台中立**：
  - 累積計數：`IoStatSource`（抽象 `read()→DiskIoSample`，列舉磁碟 + 每磁碟累積計數）+
    `NullIoStatSource`（注入序列，列盡回最後一份）。
  - 速率：`IoRateSource`（抽象 `sample()→DiskIoUsageSample`，提供者只依賴此）+
    `NullIoRateSource`（直接速率注入）+ `DifferencingIoRateSource`（把累積計數來源以「兩次
    取樣差分」轉成速率來源；首次回未知——差分至少需兩份）。
- **提供者** `DiskIoProvider`：五指標各以每磁碟為實例（各保留歷史環）；`sample()` 更新
  （新磁碟於五指標動態新增實例、下線者設未知不污染歷史）；`sampling_tier()` 供 add_demand。
- **絕不接真實 IO API**（無 IOKit / /proc/diskstats / mach / #ifdef / win32 / cocoa）；
  無讀值以 valid==false 誠實表達，不謊報 0；消費者只走 E2-01 抽象介面。
