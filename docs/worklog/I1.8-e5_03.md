## 我要做什麼（動工前計畫）

相位 1（Mac / null 期）：只寫**平台中立介面 + 呼叫端驅動的來源 + 契約測試**，
**不得**出現 `#ifdef` / win32 / cocoa / 真實平台後端。

設計（C++17，`namespace ds::events`）：

- `LifecyclePhase` enum class：surface / profile 生命週期相位——
  Created / Shown / Hidden / Activated / Deactivated / Destroyed。
- `LifecycleEvent` struct：`{ surface, from, to }`（平台中立 payload，不綁任何 OS 型別）。
- `LifecycleListener` = `std::function<void(const LifecycleEvent&)>` 回呼型別。
- `SurfaceId` / `SubscriptionId`：surface 與訂閱代號。
- `is_legal_transition(from, to)`：固定狀態機表，約束合法轉換（Destroyed 為終端、
  自我轉換非法）。
- `LifecycleSource`：`create(surface)` 登記為 Created；`transition(surface, to)`
  驗證合法性後改狀態並分派事件；`subscribe` / `unsubscribe` / `phase_of` / `has_surface`。
  多訂閱者皆收、解除後不再收、分派前取快照確保回呼中改動訂閱安全。

分派 / 驗證語意刻意平台中立：相位 2 換真實視窗系統後端時介面一行不動，真實後端只需在
OS 生命週期回呼到達時呼叫既有 `transition()` 路徑。
