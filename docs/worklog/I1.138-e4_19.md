## 我要做什麼（動工前計畫）

module 層純邏輯，消費上游 E4-02（圖片顯示）與 E4-22（2D 變形矩陣）：

- `RotatableElement`（`rotatable_element.hpp|cpp`）：內部持有一個 E4-02 `ImageElement`
  （顯示旋轉對象）、目前角度（弳度，正規化至 `[0, 2π)`）、角速度、`RotationPivot`（九宮格
  具名旋轉中心）。
- `set_angle`/`rotate_by`：驗證有限性（NaN/Inf → `RotateStatus::Invalid`，不套用、維持既有
  角度）；成功套用正規化至 `[0, 2π)`。
- `set_angular_velocity`：驗證有限性；`advance(dt)`：`angle += velocity * dt`（正規化），
  角速度 0 或 dt 非有限為安全 no-op（支援連續旋轉跨越多整圈，不接真實時鐘）。
- `set_pivot`：具名九宮格錨點（恆合法）。
- `transform()`：依 pivot 對應比例位置（如 Center=(0.5,0.5)）乘上所綁 E4-02 來源固有尺寸，
  換算出僅供內部矩陣計算用的支點，以 E4-22 `Transform2D::translate`/`rotate`/`compose`
  組出 `translate(pivot) ∘ rotate(angle) ∘ translate(-pivot)`——標準繞任意點旋轉公式。
- `set_source`/`set_scale_mode`/`set_opacity`/`set_target` 等透傳給內部 `ImageElement`；
  `render_model()` 打包 `RotatedRenderModel{ image, transform, angle_radians, pivot }`。
- 平台中立、無 `#ifdef` / win32 / cocoa；不做真實旋轉繪製；時間全注入式，不接真實時鐘 /
  計時器 / 繪製後端。NFR-02：角度為弳度語意輸出、pivot 為具名列舉，未新增絕對座標 / 數字
  z-order。
