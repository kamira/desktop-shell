預設不可用。相位 1（Mac / null 期）只寫平台中立介面 + null 後端。

   - `AutostartStatus`{ Ok, Unsupported, Failed }。
   - `Autostart` 介面：`has()` / `enable()` / `disable()` / `is_enabled()`。
   - `NullAutostart`：相位 1 null 後端，`has()==false`、變更回 `Unsupported`、`is_enabled()==false`。
   - `make_default_autostart()` 工廠（相位 1 回 NullAutostart）。
   - 平台中立：無 `#ifdef _WIN32` / win32 / cocoa 分支，不寫登錄檔 / LaunchAgent。
