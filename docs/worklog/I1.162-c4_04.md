## 組裝設計

`ds::apps::WindowOverviewApp`（`apps/c4_04/window_overview.hpp/.cpp`）：

- 注入式相依：`ds::profiles::SummonPanelProfile&`（C1-05，不取得所有權，本物件只借用其
  `open()` / `close()` / `is_open()` 生命週期，**不**碰其 `items()` 選單森林——視窗清單以
  獨立的 `WindowEntry` 向量自行管理，因為視窗總覽的資料形狀（縮圖 + 平鋪版位）與 C1-05 設計
  給選單用的階層式 `Item` 不同語意）。
- **load_windows（E4-02 組裝 + 平鋪版位）**：`load_windows(vector<WindowSpec>)` 先驗證清單
  （空 `window_id` 或清單內重複 `window_id` → 整批拒絕 `Invalid`，**不部分套用**，呼應本專案
  「無效輸入不改狀態」的既有慣例，如 c1_05 `set_items(Value)` 失敗時保留既有選項）；驗證通過
  才建新的 `WindowEntry` 清單——每個視窗若提供 `thumbnail` 來源，呼叫 E4-02
  `ImageElement::set_source()`（複製參照 + 固有尺寸）並 `set_target("surface.overview." +
  window_id)`（具名目標，沿用 E4-02 NFR-02 慣例）；`thumbnail == nullptr` 時該視窗縮圖保持
  `has_source() == false`（明確「無縮圖」，不假裝有資料，呼應 E4-02 `render_model()` 的既有
  設計）。取代完清單後呼叫 `relayout()` 重新計算所有視窗的平鋪版位；若舊選取的視窗仍在新
  清單內則保留選取索引，否則清除（不留懸置選取，指向已不存在的條目）。
- **平鋪版位（NFR-02：具名 + normalized）**：`relayout()` 以固定欄數上限
  `kOverviewColumns`（視窗數 < 欄數時欄數收斂為視窗數，避免空欄）逐格計算每個視窗的
  `TileLayout{region, x, y, width, height}`——`region` 衍生自 `window_id`（`kTileRegionPrefix
  + window_id`，具名、非數字 index）；`x/y/width/height` 為占總覽畫布的**正規化比例**
  `[0,1]`，精神直接對應 E4-02 `CropRect`（比例而非螢幕像素座標），非本單元新造概念。
- **show_overview / close_overview（委派 C1-05 生命週期）**：兩者直接委派
  `base().open(ttl)` / `base().close()`，本單元不重造生命週期規則（已開啟中重開失敗、
  `ttl == 0` 失敗、未開啟即收起失敗，皆是 C1-05 既有語意）；`close_overview()` 成功時額外
  `clear_selection()`（總覽收起後不留可見的舊選取狀態）。
- **select / activate（開啟中反白 vs. 切換並收起）**：`select()` 僅在 `is_open()` 為真時
  生效，標記 `selected_index_`，**不**收起總覽（供鍵盤導覽 / 滑鼠 hover 反白等連續互動）；
  `activate()` 額外要求找到該 `window_id` 才會 `base_.close()` 收起總覽並清除選取、記錄
  `last_activated_id_`——找不到時**保持總覽開啟**（呼應 c1_05 `select()` 對不存在 id 的
  `NotFound` 且不關閉面板的既有慣例，不靜默收起）。
- **close_window（移除視窗，非收起總覽）**：`erase` 該視窗、若恰為目前選取項則清除選取
  （否則若移除點在選取索引之前則校正索引，避免索引錯位指向錯誗條目）、`relayout()`
  重新平鋪剩餘視窗（版位不留缺口）；找不到 → `false`（no-op，不靜默）。

具名結果 `LoadStatus`（Ok / Invalid）、`SelectStatus`（Selected / NotFound / PanelClosed）、
`ActivateStatus`（Activated / NotFound / PanelClosed）皆附 `to_string()`（NFR-02，呼應
c4_03 `PickStatus` 的既有慣例）。

無效操作一律明確回具名結果，不靜默：總覽未開啟即 `select()` / `activate()`、選取 / 啟用 /
關閉不存在的 `window_id`、載入內含空 / 重複 `window_id` 的清單。
