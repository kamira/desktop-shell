## 我要做什麼（動工前計畫）

module 層純邏輯，消費上游 E4-02（圖片顯示）與 E4-09（動畫驅動源）：

- `FrameAnimationElement`（`frame_animation_element.hpp|cpp`）：持有一組幀（值語意複製自注入
  `ImageSource`，存為內部 `MemoryImageSource` 序列）與一個「累計幀進度」（double，取整數部分
  為目前幀索引）。
- `set_frames`：驗證每幀來源 `valid()` 且尺寸 > 0（整批不部分套用），成功則複製進內部序列並
  歸零進度 / 完成旗標。空序列或任一幀無效 → `FrameAnimationStatus::Invalid`。
- `set_fps`：每 tick 前進幾幀（可小數）。非正 / 非有限 → `Invalid`（不套用）。
- `set_loop` / `play` / `pause`：循環 / 單次模式切換、播放狀態控制（預設暫停）。
- `advance(dt)`：進度累計 `+= fps * dt`；循環模式以幀數為模（`fmod`）繞回；單次模式夾在最後
  一幀並標記 `is_finished()`；暫停 / 空幀序列 / 單次已完成皆安全 no-op。
- `attach(AnimationDriver&)`：對 `driver.add()` 的薄封裝，讓其每次脈衝自動呼叫
  `advance(frame.dt)`，回傳 `AnimationId`。
- 幀索引改變時呼叫 `sync_current_source()`，把該幀同步設進內部 E4-02 `ImageElement`
  （`set_source`）；`set_scale_mode`/`set_opacity`/`set_target` 透傳給該內部 `ImageElement`；
  `render_model()` 委派其 `render_model()`（NFR-02 相對佈局，未新增絕對座標 / 數字
  z-order）。
- `current_frame()` / `is_finished()` / `reset()`：查詢與控制介面。
- 平台中立、無 `#ifdef` / win32 / cocoa；時間全注入式，不接真實時鐘 / 計時器 / 繪製後端。
