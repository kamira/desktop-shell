## 分層 / NFR 遵循

- module 層純邏輯：只組合上游能力（E4-02/E1-04/E5-02）、不重造輪子，不觸碰任何 OS / 繪圖 /
  真實滑鼠 API。
- 懸停狀態完全委由 E5-02 `HoverTracker`（`attach` 登記 `HitSurface` + 訂閱，
  `handle_hover_event` 依 `surface==id()` 過濾轉譯 Enter/Leave/Move）；命中判定完全委由
  E1-04 `HitTester::hit_test`（`press`/`release` 對按鈕自身本地形狀判定）；不重新實作幾何或
  懸停分派邏輯。
- NFR-02（無絕對座標 / 無數字 z-order）：id 為具名 `SurfaceId`（字串）；圖層為具名
  `SurfaceLayer`；座標沿用 E1-04 `LocalPoint`（本地 / 相對）；渲染描述沿用 E4-02
  `ImageRenderModel`（具名目標 / 正規化裁切 / 比例透明度）。本單元未新增任何 (x,y) 螢幕位置
  或疊放層級欄位。
- 三態顯示優先序：Pressed > Hover > Normal；`hover_`/`pressed_` 獨立追蹤，`state()` 即時推導，
  避免「按下時遺失懸停資訊」。
- 不靜默失敗：
  - 建構子空 `SurfaceId` → 擲 `std::invalid_argument`。
  - `set_visual`/`visual` 遇超出三個合法 `ButtonState` 值 → `Invalid`/`nullptr`。
  - `press`/`release` 遇非有限座標或無效形狀（沿用 E1-04 `is_valid`）→ `Invalid`，不改變
    任何狀態、不觸發 `on_click`。
  - 「放開於按鈕範圍外」是正常取消點擊（`Ok` + 不觸發回呼），與上述「無效輸入」明確區分，
    不混淆為錯誤。
- 無 `#ifdef _WIN32` / `win32` / `cocoa` 分支，不涉及任何後端，不綁真實滑鼠 / 視窗系統事件。
- 未動根 `CMakeLists.txt`、`units.json`、共用 `docs/structure/directory.md`、任何上游檔案——
  G4 以每單元獨立結構檔 `docs/structure/units/e4_04.md` 滿足。
