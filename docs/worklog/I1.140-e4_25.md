## 分層 / NFR 遵循

- module 層純邏輯：只產出渲染描述，不觸碰任何 OS / 繪圖 API / 影像解碼 / 模糊函式庫。
- 圖片背景**直接重用 E4-02 `ImageElement`**（內嵌成員 + 委派 `set_source`），不重造圖片
  載入 / 縮放 / 裁切邏輯；透過可變存取器 `image()` 開放呼叫端進一步使用 E4-02 既有能力
  （縮放模式 / 裁切 / 目標等）。
- NFR-02（無絕對座標 / 無數字 z-order）：目標以具名 `SurfaceId`（字串）指涉；漸層停駐點
  位置為正規化比例 [0,1]；漸層方向、背景模式皆為具名列舉；透明度為比例；圓角半徑 / 邊框
  寬度為背景自身外觀尺寸（非螢幕位置）；本單元無任何 (x,y) 螢幕位置或疊放層級欄位。
- 不靜默失敗：未知 / 越界 `BackgroundMode` / `GradientDirection`（`static_cast<Mode>(99)`
  模擬誤用）、非有限顏色分量 / 漸層位置 / 模糊半徑 / 圓角 / 邊框寬度 / 不透明度、負值尺寸、
  空目標名一律回 `BackgroundStatus::Invalid`，不套用、不部分套用（既有合法狀態不被破壞）。
  圖片來源無效沿用 E4-02 既有報錯語意（直接透傳其 `ImageStatus`）。
- 消費上游不重造輪子：透明度沿用 E1-03 `AlphaProfile.opacity`；圖片邏輯完整沿用 E4-02
  `ImageElement`/`ImageSource`/`ImageRenderModel`。
- 無 `#ifdef _WIN32` / `win32` / `cocoa` 分支，不涉及任何後端，不連結任何影像 / 模糊函式庫。
- 未動根 `CMakeLists.txt`、`units.json`、共用 `docs/structure/directory.md`——G4 以每單元
  獨立結構檔 `docs/structure/units/e4_25.md` 滿足。
