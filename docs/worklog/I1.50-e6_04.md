## 我做了什麼

在 E6-01 命令匯流排上擴充兩種非即時執行語意，命名空間仍為 `ds::command`：

- `DeferredScheduler`（綁定一個 `const CommandBus&`）：`schedule(delay, cmd)` 排在 `now()+delay`
  執行（`delay` 須 >= 1，否則回 `kInvalidDeferredId`）；`advance(ticks)` 推進邏輯時鐘並依序分派所有
  到期命令（先到期先執行、同 tick FIFO），回 `vector<DeferredDispatch>`；`cancel(id)` 取消未執行者；
  `advance_to` / `now` / `pending` / `has`。時間全為**注入式邏輯 tick**，無真實時鐘 / sleep / thread。
- `Batch` + `run_batch(bus, cmds/batch, mode)`：`BatchMode{Atomic, Continue}`；Atomic 遇首個失敗即中止
  後續並回報 `failed_index`、Continue 跑完全部；回 `BatchResult{ok, executed, total, failed_index, steps}`。
  順序嚴格依提交序。
- 未知命令沿用 E6-01 `NotFound`（不崩潰、不靜默）。
- `deferred_batch.cpp` 提供 `deferred_batch_contract_version()` 一個實體符號，使 STATIC 程式庫非空。
- CMake：`add_library(e6_04 STATIC deferred_batch.cpp)` + `target_link_libraries(e6_04 PUBLIC e6_01)`
  + `add_executable(test_e6_04 ...)` + `add_test(NAME e6_04 ...)`。
