## 我要做什麼（動工前計畫）

一個呈現層：把 E7-01 的 `ParseError{line, message}` 轉成人類可讀、定位到行/欄、
附上下文片段與插字符的診斷輸出，並能彙整多筆錯誤。消費 E7-01 的錯誤模型，不重造輪子、
不碰解析邏輯。明確不靜默（NFR-04）。

設計（C++17，`namespace ds::format`）：

- `Severity{Error, Warning, Note}` + `severity_label`。
- `Diagnostic{severity, line, column, message}` + `from_parse_error(e[, column])`（由上游轉入）。
- `FormatOptions{show_context, show_caret}`（預設全開、無顏色、輸出決定性）。
- `format_diagnostic` / `format_error`（單筆，Rust 式診斷）；`format_report` / `format_errors`（彙整）。
- `DiagnosticReport`：累積 / 查詢（`error_count` / `ok`）/ `render`。
- 不靜默：空集合 → `no diagnostics`；line 0 仍印訊息；行號超範圍保留訊息與行號。
- CMake：`target_link_libraries(e7_06 PUBLIC e7_01)`。

參考已合併的 `engine/format/e7_01/`（`ParseError` / `ParseResult` 二選一結果、「不靜默失敗、錯誤帶定位」契約）
