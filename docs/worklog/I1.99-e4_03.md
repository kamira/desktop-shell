## 我要做什麼（動工前）

E4-03 是視覺元件「長條圖 / 進度條 / 量表(gauge)」（module 層 / 子系統 elements / phase 1 / low），
最終直接供 CPU/GPU Usage Widget 組合使用，介面須乾淨易組合。語意是把數值依範圍映射成視覺量：
長條→長度比例、進度→0–100%、量表→角度 / 弧。相位 1 **不做真實繪製**，只產「渲染描述模型」
供繪製層消費；設定以 E7-03 宣告式變數段落驅動；位置以 E1-03 具名 `SurfaceId` 指涉。

## 設計要點

- 三元件共用基底 `RangedElement`（值↔範圍、夾限、具名 surface+slot、顏色、標籤），個別加專屬語意
  （Bar 長度比例、Progress 固定 [0,100] 百分比、Gauge 弧幾何 + 值→角度）。介面乾淨易組合。
- `RenderModel` 為純資料渲染描述，相位 1 不繪製；繪製層後續消費。
- 設定載入器先呼叫 E7-03 `expand()` 展開變數段落（真正消費上游 E7-03），再讀欄位填入元件。

## NFR-02 / 分層 / 平台中立遵循

- **NFR-02**：`RenderModel` 無 x/y / 像素尺寸 / 數字 z-order；位置以具名 surface+slot、尺寸以比例 [0,1]、
  量表以角度（值→角度語意輸出）表達；顏色為具名語彙。
- 錯誤不靜默：非有限值 / 退化範圍 / 退化弧 → `std::invalid_argument`；設定型別不符 / 展開失敗 → `ConfigStatus`。
