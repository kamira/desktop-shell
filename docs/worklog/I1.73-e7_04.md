## 我要做什麼（動工前計畫）

`ReactiveScope`：註冊動態來源變數（`set`）+ 定義依賴其他變數的衍生變數（`define_derived`），
變數變更時**只重算受影響者**（相依追蹤 + 髒標記傳播 + 拓撲重算），支援循環相依偵測與變更通知訂閱。
消費 E7-01 的 `Value` 作為值型別，不重造輪子。循環相依明確報錯、不靜默（NFR-04 精神）。

設計（C++17，`namespace ds::format`）：

- 節點池 + 相依圖（正向 `deps` / 反向 `dependents`）+ 每節點快取值 / 髒標記。
- `set(name, value)`：來源變數；沿反向邊標髒下游，拓撲序重算受影響者，值變者依建立序通知。
- `define_derived(name, deps, compute)`：deps 須已存在；`compute` 只能經 `DerivedInputs` 讀已宣告 deps。
- 循環偵測：改動狀態前以 DFS（name adjacency = new_deps）判可達自身 → 失敗且狀態不變；
  另有執行期 `computing_` 堆疊防禦守衛。
- 錯誤模型對齊 E7-02：`ReactiveError{message, variable}` + `ReactiveResult`；遞迴內部以受控例外承載、邊界轉 failure。

參考已合併的 `engine/format/e7_02/`：沿用其 `ResolveResult` 二選一結果風格、「不靜默失敗、
錯誤帶肇因變數名」的契約；值型別用 E7-01 的 `Value`。
