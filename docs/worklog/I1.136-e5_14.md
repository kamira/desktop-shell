## 我要做什麼（動工前計畫）

`MouseEventRouter` 實例（完全委派 surface 命中 / 多擊追蹤 / 底層訂閱派發），另外維護一份
`std::map<SurfaceId, NamedRegionMap>` 對照表（本單元新增的橋接狀態）。`set_surfaces()` 換手時
對新清單裡每個具名 surface（去重）各訂閱一次內部橋接回呼；命中分派出的 `MouseButtonEvent`
以 `event.target` 對照的 `NamedRegionMap`（若有）查詢 `event.position`，組成 `RegionEvent`
（含原始事件 + `region_hit`/`region_name`/`region_params`）分派給本類別自身的訂閱者。未登記
子區域 / 未命中子區域仍正常派發（`region_hit=false`，其餘欄位空）。轉呼 `inject_*()` 給內部
router，語意與 E5-01 完全一致。

不重新實作任何幾何或按鍵語意——两條上游 API 皆完全委派、只加「橋接」本身。

## 遇到的錯誤

- 墊片不支援 `ASSERT_GE`（scratchpad `gtest.h` 只實作 `EXPECT/ASSERT_EQ/NE/TRUE/FALSE`）：
  `MultipleRegionsCarryDistinctParams` 首版誤用 `ASSERT_GE(received.size(), 2u)`，編譯報
  `use of undeclared identifier 'ASSERT_GE'`。改用 `ASSERT_TRUE(received.size() >= 2u)`
  後零警告一次過。
- 其餘：實作邏輯與 CMakeLists 一次寫對，未遇其他編譯 / 邏輯錯誤。
- 設計注意點（記錄備查，非錯誤）：E5-01 的 `subscribe()` 綁定特定具名 surface，沒有「訂閱全部
  surface」的 wildcard 介面；為了讓 `RegionEventDispatcher` 能攔截任一具名 surface 命中的事件
  再做橋接，`set_surfaces()` 換手時必須對清單裡每個具名 surface 各自呼叫一次內部 router 的
  `subscribe()`（去重避免同一 surface 重複訂閱、事件被橋接兩次），並記錄這些內部訂閱代號供下次
  換手時整組取消——這是本單元橋接設計的核心取捨，選擇透過既有 public API 組合達成，不修改 /
  派生上游 E5-01。
