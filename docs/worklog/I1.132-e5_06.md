相位 1（Mac / null 期）：只寫**平台中立介面 + 呼叫端注入的路由器 + 契約測試**，
**不得**出現 `#ifdef` / win32 / cocoa / 真實滑鼠或滾輪硬體 API。

設計（C++17，`namespace ds::events`）：

- `WheelEvent` struct：`{ delta_x, delta_y, position, target }`（`position`/`target`
  直接沿用 E1-04 的 `ds::kernel::LocalPoint` / `ds::kernel::SurfaceId`，不重複定義型別）。
- `WheelEventListener` = `std::function<void(const WheelEvent&)>`。
- `SubscriptionId`：0 保留為無效。
- `WheelRouteStatus` enum class：`Hit` / `NoHit` / `Invalid`（獨立具名，非沿用 E5-01
  `RouteStatus`，避免兩單元標頭同時納入同一翻譯單元時的同命名空間型別重定義衝突）。
- `WheelEventRouter`：
  - `set_surfaces(vector<HitSurface>)` / `surfaces()`：登記參與命中測試的具名 surface
    （直接沿用 E1-04 `HitSurface` 型別）。
  - `subscribe(target, listener)` / `unsubscribe(id)` / `listener_count(target)`：訂閱
    特定具名 surface；空 target / 空 listener 拒收（回 0）；未知 id 取消為 no-op。
  - `inject_wheel(delta_x, delta_y, position)`：以 `ds::kernel::HitTester::topmost_hit`
    判定命中，命中則以完整 `WheelEvent` 分派給該 surface 目前的訂閱者（依訂閱順序，
    分派前取快照）；未命中不分派給任何人（`NoHit`）；上游判定形狀 / 座標無效回
    `Invalid`（報錯不靜默）。`delta_x` / `delta_y` 原樣傳遞，不裁切、不正規化，零值
    亦視為合法事件正常路由。

滾輪事件本身無「配對」概念（不像滑鼠按鍵 down/up/多擊），故不維護額外游標狀態機——
每次 `inject_wheel()` 獨立判定、獨立分派，比 E5-01 更精簡。命中判定完全委由上游
E1-04，本單元只做「命中結果 → 事件分派」。相位 2 換真實滑鼠 / 滾輪硬體後端時，介面
與分派語意一行不動，真實後端只需在 OS 滾輪回呼到達時呼叫既有 `inject_wheel()` 路徑。
