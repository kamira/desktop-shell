以明度/飽和度階生成背景與狀態色、以 WCAG 對比度保證前景可讀，並以 `to_theme_data()` 橋接 E9-04

## 設計要點

- 顏色平台中立：`RgbColor{r,g,b}`(8-bit) / `HslColor{h,s,l}`(數值) / hex 字串；不綁繪圖框架型別。
- `ColorScheme{Complementary, Analogous, Triadic, Monochromatic}`：色相環 +180° / ±30° /
  +120°+240° / 同色相變明度飽和度。
- `PaletteGenerator::generate(seed, scheme) -> PaletteResult`：主色恆等於種子；決定性(純函式)；
  種子無效(通道超 [0,255])→ failure(帶原因)，不生成。`generate_from_hex` 對 hex 格式錯誤同樣
  failure。
- `ColorPalette`:主/次/強調/背景/前景 + 四狀態色(成功/警告/錯誤/資訊) + 方案 + 種子(溯源)。
- WCAG：`relative_luminance` / `contrast_ratio`；`ensure_readable` 讓前景對背景 < 4.5 時退回黑/白
  中對比較高者，保證 AA。
- 轉換與工具:`rgb_to_hsl` / `hsl_to_rgb`(灰階特判、色相正規化、四捨五入夾 [0,255]) / `to_hex` /
  `from_hex`(6 位/3 位簡寫、錯誤回 false 不動 out) / `lightness_scale`(明度由暗到亮線性分佈)。
- `to_theme_data(palette, name)`:attributes = 九色角色 → hex 字串的 `Value` Map，components 空組合。
- 不靜默失敗:無效種子色 / 錯誤 hex → 帶原因的 failure/false。
