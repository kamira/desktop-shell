## 我要做什麼（動工前計畫）

一個熱重載生命週期狀態機：把宣告式格式文件的「載入→解析→成功替換 / 失敗保舊值」封裝起來。
消費 E7-01 的 `parse()` / `Document` / `ParseError`（不重造解析），失敗時用 E7-06 的
`Diagnostic` / `format_report` 把錯誤定位到行呈現（NFR-04：不靜默）。相位 1 平台中立——
**不接真實檔案系統監看**，來源以可注入抽象 `ReloadSource` 表示。

設計（C++17，`namespace ds::format`）：

- `ReloadSource`（抽象：`content()` + 單調遞增 `revision()`）；`MemorySource` 相位 1 具體來源。
- `ReloadStatus{Unchanged, Loaded, Failed}` + `ReloadResult{status, has_document, diagnostics, report}`。
- `HotReloader`：`poll()`（有變更才重載）/ `reload()`（強制）/ `has_document` / `document` / `root` /
  `last_diagnostics` / `last_report` / `on_reload` / `on_error`。
- 成功替換當前 Value；失敗**保留舊值**、產生 E7-06 診斷、觸發失敗回呼；未變更不重載、不觸發回呼。
- CMake：`target_link_libraries(e7_07 PUBLIC e7_01 e7_06)`。

參考已合併的 `engine/format/e7_01/`（`parse` / `ParseResult` 二選一結果、不靜默失敗、錯誤帶定位）
與 `engine/format/e7_06/`（`Diagnostic` / `from_parse_error` / `format_report` 呈現層、消費上游、CMake 連上游樣板）。

13 個測試涵蓋：初次載入（poll 首次即讀取+解析+生效、載入前 `document()`/`root()` throw）、
內容變更→重載成功→新值生效、重載失敗保舊值（值未被壞輸入覆寫、產生定位到行的診斷、
初次即失敗則無舊值可留且 `has_document()` 為 false、成功後 `last_diagnostics`/`last_report` 清空）、
成功 / 失敗回呼（各僅於對應事件觸發、無變更 / 失敗不觸發 success）、無變更不重載
（revision 未變回 Unchanged、相同內容 `set_content` 不遞增 revision、失敗同 revision 不重試但保舊值）、
強制 `reload()` 忽略 revision 並重觸發、之後 poll 視為未變更。
