## 我要做什麼（動工前）

E4-28 是「透視與景深呈現」（module 層 / 子系統 elements / phase 1 / low，depends_on=[E4-22]）：
用上游 E4-22 2D 變形矩陣（`Transform2D`）模擬 2.5D 透視效果——依深度縮放/位移、視差、可選景深
模糊，產出帶透視變形的渲染描述。NFR-02 要求深度用相對值、變形用矩陣，不得有絕對畫面座標或
數字 z-order。

## 設計決策（施工中）

- 縮放公式選 `1/(1+k*d)`（雙曲線，透視投影常見形式：scale = focal/(focal+z) 的相對化版本），
  確定性、單調、d=0 時恆為 1（無變化），符合「用變形模擬 2.5D 透視」語意。
- 消失點角落方向正規化為單位長度（1/√2），避免對角方向視差位移量因分量未歸一而失真。
- 「無效深度處理不靜默」實作為兩層：
  - `transform_for_depth(d)` 是純函式查詢，回傳明確帶狀態碼的 `PerspectiveTransformResult`
    （同 E4-22 `InverseResult` 精神），無效時矩陣為單位矩陣佔位、scale 為 0，皆標註「勿用」。
  - `set_depth` / `set_perspective_strength` 皆先用 `transform_for_depth` 探測有效性，
    無效則拒絕（回 `Invalid`）、不套用、不改既有狀態；兩者互相校驗使「目前狀態組合恆有效」
    成為不變量，`transform()` / `render_model()` 因此恆可安全取值不必檢查狀態。
