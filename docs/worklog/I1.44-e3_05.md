## 關鍵設計取捨

- **夾限在致動器層、不在後端**：致動器把 level 夾至 [0,100] 後才交給後端，後端契約可信任
  傳入值已合法。這讓「合法化」邏輯集中一處、與後端解耦（相位 2 真實後端不必重做夾限），
  也讓 adjust 的邊界行為可完全單元測試。
- **adjust 防溢位**：以 int64 相加 `get() + delta` 後再夾限，避免 int 溢位 UB。
- **靜音不改變音量位階**：mute / unmute 只動 muted 旗標，level 不變，unmute 即恢復原音量
  （符合系統音量直覺）。
- **版本標記命名**：`ds::actuators` 命名空間已有 e3_02 的 `contract_version()`；本單元用
  `volume_contract_version()` 前綴避免符號衝突（兩者可能同時連入同一 target）。
- **成功結果回夾限後音量**：所有成功 CommandResult 的 value 皆為目前音量（int），
  訊息帶 muted/unmuted，供呼叫端 / 測試一致驗證。
