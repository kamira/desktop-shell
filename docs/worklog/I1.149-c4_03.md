## 上游研讀（動工前）

先讀懂兩個已合併、可讀不可改的擴充點/元件，理解如何組裝：

- **E2-27**（`modules/sysinfo/e2_27/screen_pixel.hpp`）：螢幕像素取樣——
  `PixelSampleSource` 抽象介面（`sample(ScreenAnchor) -> optional<PixelColor>`）、
  `NullPixelSampleSource`（相位 1 null 後端，`set_pixel` 注入假像素、無讀值回 nullopt）、
  `PixelColor`（`luminance()` / `hex()`）、`ScreenPixelProvider`（把取樣點掛成 E2-01 指標，
  本單元未直接用它，只借 `PixelSampleSource` / `PixelColor` / `ScreenAnchor`）。取樣點以
  具名 `ScreenAnchor`（Center / TopLeft / … 九宮格）表達，無絕對座標（NFR-02）。
- **E4-30**（`modules/elements/e4_30/dim_overlay.hpp`）：全螢幕調光覆蓋——
  `DimOverlayElement`：`show()` / `hide()` 顯隱、`add_cutout(region)` / `remove_cutout(region)`
  挖具名「不調光」洞、`set_intensity` / `set_color`、`fade_to`、`render_model()`。建立 / 改動
  半透明狀態經 `AlphaSurfaceService::supported()` 閘控（NFR-03），不可用時回
  `DimStatus::Unsupported`（降級不崩）。

## 組裝設計

`ds::apps::ColorPickerApp`（`apps/c4_03/color_picker.hpp/.cpp`）：

- 注入式相依：`shared_ptr<PixelSampleSource>`（E2-27，沿用 `ScreenPixelProvider` 相依風格，
  可 null——每次 `pick_at` 回 `NoSource`，不崩）+ `DimOverlayElement&`（E4-30，不取得所有權，
  借它組出放大鏡）。
- **取色（E2-27）**：`pick_at(anchor)` 呼叫 `source_->sample(anchor)`：
  - source 為 null → `NoSource`；該點無讀值 → `NoReading`（「無效點」）。兩者皆**不動**既有
    已成功取到的顏色（不靜默清空，呼應本專案「無效輸入不改狀態」的既有慣例，如 E4-30
    `set_intensity` 對非有限值的處理）。
  - 成功 → `Ok`，`current_` 更新為 `ColorPick{anchor, color, hex, rgb_text}`。`hex` 直接沿用
    `PixelColor::hex()`；`rgb_text`（`"rgb(R, G, B)"`）為本單元新增的顯示格式，不改動上游。
- **放大鏡 / 取色游標（E4-30 組裝）**：`magnify()` 呼叫 `magnifier_.show()` 後
  `add_cutout("region.magnifier." + to_string(current_.anchor))`——把目前取樣點挖成不調光
  區域，模擬放大鏡 / 取色游標；尚未成功取色（`has_pick_` 為 false）→ `DimStatus::Invalid`
  （無點可放大鏡，複用 E4-30 既有列舉，未新造狀態碼）。換取樣點後再呼叫 `magnify()` 會先
  `remove_cutout` 舊區域再挖新區域（`active_cutout_` 追蹤目前作用中的挖洞名，避免累積）。
  `dismiss_magnifier()` 移除挖洞並 `hide()`，恆安全（無需能力閘控，委派 E4-30 `hide()` 的
  既有語意）。能力不可用（NFR-03）時 `magnify()` 直接回傳 E4-30 的 `Unsupported`，本單元不
  重造閘控邏輯。
- **複製**：`copy()` 把 `current_.hex` 存入 `clipboard_`；尚未取色 → false（no-op，不靜默
  覆寫剪貼簿為空）。相位 1 明確不接系統剪貼簿（`clipboard()` 只是內部狀態，供驗證 /
  未來相位串接真實剪貼簿 API）。

具名結果 `PickStatus`（Ok / NoSource / NoReading）附 `to_string()`（NFR-02）；放大鏡的
狀態碼直接複用 E4-30 `DimStatus`（Ok / Unsupported / Invalid），不重複定義同義列舉。

無效操作一律明確回具名結果，不靜默：無來源、無效點（該點目前無讀值）、尚未取色即
`magnify()` 或 `copy()`。
