## 我要做什麼（動工前計畫）

讓宣告式格式（E7-01 `Value` 樹）能定義**元件 / 項目群組**並對群組**批次施加操作**：
把樹中一組項目（依標籤 / 選擇器）視為群組，對整組經 E6-01 分派命令或套用共同屬性變更，
**逐成員回報結果**。設計（C++17，`namespace ds::format`）：

- `Selector`（`tagged`/`has`/`where`）+ `select(Value, selector) -> Group`。
- `GroupMember{path,label,node}`：樹中唯一路徑 + 友善標籤 + 非擁有指標。
- `apply_to_group(bus, group, command, args)`（+ `make_args` 多載）→ `GroupResult{per_member[]}`，
  經 E6-01 CommandBus 逐成員分派；未知命令 NotFound、處理器失敗 Failed，部分失敗不靜默。
- `apply_attributes(group, changes) -> GroupAttributeResult{per_member[]}`：批次屬性套用，
  產出每成員新副本（E7-01 Value 無就地變更 API），非 Map 成員逐一回報。

先讀懂上游公開介面：`engine/format/e7_01/document.hpp`（`Value` 多型節點、`find`/`at`/`keys`、
`Value::map` 工廠）與 `engine/command/e6_01/command_bus.hpp`（`CommandBus::dispatch`、
`CommandArgs`、`CommandResult{Ok/Failed/NotFound}`）。沿用其「不靜默失敗 / 結構化結果」契約。
