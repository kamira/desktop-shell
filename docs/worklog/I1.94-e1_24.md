## 介面設計要點

- 三組平台原語對應單元 primitives：K1 surface kernel（視窗）/ K2 繪製 / K3 輸入，
  加能力查詢（經 E1-21）與 init/shutdown 生命週期。
- NFR-02：surface 以具名 `SurfaceId` 指涉、圖層以具名 `SurfaceLayer` 角色表達，無絕對座標 /
  數字 z-order / 數字 handle。四參數 profile（圖層 / 輸入策略 / 命中策略 / 生命週期）即
  surface kernel 的核心洞見。
- NFR-03：`has()` 為能力閘控入口，委派 E1-21 能力矩陣；未知能力保守回 false。
- null 語意：no-op / 記憶體狀態；未知 / 空 / 重複 id 結構化回 false，絕不崩潰；記錄呼叫
  計數與 surface 表供契約斷言。
