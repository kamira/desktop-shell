## 讀懂上游 has()（E1-21）

`CapabilityMatrix`（`ds::kernel`）是能力宣告的單一資料來源：`has(id)` 對已宣告且
`default_available` 者回 true，未知一律保守 false；`is_optional(id)` 標記可能缺席的能力。
E1-22 NFR-03 的預設「閘控 API 名單」即由 `defaults()` 的 **optional** 能力尾段導出
（如 `host.tray_icon` -> `tray_icon`），故本單元 `PUBLIC` link e1_21 並 include 其 header。
