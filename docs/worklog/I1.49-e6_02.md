## 關鍵設計決策

- **相關度分數用整數編碼**：種類權重（Exact 300000 > Prefix 200000 > Substring 100000 > Fuzzy）拉開
  量級，種類內以完成度/編輯距離細排。整數讓「並列最佳」以精確相等判斷，歧義偵測不受浮點誤差干擾。
- **模糊比對對整串 id 與各 `.` 段取最小編輯距離**：命令多為命名空間化（`volume.set`），
  對整串比距離會被 `.set` 拉大；對段 `volume` 比才能讓 `volme`（距離 1）正確命中。
- **歧義=並列最佳同分 > 1 → 回 candidates 不分派**：不亂猜。精確命中量級最高且唯一，永不歧義。
- **查詢層與執行層鬆耦合**：`ActionRegistry` 只存「有哪些 id」；`dispatch_best` 接收一個 E6-01
  `CommandBus` 做真正分派。註冊表與 bus 漂移（候選在表、bus 未註冊）時，如實回 bus 的結構化 NotFound。
- **模糊上限可調/可關**：`set_fuzzy_max_distance`（預設 2，設 0 關閉模糊）。
