## 關鍵發現

E1-24 的 `SurfaceProfile` 已有 `SurfaceLifecycle::Ephemeral` **取值**，但無人管理其生命週期。
本單元即補上管理器：以 E5-10 一次性計時器為每個短暫 profile 計時（建立 → 存活 → 逾時 / 手動
過期 → 清理），並承載 E1-02 `InputStrategy` 決定其輸入行為。

設計取捨：時間源採**注入式** `TimeoutTimer&`（與 E1-02 注入 `KernelBackend&` 一致，忠於
「E5-10 注入式計時器」規格），管理器 `advance` 委派之。每 profile 於 `create` 登記一次性
`set_timeout(ttl)`；逾時回呼同步自動過期。手動 `expire` 先 `cancel` 計時器再收尾，故不會逾時
重複觸發。過期即移除記錄（清理），同名可於過期後重建。無效 id / 重複過期一律明確回 false。

生命週期 caveat：回呼捕捉 `this`，故注入計時器須比管理器活得久；管理器解構主動 cancel 其所有
未觸發計時器，避免懸置回呼。
