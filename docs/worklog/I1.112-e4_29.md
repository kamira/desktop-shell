## 分層 / NFR 遵循

- module 層純邏輯：只產出渲染描述，不觸碰任何 OS / 繪圖 API。
- NFR-02（無絕對座標 / 無數字 z-order）：折線點以正規化座標 `(x,y) ∈ [0,1]`（相對圖表區之
  比例，非螢幕像素）表達；`x` 為序列內位置比例，`y` 為值域內幅值比例。多序列的疊加順序以
  清單順序（`render_model().series` 位置）表達，非數字 z-order。填充底線恆為正規化幅值 0，
  同樣非座標。合成不透明度為比例 [0,1]，同樣合規。
- 不靜默失敗：每序列 `empty` 明確回報，圖表整體 `empty` 僅所有序列皆空才為真；超範圍夾限
  並標記 `clamped`；非有限值 / 無效值域 / 未知具名序列 / 空字串或重複序列名 一律回
  `Invalid`，不部分套用、不靜默建立序列。
- 無 `#ifdef _WIN32` / `win32` / `cocoa` 分支，不涉及任何後端。
- 消費上游不重造輪子：`LineChartRange` / `LineChartStatus` 直接沿用 E4-17 的
  `HistogramRange` / `HistogramStatus`；合成描述沿用 E1-03 `AlphaProfile`（經 E4-17 傳遞）。
- 未動根 `CMakeLists.txt`、`units.json`、共用 `docs/structure/directory.md`——G4 以每單元獨立
