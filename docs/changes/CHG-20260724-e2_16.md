# CHG-20260724-e2_16 — 已安裝應用列舉（E2-16）

- Date: 2026-07-24 (UTC+0) | Branch: feat/e2_16 | Risk: low | Implemented by: I1.16
- Skill: ai-sdlc-autopilot

## Motivation
E2-16「已安裝應用列舉」是 module 層（子系統 sysinfo）的一個**指標提供者**：透過
**E2-01 統一指標介面**（擴充點 1 契約）把「已安裝應用清單／數量」掛成一個指標。這正是
「新增指標 = 新增 `MetricProvider`、掛件一行不動」機制的一個具體實例——它**消費 E2-01
契約、不自造指標模型**。相位 1（Mac / null 期）只提供平台中立介面 + null 後端，**不真的
掃描系統**（回空清單，或回注入的假資料供測試）；真實 OS 掃描留待後端相位。

## Impact

### 新增 `modules/sysinfo/e2_16/`（module 層 / 子系統 sysinfo）
- `installed_apps.hpp` / `installed_apps.cpp`（`namespace ds::sysinfo`）：
  - `InstalledApp` struct：平台中立的已安裝應用描述 —— `id`（穩定識別碼）/ `name`
    （顯示名）/ `version`（"" = 未知）；含相等運算子。刻意不含平台專屬欄位。
  - `InstalledAppSource` 抽象後端：`enumerate() → vector<InstalledApp>`（決定性順序）。
    真實平台後端於相位 2+ 實作；提供者只依賴此抽象介面。
  - `NullInstalledAppSource` null 後端：**不掃描系統**，預設回空清單；
    `set_apps` / `add_app` / `clear` 注入假資料供測試與假感測器情境。
  - `InstalledAppsProvider : public ds::metrics::MetricProvider`（消費 E2-01 契約）：
    `provider_id()=="sysinfo.apps"`；`register_metrics(registry)` 向 E2-01 註冊表掛上
    單一指標 `"apps.installed"`（name="Installed Applications"、unit=""、
    range=`at_least(0)`）。**每個已安裝應用 = 一個可列舉 `MetricInstance`**
    （instance_id=應用 id、label=顯示名、value=存在(1.0)+版本文字、history_capacity=0）。
    於是「清單」由 `Metric` 列舉實例取得、「數量」即 `Metric::instance_count()`——直接
    借用 E2-01 的可列舉實例要素，對應本單元名「已安裝應用列舉」。
  - source 為 null 或空 → 仍保守掛上「空指標」（instance_count()==0），不崩。
  - `CMakeLists.txt`：`add_library(e2_16)` **PUBLIC 連上游 `e2_01`**（標頭 include
    `metric.hpp`，須傳遞 include 目錄）；`test_e2_16` + `add_test(NAME e2_16)`。
- 上游相依：E2-01 統一指標介面（`ds::metrics::MetricProvider` / `MetricRegistry` /
  `InMemoryMetric` / `InMemoryMetricInstance`，可讀不可改）。
- **無** `#ifdef` / win32 / cocoa / 真實 OS 掃描（backend_guard 綠燈）。純邏輯、平台中立。

### 測試 `tests/e2/test_e2_16.cpp`（gtest，14 案例）
- 提供者身分（2）：`provider_id`/`kMetricId` 穩定；可上轉為 E2-01 `MetricProvider`。
- 註冊（1）：`add_provider` 掛上一個指標、registry 可查得。
- null 回空（2）：預設 null 後端與 null source 指標皆掛上但 instance_count()==0、不崩。
- 假資料注入列舉（3）：三個假應用 → 數量=3、清單依注入順序列舉、find_instance 依 id 尋得。
- 值語意（1）：每實例 value=存在(1.0)+版本文字（版本未知為空字串仍有效）。
- 範圍（1）：`at_least(0)`（下界 0、上無界）。
- null 後端注入 API（2）：set_apps/add_app/clear/建構子注入。
- InstalledApp 相等性（1）。
- 消費者範式（1）：掛件風格消費者只走 E2-01 registry / Metric 介面，全程無 sysinfo 型別。
- 重複註冊（1）：同 id 第二次掛上被保守拒絕、不覆寫既有。
