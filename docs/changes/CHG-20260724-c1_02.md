## Motivation
C1-02「立繪 profile」：角色立繪 / 桌寵靜態立繪——一個**具透明外形、具名圖層歸屬、可自由拖曳
並記憶位置、可依區域點擊觸發互動**的桌面立繪，並可切換其**具名表情 / 狀態**（如 idle /
happy）所對應的立繪圖，其定義可由**宣告式立繪檔**載入。這是一個**組裝型 artifact 單元**：
不新增引擎邏輯，而是把六個已合併的擴充點（E1-01 具名圖層、E1-03 逐像素 alpha surface、
E1-08 自由拖曳 + 位置記憶、E4-06 具名 surface 切換、E5-14 碰撞區域名事件參數、E7-01 宣告式
格式核心）組成單一「立繪」應用 profile + 行為（load_portrait / place / drag / save_position /
on_region_click）。相位 1：純資料 / 邏輯組裝，無真實 GUI，注入式後端。

實作前以 `ls` / 讀檔確認上游實際路徑（部分與任務提示描述不同）：E4-06 實際路徑為
`engine/render/e4_06/`（`SurfaceSwitcher`，語意為「具名 surface 定址與切換」，非任務提示所猜的
「立繪/圖像相關元素」），其 PUBLIC 相依 `e4_02`（`modules/elements/e4_02/image_element.hpp`，
圖片元件 `ImageElement`）——本單元經 E4-06 標頭借道使用 E4-02 的 `ImageElement` 承載每個具名
表情的圖片渲染描述（來源參照 / 固有尺寸 / 縮放模式 / 透明度 / 目標 surface）。E5-14 PUBLIC
相依 `e5_01`（滑鼠按鍵事件）+ `e1_05`（`NamedRegionMap`），一併經其標頭傳遞可用。

參考已合併的 `content/profiles/c1_01/`（Skin profile，深度相似的組裝範式：E1-01 + E1-03 +
E1-08 + E7-01 + 注入式 `KernelBackend&` / `LayerStack&`）與 `content/profiles/c1_05/`（召喚
面板 profile，宣告式載入 + 全有或全無回滾慣例）。

## Impact

### 新增 `content/profiles/c1_02/`
- `portrait_profile.hpp` / `.cpp`：`namespace ds::profiles`，`class PortraitProfile`。
  - 注入式相依（不擁有生命週期）：`ds::kernel::KernelBackend&`（E1-03 / E1-08 服務共用同一
    後端）+ `ds::kernel::LayerStack&`（可與其他 surface / profile 共用堆疊）。內部自持
    `AlphaSurfaceService`（E1-03）、`DraggableSurface`（E1-08）、`SurfaceSwitcher`（E4-06）、
    `RegionEventDispatcher`（E5-14），與一份具名表情 → `ImageElement`（E4-02）的線性配對。
  - `load_portrait(Value)`（E7-01）：解讀 `layer` / `alpha{mode,opacity}` /
    `position{anchor,dx,dy}` / `expressions[{name,source,width,height,scale}]` /
    `initial_expression`，全有或全無驗證後依序實體化：E1-03 建立 alpha surface（`Unsupported`
    降級路徑，不建立任何 surface）→ E1-01 指派具名圖層 → E1-08 登錄初始位置 → E4-06 + E4-02
    登記具名表情（`target` 一律指向本 profile 的主要 surface）→ 切至 `initial_expression` →
    E5-14 命中 surface 依目前表情固有尺寸整理。任一步失敗回滾（`teardown_backend_state()`）。
  - `unload()`：反向拆除全部後端 / 表情 / 區域狀態。
  - 表情：`add_expression` / `remove_expression` / `switch_expression`（純委派 E4-06，需
    已載入）、`current_expression()` / `expressions()` / `has_expression()` / `current_image()`。
    切表情會重新整理 E5-14 命中 surface 的形狀（依目前表情固有尺寸，尚無表情時退回 1x1
    佔位形狀）。
  - 區域點擊：`set_regions(NamedRegionMap)` / `has_regions()` / `on_region_click(listener)` /
    `unsubscribe_region_click()` / `inject_click(LocalPoint)`（皆純委派 E5-14）。
  - 定位 / 拖曳 / 位置記憶：`place` / `resolve_live` / `begin_drag` / `drag_to` / `end_drag` /
    `cancel_drag` / `is_dragging` / `save_position` / `load_position`（皆純委派 E1-08，語意與
    C1-01 `SkinProfile` 對應方法一致）。
  - 具名狀態 / 結果列舉：`PortraitState`（Unloaded / Loaded）、`PortraitStatus`（Ok /
    Unsupported / Invalid / AlreadyLoaded），各附 `to_string()`（NFR-02）。

### 相位 1 約束遵循
- 純資料 / 邏輯組裝，無真實 GUI；無平台分支（無 `#ifdef` / win32 / cocoa，僅在說明註解中
  引述禁用詞，與 E5-05 / C1-01 慣例一致）。

  後端狀態。
