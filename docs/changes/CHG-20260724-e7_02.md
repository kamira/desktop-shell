# CHG-20260724-e7_02 — 變數系統（E7-02）

## Motivation

宣告式格式（E7-01）描述設定 / profile / 內容時，同一組值（路徑、名稱、尺寸、埠號）
常需在多處複用。若處處硬寫，改一處要改多處、易漂移。**變數系統**讓宣告一次、
處處引用：定義一組具名變數，並把文件裡的 `${name}` 引用替換為對應的變數值。

本單元建構於 E7-01 之上、**消費其 `Value` / `Document`**，不重造型別模型：只新增
一個變數作用域 / 表，加上把 Value 節點樹（或整份 Document）內的引用解析、替換的邏輯。

依 NFR-04 精神「不靜默失敗」：引用到**未定義**變數、**循環引用**、未終止 `${`、
空變數名、容器型別內嵌字串化——一律回傳帶訊息（含肇因變數名）的 `ResolveError`，
絕不安靜替成空字串或跳過。本單元屬 engine 層（平台中立純邏輯）：無任何 `#ifdef` /
系統呼叫 / 真實後端，可完全單元測試。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 變數表 | `VariableScope`：名稱→`Value` 有序、鍵唯一，可選帶父作用域指標 | 保序（可重現輸出，對齊 E7-01 Map 風格）；父鏈支援巢狀作用域 |
| 巢狀作用域 | `VariableScope(parent)`；`find`/`has` 先查本層再上溯父鏈，子層遮蔽父層 | 常見的詞法式作用域語意；父層不取得所有權（`const*`） |
| 引用語法 | 字串內 `${name}` | 極簡、與眾多宣告式格式慣例一致 |
| 整串單一引用 | `"${x}"` → **保留變數值原生型別**（數字仍是數字、清單仍是清單） | 「引用變數值」的直觀語意；讓變數可承載非字串型別 |
| 內嵌引用 | 前後有字元 / 多引用 → 各引用以值的**字串呈現**替換，結果為字串 | 字串插值的自然行為；數字 / bool / null 有明確字串化 |
| 容器內嵌 | 內嵌引用到 List / Map 無法字串化 → **明確錯誤**（非靜默） | NFR-04；整串單一引用容器則型別保留（合法） |
| 巢狀引用 | 變數值本身可含 `${...}`，遞迴求值（於同一作用域） | 讓變數可組合（`path = ${base}/bin`） |
| 循環偵測 | 「求值中」變數名堆疊；再次遇到同名 → **循環引用錯誤** | 避免無限遞迴 / 堆疊爆掉；明確回報而非靜默 |
| 轉義 | `$$` 收斂為字面 `$`（故 `$${` 產生字面 `${`）；孤立 `$` 為字面 | 極簡、無歧義的最小跳脫規則 |
| 錯誤模型 | `ResolveError{message, variable}`；`ResolveResult`（Value）/ `DocumentResolveResult`（Document） | 對齊 E7-01 的 `ParseResult` 二選一風格；帶肇因變數名 |
| 錯誤傳遞 | 遞迴內部以受控例外拋 `ResolveError`，於 `resolve()` 邊界捕捉轉 failure | 讓遞迴下降碼乾淨；對外仍為無例外的結果物件（沿用 E7-01 手法） |
| 遞迴範圍 | 進入 List 每元素、Map 每成員值（**鍵不替換**）；非字串純量原樣複製 | 整棵樹一致處理；只替換值，語意清楚 |

介面平台中立：無 `#ifdef _WIN32` 等平台分支、不綁任何真實後端，符合相位 1（Mac/null）約束。
engine 層與平台無關（非 `src/kernel/backend/`，不涉 backend_guard）。不含能力閘控呼叫（純格式邏輯），
無 `has()` 降級路徑需求。

## Impact

- `VariableScope`：`define`（就地覆寫保序）、`find`/`has`（含父鏈）、`has_local`、`names`、`size`、`parent`。
