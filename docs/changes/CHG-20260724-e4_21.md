# CHG-20260724-e4_21 — 漸層填色（E4-21）

- Date: 2026-07-24 | Branch: feat/e4_21 | Risk: low | Implemented by: I1.106

- Unit: E4-21（漸層填色，module 層 / 子系統 elements / phase 1 / low）
- depends_on: E1-03（逐像素 alpha surface）

## Motivation

桌面元件（背景、進度條、裝飾邊框等）常需要漸層(gradient)填色效果——線性或放射狀、多個色停
靠點沿漸層軸漸變。繪製本身屬後續相位；相位 1 需先有一個**平台中立、可單元測試**的「漸層渲染
描述模型」：把方向與一組色停靠點描述清楚，供繪製層日後消費，且能在描述層級直接內插取色。

若在此階段就綁真實繪圖（像素座標、端點向量、z-order），將無法在單元測試中重現，也違反 module
層「平台中立、換平台不動邏輯」與 NFR-02（無絕對座標 / 無數字 z-order）。E4-21 因此只產出**渲染
描述**：正規化位置的色停靠點 + 具名種類/角度，全程無真實繪製。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 元件 | `GradientFill`：累積色停靠點 → `render_model()` 產出 `GradientRenderModel` | 純邏輯、可測；繪製層日後消費描述 |
| 種類 | `GradientType{Linear,Radial}`（建構時指定，唯讀） | 具名列舉，非數字 flag |
| 色停靠點 | `add_stop(position,color)`：`position ∈[0,1]`（沿軸比例），自動依位置排序插入 | NFR-02：位置以**比例**表達，非像素座標；排序保證 sample() 正確 |
| 顏色 | `Color{r,g,b,a}`，正規化分量 `[0,1]`（非 0-255） | 與位置同一比例語意，內插自然 |
| 方向 | `set_angle(degrees)`：非有限值拒絕，成功則正規化至 `[0,360)` | NFR-02：方向以**角度**（具名量度）表達，非端點座標 |
| 取樣 | `sample(t)`：t 先夾限 `[0,1]`；0/1 個停靠點分別回安全預設 / 恆定色；否則相鄰停靠點逐分量線性內插 | 描述層級即可取色，供快速預覽 / 測試 |
| 合成描述 | 沿用上游 E1-03 `AlphaProfile`（mode + opacity[0,1]），`set_composite` 夾限 opacity | 漸層最終如何與所在 surface 合成；opacity 為比例（符 NFR-02） |
| 越界 / 無效輸入 | `add_stop` 位置越界 → `InvalidPosition`；顏色分量越界 → `InvalidColor`；皆**不新增**該停靠點 | 明確不靜默，不夾限藏起錯誤 |
| 角度 / 合成無效 | 非有限值 → `InvalidAngle` / `InvalidComposite`，**不套用**，維持先前值 | 同上，不靜默改成預設值 |

平台中立：無 `#ifdef` / `win32` / `cocoa` / 真實繪圖 API；NFR-02 無絕對座標 / 無數字 z-order。

### 2. `modules/elements/e4_21/gradient_fill.cpp`（新增）
- `add_stop`：範圍驗證 + 依 position 用 `std::upper_bound` 穩定排序插入。
- `set_angle`：`std::fmod` 正規化至 `[0,360)`。
- `set_composite`：opacity 有限性檢查 + 夾限 `[0,1]`。

- `render_model`：組裝目前狀態的 `GradientRenderModel`（stops 已恆為排序狀態）。
