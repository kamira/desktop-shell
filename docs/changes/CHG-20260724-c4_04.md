## Motivation

C4-04「視窗總覽」（Exposé 式視窗縮圖總覽）：按下召喚鍵時，把目前所有視窗以縮圖平鋪展示，
使用者可選取、切換（activate）或直接從總覽關閉某視窗。這是一個**組裝型 artifact app**：
不新增引擎邏輯，而是把兩個已合併的擴充點/元件組成單一應用 + 行為
（`load_windows(清單)` / `show_overview` / `select` / `activate` / `close_window`）：

- **C1-05**（`ds::profiles::SummonPanelProfile`）：總覽面板本身的**基底 profile**——借用它的
  短暫生命週期（叫出 / 收起）組裝 `show_overview()` / `close_overview()`。
- **E4-02**（`ds::elements::ImageElement`）：每個視窗一個縮圖渲染描述——相位 1 縮圖為
  **可注入的 `ImageSource`** 佔位圖像參照，無真實視窗截圖 / 無真實影像解碼。

相位 1：純資料模型 + 注入式視窗來源，無真實視窗列舉、無平台分支。

## Impact

### 新增 `apps/c4_04/`
- `window_overview.hpp` / `.cpp`：`namespace ds::apps`。
  - `WindowOverviewApp`：以 `ds::profiles::SummonPanelProfile&`（C1-05，不取得所有權，只借
    其 open/close 生命週期，不碰其 `items()` 選單森林）建構。
  - `load_windows(vector<WindowSpec>)`：以一份清單取代現有視窗清單，為每個視窗建立 E4-02
    `ImageElement` 縮圖渲染描述（若提供 `thumbnail` 來源；`nullptr` = 該視窗無縮圖，仍是合法
    視窗）並設定具名目標 surface（`"surface.overview." + window_id`），重新計算所有視窗的
    平鋪版位 → `LoadStatus::Ok`；清單內有空 `window_id` 或重複 `window_id` → `Invalid`，整批
    拒絕、**現有清單不動**（不部分套用）；空清單 → `Ok`，合法的「無視窗」狀態。
  - `TileLayout`：平鋪版位 —— 具名區域字串（`kTileRegionPrefix + window_id`）+ 正規化比例
    `[0,1]`（占總覽畫布的分數，精神同 E4-02 `CropRect`；NFR-02：具名 + normalized，無絕對
    像素座標）。以固定欄數上限 `kOverviewColumns`（視窗數 < 欄數時收斂為視窗數）逐格計算。
  - `show_overview(ttl)` / `close_overview()`：直接委派 `base().open(ttl)` / `base().close()`
    （C1-05 既有語意：已開啟中重開失敗、ttl == 0 失敗、未開啟即收起失敗）；`close_overview()`
    成功時一併清除選取。
  - `select(window_id)`：總覽開啟中反白選取（不收起總覽）→ `Selected`；未開啟 →
    `PanelClosed`；找不到 → `NotFound`（總覽保持開啟、選取不動）。
  - `activate(window_id, out)`：找到該視窗 → `Activated`（`out` 指向該條目、更新
    `last_activated()`、隨即收起總覽、清除選取）；未開啟 → `PanelClosed`；找不到 →
    `NotFound`（總覽保持開啟，不靜默收起）。
  - `close_window(window_id)`：自清單移除該視窗、若恰為目前選取項則一併清除選取、重新平鋪
    剩餘視窗；找不到 → `false`（no-op）。
  - `load_windows()` 重載清單後，若舊選取的視窗仍在新清單內則保留選取，否則清除（不留懸置
    選取）。
  - 具名結果 `LoadStatus` / `SelectStatus` / `ActivateStatus` 皆附 `to_string()`（NFR-02）。
- `CMakeLists.txt`：`add_library(c4_04 STATIC)` + `target_link_libraries(c4_04 PUBLIC c1_05
  e4_02)` + `test_c4_04`（`tests/c4/test_c4_04.cpp`）+ `add_test(NAME c4_04)`。

### 新增 `tests/c4/test_c4_04.cpp`（gtest，30 案例）
涵蓋：`load_windows` 載入視窗清單 + 建立 E4-02 縮圖渲染描述（含目標 surface）、無縮圖來源
時 `has_source=false`、取代既有清單、空清單、多視窗（5 個跨列）、拒絕空/重複 `window_id`
不部分套用；平鋪版位（單視窗滿版、多視窗網格、NFR-02 具名 + `[0,1]` 邊界）；
`show_overview` / `close_overview`（委派 C1-05、重開失敗、收起清選取、未開啟收起失敗）；
`select`（未開啟 `PanelClosed`、找不到 `NotFound`、成功反白且不收起總覽）；`activate`
（未開啟 `PanelClosed`、找不到 `NotFound` 保持開啟、成功收起總覽並清選取並記錄
`last_activated`）；`close_window`（移除並重新平鋪、找不到 no-op、清除懸置選取、不影響無關
選取）；`load_windows` 重載時選取的保留/清除；`to_string()` 穩定字串。

### 相位 1 約束遵循
- 純資料模型 + 注入式視窗來源（縮圖為佔位圖像參照，無真實視窗截圖 / 無真實視窗列舉）；無
  平台分支（無 `#ifdef` / win32 / cocoa）。
- 核心 API 無絕對座標、無數字 z-order（NFR-02）：平鋪版位以具名區域字串 + 正規化比例 `[0,1]`
  表達；縮圖目標以具名 `SurfaceId` 字串指涉（沿用 E4-02 既有慣例）。
- 無效操作一律明確回具名結果，不靜默：總覽未開啟即 select/activate、選取/啟用/關閉不存在的
  `window_id`、載入內含空/重複 `window_id` 的清單。
