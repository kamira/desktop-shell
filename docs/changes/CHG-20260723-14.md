# CHG-20260723-14 — engine/sensors 改名 engine/metrics

- Date: 2026-07-24 (UTC+0) | Branch: claude/ai-sdlc-handshake-validation-380ada | Risk: low | Implemented by: I1
- Skill: ai-sdlc-autopilot v1.1

## Motivation
`engine/sensors/` 裝的是**指標介面契約**（`E2-01` 統一指標介面、`E2-02` 採集頻率），
不是感測器本體 —— 真正的感測器（CPU/GPU/記憶體…）在 `modules/sysinfo/`。
「sensors」名不副實，改名 `metrics` 使目錄名反映其內容（指標契約），
與 `modules/sysinfo`（指標提供者）區隔。

## Impact
`units.json`：`E2-01`、`E2-02` 兩筆 `write_scope` 的 `engine/sensors/` → `engine/metrics/`。
`tests/e2/` 路徑不動（`plan.py` 以 `module` 欄位組測試路徑，與此無關）。
`layer`（engine）、`stage`、`subsystem` 皆不動。

遷移後 `engine/` 九個子目錄：
`format 15 / package 9 / events 11 / render 8 / command 5 / script 5 / ipc 5 / metrics 2 / common 2` = 62。

文件同步：`docs/structure/directory.md` 樹狀圖、`docs/architecture.md` 遷移狀態列表。
全 repo 已無非歷史的 `engine/sensors` 字樣。
