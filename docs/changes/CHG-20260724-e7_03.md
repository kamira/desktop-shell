## Motivation

E7-02（變數系統）提供替換「引擎」：呼叫端**在程式外**建好一個 `VariableScope`（逐一
`define`），再以 `resolve()` 把節點樹裡的 `${name}` 引用替換掉——變數從何而來，E7-02 不管。

實務上，最自然的變數來源是**文件自身**：一份宣告式設定 / profile / 內容常希望在文件內
的某個「段落」宣告一組具名變數，其餘內容再引用它，達成「宣告一次、處處引用」而**無需外部
程式碼**。E7-03「段落變數」補上這一層：識別文件頂層的**變數段落**（預設鍵 `vars`），把它
抽出建成 `VariableScope`，再委派 E7-02 展開其餘內容。

本單元刻意極薄，嚴守「**消費上游、不重造輪子**」：型別模型沿用 E7-01 `Value`；替換 / 字串
內插 / 型別保留 / 巢狀引用 / 循環偵測 / 遞迴進入容器全數委派 E7-02 `resolve()`；錯誤模型沿用
E7-02 `ResolveError` / `ResolveResult` / `DocumentResolveResult`。新增的僅是「從段落建作用域」
與「抽出 / 移除段落」這一薄層。

依 NFR-04 精神「不靜默失敗」：變數段落若不是映射 → 明確回報；引用到未定義變數、循環引用、
未終止 `${`、容器內嵌字串化 → 沿用 E7-02 的明確 `ResolveError`（帶肇因變數名，定位到出處），
絕不安靜替成空字串或跳過。本單元屬 engine 層（平台中立純邏輯）：無任何 `#ifdef` / 系統呼叫 /
真實後端，可完全單元測試。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 變數來源 | 文件內的「變數段落」（頂層 map 的具名鍵，預設 `vars`） | 讓變數可宣告於文件自身、無需外部程式建 scope |
| 段落鍵名 | `ExpandOptions::vars_key`（預設 `"vars"`，`kDefaultVarsKey`） | 可覆寫以配合不同格式慣例（如 `$defs`） |
| 建作用域 | `build_scope(section, scope, err)`：段落成員依序 `define` 進 `VariableScope` | 薄層；值原樣（未展開）插入，成員間引用由 E7-02 惰性求值 → 宣告順序無關 |
| 段落非映射 | `build_scope` 回 false 並填 `err`；`expand` 轉 failure | NFR-04；不靜默接受畸形段落 |
| 移除段落 | `strip_vars`（預設 true）：段落只為宣告用途，展開輸出不含它 | 段落是「定義」不是「內容」；`false` 時保留且其內部引用亦展開 |
| 父作用域 | `ExpandOptions::parent`（`const VariableScope*`，不取得所有權） | 鏈接外層（全域 / 環境）變數；段落變數遮蔽父層同名者 |
| 替換委派 | 全部交 E7-02 `resolve()`：型別保留 / 內插 / 巢狀 / 循環偵測 / 遞迴容器 | 不重造輪子；行為與 E7-02 完全一致 |
| 錯誤 / 結果模型 | 沿用 E7-02 `ResolveError` / `ResolveResult` / `DocumentResolveResult` | 對齊上游二選一風格；帶肇因變數名 |
| root 非 Map | 無段落可抽，直接以（僅含 parent 的）作用域 `resolve()` 整棵樹 | Value 層入口的合理退化行為 |
| Document 層 | `expand(Document)` 展開 `root`，`format_version` 原樣保留 | 與 E7-02 `resolve(Document)` 一致 |

## 對外介面（`namespace ds::format`）

- `kDefaultVarsKey`：變數段落預設鍵名 `"vars"`。
- `struct ExpandOptions{ std::string vars_key; bool strip_vars; const VariableScope* parent; }`。
- `bool build_scope(const Value& section, VariableScope& scope, ResolveError& err)`：由段落
  （須為 Map）填入作用域；非 Map → false + err。
- `ResolveResult expand(const Value& root, const ExpandOptions& = {})`：Value 層段落變數展開。
- `DocumentResolveResult expand(const Document& doc, const ExpandOptions& = {})`：Document 層展開，
  版本欄位原樣保留。
