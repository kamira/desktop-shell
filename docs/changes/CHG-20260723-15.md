# CHG-20260723-15 — 補上三個 bootstrap 缺件，G6 停點契約由空轉轉為生效

- Date: 2026-07-24 (UTC+0) | Branch: claude/ai-sdlc-handshake-validation-380ada | Risk: low | Implemented by: I1
- Skill: ai-sdlc-autopilot v1.1

## Motivation
bootstrap 自始缺三個檔：`scripts/halt_gate.py`、`assets/halt_policy.json`、`docs/backlog/state.json`。
後果是 **G6 停點契約空轉**——`plan.py gate` 呼叫不存在的 `halt_gate.py` 會 `FileNotFoundError`，
而 G6 有 `continue-on-error: true`，於是恆走 HALT 分支，medium 單元的自動/停點判定形同虛設。
本 CHG 補齊三檔，讓停點契約真正依風險分級運作。

## Impact

### 1. `scripts/halt_gate.py`（新增）
- 由 `plan.py gate` 呼叫：`halt_gate.py --gate <GATE> --risk <RISK>`，exit 0=AUTO / 10=HALT
- 查 `assets/halt_policy.json`，**tighten-only**：政策未明確列入該停點 `auto` 清單的風險一律 HALT；
  政策檔缺失、未知停點亦一律 HALT（不因設定缺席而放行）
- 政策路徑可經環境變數 `AI_SDLC_HALT_POLICY` 覆寫

### 2. `assets/halt_policy.json`（新增）
```json
{ "version": 1, "default": "halt",
  "gates": { "before_merge_or_release": { "auto": ["low"], "halt": ["medium", "high"] } } }
```
對應 ai-guideline 驗收標準：low 可 inline 自驗自主續跑、medium 以上合併前停下等 V1。

### 3. `docs/backlog/state.json`（新增）
初始空狀態 `{"done": [], "in_progress": {}}`（`plan.py` 主迴圈回寫進度用；
先前檔案不存在時 `plan.py` 走預設空狀態，status 尚可跑，但無持久化）。

### 未觸發 G4
三檔位於 `scripts/`、`assets/`、`docs/backlog/`，皆不在 G4 涵蓋的
`^(src|engine|modules)/` 內，屬治理基礎設施而非平台程式碼，故無需同步 `docs/structure/`。

## Status
Accepted — self-verified (low risk)。

## Verification
`halt_gate.py` 直接測試：
- `--gate before_merge_or_release --risk low` → AUTO，exit 0
- `--gate before_merge_or_release --risk medium` → HALT，exit 10
- `--gate unknown_gate --risk low` → HALT，exit 10（tighten-only）

經 `plan.py gate` 完整鏈路（**先前因 halt_gate 缺失而失敗**）：
- `E1-21`（low）→ exit 0 AUTO
- `E2-01`（medium）→ exit 10 HALT
- `E1-08`（`autonomy: halt` 覆寫）→ exit 10（plan.py 直接判定，未進 halt_gate）

其餘：`state.json`/`halt_policy.json` 皆合法 JSON；`plan.py status` 176 不變；
`stage_check` 無違規；`backend_guard` 相位 1 通過。
