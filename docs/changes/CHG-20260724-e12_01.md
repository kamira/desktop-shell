# CHG-20260724-e12_01 — idle 記憶體與 CPU 門檻（E12-01）

- Date: 2026-07-24 | Branch: feat/e12_01 | Risk: low | Implemented by: I1.87
- Skill: ai-sdlc-autopilot
- Unit: E12-01（idle 記憶體與 CPU 門檻，engine 層 / 子系統 common / 相依 E2-02 / 對應 NFR-01）

## Motivation

NFR-01 要求「閒置時低資源占用」。E2-02 已把採集頻率**分級**（high/normal/low/on-demand）並
提供除頻合併，但**何時該降到低頻**仍缺一個判斷者：需要一個依「系統當前是否閒置（以 CPU /
記憶體用量衡量）」動態調整採集活動等級的門檻管理器——閒置時降頻進省電、活躍時升頻跟手。
本單元即此判斷者，並與 E2-02 的 `SamplingTier` 整合（閒置時把分級降一階）。

一個關鍵設計問題：單一門檻在臨界值附近會因讀值微幅抖動而在 Idle/Active 間反覆翻轉
（thrashing），切換本身反而消耗資源、破壞穩定。故必須引入**遲滯（hysteresis）**。

平台中立純邏輯：門檻判斷全為百分比純數，CPU% / 記憶體% 的**讀值由呼叫端注入**（未來採集
迴圈綁真實 sysinfo），本層不碰真實資源 API / 不綁時鐘，故可完全單元測試。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 活動等級 | `enum class ActivityLevel { Active, Idle }` | 二態涵蓋「跟手 / 省電」；輸出即 `evaluate` 回傳型別 |
| 判定語意 | 活躍：CPU≥門檻 **或** 記憶體≥門檻；閒置：兩者皆 < 閒置門檻 | OR 進 / AND 出：寧可誤判活躍不誤判閒置，護即時性 |
| **遲滯** | 雙門檻：活躍門檻（上緣）+ 閒置門檻（下緣 = 上緣 − 帶寬），中間死區維持現態 | 防臨界抖動 thrashing；只有明確越過某一緣才切換 |
| 門檻設定 | `set_thresholds(cpu%, mem%)`，夾 [0,100] | 門檻設定驗證：界外值不產生非法門檻 |
| 遲滯帶寬 | `set_hysteresis(band%)`，夾 >=0；帶寬 0 退化為單門檻 | 可調死區寬度；閒置門檻過低時被 [0,上緣] 夾住 |
| 初始等級 | Active | 保守：先假設活躍，待證實閒置才降頻，不誤降 |
| **與 E2-02 整合** | `lower_tier`（High→Normal→Low 夾底、OnDemand 維持）+ `adjust_tier(base)` | 閒置時把基準採集分級降一階；沿用 `ds::metrics::SamplingTier` 不另造 |
| 等級→分級 | `recommended_tier()` + `set_tier_mapping`（預設 Active→High / Idle→Low） | 呼叫端可直接取建議分級，或以自訂映射覆蓋 |
| Low 夾底 | 閒置降級不低於 Low（仍週期，不完全停採） | 閒置期仍須偶爾採集慢變指標，非完全靜默 |

## 介面（`namespace ds::common`）

- 型別：`ActivityLevel`（Active / Idle）。
- 自由函式：`to_string(ActivityLevel)`、`lower_tier(SamplingTier)`。
- `IdleThresholdPolicy`：`set_thresholds` / `set_hysteresis` / `set_tier_mapping`（皆鏈式）、
  門檻查詢（`cpu_active_threshold` / `cpu_idle_threshold` / …）、`evaluate(cpu%, mem%)`、
  `level()` / `reset()`、`recommended_tier()`、`adjust_tier(base)`。

## 測試（`tests/e12/test_e12_01.cpp`，gtest，22 案例）

涵蓋：低於門檻→閒置降頻、超過門檻→活躍升頻（CPU / 記憶體任一）、遲滯死區維持現態、
死區來回抖動不 thrashing、與 E2-02 tier 對應（預設 / 自訂映射 / OnDemand 維持 / Low 夾底）、
邊界值（恰活躍門檻 = 活躍、恰閒置門檻 = 維持、剛跌破 = 閒置）、門檻設定驗證（界外夾值、
負帶寬夾 0、大帶寬閒置門檻夾 0、鏈式設定）、端到端等級轉換驅動採集分級。
