# CHG-20260724-e4_30 — 全螢幕調光覆蓋（E4-30）

- Date: 2026-07-24 | Branch: feat/e4_30 | Risk: low | Implemented by: I1.103
- Skill: ai-sdlc-autopilot
- Unit: E4-30（全螢幕調光覆蓋，module 層 / 子系統 elements / phase 1 / low）
- depends_on: E1-03（per-pixel alpha surface）、E1-01（具名圖層與 z-order）

## Motivation

桌面外殼需要一個覆蓋整個螢幕的**半透明暗色層**（調光 / 遮罩覆蓋）：用於專注模式（壓暗其餘桌面）、
彈窗背景變暗（modal backdrop）、夜間調光等情境。此覆蓋層必須置於最上層、可調暗度、可淡入淡出，
並可選擇**挖洞**（保留不調光的具名區域，如時鐘 / 頭像）。

相位 1 不做真實繪製：本單元只產出覆蓋層的**渲染描述**（`DimRenderModel`）＋狀態，並以上游能力
表達其本質——半透明以 E1-03 `AlphaSurfaceService`（per-pixel alpha surface）表達，置頂以 E1-01
`LayerStack` 指派到**具名頂層** `SurfaceLayer::Topmost`（NFR-02：具名圖層置頂，不用絕對座標 /
數字 z-order）。真實繪製後端於後續相位另實作。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 半透明表達 | 覆蓋層 = 一個帶不透明度的 per-pixel alpha surface（E1-03）；intensity → `AlphaProfile::opacity` | 沿用上游半透明模型；挖洞需 per-pixel alpha 的不規則透明 |
| 置頂表達 | E1-01 `LayerStack::assign(id, SurfaceLayer::Topmost)`；render_model 帶 `layer_name`="layer.topmost" | NFR-02：具名頂層，非數字 z-order |
| 調光強度 | `set_intensity(0..1)`，clamp；非有限值 → Invalid | 強度即不透明度乘數；越界安全、無效報錯不靜默 |
| 顏色 | `DimColor{ r,g,b }` 正規化 [0,1]，各通道 clamp；非有限 → Invalid | 顏色與透明度分離（透明度由 intensity 表達）；預設純黑 |
| 顯示 / 隱藏 | `show()` 惰性建立置頂半透明 surface；`hide()` 標記不可見（不銷毀） | show 需能力（建立半透明 surface）；隱藏恆安全、再顯示低成本 |
| 淡入淡出 | `fade_to(target)`：設方向（In/Out/None）+ 目標，相位 1 直接抵達目標；target==0 → 淡出隱藏 | 宣告式；真實逐格動畫由後續相位承接 |
| 挖洞 | `add_cutout(具名區域)` / `remove_cutout` / `has_cutout`；空名 → Invalid、重複冪等、需能力 | 具名區域（NFR-02，無絕對座標）；挖洞屬 per-pixel 語意故需能力 |
| 能力閘控（NFR-03） | 所有建立 / 改動半透明 surface 的操作先經 `AlphaSurfaceService::supported()`；不可用 → Unsupported、不改狀態 | 降級路徑可觀測；圖層置頂被拒則**回滾**已建立的 alpha surface（不留半份狀態） |
| 相位 1 產出 | `render_model()` → `DimRenderModel`（可見性 / 強度 / 有效不透明度 / 顏色 / 具名頂層 / 淡入淡出 / 挖洞 / 能力） | 覆蓋層的宣告式渲染描述，供斷言與交接 |

介面平台中立：無 `#ifdef` / `win32` / `cocoa` / 真實繪圖 API；無絕對座標 / 數字 z-order。
