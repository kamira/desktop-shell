# CHG-20260724-e4_29 — 折線圖（E4-29）

## Motivation

最終的 CPU / GPU Widget 除了直方圖，還需要把一序列歷史用量以**折線圖**呈現（每點→座標，
連線）。繪製本身屬後續相位；相位 1 需先有一個**平台中立、可單元測試**的「渲染描述模型」——
把一序列數值映射成折線點的正規化描述，供繪製層日後消費。

E4-17（直方圖）已建立「時序資料元件」的範式：純邏輯建構者累積樣本、`render_model()` 一次
求值產出不可變描述、正規化幅值 + 清單順序表達（NFR-02）。E4-29 沿用此風格，但折線圖需要
**點對點座標**（非長條），因此每個點以正規化 `(x, y) ∈ [0,1]` 表達（相對圖表區之比例，非
螢幕像素），並加上直方圖沒有的「多序列疊加」與「平滑 / 填充」等折線圖特有能力。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 元件 | `LineChartElement`：累積一或多序列樣本 → `render_model()` 產出 `LineChartRenderModel` | 純邏輯、可測；沿用 E4-17 的建構者 / render_model 風格 |
| y 軸值域 / 狀態碼 | 直接沿用 E4-17 `HistogramRange` / `HistogramStatus`（`using LineChartRange = HistogramRange` 等） | 同語意（資料值域 / Ok-Invalid），不重造輪子，體現真實 depends_on |
| 折線點座標 | `LineChartPoint{ value, x, y, smoothed_y, clamped }`；`x=index/(count-1)`，`y=(v-min)/(max-min)` | NFR-02：正規化比例座標，非像素、非數字 z-order |
| 滾動視窗 | `set_capacity(N)`（0=無上限）；push / set_series 超出即丟最舊留最新 N，**所有序列共用同一容量** | 時序 widget 只顯示最近 N 筆；多序列須同步捲動 |
| 多序列（可選） | `add_series(name)` 新增具名序列；`push_sample(name,v)` / `set_series(name,values)`；預設序列固定為 `series[0]`（名稱 `""`） | 同一圖表疊加多條線（如 CPU 與 GPU）；疊加順序 = 清單順序，非數字 z-order |
| 平滑（可選） | `set_smoothing(bool)`；啟用時以窗口 3 移動平均（邊界取可得鄰居）算出 `smoothed_y`，原始 `y` 不受影響 | 折線圖常見降噪；未啟用時 `smoothed_y == y`，向下相容 |
| 下方填充（可選） | `set_fill(bool)`；`LineChartFill{enabled, baseline}`，`baseline` 恆為正規化幅值 0（對應 `range.min`） | 折線圖常見視覺（面積圖）；相位 1 只描述旗標與底線比例，不做真實填色 |
| 合成描述 | 沿用上游 E1-03 `AlphaProfile`（經 E4-17 傳遞）：mode + opacity[0,1] | 半透明桌面 widget 如何被合成；opacity 為比例（符 NFR-02） |
| 超範圍 | 夾限至 [0,1] 並標記 `clamped=true`，原始 `value` 保留 | 明確不靜默；繪製層可辨識溢出 |
| 空序列 | 每序列 `LineChartSeriesModel::empty=true`；圖表整體 `LineChartRenderModel::empty=true` 僅當**所有**序列皆空 | 明確不靜默假裝有資料；多序列時單一序列空不代表整圖空 |
| 非法輸入 | 非有限值 / 無效值域 / 未知具名序列 / 空字串或重複序列名 → `LineChartStatus::Invalid`，不部分套用 | 不靜默改成預設值、不靜默建立序列 |

平台中立：無 `#ifdef` / `win32` / `cocoa` / 真實繪圖 API；NFR-02 無絕對座標（皆為 [0,1] 正規化
比例）、無數字 z-order（疊加順序 = 清單順序）。
