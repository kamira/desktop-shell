# CHG-20260724-e2_20 — 網路連通性（E2-20）

- Date: 2026-07-24 | Branch: feat/e2_20 | Risk: low | Implemented by: I1.71
- Skill: ai-sdlc-autopilot

## Motivation
E2-20「網路連通性」是 module 層（子系統 sysinfo）的一個**指標提供者**：透過 **E2-01 統一
指標介面**（擴充點 1 契約）把「網路連通性」——**是否連上網際網路**（online，bool）、
**延遲 / ping**（ms）、**封包遺失率**（%）、**對特定目標的可達性**（bool，支援多目標）、
**DNS 是否可解析**（bool）——掛成指標，並以 **E2-02 採集頻率分級**決定採樣節奏。這是
「新增指標 = 新增 `MetricProvider`、掛件一行不動」機制的又一個具體實例——它**消費
E2-01 / E2-02 契約、不自造指標模型或排程器**（範式與 E2-08 網路流量、E2-03 CPU 負載
一致）。相位 1（Mac / null 期）**絕不接任何真實網路探測**（不含 `socket` / `ping` /
`getaddrinfo` / `#ifdef` / win32 / cocoa）；改為**可注入的 `ConnectivitySource` 抽象** +
null / 假來源（可注入**固定 / 序列**）。真實平台探測留待相位 2。

## Impact

### 新增 `modules/sysinfo/e2_20/`（module 層 / 子系統 sysinfo）
- `connectivity.hpp` / `connectivity.cpp`（`namespace ds::sysinfo`）：
  - **值模型**：`ConnectivityTarget`（單目標：reachable / latency_ms / loss_pct /
    dns_resolvable，各帶獨立 valid 旗標）、`ConnectivitySample`（整體 online + online_valid、
    各目標讀值、整體 valid）。
  - **純邏輯自由函式**（獨立可測、平台中立純算術）：
    - `loss_pct_from_counts(sent, received)`＝(sent-received)/sent*100；防護：sent==0→0、
      received>=sent→0（不謊報 / 保守夾住）。
    - `online_from_targets(sample)`＝任一目標有效可達即 online；無任一有效可達性讀值時回
      `{valid=false}`（不謊報 online / offline）。
  - **來源抽象**：`ConnectivitySource::sample()→ConnectivitySample`；相位 1 只有注入式
    `NullConnectivitySource`——**永不含平台探測**。支援**固定**用法（`set_sample` /
    `set_online` / `set_target`，單元素固定快照）與**序列**用法（`set_sequence` /
    `push_sample`，逐份推進、列盡回最後一份，模擬連通性隨時間變化）；空列預設回無讀值。
  - **提供者** `ConnectivityProvider : ds::metrics::MetricProvider`：`register_metrics()`
    掛上**五個**指標——`net.connectivity.online`（單一實例、整體連通性、range
    bounded(0,1)）、`net.connectivity.reachable`（bounded(0,1)）、`net.connectivity.latency`
    (unit "ms"、at_least(0))、`net.connectivity.loss`（unit "%"、bounded(0,100)）、
    `net.connectivity.dns`（bounded(0,1)）；後四者以**每探測目標**為可列舉實例（同名、
    首見序、各保留歷史環）。`sample()` 重新讀來源更新各實例（有效值推入歷史，新目標動態
    新增實例、消失者設未知不污染歷史）；`sampling_tier()` 回建議採集分級（預設 Normal），
    供 `SamplingScheduler::add_demand`。bool 面向以 1.0 / 0.0 表達（配合 bounded(0,1) 可正規化）。
- `CMakeLists.txt`：`add_library(e2_20 STATIC connectivity.cpp)`；**PUBLIC 連上游
  `e2_01` `e2_02`**；`add_executable(test_e2_20 …)` + `add_test(NAME e2_20)`。

### 測試 `tests/e2/test_e2_20.cpp`（gtest，27 案例 / 101 檢查）
涵蓋：純函式 `loss_pct_from_counts`（比率 + 防護）與 `online_from_targets`（任一可達 /
全不可達但有效 / 無有效讀值未知）、提供者身分與 `metric_ids`、五指標註冊（單位 / 範圍）、
online 單一實例與逐目標實例列舉、**連通 / 斷線**、**延遲 ms**、**封包遺失率 %**、
**多目標可達性**、**DNS 可解析**、各面向獨立誠實 invalid、online 面向未知但目標有效、
**整體無讀值誠實 invalid**、目標上線 / 下線（消失者未知、不縮減、不污染歷史）、
**null 來源**（空 / 固定重複 / 序列推進 / reset / 無 source 仍註冊）、**經 E2-02 採樣**
（排程驅動 + 除頻合併至最高頻）、重複註冊保守拒絕、消費者只走 E2-01 抽象介面、
sample() 未 register 前為 no-op。

## Layer / Phase 合規
- module 層平台中立純邏輯：**無 `#ifdef` / win32 / cocoa / socket / ping / getaddrinfo /
  真實網路探測**（原始碼僅於註解中敘明「不含」這些）。
- 相位 1（Mac / null 期）：只寫介面 + 注入式 null / 假來源；真實後端另實作
  `ConnectivitySource`，提供者一行不動。
- 誠實 invalid：各面向 / 整體無讀值皆以 valid==false 表達，不謊報 0 / 不謊報 online。

## Risk
low — 純新增單元，僅消費 E2-01 / E2-02 既有契約（可讀不可改），不改上游 / 根建置 /
其他單元。指標 id 命名空間 `net.connectivity.*` 與既有 `net.*`（E2-08）無碰撞。
