# CHG-20260724-e4_20 — 向量圖形（E4-20）

- Date: 2026-07-24 | Branch: feat/e4_20 | Risk: low | Implemented by: I1.107
- Skill: ai-sdlc-autopilot
- Unit: E4-20（向量圖形，module 層 / 子系統 elements / phase 1 / low）
- depends_on: E1-03（逐像素 alpha surface）

## Motivation

桌面元件需要以向量方式描述圖示 / 裝飾圖形（路徑、矩形、圓、多邊形、線段），供日後繪製層
畫出可縮放、不失真的圖形。相位 1 只需一個**平台中立、可單元測試**的「向量渲染描述模型」——
把 moveto/lineto/curveto 路徑指令與基本形狀轉換為一份含樣式的描述，供繪製層日後消費。

若此階段就綁真實繪圖 API（座標、像素、z-order），將無法在單元測試中重現，也違反 module 層
「平台中立、換平台不動邏輯」與 NFR-02（無絕對座標 / 無數字 z-order）。E4-20 因此只產出
**渲染描述**：本地座標系的路徑指令序列 + 樣式，全程無真實繪製。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 路徑累積 | `VectorPath`：`move_to/line_to/curve_to/close` | 對應 SVG/PDF 式路徑文法，語意清楚 |
| 路徑合法性 | `line_to`/`curve_to`/`close` 前必須先 `move_to`；已 `close` 未再 `move_to` 前不可再操作 | 「無效路徑(未 move 先 line)」不靜默：回 `Invalid`、不追加指令 |
| 座標系 | 所有頂點/控制點為元件**本地座標系**（`Point{x,y}`），非螢幕像素 | NFR-02：同一份路徑可放到畫面任意位置，位置換算是繪製層的事 |
| 順序 | 指令 / 頂點的先後即連線順序（語意順序） | NFR-02：不提供任何數字 z-order 欄位 |
| 基本形狀 | `Shape{Rect,Circle,Polygon,Line}`（`kind` 標記）+ `build_shape_path()` 轉為路徑指令 | 統一介面涵蓋四種基本形狀，內部各自組出對應指令序列 |
| Rect | MoveTo + 3×LineTo（矩形四角）+ Close | 標準矩形路徑 |
| Circle | MoveTo + 4×CurveTo（三次貝茲圓弧近似，kappa≈0.5522847498）+ Close | 貝茲曲線精確度足夠、示範 `curve_to` |
| Polygon | MoveTo(v0) + LineTo(其餘頂點) + Close | 依序連線；順序即連線順序，非 z-order |
| Line | MoveTo(from) + LineTo(to)，**不** close | 線段無面積，不可視為可填色的封閉形狀 |
| 退化形狀 | 零/負寬高矩形、零/負半徑圓、<3 頂點多邊形、零長度線段 → `Invalid`，不寫入輸出 | 明確不靜默；不產出無意義的渲染描述 |
| 描邊/填色 | `StrokeStyle{enabled,width,paint}` / `FillStyle{enabled,paint}`；`paint` 沿用 E1-03 `AlphaProfile` | 顏色的合成描述複用上游，避免重造輪子；opacity 為比例符合 NFR-02 |
| 描邊寬度 | 本地單位（非像素）；`enabled=true` 時須 > 0，否則 `Invalid` | 啟用描邊卻寬度非正無意義 |
| 非有限值 | 座標 / 寬高 / 半徑 / 不透明度為 NaN/Inf → `Invalid`，不套用 | 不靜默改成預設值 |
| render_model | `VectorRenderModel{commands, stroke, fill, empty}` | 空路徑 `empty=true`，明確不靜默假裝有資料 |

平台中立：無 `#ifdef` / `win32` / `cocoa` / 真實繪圖 API；NFR-02 無絕對座標 / 無數字 z-order。
