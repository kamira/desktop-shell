## Motivation

桌面外殼需要對作業系統層級的事件作出反應：系統睡眠 / 喚醒、顯示器組態變更、
使用者 session 鎖定 / 解鎖、電源狀態變更等。這些是**全域事件**（觸發來源為 OS、
需 per-platform 後端），依 `docs/structure/directory.md` 置於 `src/events/`。

各平台的觸發機制不同（macOS 的 `NSWorkspace` 通知、Windows 的
`WM_POWERBROADCAST` / `WTS` session 通知…），但事件的**語意跨平台一致**。
本單元在相位 1（Mac / null 期）先把這層語意定稿為平台中立介面，讓上層訂閱者
現在就能寫好；相位 2 只需補真實後端，介面與分派語意一行不動。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 事件種類 | `enum class SystemEventType`（Sleep/Wake/DisplayChanged/SessionLocked/Unlocked/PowerStatusChanged） | 跨平台一致的語意集合，各平台以自身機制觸發同一種類 |
| 事件承載 | `SystemEvent{ type, detail }`，`detail` 為平台中立字串 | 不綁任何 OS 原生型別 / 控制代碼，換平台不動 |
| 訂閱模型 | `std::function` 回呼 + `SubscriptionId` 訂閱代號 | 解耦訂閱者；代號供精準解除訂閱 |
| 來源介面 | 抽象 `SystemEventSource`（subscribe/unsubscribe/listener_count） | 相位 2 真實後端只需實作本介面即可 |
| null 後端 | `NullSystemEventSource`，事件由 `inject()` 手動注入 | 不連真實 OS；供測試與相位 1 契約驗證分派路徑 |
| 分派順序 | 依 `SubscriptionId` 遞增（即訂閱順序），以有序 `std::map` 保存 | 順序穩定、可測 |
| 回呼中改動訂閱 | 分派前先取快照 | listener 在回呼內訂閱 / 解除訂閱不影響本輪、避免疊代中改容器的 UB |
| 空 listener / 未知 id | 空 listener 回傳 0（無效訂閱）；未知 id 解除為 no-op 回 false | 呼叫端永遠安全，語意保守 |

介面平台中立：無 `#ifdef _WIN32` 等平台分支、不綁任何真實後端，符合相位 1（Mac/null）約束。
