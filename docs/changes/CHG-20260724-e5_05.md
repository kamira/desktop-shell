## Motivation
E5-05「全域熱鍵註冊」：註冊系統全域熱鍵並於按下時觸發回呼。這是能力閘控項——
`host.global_hotkey` 已於 E1-21 能力矩陣宣告為 optional 且 `default_available=false`
（受平台 / 權限限制可能不存在）。需在相位 1（Mac / null 期）先立好平台中立介面與
null 後端，讓呼叫端能以 `has()` 閘控（NFR-03），相位 2 換真實後端時介面與分派語意一行不動。

## Impact

### 新增 `src/events/e5_05/`
- `global_hotkey.hpp`：
  - `Modifier`（位元旗標：Control / Alt / Shift / Meta，附 `operator|` `operator&` `has_modifier`）與
    `Key`（具名鍵 enum，**非平台掃描碼**）——熱鍵以具名描述，跨平台語意一致。
  - `Hotkey`（modifiers + key，附 `==` / `!=` / `<` 供 map 鍵與去重）。
  - `GlobalHotkeys` 抽象介面：`has()` / `register_hotkey(Hotkey, cb)→HotkeyId` / `unregister(id)`。
    （方法名 `register_hotkey`：`register` 為 C++ 保留字，不可作識別碼。）
  - `NullGlobalHotkeys` null 後端：以建構參數 `available` 模擬平台支援與否；提供
    `inject(hotkey)` 供測試手動注入模擬按下、`count()` / `is_registered()` 查詢。
- `global_hotkey.cpp`：註冊 / 分派 / 解除邏輯。契約：能力不存在→register 回 0；
  無效熱鍵（`Key::Unknown`）/ 空回呼→回 0；同一熱鍵獨佔（重複註冊衝突→回 0）；
  未知 id 解除為 no-op；inject 前先複製回呼，回呼中解除自己安全。
- `CMakeLists.txt`：BUILD.md 樣板（`add_library(e5_05 STATIC)` + `test_e5_05` + `add_test(NAME e5_05)`）。

### 相位 1 約束遵循
- 只有平台中立介面 + null 後端；**無** `#ifdef` / `_WIN32` / win32 / cocoa / RegisterHotKey /
  真實 OS 呼叫（僅在說明註解中引述禁用詞，與 E5-08 慣例一致）。
- 核心 API 無絕對座標、無數字 z-order（NFR-02 不適用本單元）。
- 能力閘控呼叫以 `has()` 保護（NFR-03）——測試含 has()-先閘控樣式。
