# CHG-20260724-e1_16 — 螢幕邊緣熱區（E1-16）

- Date: 2026-07-24 | Branch: feat/e1_16 | Risk: low | Implemented by: I1.128
- Skill: ai-sdlc-autopilot
- Unit: E1-16（螢幕邊緣熱區，platform 層 / kernel / low / 承重 1x，depends_on=[E1-04]）

## Motivation

多桌面 / 視窗管理情境常見「滑到螢幕邊緣或角落觸發動作」的互動（如滑到左邊緣拉出側欄、
滑到角落觸發某效果）。這需要一組平台中立的**具名邊/角熱區**定義與判定：以**螢幕比例**
表達熱區厚度、以**具名邊/角**（非數字方位）指涉，並複用上游 E1-04 的幾何命中測試能力，
避免重造矩形點內判定邏輯。

相位 1（Mac / null 期）尚無真實滑鼠事件迴圈：只提供「註冊 + 判定」的純資料/幾何介面，
不執行實際動作（動作執行留給呼叫端，依觸發結果自行決定行為）。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 邊/角指涉 | 具名 `EdgeHotZone`（8 個具名列舉值：Left/Right/Top/Bottom/TopLeft/TopRight/BottomLeft/BottomRight） | NFR-02 禁止絕對座標與數字方位；具名跨平台一致 |
| 熱區厚度 | `thickness_ratio`（0 < ratio <= 1，相對螢幕尺寸） | 換螢幕尺寸不失真，避免絕對像素座標 |
| 螢幕表達 | `ScreenExtent{width, height}`（僅尺寸，非桌面絕對位置） | 與 E1-04 `Shape` 的 width/height 同語意，非 NFR-02 禁止的絕對座標 |
| 幾何判定 | 複用 E1-04 `HitTester::hit_test` + `make_rect`，換算熱區矩形後平移點座標判定 | 避免重造矩形點內判定；符合「用 E1-04 判定」的單元語意 |
| 命中優先 | 角落熱區優先於邊熱區；同類別中較晚註冊者為準 | 直覺互動語意（角落通常是更精確的意圖）；與 E1-04 topmost 的宣告順序精神一致 |
| 動作表達 | `HotZoneAction`（具名字串標籤），本單元只回報觸發、不執行 | 相位 1 無真實 UI 可觸發；動作語意留給呼叫端 |
| 無效輸入 | `register_zone` 回結構化 `HotZoneStatus`（`InvalidZone` / `InvalidThickness`），拒絕註冊 | 報錯不靜默；無效設定不該悄悄變成「永不觸發」的熱區 |
| 無效幾何輸入（`test`） | 螢幕尺寸 / 點非有限或非正 → 回 `nullopt` | API 形狀固定為 `optional<觸發熱區>`；幾何前提不成立時「無熱區可觸發」是自然結果，設定期錯誤已由 `register_zone` 把關 |

介面平台中立：無 `#ifdef _WIN32` 等平台分支、不綁任何真實後端、無滑鼠事件迴圈整合，
符合相位 1（Mac/null）與 NFR-02 約束。

## Impact

### 1. `src/kernel/e1_16/edge_hot_zone.hpp`（新增）
- `EdgeHotZone`（8 個具名邊/角）、`ScreenExtent`、`HotZoneAction`、`HotZoneStatus`、
  `TriggeredHotZone`、`is_named_zone()`。
- `EdgeHotZoneRegistry`：`register_zone()` / `test()` / `size()`。

### 2. `src/kernel/e1_16/edge_hot_zone.cpp`（新增）
- 熱區矩形換算（依邊/角 + ratio + 螢幕尺寸算出矩形原點與範圍）。
- 用 E1-04 `HitTester::hit_test` 判定平移後的本地點是否落入矩形。
- 角落優先於邊、同類別後者為準的命中選擇邏輯。
- 無效邊 / 無效厚度拒絕註冊（`HotZoneStatus` 非 Ok）。

### 3. `src/kernel/e1_16/CMakeLists.txt`（新增）
- `add_library(e1_16 STATIC edge_hot_zone.cpp)` + `target_link_libraries(e1_16 PUBLIC e1_04)`
  + `test_e1_16` executable + `add_test(NAME e1_16)`，依 BUILD.md 樣板；根 CMakeLists 自動
  glob 收入。

### 4. `tests/e1/test_e1_16.cpp`（新增）
- 19 個 gtest 案例：四邊熱區觸發、四角熱區觸發、厚度比例換算（含全覆蓋 ratio=1.0）、
  邊界情形（含邊界 / 剛超出）、多熱區（同邊重複註冊後者為準、多個不同熱區並存）、
  角落優先於邊（含無角落註冊時退回邊）、無效邊 / 無效厚度（非正、超過 1、非有限值）
  報錯不靜默、不同螢幕尺寸下 ratio 換算出不同絕對熱區、無效螢幕尺寸回 `nullopt`。

### 5. `docs/structure/units/e1_16.md`（新增；G4 要求）
- 本單元獨立結構註記（不動共用 `docs/structure/directory.md`）。

## 不含（避免越界）

- **不執行任何真實動作**（開側欄 / 顯示 Dock 等）；本單元只回報「觸發了哪個具名熱區」，
  相位 1 無真實 UI / 事件迴圈可整合。
- **不實作任何真實平台後端**（win32/cocoa）；純幾何 + 資料註冊，無真實滑鼠事件來源。
- **無任何絕對像素座標 / 數字 z-order / 數字方位 API**（NFR-02）；一律具名邊/角 + 相對比例。
