## Motivation
C1-03「氣球 profile」：角色說話的**對話氣球**（亦適用一般氣泡通知）——掛在一個角色立繪
（C1-02）旁，顯示一段**逐字顯示**的文字，存活一段（邏輯）時間後**自動消失**，也可提早手動
關閉。這是一個**組裝型 artifact 單元**：不新增引擎邏輯，而是把三個已合併的擴充點（E4-11
逐字顯示、E1-14 短暫生命週期、E1-11 依附角色的相對定位）組成單一「氣球」應用 profile + 行為
（`show_balloon` / `advance` / `dismiss` / `resolve`）。相位 1：純資料 / 邏輯組裝，無真實
GUI，注入式 tick，平台中立。

實作前以 `ls` / 讀檔確認上游實際路徑：E1-11（`src/kernel/e1_11/subordinate_layout.hpp`，
從屬 surface 相對定位——子以具名 anchor 相對父已解析矩形定位，父移動子跟隨、父關閉子連帶）、
E1-14（`src/kernel/e1_14/transient_profile.hpp`，短暫 profile 生命週期——建立時登記 E5-10
一次性逾時，時間到自動過期或手動 `expire()`）、E4-11（`modules/elements/e4_11/typewriter_element.hpp`，
逐字顯示——以注入式 `advance(dt)` 推進「目前顯示到第 N 字」並委派 E4-01 對前綴子字串排版）、
C1-02（`content/profiles/c1_02/portrait_profile.hpp`，立繪 profile，剛合併，作為本單元的依附
對象與組裝範式參考）。

**實作中發現一個既有上游命名碰撞**（不可修改上游解決）：E1-14 `transient_profile.hpp` 經
`#include "input_strategy.hpp"`（E1-02）於 `ds::kernel` 宣告 `enum class HitResult`；C1-02
`portrait_profile.hpp` 經 E5-14 → E5-01 傳遞 `#include "hit_test.hpp"`（E1-04）於**同一**
`ds::kernel` 命名空間宣告**另一個不同型別**的 `struct HitResult`。本單元是**第一個**同時需要
E1-14 與 C1-02 的合併單元，兩者標頭若同時 `#include` 進同一翻譯單元會編譯失敗（本機以 g++
實測重現：`use of 'HitResult' with tag type that does not match previous declaration`）。查得
已合併的 `content/profiles/c1_06/`（Dock profile）已記錄並解決過**完全相同**的碰撞（E1-02 對
E1-16 經 `hit_test.hpp` 傳遞的 `HitResult`），採用「不透明橋接層 + pimpl」把其中一條上游
include 樹隔離到獨立翻譯單元。本單元沿用相同手法（見 Impact）。

## Impact

### 新增 `content/profiles/c1_03/`
- `balloon_profile.hpp` / `.cpp`：`namespace ds::profiles`，`class BalloonProfile`。
  - 每個實例代表一個具名氣球，內部自持三份純記憶體 / 純邏輯服務（不需注入後端）：本氣球
    專屬的 E5-10 `TimeoutTimer` + 綁定其上的 E1-14 `TransientProfileManager`（各氣球獨立
    計時，互不干擾，天然支援多氣球同時顯示）、E1-11 `SubordinateLayout`（僅記錄本氣球自身
    一筆附著）、E4-11 `TypewriterElement`（綁定注入式 `FontMetrics&`，承 E4-01 慣例，不取得
    其所有權）。
  - `show_balloon(character, text, ttl, spec)`：依附一個**已載入**的 C1-02 `PortraitProfile`
    角色（未載入 → `Invalid`）。前置條件驗證（空 id / 空文字 / 已顯示中 / ttl 為 0）→
    `Invalid` / `AlreadyShowing`，不改狀態。成功依序：E4-11 設文字（進度歸零）→ E1-11 依附
    角色（具名 anchor + 相對偏移，預設角色頭頂上方 `TopCenter` + 向上偏移，任一步失敗回滾）
    → E1-14 登記 ttl tick 存活計時 → `Ok`，`state()` 轉 `Showing`。
  - `advance(dt)`：先推進 E1-14 存活計時（可能同步觸發本次逾時自動消失），仍顯示中才推進
    E4-11 逐字進度（消失當下不再推進文字）。未顯示中 no-op。
  - `dismiss()`：手動觸發 E1-14 `expire()`（Manual 到期），與逾時自動消失共用同一條收尾路徑
    （`teardown_display()`：解除依附、逐字進度歸零、`state()` 轉 `Hidden`）。未顯示中 → false。
  - `resolve(character_placement, balloon_size, out)`：純委派 E1-11 `resolve_child`——角色
    矩形每次呼叫皆可不同，藉此達成「角色移動氣球跟隨」，不快取結果。
  - 查詢：`visible_count()` / `total_count()` / `is_text_complete()` / `render_model()` /
    `remaining()` / `anchor_parent()`，未顯示中一律回安全預設值（0 / true 不成立 / 空渲染 /
    `nullopt` / 空字串）。
  - 具名狀態 / 結果列舉：`BalloonState`（Hidden / Showing）、`BalloonStatus`（Ok / Invalid /
    AlreadyShowing），各附 `to_string()`（NFR-02）。
- `character_bridge.hpp` / `.cpp`：**內部橋接層**（沿用 `content/profiles/c1_06/dock_hot_zone_bridge.*`
  手法解決上述命名碰撞）——`character_bridge.cpp` 是本單元**唯一** `#include "portrait_profile.hpp"`
  之處，暴露中立函式 `detail::character_snapshot(character, out_id)`（已載入 → 回 true 並填
  `out_id`；未載入 → 回 false）。`balloon_profile.hpp` 只前置宣告 `PortraitProfile`（透過此
  橋接層標頭），不直接 `#include "portrait_profile.hpp"`；E1-14 `TransientProfileManager` 的
  實際串接則以 pimpl（`BalloonProfile::Impl`，完整定義於 `balloon_profile.cpp`）隔離，讓
  `balloon_profile.hpp` 也不需 `#include "transient_profile.hpp"`。兩處隔離合力確保
  `ds::kernel::HitResult` 的兩個不同定義（E1-02 `enum class` / E1-04 `struct`）永不同時出現
  在同一翻譯單元。
- `CMakeLists.txt`：`add_library(c1_03 STATIC balloon_profile.cpp character_bridge.cpp)` +
  `target_link_libraries(c1_03 PUBLIC e1_11 e1_14 e4_11 c1_02)` + `test_c1_03`
  （`tests/c1/test_c1_03.cpp`）+ `add_test(NAME c1_03)`。

### 新增 `tests/c1/test_c1_03.cpp`（gtest，21 案例）
涵蓋：組裝（建構預設，`Hidden` 狀態下各查詢的安全預設值）、`show_balloon`（依附角色 + 逐字
內容 + 存活計時三方一次到位）、E4-11 逐字推進（`advance` 依速度逐步顯示、完成後安全 no-op、
未顯示中 no-op）、E1-14 計時消失（注入 tick 推進跨過 ttl 即自動消失、單次大幅推進跨過 ttl 仍
消失、`remaining()` 倒數、消失後可重新顯示）、E1-11 定位 / 跟隨（預設錨點角色頭頂上方之精確
數值、角色矩形改變後重新解析即「跟隨」、自訂 anchor spec 覆寫預設）、`dismiss`（手動提早結束、
重複 `dismiss` 不靜默拒絕、`dismiss` 後可重新顯示且進度歸零）、多氣球（各自獨立計時 / 內容，
一顆消失不影響另一顆）、空文字（拒絕顯示）、以及各類無效輸入（空 id、角色未載入、ttl 為 0、
已顯示中重複顯示、自附（角色與氣球同名）、無效 anchor spec）、具名結果字串。
