# CHG-20260724-e9_05 — 佈局存檔與還原（E9-05）

- Date: 2026-07-24 | Branch: feat/e9_05 | Risk: low | Implemented by: I1.78
- Skill: ai-sdlc-autopilot
- Unit: E9-05（佈局存檔與還原，engine 層 / package 子系統 / 相依 E7-12）

## Motivation

桌面殼需要把「目前佈局」——哪些元件、各自的位置 / 大小 / 設定——存成具名檔（profile），
日後可還原重建。E7-01 提供宣告式格式根契約、E7-12 提供把值序列化回宣告式文字的能力；
本單元站在二者之上，定義**佈局狀態的抽象資料模型**與**具名存 / 取 / 列舉 / 刪除**，
序列化完全走 E7-12（`serialize`），不自造格式。

相位 1 平台中立：佈局狀態以抽象資料（`LayoutState`）表示，持久化走**可注入的儲存後端**
（`LayoutStorage` 抽象；預設 `MemoryLayoutStorage` 純記憶體），無任何真實檔案 I/O、
無 `#ifdef` / 平台分支。真實磁碟後端留待後續相位（只需另實作 `LayoutStorage`）。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 佈局模型 | `LayoutState { vector<LayoutElement> }`；`LayoutElement { id, type, Value properties }` | 保序、抽象、平台中立；捕捉「哪些元件 + 各元件屬性」 |
| 位置 / 大小 / 設定 | 一律收進宣告式 `properties`（`ds::format::Value` 的 Map），存檔器對其不透明 | **NFR-02**：核心 API 面不出現絕對座標欄位與數字 z-order；座標語意由呼叫端決定 |
| 序列化 | `serialize_layout` → E7-12 `serialize(root, kLayoutFormat)`；產出即 E7-01 可再解析文字 | 不重造格式；round-trip 不變式由 E7-01/E7-12 保證 |
| 反序列化 | `deserialize_layout` → E7-01 `parse` → 重建 `LayoutState` | 型別化一致還原 |
| 儲存後端 | `LayoutStorage` 抽象介面（put/get/has/erase/names）+ `MemoryLayoutStorage` 記憶體實作 | 相位 1 平台中立、可注入、可測；後續相位換磁碟後端不動核心 |
| 存檔器 | `LayoutStore(LayoutStorage&)`：`save/load/list/remove/contains` | 多具名 profile 的管理面；不擁有後端生命週期 |
| 覆寫 | `save` 同名 → 覆寫（後端 `put`），列舉不重複 | 存檔語意：具名槽位 |
| 錯誤模型 | 查無佈局（load / remove）、空名稱、解析 / 結構違反 → throw `std::runtime_error`（可定位） | 承 NFR-04「不靜默失敗」；絕不回傳空佈局掩蓋錯誤 |
| 列舉順序 | `MemoryLayoutStorage` 以名稱字典序（`std::map`） | 穩定、可測 |

介面平台中立：無平台分支、不綁真實後端、無真實檔案 I/O，符合相位 1（Mac/null）。

## 影響分析

- 新增單元，僅新增 `engine/package/e9_05/**` 與測試；不改上游、不改 root CMakeLists。
- 相依：`target_link_libraries(e9_05 PUBLIC e7_12)`（E7-01 經 e7_12 PUBLIC 傳遞）。
- 下游可在此之上做「佈局管理 UI / 命令」等；本單元僅負責存 / 取 / 列舉 / 刪除與序列化。

## 測試（tests/e9/test_e9_05.cpp，GoogleTest，16 例）

- 存檔→還原往返一致（含整數 / 浮點 properties 型別保真、空佈局、純函式往返）。
- 序列化用 E7-12：輸出首行 `format_version`、為 E7-01 可再解析的宣告式格式。
- 多具名 profile 相互獨立；列舉全部名稱（字典序）；`contains`。
- 刪除；覆寫既有（列舉不新增）。
- 查無佈局明確報錯（load / remove）、空名稱報錯、文字損毀 / 缺必要欄位 / elements 型別錯報錯。
- Null properties 視為空 Map 的往返。

本機驗證：`g++ -std=c++17 -Wall -Wextra` 連 E7-12 / E7-01 上游 .cpp + gtest 墊片，零警告、16/16 通過。
