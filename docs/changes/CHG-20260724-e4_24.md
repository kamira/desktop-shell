# CHG-20260724-e4_24 — 反鋸齒與內距（E4-24）

- Date: 2026-07-24 | Branch: feat/e4_24 | Risk: low | Implemented by: I1.113
- Skill: ai-sdlc-autopilot
- Unit: E4-24（反鋸齒與內距，engine 層 / 子系統 render / phase 1 / low）
- depends_on: E1-03

## Motivation

渲染層繪製桌面元件前，需要一組共通的**反鋸齒（anti-aliasing）與內距（padding / inset）
渲染設定**：邊緣要以什麼模式柔化（不做 / 灰階 / 次像素）、以多高品質取樣、內容區要留多少
內距。目前缺此宣告式設定基座，各處若各自約定容易不一致，也難以驗證。

E4-24 提供 `ds::render::RenderStyle{aa, quality, insets}` 作為宣告式輸入，與
`RenderStyleService::apply()` / `render_model()` 作為驗證 + 正規化服務：輸出一份可直接
供渲染層消費的 `RenderModel`（內距一律已解析為正規化比例）。本單元**純渲染設定邏輯**，
不繪任何實際像素、不綁真實繪圖 API。內距遵循 NFR-02：一律以**正規化比例**或**具名間距
權杖**表達，不用絕對畫面座標、不用數字 z-order。無效輸入（未知列舉值、非有限值）一律
以 `RenderConfigStatus::Invalid` 明確報錯，不靜默。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 反鋸齒模式 | `AntiAliasMode`{None, Grayscale, Subpixel}（具名列舉） | 語意清楚，非數字碼 |
| 渲染品質 | `RenderQuality`{Low, Medium, High}（具名等級） | 供反鋸齒取樣等成本/畫質權衡，非數字碼 |
| 內距表達 | `InsetValue`{unit, proportion, token}：`InsetUnit::Proportion`（[0,1] 正規化比例）或 `InsetUnit::Named`（`SpacingToken`） | NFR-02：兩種表達皆與絕對像素無關；呼叫端可依情境擇一 |
| 具名間距 | `SpacingToken`{None,XSmall,Small,Medium,Large,XLarge} → `resolve_spacing_token()` 固定查表換算為正規化比例 | 具名等級與容器實際尺寸解耦，換算結果單調遞增 |
| 內距容器 | `Insets`{top,right,bottom,left} + 工廠 `none()`/`uniform()`/`symmetric()` | 對稱慣用內距免逐側手填 |
| 輸入/輸出分離 | `RenderStyle`（未驗證輸入）vs `RenderModel`（已驗證/已解析輸出） | 呼叫端讀 `RenderModel` 恆得到合法、已正規化的資料，不必重複驗證 |
| 驗證/套用服務 | `RenderStyleService::apply(style)` → `RenderConfigStatus`；`render_model()` 唯讀查詢目前設定 | 呼應 E1-03 `AlphaSurfaceService` 的服務層精神：驗證後才落地，失敗不留半份狀態 |
| 越界比例 | 有限但超出 [0,1] → **夾限**（非錯誤），與 E1-03 opacity 同精神 | 越界通常是上游計算誤差，夾限比拒絕更符合使用情境 |
| 非法輸入 | 非有限值（NaN/Inf）、未知列舉值（含被 `static_cast` 硬轉出範圍者）→ `Invalid`，不更新目前設定 | 明確報錯不靜默；`apply()` 失敗時原子性（保留前一份合法設定） |

平台中立：無 `#ifdef _WIN32` / `win32` / `cocoa` 分支、不綁任何真實繪圖 API 或 OS。
不含硬編絕對座標 / 數字 z-order（NFR-02）。純函式 + 純資料，確定性、可完全單元測試。

## Impact

### 1. `engine/render/e4_24/render_style.hpp`（新增）
