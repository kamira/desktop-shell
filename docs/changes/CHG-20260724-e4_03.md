# CHG-20260724-e4_03 — 長條 / 進度 / 量表（E4-03）

## Motivation

桌面外殼需要一組把數值視覺化的基礎元件——長條圖 / 進度條 / 量表(gauge)——最終將直接供
CPU/GPU Usage Widget 等資訊元件組合使用。這些元件的共同語意是「把一個數值依範圍映射成
視覺量」：長條映射為長度比例、進度映射為 0–100%、量表映射為角度 / 弧。

相位 1 平台中立、**不做真實繪製**：本單元只產出「**渲染描述模型**」（`RenderModel`）供後續
繪製層消費，介面須乾淨易組合。設定以 E7-03 宣告式變數段落驅動；元件所在位置以 E1-03 的
具名 `SurfaceId` 指涉。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 元件 | `BarElement` / `ProgressElement` / `GaugeElement`，共用基底 `RangedElement` | 三者共享「值↔範圍映射 / 夾限 / 具名佈局 / 顏色 / 標籤」，個別再加專屬語意 |
| 值↔範圍 | `set_range(min,max)` / `set_value(v)`；`value()` / `ratio()` 回夾限後結果 | 超範圍夾限（正常行為）；變更範圍自動重新夾限 |
| Bar | 值→長度 `fill_ratio` ∈ [0,1] | 長條核心語意 |
| Progress | 固定範圍 [0,100]，`set_percent` / `percent`；標籤預設 "N%" | 進度即百分比完成度 |
| Gauge | 弧幾何 `set_arc(start,sweep)`（度）；`angle()=start+ratio*sweep` | 值→角度為量表語意輸出 |
| 渲染描述 | `RenderModel`：kind / 具名 surface+slot / orientation / fill_ratio / 量表角度 / 具名顏色語彙 / 標籤 | 純資料，供繪製層消費；相位 1 不繪製 |
| 設定驅動 | `load_*_config(Value, elem, err)`：先 E7-03 `expand()` 展開變數段落，再填欄位 | 宣告式「宣告一次、處處引用」；直接消費上游 E7-03 |
| 錯誤 | 非有限值 / 退化範圍 / 退化弧 → `std::invalid_argument`；設定型別不符 / 展開失敗 → `ConfigStatus`（帶訊息） | 不靜默失敗（NFR-04 精神） |

### NFR-02 遵循（無絕對座標 / 數字 z-order）

`RenderModel` **刻意不含任何 x/y / 寬高像素 / 整數層級**欄位：
- 位置：具名 `surface`（`ds::kernel::SurfaceId`）+ 具名 `slot`（佈局槽）。
- 尺寸 / 進度：`fill_ratio` ∈ [0,1] 比例。
- 量表：`angle_degrees` 落在宣告弧 [start, start+sweep] 內——值→角度的語意輸出，非版面座標。
- 顏色：具名 / 語意色彩語彙（如 "accent" / "muted"），非 RGB 數字座標。
