## Motivation

桌面外殼需要一個「徑向線 / 指針(needle/pointer)」視覺元件——從中心以某角度延伸的一條線，
即量表指針 / 時鐘指針的核心語意——最終將直接供 CPU/GPU Usage Widget 等量表(gauge)元件的
指針部分組合使用。核心映射與 E4-03 的 Gauge 相同（值 → 角度），但輸出聚焦於「指針本身」
的幾何：一條線（長度 / 粗細比例），而非一段弧 / 填充區。

相位 1 平台中立、**不做真實繪製**：本單元只產出「**渲染描述模型**」（`RenderModel`）供後續
繪製層消費，介面須乾淨易組合。設定以 E7-03 宣告式變數段落驅動；元件所在位置以 E1-03 的
具名 `SurfaceId` 指涉。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 元件 | `RadialPointerElement` | 單一元件即涵蓋「值↔範圍、夾限、弧幾何、值→角度、長度/粗細比例、顏色、具名佈局」全部語意 |
| 值↔範圍 | `set_range(min,max)` / `set_value(v)`；`value()` / `ratio()` 回夾限後結果 | 超範圍夾限（正常行為）；變更範圍自動重新夾限。與 E4-03 RangedElement 同語意，但本單元僅依賴 E1-03/E7-03（不依賴 E4-03），故自成一套實作 |
| 角度 | `set_angle_span(start,sweep)`（度）；`angle()=start+ratio*sweep` | 值→角度為指針語意輸出；API 名稱依規格採 `set_angle_span`（語意同 E4-03 Gauge 的 `set_arc`） |
| 指針幾何 | `set_length_ratio(r)` / `set_thickness_ratio(r)`，非有限值報錯，否則夾限至 [0,1] | 長度 / 粗細皆為**比例**（相對量表半徑 / 參考粗細），非像素數字 |
| 顏色 | `set_color(name)`，具名語彙（預設 "accent"） | 語意色彩，非 RGB 座標數字 |
| 渲染描述 | `RenderModel`：具名 surface+slot / value_ratio / 弧幾何 / angle_degrees / length_ratio / thickness_ratio / color | 純資料，供繪製層消費；相位 1 不繪製 |
| 設定驅動 | `load_radial_pointer_config(Value, elem, err)`：先 E7-03 `expand()` 展開變數段落，再填欄位 | 宣告式「宣告一次、處處引用」；直接消費上游 E7-03 |
| 錯誤 | 非有限值 / 退化範圍 / 退化角度跨距 / 非有限長度或粗細比例 → `std::invalid_argument`；設定型別不符 / 展開失敗 → `ConfigStatus` | 不靜默失敗（NFR-04 精神） |

### NFR-02 遵循（無絕對座標 / 數字 z-order）

`RenderModel` **刻意不含任何 x/y / 寬高像素 / 整數層級**欄位：
- 位置：具名 `surface`（`ds::kernel::SurfaceId`）+ 具名 `slot`（佈局槽）。
- 指針幾何：`length_ratio` / `thickness_ratio` ∈ [0,1]（比例，非像素）。
- 角度：`angle_degrees` 落在宣告弧 [start, start+sweep] 內——值→角度的語意輸出，非版面座標。
- 顏色：具名 / 語意色彩語彙（如 "accent" / "needle"），非 RGB 數字座標。
