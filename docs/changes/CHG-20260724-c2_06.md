## Motivation

C2-06「動畫 / 序列圖」是桌面小工具目錄裡的一個**組裝型 widget**（非新引擎邏輯）：播放一組幀
序列動畫（如 GIF / 雪碧圖），可宣告式設定幀來源 / fps / 循環，支援播放 / 暫停與注入式 tick
推進。它把兩個已合併的擴充點組起來——

- **C1-01**（`ds::profiles::SkinProfile`）：本 widget 掛載的**基底**——所有 C2 系列 widget 皆
  以 C1-01 為共用基底（見 `docs/backlog/units.json` 各 C2 單元的 `depends_on`）。本 widget 不
  驅動其載入 / 拖曳等生命週期（呼叫端自行管理該 skin），僅取用其具名 `id()` 作為渲染輸出的
  目標 surface（NFR-02：具名，非數字 handle），代表這個動畫「掛」在該桌面角色 / skin 之上顯示。
- **E4-07**（`ds::elements::FrameAnimationElement`）：幀序列動畫本體——本 widget 內部自持一個
  實例，把宣告式設定（幀清單 / fps / 循環）與播放控制（play/pause/advance/current_frame/
  render_model）皆委派給它。

相位 1：純資料 / 邏輯組裝，無真實 GUI。時間全為注入式 tick（沿用 E4-07），不碰真實時鐘 /
計時器 / 繪製後端。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 掛載方式 | 建構子注入 `ds::profiles::SkinProfile&`（不取得所有權），立即 `set_target(skin.id())` 綁定渲染目標 | `SkinProfile::id()` 於其生命週期內不變，故僅需綁定一次；不驅動 skin 的載入 / 拖曳等生命週期，保持單一職責（widget 只管動畫，不管桌面角色本身的組裝） |
| 設定介面 | `configure(const ds::format::Value&)`：宣告式 Map，欄位 `frames`（List，必填，每項 `{ref, width, height}`）/ `fps`（選填 Number）/ `loop`（選填 Bool） | 承 C1-01 `load_skin(Value)` 與 BUILD.md 的宣告式設定慣例；`frames` 之外的欄位選填、未給沿用目前值（元件預設 fps=1.0、loop=true） |
| 驗證順序 | 先整批驗證 `frames`（每項結構 + 具名值合法性）與選填欄位，全數通過才建構 `MemoryImageSource` 序列並委派 `FrameAnimationElement::set_frames`（其本身亦全有或全無） | 承 E4-07 `set_frames` 「不部分套用」精神；widget 層的驗證失敗與 E4-07 層的驗證失敗都不得使既有設定產生半套用狀態 |
| 播放 / 進度控制 | `play()`/`pause()`/`is_playing()`/`advance(Tick)`/`reset()`/`current_frame()`/`is_finished()`/`frame_count()`/`fps()`/`loop()` 皆為 E4-07 對應介面的薄封裝 | 不重新發明播放狀態機；widget 層只負責「掛載 + 宣告式設定的解讀與驗證」，播放邏輯完全委派 E4-07 |
| 渲染輸出 | `render_model()` 委派 E4-07（進而委派 E4-02），回傳目前幀的 `ImageRenderModel`；未設定幀（空幀）時 `has_source=false`，但 `target` 欄位仍反映已綁定的 skin id | 明確降級不靜默假裝有資料（承 E4-07/E4-02 精神）；目標綁定與是否已設定幀序列彼此獨立，符合「掛載」與「設定」是兩個獨立步驟的語意 |
| 錯誤處理 | `AnimationWidgetStatus`（`Ok`/`Invalid`），附 `to_string()`（NFR-02：具名結果碼） | 與同子系統其餘單元同精神：明確、不靜默 |

介面平台中立：無 `#ifdef _WIN32` / `win32` / `cocoa` 等平台分支、不綁真實時鐘 / 計時器 / 繪製
後端。**NFR-02**：幀來源以具名參照（`ref`）承載，`render_model()` 直接回傳 E4-02 的渲染描述
（正規化裁切 [0,1]、具名 `SurfaceId` 目標、具名縮放模式列舉），本單元未新增任何絕對座標或
數字 z-order。

  `set_fps` / `set_loop`）。其餘方法皆為 E4-07 對應介面的薄封裝。

### 4. `tests/c2/test_c2_06.cpp`（新增）
- 20 個 gtest 案例：空幀降級（未 configure 時 frame_count/current_frame/is_finished/

  reset 皆安全 no-op）、configure 套用幀清單 + fps + loop（含選填欄位省略沿用預設、重新

## 不含（避免越界）

- **不驅動所掛載 C1-01 基底的載入 / 卸載 / 拖曳等生命週期**——那是呼叫端 / C1-01 自身的職責，
  本 widget 只取用其具名 id 作為渲染目標。
- **不綁真實時鐘 / 計時器 / 繪製後端**；時間全由外部注入（`advance(dt)`）。
- 不做真實影像解碼 / 幀圖精靈表切割 —— 沿用 E4-02 / E4-07 相位 1 的「注入式 `ImageSource`」
  抽象，不新增解碼後端。
- 未動根 `CMakeLists.txt`、`units.json`、`docs/structure/directory.md` 或任何鎖定範圍以外的
  檔案。
- 不改上游 C1-01 / E4-07（僅連結使用）。
