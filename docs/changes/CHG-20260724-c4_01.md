## Motivation
C4-01「鍵位速查」（keyboard shortcut cheat sheet）：顯示目前可用快捷鍵清單的速查 HUD
面板，以鍵位 → 說明對應表呈現。這是一個**組裝型 artifact app**：不新增引擎邏輯，而是
把兩個已合併的擴充點組成單一應用 + 行為（`load_shortcuts(清單)` / `show` / `hide` /
`filter`）：

- **C1-04**（`ds::profiles::OsdOverlayProfile`）：面板本身的顯隱生命週期——本單元掛
  （以參考持有，不取得所有權）一個既有 OSD 浮層 profile 當作速查面板的基底，`show()` /
  `hide()` 委派其 `show()` / `dismiss()`（E1-14 短暫生命週期 + E1-01 具名頂層 Overlay
  歸屬皆由 C1-04 負責）。
- **E4-01**（`ds::render::TextLayout`）：把「鍵位 → 說明」清單排成一份渲染描述
  （`LayoutResult`：每個可見鍵位一行），字型度量一律經注入式 `FontMetrics`。

相位 1：純資料 / 文字排版組裝，無真實 GUI 繪製、無真實鍵盤 hook（`ShortcutEntry.keys`
僅為顯示用字串，不做鍵盤事件擷取 / 監聽）。

## Impact

### 新增 `apps/c4_01/`
- `shortcut_cheat_sheet.hpp` / `.cpp`：`namespace ds::apps`。
  - `ShortcutEntry{keys, description}`：一筆鍵位 → 說明對應（純資料）。
  - `ShortcutCheatSheetApp`：以 `ds::profiles::OsdOverlayProfile&`（C1-04，不取得所有權，
    須比本物件活得久）+ `const ds::render::FontMetrics&`（E4-01，同樣不取得所有權）建構。
  - `load_shortcuts(entries)`：覆蓋既有清單。任一項目 `keys` / `description` 為空字串
    → 整批拒絕（`LoadStatus::Invalid`），既有清單不變（不留半份殘留）。空清單合法
    （`Ok`，清空既有內容）。成功且面板顯示中 → 即時刷新面板內容（委派
    `OsdOverlayProfile::update()`）。
  - `filter(query)`：ASCII 大小寫不敏感子字串比對鍵位或說明任一命中即可見；空字串清除
    篩選。面板顯示中同樣即時刷新內容。
  - `visible_shortcuts()` / `display_text()`：篩選後可見清單與其組成的顯示文字（每行
    `"<keys>" + "  -  " + "<description>"`，行間 `'\n'`）。
  - `layout(constraints = {})`：純函式，委派 E4-01 `TextLayout::layout(display_text(),
    constraints)`，與面板是否顯示中無關。
  - `show(ttl)` / `hide()`：委派 C1-04 `panel_.show(display_text(), ttl)` /
    `panel_.dismiss()`，語意（重複顯示回 false、ttl==0 委派 E1-14 拒絕）完全沿用
    C1-04，本層不重複判斷。
  - `shortcut_count()` / `shortcuts()` / `visible_count()` / `filter_query()` /
    `filter_active()` / `is_showing()` / `panel_id()`：內省查詢。
  - `LoadStatus`（Ok / Invalid）附 `to_string()`（NFR-02）。
- `CMakeLists.txt`：`add_library(c4_01 STATIC)` +
  `target_link_libraries(c4_01 PUBLIC c1_04 e4_01)` + `test_c4_01`
  （`tests/c4/test_c4_01.cpp`）+ `add_test(NAME c4_01)`。

### 新增 `tests/c4/test_c4_01.cpp`（gtest，26 案例）
涵蓋：組裝正確（建構預設值）、`load_shortcuts`（多鍵位載入成功並保序、空清單合法、鍵位
/ 說明為空整批拒絕不留殘留）、`filter`（大小寫不敏感比對鍵位 / 說明、清除篩選、無命中、
保序）、`display_text` 格式、E4-01 排版整合（每個可見鍵位一行、行相對偏移 `y = 行索引 ×
行高`、空清單排版結果為空、篩選後排版跟著變、`max_lines` 裁切與 `truncated`）、`show` /
`hide`（成功委派、重複顯示失敗、`ttl=0` 失敗、收起、未顯示即收起失敗、顯示中
`filter`/`load_shortcuts` 即時刷新面板內容、無效載入不改動面板內容）、
`to_string(LoadStatus)` 穩定字串。

### 相位 1 約束遵循
- 純資料 / 文字排版組裝，無真實 GUI 繪製；無平台分支（無 `#ifdef` / win32 / cocoa）；
  無真實鍵盤 hook（`keys` 僅顯示用字串，不擷取 / 監聽鍵盤事件）。
- 核心 API 無數字 z-order / 絕對座標（NFR-02）：面板頂層歸屬委派 C1-04/E1-01 具名處理；
  E4-01 `LayoutResult` 全為相對偏移。
- 無效操作一律明確回具名結果，不靜默（無效鍵位清單整批拒絕、面板已顯示中再次顯示、
  未顯示即收起）。
