# CHG-20260724-e3_05 — 音量設定（E3-05）

- Date: 2026-07-24 | Branch: feat/e3_05 | Risk: low | Implemented by: I1.44
- Skill: ai-sdlc-autopilot

## Motivation
E3-05「音量設定」是 modules/actuators（動作層 / 子系統 actuators）的一個**系統音量致動器**：
把「設定系統音量（0–100）／靜音／取消靜音／相對增減／查詢目前音量」這組副作用，以具名
命令掛上 **E6-01 命令匯流排**（擴充點 3「動作」契約）。呼叫端只需 命令 id + 具名參數即可
觸發，**不需相依本致動器或任何 OS 音訊 API**——與已合併的 E3-02（啟動 / 開檔 / 網頁搜尋
致動器）採同一「注入式後端 + null 樣式」範式。相位 1（Mac / null 期）**絕不呼叫真實 OS
音訊 API**（不含 CoreAudio / MPVolumeView / IAudioEndpointVolume 等），只提供**平台中立
介面 + null / 假後端（純記憶體狀態模擬）+ 契約測試**；真實平台後端留待相位 2，屆時致動器
與命令契約一行不動。

## Impact

### 新增 `modules/actuators/e3_05/`（module 層 / 子系統 actuators）
- `volume_actuator.hpp` / `volume_actuator.cpp`（`namespace ds::actuators`，與 e3_02 一致）：
  - 五個具名命令 id（穩定可讀字串，不用數字 opcode）：`volume.set` / `volume.get` /
    `volume.mute` / `volume.unmute` / `volume.adjust`。
  - `kVolumeMin=0` / `kVolumeMax=100` + `clamp_volume(int)`：致動器層唯一的「合法化」點
    （音量為相對值域 0–100，非絕對座標 / z-order）。
  - `VolumeState` struct：`level`（恆在 [0,100]）+ `muted`；含相等運算子，供查詢 / 內省。
  - `VolumeBackend` 抽象後端：最小介面 `set(level)` / `get()` / `set_muted(bool)` /
    `is_muted()`。相位 2+ 由平台後端以真實音訊 API 實作；致動器只依賴此抽象。契約：
    傳入 `set()` 的 level 已由致動器夾限至 [0,100]（後端可信任）。
  - `NullVolumeBackend`（相位 1 預設後端）：**不接真實系統音訊 API**，以純記憶體狀態
    （音量整數 + 靜音旗標）模擬；初值可注入（預設音量 50、未靜音）；`set()` 亦自夾限；
    `state()` 內省。讓致動器在無真實後端時仍可完整跑通、狀態一致。
  - `VolumeActuator`：建構綁定一個 `VolumeBackend`（預設 NullVolumeBackend）。
    `register_on(bus)` 把五個具名命令註冊到 E6-01 匯流排（全成功才 true；任一失敗回滾
    已掛者、不遮蔽既有致動器；無後端回 false）；`unregister_from(bus)` 回移除數（0..5）。
    處理器亦可直接呼叫（測試不經匯流排也能驗證語意）：
    - `volume.set`：必填 `level`（int）；超出 [0,100] 自動夾限（不失敗）；回夾限後音量。
    - `volume.get`：無參數；回目前音量（int），訊息帶靜音狀態。
    - `volume.mute` / `volume.unmute`：無參數；設 / 清靜音（**不改變音量位階**）；回目前音量。
    - `volume.adjust`：必填 `delta`（int，可負）；以 int64 相加後夾限至 [0,100]（防溢位）；
      回夾限後音量。
    缺 / 型別錯的必填參數 → `CommandResult{Failed}`（以 `has()` / `get_int` 保護，不崩潰、
    不改後端狀態、不丟例外）。所有成功結果的 `value` 皆為夾限後目前音量（int）。
  - `volume_contract_version()`：契約版本標記 `"e3_05/1.0.0"`（定義在 .cpp，使 STATIC
    程式庫非空並集中版本字串；命名加 `volume_` 前綴避免與同命名空間 e3_02 的
    `contract_version()` 衝突）。
  - `CMakeLists.txt`：`add_library(e3_05 STATIC volume_actuator.cpp)` **PUBLIC 連上游
    `e6_01`**（標頭 include `command_bus.hpp`，須傳遞 include 目錄）；
    `test_e3_05`（`tests/e3/test_e3_05.cpp`）+ `add_test(NAME e3_05)`。
- 上游相依：E6-01 命令匯流排（`ds::command::CommandBus` / `CommandArgs` / `CommandResult` /
  `CommandValue`），可讀不可改——消費擴充點 3「動作」契約，不自造匯流排或值型別。
- **無** `#ifdef` / win32 / cocoa / CoreAudio 等真實音訊 API（backend_guard 綠燈）。
  致動器邏輯（夾限、分派、結果回報）與後端完全解耦、純邏輯、平台中立、可注入。

### 測試 `tests/e3/test_e3_05.cpp`（gtest，21 案例）
- 註冊 / 反註冊（4）：五命令全掛、重複註冊回滾且不改既有、null 後端不可註冊、
  unregister 移除全五個且再呼叫回 0。
- 設定 + 分派 + null 後端一致（2）：經匯流排 set 更新後端、get 反映先前 set。
- 範圍夾限（3）：超上限夾至 100、超下限夾至 0（皆不失敗）、`clamp_volume` 邊界。
- 靜音 / 取消靜音（2）：mute → unmute 不改變音量位階、訊息正確；`VolumeState` 配對一致。
- 相對增減（2）：正負 delta、跨越邊界上下夾限。
- 參數驗證（3）：set 缺 level / 型別錯、adjust 缺 delta → Failed 且不改後端狀態。
- 未知命令（1）：匯流排回 NotFound（不崩潰）。
- null 後端序列一致（1）：連續 set / 夾限 / 靜音後狀態一致。
- 直接呼叫處理器（2）：set 語意等價；無後端各處理器回 Failed。
- 契約版本標記（1）。
