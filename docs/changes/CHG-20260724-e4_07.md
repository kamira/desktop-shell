## Motivation

角色動作 / 特效常見「幀序列(sprite/frame sequence)動畫」：一組圖片幀依序輪替顯示，形成如
GIF、雪碧圖(sprite sheet)動畫般的視覺效果。此效果需要兩件事：一個「時間 → 目前應顯示第幾幀」
的推進來源，與一個把「目前幀」轉成可繪製渲染描述的顯示器。E4-09 已提供平台中立的動畫驅動源
（把心跳脈衝轉為時間推進），E4-02 已提供圖片元件（把注入的圖片來源轉成相對佈局渲染描述）。
E4-07 是把兩者組起來的 elements 層元件：`FrameAnimationElement` 以注入式 tick 依 fps 推進
「目前幀索引」，並委由 E4-02 `ImageElement` 對「目前幀」產出 `ImageRenderModel`。相位 1 不接
真實時鐘，一切時間由外部注入（手動 `advance(dt)` 或 `attach()` 一個 E4-09
`AnimationDriver`）。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 幀儲存 | `set_frames` 以值語意複製每幀來源的參照 + 固有尺寸為內部 `MemoryImageSource` 序列，不持有對外部 `ImageSource` 的懸空參照 | 承 E4-02 `set_source` 的值語意慣例：來源物件可於 `set_frames` 呼叫後即銷毀 |
| 進度單位 | 以**幀（frame）**計數；`progress_`（double）累計 `fps * dt`，`current_frame()` 回傳其整數部分 | 支援小數 fps（< 1 幀/tick）：殘餘進度保留累計，累計滿一整幀才前進，不卡住也不漂移（承 E4-11 進度累計模式） |
| fps | `set_fps(fps)`：每 tick 前進幾幀（可小數） | 對外用「fps」直覺對應動畫速率；`<=0` 或非有限 → `Invalid`（不套用，不靜默） |
| 循環 / 單次 | `set_loop(bool)`：循環模式進度以幀數為模（`fmod`）恆繞回；單次模式抵達最後一幀即夾住並標記 `is_finished()==true`，不再前進 | 兩種常見動畫語意（跑步循環 vs. 一次性特效）；單次模式完成後再 `advance` 為安全 no-op（承 E4-11「完成後安全 no-op」慣例） |
| 播放 / 暫停 | `play()`/`pause()`/`is_playing()`；預設暫停（`playing_=false`），需顯式 `play()` | 顯式啟動避免元件建構即隱含播放的意外行為；暫停中 `advance` 為安全 no-op |
| 推進來源 | `advance(Tick dt)` 手動注入；`attach(AnimationDriver&)` 把該驅動源的每次脈衝自動轉呼 `advance(frame.dt)`，回傳其 `AnimationId` | 相位 1 平台中立注入式 tick；`attach` 是 E4-09 整合的薄封裝，不侵入其派發邏輯（承 E4-11 慣例） |
| 顯示整合 | `render_model()` 委由內部 E4-02 `ImageElement`：每次幀索引改變即呼叫其 `set_source(frames_[index_])` 同步目前幀；`set_scale_mode`/`set_opacity`/`set_target` 皆透傳給該內部 `ImageElement` | 不重新發明圖片渲染描述邏輯，直接委派 E4-02；縮放模式 / 透明度 / 目標 surface 對「目前幀」一致套用 |
| 錯誤處理 | 空幀序列、任一幀來源無效 / 尺寸非正、非正 / 非有限 fps → `FrameAnimationStatus::Invalid`（不套用，整批失敗不部分套用） | 承 E4-02 `ImageStatus::Invalid` 精神：明確狀態碼、不靜默、不部分套用 |
| reset / 換幀序列 | `reset()` 只歸零進度（保留幀序列 / fps / loop / 播放狀態）；`set_frames()` 換新幀序列時一併歸零進度與播完旗標 | 換新幀序列理應重新從第 0 幀開始；`reset()` 供「重播同一組幀」情境 |

介面平台中立：無 `#ifdef _WIN32` / `win32` / `cocoa` 等平台分支、不綁真實時鐘 / 計時器 / 繪製
後端。**NFR-02**：`render_model()` 直接回傳 E4-02 的渲染描述（正規化裁切 [0,1]、具名
`SurfaceId` 目標、具名縮放模式列舉），本單元未新增任何絕對座標或數字 z-order。
