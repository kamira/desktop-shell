# CHG-20260724-e7_12 — 設定值寫回（E7-12）

- Date: 2026-07-24 (UTC+0) | Branch: feat/e7_12 | Risk: low | Implemented by: I1.19
- Skill: ai-sdlc-autopilot
- Unit: E7-12（設定值寫回，engine 層 / 描述子系統 / 相依 E7-01）

## Motivation

E7-01 提供宣告式格式的**根契約**（`Value` / `Document` / `FormatVersion` + `parse()` 文字→模型），
但只有「讀」的方向。設定持久化需要**寫回**的另一半：把使用者 / 系統修改後的值，以路徑定位、
更新或新增進宣告式文件，並**序列化回 E7-01 的文字格式**，寫回設定檔。

本單元不自造格式模型——完全消費 E7-01 契約，是「更通用格式」的一個應用（設定持久化）。
核心不變式是 round-trip：`parse` → 改值 → `serialize` → 再 `parse` 得型別化上一致的文件。
屬 engine 層（平台中立純邏輯）：無任何 `#ifdef` / 系統呼叫 / 真實後端，可完全單元測試。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 定位 | `Path` = `PathSegment`（Key / Index）序列 + `parse_path("a.b[0].c")` | map 鍵與 list 索引皆可定位；字串語法便於呼叫端 |
| 寫回語意 | `set_value(root, path, value)` 純函式，回傳**新** Value 樹（不就地改寫） | 與 E7-01 的不可變 Value 值語意一致；原樹不動、易測、無別名副作用 |
| 更新 vs 新增 | 鍵存在則更新；不存在則**附加於尾端**（保序）；缺失中繼段自動建空 Map | 涵蓋「設值」與「新增鍵」；保序讓輸出可重現 |
| list 附加 | 索引 == size 且為最後一段 → 附加 | 支援清單擴充；越界（> size）則明確失敗 |
| 錯誤模型 | 契約違反（型別不符 / 索引越界 / 以索引建缺失容器 / 路徑語法錯）→ throw `std::runtime_error` | 承 E7-01 NFR-04「不靜默失敗」；訊息可定位 |
| 序列化字串引號 | 借 E7-01 `parse_scalar` 反推：凡「裸寫再解析 ≠ 同一字串」者即加引號 + 轉義 | 保證型別 / 內容不因來回而漂移（`"42"`/`"true"`/空字串/前後空白/含換行） |
| 數字序列化 | 整數走 `as_int()`；非整數以 `%.15/16/17g` 取最短 round-trip 表示，且保證帶小數點 | 再解析為相同 `double` 且 `integral` 旗標不漂移（如 `5.0` 不塌成整數） |
| 縮排 | 每層 2 空白，與 E7-01 文件範例一致；輸出即合法再解析輸入 | round-trip 對稱 |

介面平台中立：無平台分支、不綁真實後端，符合相位 1（Mac/null）。engine 層與平台無關
（非 `src/kernel/backend/`，不涉 backend_guard）。

### 已知限制（明確記錄，非靜默）

- **空容器不 round-trip 為同型**：E7-01 文法中 `key:`（其下無更深縮排）解析為 `null`，
  故序列化空 Map / 空 List 會於再解析時塌成 Null。設定寫回實務極少產生空容器。
- **map 鍵不支援引號**：E7-01 的鍵為裸 token，鍵不得含 `:` / 換行 / 前後空白；此為 E7-01
  文法限制，寫回端假設鍵為單純設定鍵名。值（value）無此限制（含轉義字串）。
