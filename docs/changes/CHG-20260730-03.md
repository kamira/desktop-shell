# CHG-20260730-03 — 目錄扁平化：去除 per-unit 代號（slug）層

- Date: 2026-07-30 (UTC+0) | Branch: chore/flatten-structure | Risk: low | Implemented by: I1
- Skill: ai-sdlc-autopilot v1.1

## Motivation
使用者指定（2026-07-28，全部 176 單元合併後執行）：現況每個單元的源碼多包一層代號目錄
（如 `modules/elements/e4_07/frame_animation.cpp`），目標是把源碼直接放在**子系統**目錄下
（`modules/elements/frame_animation.cpp`）。全部單元既已合併，於此一次性重構。

前置修復 **CHG-20260730-02** 已解除 `HitResult` 命名碰撞（移除 C1-03 橋接），故本次扁平化為
**純機械搬檔**，無語意變更。基礎設施 **CHG-20260730-01** 已讓本 infra 分支能跑 G3 全建驗證。

## 可行性（動手前全庫分析確認）
- **include 慣例**：全庫用**裸檔名** `#include "foo.hpp"` + 每 lib `target_include_directories(<lib> PUBLIC ${CMAKE_CURRENT_SOURCE_DIR})`。扁平化後子系統目錄即該 lib 的 include 目錄，`#include` 解析結果**不變**，無需改任何 include 行。
- **零檔名衝突**：全庫掃描確認，任一子系統目錄內扁平化後**無重複 basename**（179 hpp + 176 cpp，皆唯一）。
- **測試不動**：`tests/<module>/test_<slug>.cpp` 本就獨立於單元目錄、以絕對 `${CMAKE_SOURCE_DIR}` 路徑引用，未搬動。

## Impact
### 1) 源碼搬移（`git mv`，355 檔）
19 個子系統的各 slug 單元源碼上移一層：
- platform：`src/kernel/`（23 單元）、`src/events/`（3）、`src/host/`（3）
- engine：`engine/{command,common,events,format,ipc,metrics,package,render,script}/`（共 62）
- module：`modules/{sysinfo,elements,actuators}/`（共 58）
- artifact：`content/`（C3，3）、`content/profiles/`（C1，7）、`content/widgets/`（C2，9）、`apps/`（C4，5）
- 保留 `src/kernel/backend/null/`（後端家族，非 slug 層）原位。

### 2) CMakeLists 合併（19 子系統各一）
原每單元一個 `CMakeLists.txt` → 每**子系統**一個合併檔，逐一保留各單元的
`add_library(<slug> STATIC <裸源碼>)` / `target_include_directories` / `target_link_libraries` /
`add_executable(test_<slug> ${CMAKE_SOURCE_DIR}/tests/…)` / `add_test(NAME <slug>)`。
target 名沿用 slug（`e1_02` / `c2_02` / `test_e1_02`…）**完全不變**，下游 `target_link_libraries` 依賴不受影響。

### 3) root `CMakeLists.txt` GLOB 深度
少一層：`src/*/*/` → `src/*/`、`engine/*/*/` → `engine/*/`、`modules/*/*/` → `modules/*/`、
`content/*/`+`content/*/*/` → `content/`+`content/*/`、`apps/*/` → `apps/`。
保留 `src/*/*/*/`（backend/null）與 `tests/contract/*`。configure 實測收入 21 個 CMakeLists
（19 子系統 + backend/null + tests/contract）。

### 4) 結構文件（G4 同步）
- `docs/structure/directory.md`：新增「目錄扁平化」段（前後對照表 + 慣例說明），修正兩個過時範例路徑。
- 各 `docs/structure/units/<slug>.md` 內文的源碼路徑一律少一層 `<slug>/`（機械對應，語意不變，未逐檔改寫）。

## 明確不改
- 未改任何源碼**內容**（純搬檔）；未改任何 `#include` 行；未改 target 名。
- 未改單元行為 / 測試；未改 units.json（其 `write_scope` 欄位為派工期治理輸入，實作已全數完成，扁平化不回改歷史派工紀錄）。
- 未改 `src/kernel/backend/null/`、`tests/contract/`。
