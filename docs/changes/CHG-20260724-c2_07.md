## Motivation

C2-07「媒體控制」：桌面「媒體控制」widget——經 **E2-13** 注入式 `MetricRegistry` 讀取
「media.nowplaying」指標（曲名 / 演出者 / 專輯 / 播放狀態 / 封面參照），以 **E4-02**
`ImageElement` 把封面參照組裝為圖片渲染描述，並以 **E4-04** `ButtonElement`（播放 / 暫停 /
上一首 / 下一首四顆具名控制按鈕）作為控制元素，其點擊直接觸發 **E3-03**
`MediaControlActuator`（注入式後端，相位 1 為 `NullMediaControlBackend`）的對應命令處理器。
掛 **C1-01**（`SkinProfile`）為桌面基底。這是一個**組裝型 artifact 單元**（非新引擎邏輯）。
相位 1：純資料 / 邏輯組裝，無真實媒體 API、無真實影像解碼。

組裝的五個擴充點：
- **C1-01**（`SkinProfile`）：桌面基底——圖層 / 輸入策略 / 透明外形 / 自由拖曳，本單元不重造，
  以 `base()` 存取。
- **E2-13**（`MediaMetadataProvider` 欄位鍵常數 / `PlaybackState`）：讀「media.nowplaying」
  指標的六個固定欄位實例（狀態 / 曲名 / 演出者 / 專輯 / 進度 / 總長 / 封面，本單元用其中
  state/title/artist/album/artwork 五項）。
- **E3-03**（`MediaControlActuator` / `NullMediaControlBackend`）：控制按鈕點擊直接呼叫其
  `handle_play` / `handle_pause` / `handle_next` / `handle_prev`（不經 E6-01 命令匯流排，直接
  持有致動器）。
- **E4-02**（`ImageElement` / `MemoryImageSource`）：把封面參照組裝為渲染描述。
- **E4-04**（`ButtonElement` / `ButtonRenderModel`）：四顆具名控制按鈕，`on_click` 綁定 E3-03
  致動器命令處理器。

## 上游命名碰撞（施工過程發現，已依既有範式解決）

實作過程中，將 C1-01（`skin_profile.hpp` #include `input_strategy.hpp`，E1-02 於
`ds::kernel` 宣告 `enum class HitResult`）與 E4-04（`button_element.hpp` #include
`hover_tracker.hpp` → `hit_test.hpp`，E1-04 於同一 `ds::kernel` 命名空間宣告**另一個不同
型別**的 `struct HitResult`）同時 `#include` 進 `media_control_widget.hpp` 時，本機以 g++
實測重現編譯失敗：

```
error: use of 'HitResult' with tag type that does not match previous declaration
```

自查發現此碰撞**並非本單元獨有**——已合併的 **C1-06**（`content/profiles/c1_06/`）已先一步
遇到相同碰撞（E1-02 vs. E1-16 transitively 帶入的 E1-04）並確立解法：把「實際觸碰 E1-04 的
那一半」隔離到**獨立翻譯單元**（pimpl 橋接），該橋接層的標頭只用中立值型別、不 include 任何
上游標頭，只有其 `.cpp`（且僅有它）才 `#include` 會觸發碰撞的上游標頭。

本單元依此既有範式，於**本單元 write_scope 內**（未動任何上游檔案）新增：
- `media_control_button_bridge.hpp`：中立化的 `MediaButtonState` / `MediaButtonRenderModel` /
  `MediaControlButtonBridge`（pimpl），不 include `button_element.hpp`。
- `media_control_button_bridge.cpp`：本單元**唯一** `#include "button_element.hpp"` 之處。

`media_control_widget.hpp` 因此改為 `#include "media_control_button_bridge.hpp"`（而非直接
`#include "button_element.hpp"`），得以安全地與 `skin_profile.hpp`（E1-02）共存於同一翻譯
單元。`MediaControlRenderModel` 的四顆按鈕欄位型別相應改為 `MediaButtonRenderModel`（中立
型別，非 `ds::elements::ButtonRenderModel`）。
