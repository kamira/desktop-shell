# CHG-20260724-e4_19 — 旋轉元件（E4-19）

- Date: 2026-07-24 | Branch: feat/e4_19 | Risk: low | Implemented by: I1.138
- Skill: ai-sdlc-autopilot v1.1
- Unit: E4-19（旋轉元件，module 層 / elements 子系統 / 平台無關純邏輯 / low）
- 相依上游：E4-02 圖片元件（已合併，可讀不可改）、E4-22 2D 變形矩陣（已合併，可讀不可改）

## Motivation

許多桌面元件需要「依角度旋轉顯示」的視覺效果——載入中的轉圈圖示、可調轉向的指南針貼圖、
旋轉相框等。E4-22 已提供平台中立的 2D 仿射變形矩陣（`Transform2D`：平移 / 旋轉 / 縮放 /
傾斜 + 組合 + 反矩陣），E4-02 已提供圖片元件（把注入的圖片來源轉成相對佈局渲染描述）。
E4-19 是把兩者組起來的 elements 層元件：`RotatableElement` 讓呼叫端設定旋轉角度、選擇
具名旋轉中心（center/top-left 等九宮格錨點），以 E4-22 `Transform2D` 算出「繞該中心旋轉
該角度」的變形矩陣，並委由 E4-02 `ImageElement` 顯示旋轉對象，兩者一併打包進
`RotatedRenderModel` 供後續相位的繪製層消費。另支援「連續旋轉」（設定角速度 + 以注入式
時間增量 `advance(dt)` 持續累加角度，可跨越多整圈），供轉圈載入圖示一類的動態場景使用。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 角度表達 | 弳度（radians）；`set_angle`/`rotate_by` 皆正規化至 `[0, 2π)` | 元件本身的旋轉語意輸出（NFR-02 合法：非螢幕座標）；正規化避免連續旋轉長時間運行後角度值無界增長 |
| 旋轉中心 | `RotationPivot` 具名九宮格錨點（Center/TopLeft/TopCenter/TopRight/CenterLeft/CenterRight/BottomLeft/BottomCenter/BottomRight），沿用 E2-27 `ScreenAnchor` 的具名錨點精神 | NFR-02：具名，非螢幕像素座標；呼叫端不需知道來源實際尺寸即可指定「繞哪個角/邊/中心轉」 |
| pivot → 旋轉矩陣換算 | 內部依 pivot 對應的比例位置（如 Center=(0.5,0.5)）乘上所綁 E4-02 來源的固有尺寸，得出**內部**支點座標，只用於矩陣計算，不對外暴露任何座標欄位 | 固有尺寸是來源自身資料（同 E4-02 對 NFR-02 的立場），非螢幕擺放位置；換算結果不外流即不違反 NFR-02 |
| 旋轉矩陣計算 | `transform()` = `translate(pivot) ∘ rotate(angle) ∘ translate(-pivot)`（皆呼叫 E4-22 `Transform2D` 具名工廠 + `compose`/`operator*`） | 標準「繞任意點旋轉」仿射公式；未新增數學實作，直接組合 E4-22 既有工廠函式 |
| 未綁來源時的 pivot | 固有尺寸為零 → pivot 換算恆為 (0,0)，等同繞原點旋轉 | 明確、可預期的退化行為（不報錯、不崩潰），呼叫端可先設角度再設來源 |
| 連續旋轉 | `set_angular_velocity(弳度/單位時間)` + `advance(dt)`：`angle += velocity * dt`（正規化）；`rotate_by(delta)` 供一次性疊加 | 支援持續轉動的視覺效果（如 loading 圖示）；沿用 E4-07/E4-11 系列「注入式時間推進」慣例，不接真實時鐘 |
| 錯誤處理 | 非有限角度（`set_angle`/`rotate_by`）、非有限角速度（`set_angular_velocity`）→ `RotateStatus::Invalid`（不套用，維持既有值）；`advance` 對非有限 dt / 零角速度為安全 no-op（不崩潰、不寫入非有限角度） | 承 E4-02 `ImageStatus::Invalid` 精神：明確狀態碼、不靜默、不部分套用 |
| 顯示整合 | `set_source`/`set_scale_mode`/`set_opacity`/`set_target` 等皆透傳給內部 E4-02 `ImageElement`；`render_model()` 回傳 `RotatedRenderModel{ image, transform, angle_radians, pivot }` | 不重新發明圖片渲染描述邏輯，直接委派 E4-02；旋轉資訊另包一層供繪製層取用 |

介面平台中立：無 `#ifdef _WIN32` / `win32` / `cocoa` 等平台分支、不做真實旋轉繪製、不綁真實
時鐘 / 計時器 / 繪製後端。**NFR-02**：角度為弳度語意輸出、旋轉中心為具名列舉、目標 /
縮放 / 裁切 / 透明度沿用 E4-02 既有相對佈局表達，本單元未新增任何絕對座標或數字 z-order
欄位。

## 不含（避免越界）

- **不做真實旋轉繪製**；只計算應套用的變形矩陣（`Transform2D`），交由後續相位的繪製層消費。
- 不接真實時鐘 / 計時器；連續旋轉的時間全由外部注入式 `advance(dt)`。
- 不做真實影像解碼；沿用 E4-02 相位 1 的「注入式 `ImageSource`」抽象，不新增解碼後端。
- 不改上游 E4-02 / E4-22（僅 `PUBLIC` 連結使用）。
- 未動 `units.json`、根 `CMakeLists.txt`、`docs/structure/directory.md` 或任何鎖定範圍以外
  的檔案。
