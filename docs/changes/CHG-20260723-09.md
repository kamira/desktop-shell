# CHG-20260723-09 — G4 結構同步閘門擴及 modules/

- Date: 2026-07-24 (UTC+0) | Branch: claude/ai-sdlc-handshake-validation-380ada | Risk: low | Implemented by: I1
- Skill: ai-sdlc-autopilot v1.1

## Motivation
CHG-08 把 module 層搬到 `modules/` 之後，G4 只判 `^src/`，導致 58 個 module 層單元
**脫離結構同步閘門**（觸發單元由 150 降為 92）。這是治理涵蓋範圍的實質縮小，
且 `docs/structure/directory.md` 的分層對應表同時記錄 `modules/` 的組成，
模組增減若不同步會造成結構文件漂移。

## Impact
`.github/workflows/governance.yml` 的 G4 判定條件：

```diff
- echo "$D" | grep -q '^src/' && ! echo "$D" | grep -q '^docs/structure/' \
-   && { echo "::error::改了 src/ 但沒更新 docs/structure/"; exit 1; } || true
+ echo "$D" | grep -qE '^(src|modules)/' && ! echo "$D" | grep -q '^docs/structure/' \
+   && { echo "::error::改了 src/ 或 modules/ 但沒更新 docs/structure/"; exit 1; } || true
```

這是一次**收緊**（停點契約為 tighten-only，收緊不需放寬審批）。
涵蓋範圍回復到搬移前的水準：

| | CHG-08 前 | CHG-08 後 | 本 CHG 後 |
|---|---|---|---|
| 觸發 G4 的單元 | 150 | 92 | **150**（core 92 + module 58） |

`artifact` 層（`content/**`、`apps/**`，24 項）維持不在 G4 涵蓋內 —— 與搬移前一致，未變動。
