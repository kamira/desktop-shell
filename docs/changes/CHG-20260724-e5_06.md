# CHG-20260724-e5_06 — 滾輪事件（E5-06）

## Motivation

桌面外殼需要處理滑鼠滾輪事件：垂直 / 水平捲動量（delta），並以幾何命中測試（E1-04）
判定事件落在哪個具名 surface，再把事件路由（dispatch）給命中之 surface 的訂閱者。
這是輸入處理的基礎積木之一（與 E5-01 基本滑鼠按鍵事件、E5-02 懸停進出事件同層級），
供上層（如可捲動清單、面板內容區）訂閱使用。

本單元屬 engine 層（平台中立純邏輯）：**不接真實滑鼠 / 滾輪硬體**，事件由呼叫端 / 測試
注入。命中判定完全委由已合併的上游 E1-04 `HitTester::topmost_hit()`，本單元不重新
實作任何幾何邏輯，只負責「滾輪事件語意 + 訂閱 / 路由派發」。相位 2 接真實滾輪後端時，
介面與分派語意一行不動，後端只需把 OS 滾輪事件轉為本地座標 + delta 並呼叫既有
`inject_wheel()` 路徑。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 事件 | `WheelEvent{ delta_x, delta_y, position, target }` | 純資料、平台中立；單一注入同時攜帶垂直（`delta_y`）+ 水平（`delta_x`）捲動量，貼近真實滾輪事件慣例；`position` 用 E1-04 `LocalPoint`（本地 / 相對座標，NFR-02）；`target` 為命中之具名 surface |
| delta 語意 | 原樣傳遞，不裁切 / 不正規化 / 不詮釋正負號 | 單位與方向慣例由呼叫端 / 上層元件決定，本單元只負責路由，不綁定任何捲動策略 |
| 零 delta | 視為合法事件，正常命中路由，不特別過濾 | 保守語意：呼叫端可能因裝置精度發出零值事件，仍應可路由（供上層自行決定是否忽略） |
| 命中判定 | 委由 E1-04 `HitTester::topmost_hit()`，本單元只持有 `std::vector<HitSurface>` | 不重複實作幾何邏輯；具名圖層 + 宣告順序決定 topmost（NFR-02 無數字 z-order），同 E5-01 慣例 |
| 路由 | `WheelEventRouter::subscribe(target, listener)`：訂閱者綁定**特定具名 surface**；只把命中之 surface 的事件分派給其訂閱者 | 「事件路由」語意直接對應命中結果，未命中不分派給任何人 |
| 路由結果 | `enum class WheelRouteStatus { Hit, NoHit, Invalid }` | 報錯不靜默：呼叫端可分辨命中 / 未命中 / 上游命中測試判定形狀無效三種情形；獨立具名（非沿用 E5-01 `RouteStatus`）避免兩單元標頭同時納入時的同命名空間型別衝突 |
| 無配對狀態機 | 每次 `inject_wheel()` 獨立判定、獨立分派，不維護游標 / 序列狀態 | 滾輪語意本身無「配對」概念（不像滑鼠按鍵的 down/up/多擊），無需額外狀態 |
| 分派順序 / 安全 | 依訂閱順序（`SubscriptionId` 遞增）以 `std::map` 保存；分派前取快照 | 順序穩定、可測；與 E5-01 `MouseEventRouter` / E5-02 `HoverTracker` 同慣例，listener 於回呼中訂閱 / 取消訂閱安全 |
| 空 listener / 空 target / 未知 id | `subscribe()` 回 0（無效訂閱，不佔用代號）；`unsubscribe()` 未知 id 為 no-op 回 false | 呼叫端永遠安全，語意保守 |

介面平台中立：無 `#ifdef _WIN32` 等平台分支、不綁任何真實滑鼠 / 滾輪硬體後端，符合
相位 1（Mac/null）約束。engine 層與平台無關（非 `src/kernel/backend/`，不涉
backend_guard）。
