# CHG-20260724-e1_08 — 自由拖曳與位置記憶（E1-08）

- Date: 2026-07-24 | Branch: feat/e1_08 | Risk: medium | Implemented by: I1.152
- Skill: ai-sdlc-autopilot
- Unit: E1-08（自由拖曳與位置記憶，platform 層 / kernel 子系統 / phase=1 / risk=medium / depends_on=[E1-03, E1-07, E7-12] / load_bearing=3）

## Motivation

桌面外殼要讓使用者**自由拖曳** surface（桌寵 / 面板 / 浮層）到任意位置，放開後**記住該位置**、
下次啟動還原。這牽涉三件事：(1) 拖曳過程的狀態機（開始 / 移動 / 放開 / 取消）；(2) 位置以何種
形式表達與儲存；(3) 位置如何持久化跨工作階段。

相位 1（Mac / null 期）為平台中立：**沒有真實視窗拖曳 API**，拖曳事件以注入式呼叫表達。位置
若以絕對像素座標 `(x, y)` 表達會違反 **NFR-02**（核心 API 不得絕對座標 / 數字 z-order），且無法
適應不同解析度 / 容器尺寸。E1-08 因此把位置一律以 **E1-07 anchor 定位模型**（九宮具名錨點 +
容器尺寸正規化偏移）承載，並以 **E7-12 設定值寫回**把記憶位置序列化回 E7-01 宣告式文字格式做
持久化。本單元不自造格式 / 定位模型，純粹**組合**三個上游：E1-03（surface 後端存在性閘控）、
E1-07（宣告式位置 + 落地）、E7-12（設定持久化）。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 位置表達 | 一律以 E1-07 `AnchorSpec`（九宮錨點 + 正規化偏移）承載，**無** `(x,y)` 欄位 | NFR-02 正解；隨容器縮放，不硬編像素 |
| 拖曳狀態機 | `begin_drag` → `drag_to`（可多次，只更新 pending）→ `end_drag`（提交 committed）/ `cancel_drag`（放棄 pending） | 相位 1 無真實視窗拖曳 API，拖曳為注入式事件；pending / committed 分離使「放開才記住」與「取消還原」自然成立 |
| 記憶位置 | committed `AnchorSpec` 即「記憶位置」；`end_drag` 把 pending 提交為 committed | 「放開後記住、下次還原」的直接落地 |
| 後端閘控 | `set_position` / `begin_drag` 以 `backend.has_surface(id)` 閘控（承 E1-03 → E1-24 surface 模型） | 只拖曳真實存在的 surface；給 e1_03 依賴實質角色 |
| 持久化「存」 | `serialize_positions()` 以 E7-12 `set_value`（顯式 Path 段）逐欄寫入設定樹、`serialize` 落回 E7-01 文字 | 消費 E7-12 寫回契約；顯式 Path 段使含 `.` 的具名 SurfaceId（如 `surface.panel`）作為單一鍵不被字串路徑誤拆 |
| 持久化「取」 | `load_positions()` 以 E7-01 `parse` 讀回、逐條驗證後**全有或全無**套用 | round-trip 還原；任一條目不合即整批放棄，不留半套狀態（不靜默） |
| 位置落地 | `resolve_live(id, container, element, out)` 委由 E1-07 `resolve` | 具體像素只在此計算邊界、由呼叫端提供尺寸推導；拖曳中反映 pending |
| 結果碼 | `enum class DragStatus`{Ok, Invalid, NotDragging, AlreadyDragging} | 結構化、平台中立、不靜默；狀態機專屬碼精確回報而非一律 Invalid |
| 錯誤處理 | 空 / 未知 / 未註冊 surface、越界 anchor、非有限 offset、非拖曳中操作、重複 begin、無法解析文字 → 對應結構化碼且不改狀態 | 「無效拖曳 / 位置報錯不靜默」（規格硬項）；不崩潰 |
| 具名 anchor ↔ 名稱 | `anchor_to_name` / `anchor_from_name`（小寫連字號，如 `bottom-right`） | 持久化以**具名角色**存取九宮，非數字（NFR-02）；未知名回 false 不觸碰 out |

### 持久化文字格式（E7-01，經 E7-12 產出）

每個 surface 一個 map 條目，鍵為具名 `SurfaceId`；值為 `{ anchor: <具名>, dx: <正規化>, dy: <正規化> }`：

```
format_version: 1.0
surface.panel:
  anchor: bottom-right
  dx: -0.08
  dy: -0.08
surface.clock:
  anchor: top-center
  dx: 0.0
  dy: 0.02
```

`dx` / `dy` 為**容器尺寸正規化分數**（比例，非像素座標 / 非數字 z-order）；anchor 為具名九宮角色。
round-trip 不變式：`serialize_positions()` 的輸出即 `load_positions()` / E7-01 `parse()` 能再讀回的合法輸入。

## Impact

### 影響分析（medium 風險，load_bearing=3）

- **回溯相容**：純新增單元。未改任何既有 `src` / `engine` / `modules` / 上游單元（E1-03 / E1-07 /
  E7-12 / E7-01 / E1-24 / E1-21）/ `units.json` / 根 CMakeLists / 共用 `directory.md`；對既有單元零影響。
- **上游耦合（medium 的來源）**：本單元**同時**唯讀依賴三個上游、且跨層（platform 的 e1_03 / e1_07
  與 engine 的 e7_12），耦合面比一般 low 單元廣，故評 medium。緩解：
  - 全部為**組合 / 型別複用**——不觸碰上游任何符號實作、不加虛擬方法、不改上游標頭。
  - 對 E7-12 僅用其公開 `set_value`（Path 多載）/ `serialize`；對 E7-01 僅用 `parse` / `Value` 查詢；
    對 E1-07 僅用 `AnchorSpec` / `resolve` / `is_valid_anchor`；對 E1-03 僅經其 include 鏈取得
    `KernelBackend::has_surface`。任一上游若改介面，衝擊面侷限於本單元 `.cpp` 的少數呼叫點。
  - 跨模組連結（`e1_08` PUBLIC 連 engine 層 `e7_12`）已由根 CMakeLists 的統一 GLOB + `add_subdirectory`
    保證 target 可見；順序無關（CMake 目標圖在設定期解析）。
- **狀態一致性**：pending（拖曳中）與 committed（記憶）分離；`set_position` 於拖曳中被拒以免與
  pending 競態；`forget` 同時清 committed 與進行中拖曳。無共享可變全域、無執行緒（相位 1 單執行緒
  記憶體模型）。
- **NFR-02（核心 API 不得絕對座標 / 數字 z-order）**：位置型別全為 E1-07 `AnchorSpec`（具名錨點 +
  正規化偏移），本單元**未新增**任何 `(x,y)` 或數字層級欄位；具體像素只在 `resolve_live` 的輸入尺寸
  （呼叫端提供）與輸出佈局（計算結果）出現。持久化欄位為具名 anchor + 正規化分數。
- **持久化「已知限制」（承 E7-12，明確記錄非靜默）**：SurfaceId 作為 E7-01 map 鍵須為裸 token
  （不得含 `:` / 換行 / 前後空白）；含 `.` 的 id 可（作單一鍵段，round-trip 保留）。空 committed 集合
  序列化為僅 `format_version:` 行，`load_positions` 讀回為零條目（Ok）。
- **建置面**：新增靜態庫 `e1_08`（PUBLIC 連 `e1_03` / `e1_07` / `e7_12`）與可執行檔 `test_e1_08` +
  CTest `e1_08`。根 CMakeLists 既有層級 GLOB（`src/*/*/CMakeLists.txt`，深度 2）已涵蓋
  `src/kernel/e1_08/CMakeLists.txt`，**無需**改根建置檔。
- **相位閘門**：未建立 `src/kernel/backend/win32|cocoa/`，無 `#ifdef` / 真實 OS / 視窗 / 繪圖 API，

### 測試（gtest，13 案例）

具名 anchor 名稱 round-trip / 未知名回 false 不觸碰 out；`set_position` 後端閘控 + 空 id / 越界 anchor /
非有限 offset → Invalid、就地更新；完整拖曳週期（begin/drag_to/end）提交並記住新位置、拖曳中
remembered 仍為提交前 / live 為 pending；多次 drag_to 更新 pending；cancel 放棄 pending 還原；
無效拖曳結構化回報（未註冊 Invalid、非拖曳中 NotDragging、重複 begin AlreadyDragging、拖曳中無效
spec Invalid 且 pending 不變）；後端銷毀後 begin_drag Invalid；多 surface 各自獨立拖曳 / 記憶 /
forget；E7-12 序列化 → load 還原（含 `.` 具名 id 保留、拖曳後持久化）；空集合 round-trip；load
拒絕無法解析 / anchor 名無效 / 缺欄位 / 型別錯且**全有或全無**（不動既有）；NFR-02 相對位置
`resolve_live` 隨容器縮放、拖曳中反映 pending、未註冊回 Invalid。
