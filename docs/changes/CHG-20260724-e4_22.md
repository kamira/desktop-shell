# CHG-20260724-e4_22 — 2D 變形矩陣（E4-22）

- Date: 2026-07-24 | Branch: feat/e4_22 | Risk: low | Implemented by: I1.100

- Unit: E4-22（2D 變形矩陣，engine 層 / 子系統 render / phase 1 / low）
- depends_on: E1-03

## Motivation

渲染層做 2D 變形（平移 / 旋轉 / 縮放 / 傾斜非矩形桌寵、浮層、動畫過場等）需要一套通用的
**2D 仿射變形數學**：可組合的變形矩陣、點 / 向量變換、求反（把螢幕座標映回本地座標）。
目前缺此純數學基座，各處若各自手刻矩陣運算易出錯且無法統一測試。

E4-22 提供 `ds::render::Transform2D`：一個平台中立、確定性的 2x3 仿射矩陣工具，供渲染層
組合與套用 2D 變形。它是**相對變形數學**（平移量 / 角度 / 縮放比 / 傾斜量），不暴露任何
硬編畫面座標或數字 z-order（NFR-02 針對核心 API 硬編絕對座標；通用變形矩陣為合法數學工具）。
奇異矩陣求反時**明確以狀態回報**，絕不靜默回傳無意義數值。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 矩陣表達 | 6 係數 2x3（隱含末列 [0 0 1] 的 3x3 仿射） | 仿射變形不需完整 3x3 儲存；省記憶體、運算直接 |
| 座標慣例 | `matrix(a,b,c,d,e,f)`：(x,y)→(ax+cy+e, bx+dy+f)（同 SVG / Canvas） | 業界通用、與後續繪圖後端一致 |
| 具名工廠 | `identity` / `translate` / `rotate` / `scale`(含均勻多載) / `shear` | 呼叫端以語意建構，不手填係數 |
| 組合 | `compose(rhs)` / `operator*`：**右運算元先套用** | 符合矩陣乘法慣例：`a*b` 表「先 b 後 a」 |
| 變換 | `apply_point`（含平移）/ `apply_vector`（忽略平移） | 點與方向的仿射語意不同，分開表達 |
| 旋轉方向 | 逆時針為正（標準數學慣例），弧度輸入 | 確定性、與三角函式一致 |
| 求反 | `inverse(epsilon)` 回 `InverseResult{status, matrix, ok()}` | 奇異（\|det\|≤epsilon）明確回 `Singular` 不靜默；閾值可覆寫 |
| 奇異判定 | `is_invertible()` / `determinant()` / `kSingularEpsilon`(1e-12) | 呼叫端可動作前自檢；避免除以近零 |
| 比較 | `approx_equals(other, eps)` | float 逐係數近似比較，供測試 / 收斂判斷 |

純數學：無 `#ifdef _WIN32` / `win32` / `cocoa` 平台分支、不綁任何真實繪圖 API 或 OS、
不含硬編絕對座標 / 數字 z-order。相同輸入必得相同輸出，可完全單元測試。
