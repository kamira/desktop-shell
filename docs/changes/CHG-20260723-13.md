- Skill: ai-sdlc-autopilot v1.1

## Motivation
CHG-12 把 `E1-25`（契約測試組）、`E1-26`（後端白名單 lint）歸為 `platform`，理由是
「後端契約基礎設施」。但兩者皆平台中立、且不在 `src/`（分別在 `tests/contract/`、`scripts/`），
歸 `engine` 更貼合「`platform` = 需要 per-platform 後端的項目」這個定義。改歸 `engine`。

## Impact
`units.json`：`E1-25`、`E1-26` 的 `layer` 由 `platform` → `engine`。`totals.by_layer` 改值。
其餘欄位不動；判定規則的 fallback 隨之改為：
`engine/` 路徑 → engine；否則 `src/` 路徑 → platform；否則（無 src/ 亦無 engine/）→ **engine**。
