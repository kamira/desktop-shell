# CHG-20260724-c1_01 — 實作 C1-01 Skin profile（桌面寵物 / 角色皮膚基底 profile）

- Date: 2026-07-24 | Branch: feat/c1_01 | Risk: medium | Implemented by: I1.153
- Skill: ai-sdlc-autopilot

## Motivation

C1-01「Skin profile」：桌面寵物 / 角色皮膚的**基底 profile**——一個可自由拖曳、具名圖層歸屬、
可互動、具透明外形的桌面角色，其定義可由**宣告式 skin 檔**載入。這是一個**組裝型 artifact
單元**（非新引擎邏輯），作為多個具體 skin 的**共用基底**（lb=9），把六個已合併的擴充點組成
單一「角色皮膚」應用 profile + 行為（`load_skin(Value)` / `place` / `drag` / `save_position`）。
相位 1：純資料 / 邏輯組裝，無真實 GUI。

組裝的六個擴充點：
- **E7-01**（`ds::format::Value`）：宣告式 skin 定義的資料模型（`load_skin` 消費之）。
- **E1-03**（`AlphaSurfaceService`）：逐像素 alpha 透明外形（可選能力，`has()` 閘控 NFR-03）。
- **E1-01**（`LayerStack`）：具名圖層歸屬（NFR-02 具名非數字 z-order）。
- **E1-02**（`InputStrategyController`）：可互動的具名輸入策略（含 `to_backend_policy` 對映）。
- **E1-07**（`AnchorSpec` / `resolve`）：anchor 定位（九宮錨點 + 正規化偏移，取代絕對座標）。
- **E1-08**（`DraggableSurface`）：自由拖曳狀態機 + 位置記憶持久化（序列化回 E7-01 文字）。

## Impact

### 新增 `content/profiles/c1_01/`
- `skin_profile.hpp` / `.cpp`：`namespace ds::profiles`。
  - `SkinProfile`：注入式相依 `ds::kernel::KernelBackend&`（surface 宿主）+ `ds::kernel::LayerStack&`
    （E1-01 具名圖層堆疊，可共用）。內部自持三個**以同一注入後端建構**的服務——
    `AlphaSurfaceService`（E1-03）、`InputStrategyController`（E1-02）、`DraggableSurface`（E1-08，
    透傳 E1-07）——由建構子確保三者綁同一後端（避免組裝陷阱）。
  - `load_skin(const ds::format::Value&)`：從宣告式定義（E7-01 Map，通常為 `Document::root`）解讀
    圖層 / 輸入策略 / alpha / 初始位置，再跨擴充點實體化：**E1-03 建立 alpha surface → E1-01 指派
    具名圖層 → E1-02 設定輸入策略 → E1-08 登錄初始位置**。全有或全無：任一步失敗即回滾先前步驟
    （不留殘留後端狀態）。具名結果 `SkinStatus`（Ok / Unsupported / Invalid / AlreadyLoaded /
    NotLoaded）。
  - `unload()`：反向拆除後端狀態（位置登錄 / 輸入策略 / 圖層指派 / alpha surface）。
  - `place(AnchorSpec)`（E1-07/E1-08 `set_position`）、`begin_drag` / `drag_to` / `end_drag` /
    `cancel_drag`（E1-08 拖曳狀態機，回傳原生 `DragStatus` 保留精確碼）、`is_dragging()` /
    `live_position()` / `remembered_position()` / `resolve_live(container, element, out)`
    （E1-08 `resolve_live` → E1-07 `resolve`）。
  - `save_position()`：序列化記憶位置為 E7-01 文字（E1-08 `serialize_positions`）；
    `load_position(text)`：自 E7-01 文字還原（E1-08 `load_positions`，純資料回填，可在 load_skin
    前先做）。
  - 查詢：`state()` / `is_loaded()` / `id()` / `layer()` / `layer_name()`（透傳 E1-01）/
    `assigned_to_layer()` / `input_strategy()` / `backend_input_policy()` / `hit_result()`
    （透傳 E1-02 純函式）/ `alpha()` / `alpha_supported()`（E1-03 能力閘門）。
  - 解構安全：dtor 若仍載入則強制 `unload()`（不留殘留於共用後端 / 圖層堆疊）。
  - 宣告式 skin schema（皆選填，未知鍵忽略，已知欄位型別 / 具名值嚴格驗證）：
    `layer`（wallpaper|below-normal|normal|overlay|topmost）/ `input`（interactive|capture|
    click-through|inert）/ `alpha`（{mode: opaque|per-pixel, opacity: [0,1]}）/ `position`
    （{anchor: 九宮具名錨點, dx, dy: 正規化偏移}）。anchor 具名 ↔ 列舉透傳 E1-08 `anchor_from_name`。
  - 具名列舉：`SkinState`（Unloaded / Loaded）、`SkinStatus`，各附 `to_string()`（NFR-02）。
- `CMakeLists.txt`：`add_library(c1_01 STATIC)` + `target_link_libraries(c1_01 PUBLIC e1_01 e1_02
  e1_03 e1_07 e1_08 e7_01)` + `test_c1_01`（`tests/c1/test_c1_01.cpp`）+ `add_test(NAME c1_01)`。

### 相位 1 約束遵循
- 純資料 / 邏輯組裝，無真實 GUI；無平台分支（無 `#ifdef` / win32 / cocoa，僅在說明註解引述
  禁用詞，與 C1-05 慣例一致）。
- 核心 API 無絕對座標、無數字 z-order（NFR-02）：圖層以具名 `SurfaceLayer` 表達、位置以九宮
  具名 anchor + 正規化偏移表達，具體像素僅在 `resolve_live` 計算邊界出現（由呼叫端提供尺寸）。
- 能力閘控（NFR-03）：per-pixel alpha 經 `alpha_svc_.supported()` 前置閘門；圖層指派 /
  Capture 輸入策略經上游 `has()` 閘控；失敗一律回滾、不留殘留、走降級路徑。
- 無效操作一律明確回具名結果，不靜默；`load_skin` 中途失敗全有或全無回滾。
