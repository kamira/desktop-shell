### §0-B 是本次更新的重點

那六項不是「還沒測」，是**已知沒有實機證據**：

1. 自繪選單的實機外觀
2. 選單的滑鼠 hover / 點選 / Esc / 點外面關閉
3. 選單彈出位置與邊緣翻轉的實機行為
4. 螢幕閱讀器實際朗讀（MSAA 介面正確 ≠ 閱讀器體驗可用）
5. 托盤圖示在通知區的外觀
6. 合成滑鼠拖曳為何在本機時好時壞（原因未查明）

每一項都註明了「為什麼單元測試不夠」，並指向對應 CHG 的 Verification 段落
（那裡有 `WM_EXITSIZEMOVE` / `WM_APP+1` / `WM_NCHITTEST` 等可循的確定性驗收手法）。
