# CHG-20260724-e2_11 — 系統運行時間（E2-11）

- Date: 2026-07-24 | Branch: feat/e2_11 | Risk: low | Implemented by: I1.66
- Skill: ai-sdlc-autopilot

## Motivation
E2-11「系統運行時間」是 module 層（子系統 sysinfo）的一個**指標提供者**：透過 **E2-01 統一
指標介面**（擴充點 1 契約）把「系統運行時間 uptime」（開機至今的秒數，可衍生天/時/分格式化
文字；並可選帶開機時間戳）掛成一個指標，並以 **E2-02 採集頻率分級**決定採樣節奏（uptime
變動緩慢且單調遞增，屬低頻週期採集）。這是「新增指標 = 新增 `MetricProvider`、掛件一行不動」
機制的又一個具體實例——它**消費 E2-01 / E2-02 契約、不自造指標模型或排程器**。相位 1
（Mac / null 期）**絕不接任何真實時間 / uptime API**（不含 `sysctl kern.boottime` /
`/proc/uptime` / `GetTickCount` / `mach_absolute_time` / `#ifdef`）；改為**可注入的
`UptimeSource` 抽象** + null / 假來源（注入固定值或遞增序列），真實平台後端留待相位 2。

## Impact

### 新增 `modules/sysinfo/e2_11/`（module 層 / 子系統 sysinfo）
- `uptime.hpp` / `uptime.cpp`（`namespace ds::sysinfo`）：
  - **值模型**（平台中立）：
    - `UptimeReading`：某時刻的運行時間快照——`seconds`（開機至今秒數，>= 0）+ 可選
      `boot_unix_time`（開機時間戳，Unix 秒）+ `valid`；`of(secs)` / `of(secs, boot_ts)` /
      `unknown()` 工廠，含相等運算子。`valid==false` = 無讀值（未知），保守預設。
  - **格式化演算法**（自由函式，獨立可測、純算術）：
    - `format_uptime(seconds)`：把秒數格式化為 "Nd HH:MM:SS"（天數任意位數、時/分/秒補零
      兩位）；負值（uptime 只增，理論不該發生）視為 0、小數秒截斷取整。
  - **uptime 來源**（提供者只依賴此抽象）：
    - `UptimeSource`（抽象 `read()→UptimeReading`；非 const，序列型來源取樣推進游標，有副作用）。
    - `NullUptimeSource`：相位 1 null / 假來源——**不接真實時間 API**，預設回無讀值；
      `set_reading` / `set_seconds` 注入**固定值**、`set_sequence` / `push_reading` 注入
      **遞增序列**（模擬時間推進下 uptime 累積）；序列非空時優先於固定值、列盡持續回最後
      一份（穩定不出界）；`reset` 回序列起點、`clear` 回無讀值預設。供測試與假感測器情境。
  - **提供者** `UptimeProvider : public ds::metrics::MetricProvider`（消費 E2-01 契約）：
    `provider_id()=="sysinfo.uptime"`；`register_metrics(registry)` 向 E2-01 註冊表掛上單一
    指標 `"system.uptime"`（name="System Uptime"、unit="s"、range=`at_least(0)`——下界 0、
    上無界，uptime 只增無自然上限）。
    - **可列舉實例**：`uptime` 實例(label "System Uptime") 恆存在（列舉順序第一），value =
      秒數(number) + "Nd HH:MM:SS" 格式化文字(text)，保留歷史環（`kDefaultHistory=64`，配合
      E2-02 週期採集鋪成序列）；`boot.time` 實例(label "Boot Time") **可選**——僅當來源提供
      開機時間戳時動態新增（靜態值、`history_capacity=0` 無歷史，unique_ptr 持有故既有參照
      不失效）。
    - `sample()`：重新讀來源、把新讀值寫入各實例（uptime 推入歷史、開機時間戳只設值）；讀值
      首次帶開機時間戳則動態新增 `boot.time` 實例，本次無開機時間戳則將既有該實例設未知
      （不縮減、誠實表達本次無讀值）。register 尚未呼叫時為 no-op（保守不崩）。
    - `sampling_tier()`：回建議的 E2-02 採集分級（`kDefaultTier=SamplingTier::Low`，建構子
      可覆寫），供呼叫端 `SamplingScheduler::add_demand`。
    - `has_boot_time()`：是否已建立開機時間戳實例。
  - 無讀值語意：指標仍掛上；uptime / 開機時間戳以 `valid==false`（未知）誠實表達，而非塞
    假值。source 為 null 亦保守不崩（僅 uptime 實例、未知、無 boot 實例）。
  - `CMakeLists.txt`：`add_library(e2_11)` **PUBLIC 連上游 `e2_01` `e2_02`**（標頭 include
    `metric.hpp` 與 `sampling.hpp`，須傳遞 include 目錄）；`test_e2_11` + `add_test(NAME e2_11)`。
- 上游相依：E2-01 統一指標介面（`ds::metrics::MetricProvider` / `MetricRegistry` /
  `InMemoryMetric` / `InMemoryMetricInstance` / `MetricRange::at_least`）＋ E2-02 採集頻率
  分級（`ds::metrics::SamplingTier` / `SamplingScheduler`），皆可讀不可改。
- **無** `#ifdef` / win32 / cocoa / `sysctl kern.boottime` / `/proc/uptime` / `GetTickCount` /
  `mach` 等真實時間 API（backend_guard 綠燈）。純邏輯、平台中立、可注入。

### 測試 `tests/e2/test_e2_11.cpp`（gtest，26 案例）
- 提供者身分（3）：`provider_id`/`kMetricId`/`kMetricName`/`kUnit` 穩定；可上轉為 E2-01
  `MetricProvider`；預設採集分級 = Low（可覆寫）。
- 註冊 / 列舉 / 秒數（2）：`add_provider` 掛上一個指標；無開機時間戳時僅 uptime 實例；
  uptime 秒數讀值正確（number = 秒數）。
- **格式化文字**（3）：`format_uptime` 天/時/分/秒（0 / 42 / 3661 / 86400 / 90061 / 十天）、
  負值視為 0、小數截斷；提供者把格式化文字掛在 `value().text`（"1d 01:01:01"）。
- **遞增序列**（3）：注入 +1 秒序列 → 多次 `sample()` 歷史單調累積（100→103）；
  `NullUptimeSource` 列盡回最後一份；`reset` 回序列起點。
- **開機時間戳**（3）：來源帶開機時間戳 → 建立可選 `boot.time` 實例（讀值正確）；跨採樣
  動態新增（首次無、後來有，既有參照不失效）；開機時間戳實例無歷史（capacity 0）。
- **無讀值誠實 invalid**（4）：source 為 null 指標 → 僅 uptime 實例、未知、無 boot、不崩、
  `sample()` no-op；`NullUptimeSource` 預設未知且不推歷史、注入後可讀；開機時間戳消失 →
  該實例設未知（不縮減）；`sample()` 未註冊為 no-op。
- **經 E2-02 頻率採樣**（2）：以 `SamplingScheduler`（Low 間隔 64）登記需求、推進 192 tick
  於到期（t=64/128/192）時呼叫 `sample()` → 歷史累積、值前進；除頻合併多消費者（最高頻者
  供給、撤銷後仍追蹤）。
- 範圍 / 消費者範式 / 重複註冊（3）：`at_least(0)`（有下界、無上界、非有界、無法正規化）；
  掛件風格消費者只走 E2-01 registry / Metric 抽象介面；同 id 第二次掛上保守拒絕、不覆寫。
- 值模型單元（3）：`UptimeReading` 工廠 / 相等；`NullUptimeSource` 固定注入 / clear；
  序列優先於固定值、clear 後兩者皆重置。
