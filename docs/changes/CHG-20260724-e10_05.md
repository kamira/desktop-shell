# CHG-20260724-e10_05 — 獨立行程 widget 宿主（E10-05）

- Unit: E10-05（獨立行程 widget 宿主，engine 層 / ipc / low）
- 相依：E10-01 本機 IPC 訊息投遞、E1-03 逐像素 alpha surface（皆已合併，可讀不可改）。

## Motivation

widget 若與主程式同行程執行，一個 widget 崩潰或失控可能拖垮整個桌面殼層。需要一個「宿主」
抽象，讓 widget 可跑在與主程式隔離的行程（崩潰隔離 / 資源限制），並統一管理其生命週期
（啟動 / 停止 / 監看 / 重啟），同時經 E10-01 通道與主程式通訊、widget 的視覺 surface 經
E1-03 的能力閘控協定橋接。

E10-05 於相位 1 刻意**不真的 fork / exec**：以**可注入的 `ProcessLauncher` 抽象**
（spawn / terminate / is_alive）+ `NullProcessLauncher`（記憶體模擬）表達行程生命週期，
`WidgetHost` 的生命週期管理、崩潰偵測、surface 橋接邏輯與行程實作方式無關；真實行程隔離
（fork/exec、win32 CreateProcess...）留待相位 2 實作同介面的後端即可，`WidgetHost` 本身
不需改動。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 行程宿主抽象 | `ProcessLauncher`（spawn/terminate/is_alive 三原語）+ 可注入 | 相位 1 不綁真實行程 API；相位 2 換後端不動呼叫端 |
| 相位 1 參考實作 | `NullProcessLauncher`：記憶體模擬行程表，具名遞增 handle | 無真實 OS 呼叫，仍可測完整生命週期語意 |
| 崩潰模擬 | `NullProcessLauncher::simulate_crash()` | 供測試 / 上層注入「非預期終止」，驗證 `WidgetHost` 崩潰偵測路徑 |
| widget / 行程識別 | 具名 `WidgetId` / `ProcessHandle`（字串），非數字 handle | NFR-02 一致慣例，跨模組邊界穩定可讀 |
| 生命週期管理 | `WidgetHost::start/stop/restart` + `state()`/`is_alive()` | 一個 host 對應一個 widget 行程；狀態機清楚（NotStarted/Running/Stopped/Crashed） |
| 崩潰偵測 | `poll_crash()`（輪詢式）+ `on_crash` 回呼 | 相位 1 無真實訊號，呼叫端輪詢；偵測到即明確通知，不靜默吞掉 |
| 通訊 | 經 E10-01 `MessageChannel`：宿主事件廣播（started/stopped/crashed/surface_attached/surface_detached）+ `channel()` 直接收發存取點 | 重用既有本機 IPC 契約，宿主與主程式解耦 |
| surface 協定橋接 | `spec.surface_id` 非空時，`start()` 經 E1-03 `AlphaSurfaceService` 建立對應具名 alpha surface 並廣播 attach 事件；`stop()` 銷毀並廣播 detach 事件 | widget 的視覺 surface 狀態隨生命週期同步，且受 NFR-03 能力閘控保護 |
| 無效輸入 / 能力不可用 | 空 id/entry → `Invalid`；能力不可用 → `SurfaceUnsupported`；surface id 衝突 / 未注入服務 → `Invalid`；一律先檢查、不啟動行程或於失敗時回滾（終止剛啟動的行程），不留孤兒行程 | 崩潰 / 無效 spec 明確回報不靜默（單元規格硬性要求） |
| 契約版本 | `widget_host_contract_version()` = "e10_05/1.0.0"（非 `contract_version()`，避免與 E10-01 同命名空間撞名，沿用 E10-02/E10-04 前綴慣例） | `ds::ipc` 命名空間下與 E10-01 共存於同一連結單元 |

介面平台中立：無 `#ifdef _WIN32` / `cocoa` / `__APPLE__` 等平台分支、不含任何真實 fork/exec/
win32 CreateProcess 等行程 API；僅注入式 `ProcessLauncher`。
