# CHG-20260724-e4_10 — 閒置自動動畫觸發（E4-10）

- Date: 2026-07-24 | Branch: feat/e4_10 | Risk: low | Implemented by: I1.156
- Skill: ai-sdlc-autopilot v1.1
- Unit: E4-10（閒置自動動畫觸發，module 層 / elements 子系統 / 平台無關純邏輯 / low）
- 相依上游：E4-07 幀序列動畫（已合併，可讀不可改）、E5-09 機率排程器（已合併，可讀不可改）

## Motivation

桌面角色在「一段時間沒有互動」後，該偶發地自己做點動作（眨眼、換姿勢等），而不是死板地保持
靜止——E5-04 心跳文件本就點名「閒置動畫」為其消費場景之一。E5-09 已提供平台中立的機率排程器
（把時間推進轉為「機率觸發」），E4-07 已提供幀序列動畫元件（把注入的圖片幀序列轉成可播放的
渲染描述）。E4-10 是把兩者組起來的 elements 層元件：`IdleAnimationTrigger` 以注入式 tick 累計
「距上次活動已過多久」，達所設閒置門檻才把時間餵給內部 E5-09 排程器，由其以機率決定何時對
登記的 E4-07 `FrameAnimationElement` 觸發（`reset()` + `play()`）。相位 1 不接真實時鐘 /
真實互動偵測，一切時間與活動通知皆由外部注入。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 閒置判定 | `advance(dt)` 累計 `idle_elapsed_`；`idle_elapsed_ >= idle_threshold_` 才視為閒置中 | 承 E5-04/E5-09 注入式 tick 慣例；門檻與 tick 意義皆由呼叫端決定，本單元只管累計與比較 |
| 決定性邊界 | 未達閒置門檻前，`advance` **完全不呼叫**內部 `ProbabilisticScheduler::advance`——排程器不推進、不消耗任何亂數 | 亂數消耗次序只由「真正進入閒置後」的評估次數決定，避免非閒置期間的推進打亂序列，維持可預期、可重現（呼應 E5-09 的決定性精神） |
| 活動重置 | `notify_activity()` 只將 `idle_elapsed_` 歸零；不觸碰已登記動畫的播放狀態、不重置內部排程器的任務狀態 | 「重新開始累計閒置時間」已足夠表達語意；排程器任務本就只在被餵 dt 時才推進評估，活動期間本單元不再餵它 dt，天然暫停，不需額外清空排程器狀態 |
| 觸發動作 | 機率命中時對綁定的 `FrameAnimationElement` 呼叫 `reset()` 後 `play()`：從頭播放一次 | 閒置動畫語意上是「重新做一次動作」而非接續播放；`reset()` 保證每次觸發皆從第 0 幀起播，行為明確可測 |
| 分工邊界 | 本單元**不**自行推進動畫逐幀進度（不呼叫 `FrameAnimationElement::advance()`），也**不**判斷什麼是「互動」 | 避免與 E4-07（幀推進，由呼叫端另接 E4-09 驅動）、輸入偵測層重疊；本單元只做「該不該觸發」的決定，職責單一 |
| 登記 / 識別碼 | `register_animation(FrameAnimationElement&, eval_interval, probability)` 直接把 E5-09 `schedule()` 的 `SubscriptionId` 轉用為 `RegistrationId`；`unregister_animation` 委派 `cancel()` | 不另造平行的 id 系統；`interval<=0` 沿用 E5-09「回傳 0＝無效」慣例 |
| 多動畫 | 每個登記各自獨立的評估間隔 + 機率（各自一個內部排程任務） | 不同候選動畫（眨眼 / 伸懶腰 / 換姿勢）本就該有各自的觸發節奏與機率，不強制共用單一設定 |
| 生命週期 | `IdleAnimationTrigger` 因內部排程任務回呼閉包參照 `this`，故刪除複製 / 搬移建構與賦值 | 承 E4-09 `AnimationDriver` 同類自參照理由，避免搬移後產生懸空 `this` |
| 錯誤處理 | `set_idle_threshold(0)` → `IdleAnimationStatus::Invalid`（不套用，維持既有門檻） | 承子系統各單元「不靜默」精神；門檻 0 代表「恆閒置」，語意上無意義故拒絕套用 |

介面平台中立：無 `#ifdef _WIN32` / `win32` / `cocoa` 等平台分支、不綁真實時鐘 / 計時器 /
輸入裝置。**NFR-02**：本單元不新增任何座標 / z-order 概念，觸發動作僅呼叫 E4-07 既有的
`reset()`/`play()`，未新增任何渲染相關欄位。

## 不含（避免越界）

- **不綁真實時鐘 / 計時器 / 輸入裝置**；時間全由外部注入（`advance`），活動偵測全由外部注入
  （`notify_activity`）。
- **不自行推進動畫逐幀進度**——`FrameAnimationElement::advance()` / `attach()` 由呼叫端另行
  接線（如接到 E4-09 動畫驅動源）；本單元只在「該不該觸發」做決定。
- 未動根 `CMakeLists.txt`、`units.json`、`docs/structure/directory.md` 或任何鎖定範圍以外的
  檔案。
- 不改上游 E4-07 / E5-09（僅連結使用）。
