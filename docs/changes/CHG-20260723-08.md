# CHG-20260723-08 — module 層由 src/ 遷至 modules/<subsystem>/

- Date: 2026-07-24 (UTC+0) | Branch: claude/ai-sdlc-handshake-validation-380ada | Risk: low | Implemented by: I1
- Skill: ai-sdlc-autopilot v1.1

## Motivation
架構要求「`src/` 只放平台，模組放 `modules/`」，理由是讓「第三方能不能加」
變成**目錄結構就看得出來的事**——若某個感測器出現在 `src/`，那就是擴充點沒做好的訊號。
CHG-07 確立三層分層後，`module` 層仍混在 `src/sensors/`、`src/render/`、`src/actuators/`，
這個矛盾變得明確，故執行遷移。

## Impact

### `write_scope` 遷移（58 筆）
| subsystem | 原路徑 | 新路徑 | 筆數 |
|---|---|---|---|
| `sysinfo` | `src/sensors/e2_XX/**` | `modules/sysinfo/e2_XX/**` | 25 |
| `elements` | `src/render/e4_XX/**` | `modules/elements/e4_XX/**` | 22 |
| `actuators` | `src/actuators/e3_XX/**` | `modules/actuators/e3_XX/**` | 11 |

**逐單元搬移，不是整根搬移** —— `src/sensors` 與 `src/render` 是 core 與 module 共用的根：
- `src/sensors/` 遷移後僅餘 **core 2 項**（`E2-01` 指標介面契約、`E2-02` 採集頻率基礎設施）
- `src/render/` 遷移後僅餘 **core 8 項**（繪製基座）
- `src/actuators/` **完全清空**，不再存在

### 刻意不動的部分
- **`tests/` 路徑維持原樣**（`tests/e2/`、`tests/e3/`、`tests/e4/`）。
  `plan.py` 的 BRIEF 以 `module` 欄位組出 `tests/<modl>/test_<slug>*`，
  若搬移測試路徑而不同步改 `plan.py`，派工簡報會與 `write_scope` 不一致，PR 直接吃 G1 紅燈。
- `docs/changes/**` 一條不動
- core / artifact 層的 `write_scope` 一律不動（寫入時 assert 驗證無任何非 module 層單元指向 `modules/`）

## ⚠ 副作用：G4 涵蓋範圍縮小
G4 的判定是「diff 觸及 `^src/` 卻沒動 `docs/structure/` → 紅燈」。
遷移後 module 層不再寫 `src/`，因此**脫離 G4 涵蓋**：

| | 遷移前 | 遷移後 |
|---|---|---|
| 會觸發 G4 的單元 | 150 | **92**（全為 core 層） |
| 脫離 G4 涵蓋 | — | **58**（整個 module 層） |

**這是一次治理涵蓋範圍的實質縮小，尚未處理。** 兩種立場：
- **維持現狀**：模組是可插拔的，本來就不該牽動平台結構文件
- **擴大 G4 為 `^src/|^modules/`**：`docs/structure/directory.md` 的分層對應表同時記錄
  `modules/` 的組成，模組增減若不同步會造成文件漂移。此為**收緊**（停點契約允許）

本 CHG **未改動 G4**，待決。
