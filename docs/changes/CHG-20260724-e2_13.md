# CHG-20260724-e2_13 — 媒體播放中繼資料（E2-13）

- Date: 2026-07-24 | Branch: feat/e2_13 | Risk: low | Implemented by: I1.37
- Skill: ai-sdlc-autopilot

## Motivation
E2-13「媒體播放中繼資料」是 module 層（子系統 sysinfo）的一個**指標提供者**：透過
**E2-01 統一指標介面**（擴充點 1 契約）把「目前媒體播放狀態的中繼資料」（曲名／演出者／
專輯／播放狀態 playing/paused/stopped／進度／總長／封面參照）掛成一個指標，並以
**E2-02 採集頻率分級**決定輪詢節奏（媒體進度會變動，宜週期採集而非隨選）。這是「新增
指標 = 新增 `MetricProvider`、掛件一行不動」機制的又一個具體實例——它**消費 E2-01 / E2-02
契約、不自造指標模型或排程器**。相位 1（Mac / null 期）只提供**平台中立介面 + null/假來源
+ 欄位模型**，**不接任何真實系統媒體 API**（不含 MediaRemote / MPNowPlayingInfoCenter /
SMTC 等）；真實平台後端留待相位 2。

## Impact

### 新增 `modules/sysinfo/e2_13/`（module 層 / 子系統 sysinfo）
- `media_metadata.hpp` / `media_metadata.cpp`（`namespace ds::sysinfo`）：
  - `PlaybackState` enum：`Stopped` / `Paused` / `Playing`（三態）；輔助
    `state_rank`（Stopped=0/Paused=1/Playing=2，供 MetricValue 數值維度）與
    `to_string`（"stopped"/"paused"/"playing"，穩定字串）。
  - `MediaMetadata` struct（欄位模型）：`has_media`（false = 無播放）/ `state` /
    `title` / `artist` / `album` / `position_seconds` / `duration_seconds` /
    `artwork_ref`（封面**參照**，非影像資料本身）；`none()` = 無播放；含相等運算子。
    刻意不含任何平台專屬欄位。
  - `MediaSource` 抽象來源：`snapshot() → MediaMetadata`（隨時查詢目前媒體狀態）。
    真實平台後端於相位 2+ 實作；提供者只依賴此抽象介面。
  - `NullMediaSource` null / 假來源：**不接真實系統媒體 API**，預設回「無播放」；
    `set_metadata` / `set_state` / `set_position` / `clear` 注入固定中繼資料，供測試與
    假感測器情境（含狀態轉換與進度更新模擬）。
  - `MediaMetadataProvider : public ds::metrics::MetricProvider`（消費 E2-01 契約）：
    `provider_id()=="sysinfo.media"`；`register_metrics(registry)` 向 E2-01 註冊表掛上
    單一指標 `"media.nowplaying"`（name="Now Playing"、unit=""、range=`unbounded()`）。
    **七個中繼資料欄位各建成一個可列舉 `MetricInstance`**（決定性順序：
    state / title / artist / album / position / duration / artwork）：狀態欄位承載
    位階數值 + 文字；文字欄位（曲名/演出者/專輯/封面）讀 text；進度 / 總長讀秒數。
    進度欄位保留歷史環（`kDefaultPositionHistory=64`），配合 E2-02 週期採集鋪成進度
    序列；其餘欄位 `history_capacity=0`。
    - `sample()`：重新查詢來源並更新各實例（進度值推入歷史；無播放時進度轉未知且不
      推歷史，不污染序列）。呼叫端在 E2-02 排程器判定該指標到期時呼叫。
    - `sampling_tier()`：回建議的 E2-02 採集分級（`kDefaultTier=SamplingTier::Normal`，
      建構子可覆寫），供呼叫端 `SamplingScheduler::add_demand`。
  - 「無播放」語意：指標仍掛上、仍列舉七欄（決定性）；狀態欄位恆有效（stopped），其餘
    欄位以 `valid==false`（未知）誠實表達，而非塞假值。source 為 null 亦保守不崩。
  - `CMakeLists.txt`：`add_library(e2_13)` **PUBLIC 連上游 `e2_01` `e2_02`**（標頭 include
    `metric.hpp` 與 `sampling.hpp`，須傳遞 include 目錄）；`test_e2_13` + `add_test(NAME e2_13)`。
- 上游相依：E2-01 統一指標介面（`ds::metrics::MetricProvider` / `MetricRegistry` /
  `InMemoryMetric` / `InMemoryMetricInstance`）＋ E2-02 採集頻率分級
  （`ds::metrics::SamplingTier` / `SamplingScheduler`），皆可讀不可改。
- **無** `#ifdef` / win32 / cocoa / MediaRemote 等真實媒體 API（backend_guard 綠燈）。
  純邏輯、平台中立、可注入。

### 測試 `tests/e2/test_e2_13.cpp`（gtest，21 案例）
- 提供者身分（3）：`provider_id`/`kMetricId`/`kMetricName` 穩定；可上轉為 E2-01
  `MetricProvider`；預設採集分級 = Normal（可覆寫）。
- 註冊 / 列舉（2）：`add_provider` 掛上一個指標、七欄；欄位鍵與順序決定性。
- 注入播放中取得各欄位（1）：狀態/曲名/演出者/專輯/進度/總長/封面皆可讀（走抽象介面）。
- 無播放（3）：null 來源預設 / 明確 none / null source 指標——狀態=stopped、其餘欄位未知、
  仍列舉七欄、不崩；`sample()` 未註冊時 no-op。
- 狀態轉換（1）：playing → paused → stopped(+無媒體) 經 sample 反映。
- 進度更新（2）：sample 逐次把進度推入歷史環、總長不入歷史；無播放不污染歷史。
- 透過 E2-02 採集（2）：以 `SamplingScheduler` 登記需求（Normal 間隔 8），推進 32 tick
  於到期時採集 → 恰 4 次、歷史累積 4 筆、進度前進；撤銷需求後停止追蹤。OnDemand 分級
  不週期、靠 `request_now` 觸發。
- 範圍 / 消費者範式 / 重複註冊（3）：unbounded；掛件風格消費者只走 E2-01 registry；
  同 id 第二次掛上保守拒絕、不覆寫。
- 值模型單元（4）：`state_rank` / `to_string`、`MediaMetadata::none` 與相等性、
  `NullMediaSource` 注入 API、建構子注入。
