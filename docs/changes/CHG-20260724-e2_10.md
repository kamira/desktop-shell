# CHG-20260724-e2_10 — 時間與日期（E2-10）

- Date: 2026-07-24 (UTC+0) | Branch: feat/e2_10 | Risk: low | Implemented by: I1.26
- Skill: ai-sdlc-autopilot v1.1
- Unit: E2-10（時間與日期，low / module 層 / 子系統 sysinfo / 指標提供者 / 相依已合併 E2-01）

## Motivation

時間與日期是最基本的 sysinfo 面向之一。依平台「新增指標 = 新增 `MetricProvider`、掛件
一行不動」的機制（擴充點 1，見 E2-01），它應是**消費 E2-01 契約的一個具體提供者**，而
非自造指標模型。本單元把當前時間／日期透過 E2-01 的 `MetricProvider` 掛成一個指標。

關鍵約束：**平台中立**（相位 1 = Mac / null 期，`engine`/`module` 層與平台無關），且
**時間來源可注入**——不直接綁 `system_clock::now()`，否則測試不決定性、無法驗值。

## 設計（可覆核可改）

C++17，`namespace ds::sysinfo`。以 `std::chrono` + 純算術達成平台中立；以抽象時鐘介面
達成可測試。

| 項目 | 選擇 | 理由 |
|---|---|---|
| 時間來源 | 抽象 `TimeSource`（`now()`）+ `FixedTimeSource`（注入固定時間點） | 不綁 `now()`：測試 / 相位 1 餵固定值→取樣**決定性**；真實壁鐘後端相位 2+ 另實作，提供者一行不動 |
| 曆法分解 | 純算術 `civil_from_epoch_seconds`（Howard Hinnant civil-from-days，公有領域） | 不呼叫 `gmtime`/`localtime`/時區 API → 無 OS 相依、無 `#ifdef`；一律 **UTC**（本地時區涉及 OS，留待後端相位） |
| 格式化 | `format_iso8601`/`format_date`/`format_clock`（`std::snprintf` 固定寬度） | 零外部相依、決定性、可精確斷言 |
| 指標形狀 | 沿用 E2-01 六要素，不新增模型 | id=`time.now`、name=`Current Time & Date`、unit=``、range=`unbounded` |
| 可列舉實例 | 當前時間的三個面向：`epoch`/`date`/`time` | 直接借用 E2-01「可列舉實例」要素；單元名「時間與**日期**」→ 面向可分別被掛件消費（時鐘 widget 取 time、日曆 widget 取 date） |
| 實例值 | 各面向 number = 對應數值維度、text = 人類可讀表述 | epoch: 秒 / ISO-8601；date: 曆日數 / "YYYY-MM-DD"；time: 日內秒 / "HH:MM:SS" |
| 歷史 | `history_capacity = 0` | 時間點無時序歷史語意，誠實表達「無歷史」 |
| null source | 仍掛指標、三實例值 `unknown()`（valid=false） | 保守不崩、不謊報 0 為真實讀值 |

平台中立：無 `#ifdef`、無系統呼叫、無真實後端；`grep` 僅命中宣示平台中立的註解，無實際分支。

## 不含（避免越界）

- **不讀真實時鐘**：`TimeDateProvider` 只依賴注入的 `TimeSource`；相位 1 用 `FixedTimeSource`。
- **不做本地時區 / DST 換算**：涉及 OS 時區資料，屬後端相位；本單元一律 UTC。
- **不含真實後端 / 平台分支**：無 `#ifdef` / win32 / cocoa / `__APPLE__` / `gmtime`。
- 不引入曆法算術以外的日期程式庫、不排程週期取樣（由呼叫端 / 未來後端驅動）。
- 未動 `units.json`、根 `CMakeLists.txt`、`docs/structure/directory.md` 或任何鎖定範圍以外檔案。
