## Motivation

C2-04「天氣」：桌面「天氣」widget——經 **E2-14** 注入式 `HttpTransport` 對一個端點發 GET 取回
結構化（JSON）天氣資料，以 E2-14 自帶的 `parse_json` / `JsonPath` / `seek` 解析出溫度 / 描述 /
圖示代碼三個欄位，經 **E7-10** 字串函式庫格式化為可讀文字，再以 **E4-01** `TextLayout` 排版、
**E4-02** `ImageElement` 組裝圖示，合成一份渲染描述供後續相位的繪製層消費。掛 **C1-01**
（`SkinProfile`）為桌面基底。這是一個**組裝型 artifact 單元**（非新引擎邏輯）。相位 1：純資料 /
邏輯組裝，無真實網路、無真實影像解碼 / 字型光柵化。

組裝的五個擴充點：
- **C1-01**（`SkinProfile`）：桌面基底——圖層 / 輸入策略 / 透明外形 / 自由拖曳，本單元不重造，
  以 `base()` 存取。
- **E2-14**（`HttpTransport` / `JsonValue` / `parse_json` / `JsonPath` / `seek`）：注入式 HTTP
  擷取 + 自帶輕量 JSON 解析器。
- **E7-10**（`strings::format` / `strings::concat`）：宣告式格式脈絡字串函式庫——組顯示文字
  樣板、組請求 URL。**自查結果**：E7-10 實際為「字串處理函式庫」（concat/length/substring/
  upper/lower/trim/replace/split/join/contains/pad/format），不是 JSON 解析器；JSON 結構化解析
  由 E2-14 自帶（`parse_json` / `JsonValue` / `seek`）提供，E7-10 用於本單元的**格式化**角色
  （組可讀文字、組 URL），與其自身文件定位一致。
- **E4-01**（`TextLayout`）：文字排版，產出相對佈局渲染描述（NFR-02）。
- **E4-02**（`ImageElement` / `MemoryImageSource`）：圖片元件，把 icon 代碼組裝為渲染描述。

## Impact

### 新增 `content/widgets/c2_04/`
- `weather_widget.hpp` / `.cpp`：`namespace ds::widgets`。
  - `WeatherWidget`：注入式相依 `ds::kernel::KernelBackend&` + `ds::kernel::LayerStack&`
    （透傳給內部自持的 C1-01 `SkinProfile` 基底）、`std::shared_ptr<ds::sysinfo::HttpTransport>`
    （相位 1 為 `NullHttpTransport`，可為 nullptr）、端點基底 URL、`const ds::render::FontMetrics&`
    （E4-01 排版用，不取得所有權）。內部自持一個 E4-01 `TextLayout`（綁定注入的 metrics 與
    `"<id>.text"` 目標 surface）。
  - `configure(const Value&)`：解讀 `location`（字串，必填非空）/ `unit`（字串，選填，
    "celsius"（預設）或 "fahrenheit"）。定義非 Map / location 缺失或空 / unit 非法具名值 →
    `Invalid`（不套用）。
  - `request_url()`：以 E7-10 `strings::concat()` 組出 `endpoint_url + "?location=" + location`
    （供診斷 / 測試核對）。
  - `refresh()`：未 `configure()` → `Invalid`；`transport` 為 nullptr 或回應非 2xx →
    `FetchFailed`（既有資料保留，供降級顯示）；body 無法解析為 JSON、非 Object、或必要欄位
    （`temp_c` 數值 / `description` 字串）缺失 / 型別不符 → `ParseFailed`（既有資料保留）；
    `icon` 欄位選填（缺失 / null 視為無圖示，存在但非字串 → `ParseFailed`）；全數成功 → `Ok`，
    `has_data()` 轉 true。
  - `display()`：尚無有效資料 → `Invalid`；成功則依 `config().unit` 換算顯示溫度（攝氏 ↔
    華氏）、以 E7-10 `strings::format()` 依樣板 `"{0}°{1} {2}"` 組出可讀文字、以 E4-01
    `TextLayout::layout()` 排版、以 E4-02 `ImageElement` 組裝圖示渲染描述（icon 代碼為空則
    `has_source=false`），寫入 `WeatherRenderModel`（`render_model()` 查詢）。
  - 具名列舉：`TemperatureUnit`（Celsius / Fahrenheit）、`WeatherStatus`（Ok / Invalid /
    FetchFailed / ParseFailed），各附 `to_string()`（NFR-02）。
  - 診斷查詢：`temperature_celsius()` / `description()` / `icon_code()` / `last_status()`
    （反映最後一次成功 `refresh()`）。
- `CMakeLists.txt`：`add_library(c2_04 STATIC)` + `target_link_libraries(c2_04 PUBLIC c1_01
  e2_14 e4_01 e4_02 e7_10)` + `test_c2_04`（`tests/c2/test_c2_04.cpp`）+ `add_test(NAME c2_04)`。
