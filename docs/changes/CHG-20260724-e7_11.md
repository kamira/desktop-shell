## Motivation

描述子系統的宣告式格式（E7-01 `Value` 樹）常以「一組同類項目」表達 UI 元件、圖層、動作目標
（例如 `layers:` 清單，其成員各帶 `group` / `tag` 標籤）。呼叫端需要一個統一方式：**把樹中一組
項目視為群組，對整組批次施加操作**——或透過命令匯流排（E6-01）對每個成員發令，或對整組套用
共同屬性變更；並且**逐成員回報結果**，部分失敗不得靜默。本單元提供此批次操作層。

本單元屬 engine 層（平台中立純邏輯）：無 `#ifdef` / 系統呼叫 / 真實後端，可完全單元測試。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 選擇器 | `Selector`：`tagged(value,key="group")` / `has(key)` / `where(pred,label)` | 涵蓋依標籤、依鍵存在、與自訂三種常見選法；內部以 `std::function` 述詞統一，只對 Map 節點求值 |
| 群組成員身分 | `GroupMember{path,label,node}` | `path` 為樹中規範路徑（如 `/layers/1`），恆唯一非空，作逐成員回報主鍵；`label` 取自 `id`/`name` 欄位（退化為 path）供人閱讀 |
| 成員參照 | 非擁有 `const Value*` 指入來源樹 | 對來源樹唯讀、零複製；生命週期由呼叫端保證（對齊 E7-01 `find` 回 `const Value*` 的風格） |
| 遍歷順序 | 前序、決定性 | 可重現、穩定測試 |
| 批次命令 | `apply_to_group(bus, group, command, args)` + `make_args` 多載 | 固定參數版簡單；`make_args(GroupMember)` 版可依成員節點屬性客製每成員參數（如注入成員 path） |
| 逐成員結果 | `GroupResult{per_member[]}` + `ok/failed/not_found_count` / `all_ok` / `any_error` | 未知命令 → NotFound（匯流排產生，不崩潰）；處理器失敗 → Failed。部分失敗逐一浮現，不靜默（NFR-04 精神） |
| 批次屬性套用 | `apply_attributes(group, changes)` 產出**新副本** | E7-01 的 Value 無就地變更 API，故不改來源樹；既有鍵保序覆寫、新鍵附加於尾 |
| 非 Map 成員 | 逐一回報 `applied=false` + 原因訊息 | 不靜默吞掉無法套用的成員 |
| 空群組 | `select` 無命中回空 Group（合法非錯誤）；批次操作回空結果，`all_ok`/`all_applied` 為 true | 空集合語意明確、無副作用 |

介面平台中立：無平台分支、不綁任何真實後端，符合相位 1（Mac/null）。engine 層與平台無關
（非 `src/kernel/backend/`，不涉 backend_guard）。不含能力閘控呼叫（純格式 / 分派邏輯），無 `has()` 降級需求。
