# CHG-20260723-24 — root CMakeLists 加收 content/ 與 apps/，解鎖 artifact 層（C 系列）24 單元

- Date: 2026-07-29 (UTC+0) | Branch: chore/artifact-glob | Risk: low | Implemented by: I1
- Skill: ai-sdlc-autopilot v1.1

## Motivation
artifact 層（C 系列，共 24 單元）的交付物位於 `content/` 與 `apps/` 下，root `CMakeLists.txt` 現有的 GLOB 只涵蓋 `src|engine|modules/*/*[/*]/CMakeLists.txt` 與 `tests/contract/`（CHG-22），**收不到 artifact 單元的 CMakeLists**，其 gtest 因而不進建置、CI 的 G3（`ctest`）看不到 → artifact 單元無法通過。與 E1-25 收 `tests/contract/` 同性質（單元交付物不在 `src|engine|modules` 底下）。root CMakeLists 不在任何單元 write_scope 內，由 I1 以 bootstrap infra 變更補上。

## artifact 單元的實際路徑（取自 units.json write_scope）
- `content/profiles/<slug>/`（C1，深度 3）：如 `content/profiles/c1_05/`
- `content/widgets/<slug>/`（C2，深度 3）：如 `content/widgets/c2_01/`
- `content/<slug>/`（C3，深度 2）：如 `content/c3_01/`
- `apps/<slug>/`（C4，深度 2）：如 `apps/c4_01/`
- 各單元測試位於 `tests/c1|c2|c3|c4/test_<slug>*`（C++ gtest，同全庫慣例）。

## Impact（`CMakeLists.txt`）
在 `file(GLOB _unit_cmakes ...)` 增加三行，沿用「明確層級、每個 `*` = 一段路徑」風格（不用 `**` 遞迴）：
```cmake
  "${CMAKE_SOURCE_DIR}/content/*/CMakeLists.txt"      # 深度 2：content/<slug>/（C3）
  "${CMAKE_SOURCE_DIR}/content/*/*/CMakeLists.txt"    # 深度 3：content/profiles|widgets/<slug>/（C1/C2）
  "${CMAKE_SOURCE_DIR}/apps/*/CMakeLists.txt"         # 深度 2：apps/<slug>/（C4）
```
- 三條 GLOB 對尚不存在的路徑回空集合，故在 artifact 單元落地前為 no-op（現有單元收入數不變）。
- artifact 單元於自身目錄放 `add_executable`+`add_test` 的 CMakeLists，被本 GLOB 收入後與其他單元一致經 `add_subdirectory` 納入建置。

## 明確不改
- **未動 G4 結構同步閘門**：G4 判定式為 `grep -qE '^(src|engine|modules)/'`——artifact 單元只動 `content/`/`apps/`，不匹配該式，G4 對其**恆真通過**（短路 `|| true`），無需結構檔即合規；artifact 單元仍依慣例寫 `docs/structure/units/<slug>.md`（在 scope_check COMMON 內，可寫）。artifact 為組裝型內容，不強制結構同步屬合理設計，本次不擴 G4。
- 未動 units.json、其餘 7 道閘門、G3 的其餘邏輯（-j2 建置上限見 CHG-23、真空綠燈防線、ctest）。
- 未先建 `content/`/`apps/` 任何檔——交由 artifact 單元於其 write_scope 內建立。

## Status
Accepted — self-verified (low risk)。

## Verification
- `file(GLOB)` 對不存在路徑回空，故落地前對建置為 no-op。
- CMake 語法：三行為既有 GLOB 引數清單同型延伸，括號/引號閉合正確。
- 效果：任一 artifact 單元於其目錄提供 `add_test(...)` 後，root CMake 自動收入，`ctest` 可見其測試，G3 可通過 → 解鎖 C1~C4 全 24 單元。
- 分支 `chore/artifact-glob` 非 feat/ 單元分支，`plan.py unit-for-branch` 查無對應單元，預期 gate 於 branch-lookup 紅燈；由 I1 以 `gh pr merge --admin` 併入（bootstrap infra 慣例，同 CHG-17~23）。
