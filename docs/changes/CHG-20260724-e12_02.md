# CHG-20260724-e12_02 — 多語系（E12-02）

- Date: 2026-07-24 | Branch: feat/e12_02 | Risk: low | Implemented by: I1.122
- Skill: ai-sdlc-autopilot
- Unit: E12-02（多語系，engine 層 / 子系統 common / 相依 E4-01 / phase 1）

## Motivation

E4-01 文字排版只消費「已成文的字串」，不知道多語系；顯示層需要一個具名訊息鍵
（如 `"app.title"`）到各語系翻譯字串的查詢層，讓排版前先把鍵解析為在地化文字。
本單元即此翻譯目錄：註冊翻譯、切換當前語系、缺翻譯明確可見地回退（不靜默、不崩潰）、
參數化訊息（`{name}` 佔位替換）、以及可選的複數形式（單 / 複數二態）。

平台中立純邏輯：翻譯資料全由呼叫端以 `add_translation` / `add_plural` 靜態注入
（未來相位可接資源檔載入，載入邏輯不在本單元），本層只管查詢 + 回退 + 佔位替換，
故可完全單元測試。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 命名空間 | `ds::common`（延續 E12-01 慣例） | engine/common 子系統一致命名 |
| 核心型別 | `LocaleCatalog`：`add_translation` / `add_plural` / `set_locale` / `current_locale` / `has_key` / `translate` / `translate_detailed` / `translate_plural` | 涵蓋規格列舉的全部 API 面 |
| 語系身分 | `LocaleId = std::string`，不驗證真實 BCP-47 語法 | 純對照表鍵；平台中立、無真實 locale API |
| **缺翻譯回退** | current_locale 缺鍵 → 退 default_locale（`LocaleFallback`）；default_locale 亦缺 → 退可見標記包裹的鍵本身 `[missing:key]`（`KeyFallback`） | 缺鍵/缺語系明確可見回退，不靜默顯示空白、不吞鍵名混入正常文案 |
| **不擲例外的查詢路徑** | `translate()` / `translate_detailed()` / `translate_plural()` 對「查無翻譯」永不擲例外 | 查無翻譯是預期可回退情境，非程式錯誤；仍以 `TranslationStatus` 讓呼叫端可診斷 |
| 契約違反仍擲例外 | 空 `locale` / 空 `key` / 空 `default_locale` → `std::invalid_argument` | 這些是明顯呼叫錯誤，非「缺翻譯」；區分「資料缺失」與「呼叫契約違反」 |
| 佔位替換 | `{name}` 掃描替換；`args` 未提供的名稱**原樣保留**；未閉合 `{` 視為 literal | 同一「可見」原則：漏傳參數比默默消失更容易被發現；不因樣板語法小瑕疵擲例外 |
| 複數形式 | `add_plural(locale, key, singular, plural)` + `translate_plural(key, count, args)`；count==1 用單數，其餘用複數（簡化二態，非完整 CLDR 規則） | 規格列為「可選」；相位 1 契約單元用最小可用實作，複雜複數規則留待未來相位視需求擴充 |
| 複數 `{count}` 自動注入 | `args` 未顯式提供 `"count"` 時自動代入十進位字串 | 常見用例 `"{count} items"` 不必每次手動塞 count |
| 診斷 | `TranslationStatus`（Exact/LocaleFallback/KeyFallback）+ `to_string` | 承 E12-01 `ActivityLevel`/`to_string` 的診斷慣例 |

## 介面（`namespace ds::common`）

- 型別別名：`LocaleId`、`MessageKey`、`TranslationArgs`（`std::map<std::string,std::string>`）。
- `TranslationStatus`（Exact / LocaleFallback / KeyFallback）+ `to_string`。
- `TranslationResult{text, status, locale_used}`。
- `LocaleCatalog`：建構 `LocaleCatalog(default_locale = "en")`；`add_translation` /
  `add_plural`（鏈式）；`set_locale` / `current_locale()` / `default_locale()`；
  `has_key(locale,key)` / `has_key(key)`；`translate(key, args={})`；
  `translate_detailed(key, args={})`；`translate_plural(key, count, args={})`。
- 自由函式：`substitute_placeholders(text, args)`（對外公開，便於測試 / 其他單元覆用）。

## 測試（`tests/e12/test_e12_02.cpp`，gtest，31 案例）

涵蓋：建構契約驗證（空 default_locale / 空 locale·key / 空鍵 → 擲例外）、註冊與查詢
（新增、覆寫、鏈式、`has_key`）、語系切換（含切至未註冊語系不失敗）、多語系並存（三語系
互不干擾）、缺翻譯回退（退 default_locale / 退可見鍵標記、`current_locale==default_locale`
不誤判回退、`KeyFallback` 絕不擲例外）、缺鍵處理（`has_key` 存在性語意不含回退）、
參數化訊息佔位替換（單 / 多佔位、未提供佔位原樣保留、未閉合 `{` 視 literal、無佔位符原樣
輸出、回退後仍代入參數）、複數形式（單 / 複數選擇、顯式 count 覆蓋自動注入、複數亦回退、
多語系複數並存）、`to_string` 穩定診斷字串。

  CMakeLists / units.json / `docs/structure/directory.md`。
