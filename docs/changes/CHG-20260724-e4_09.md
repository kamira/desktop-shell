# CHG-20260724-e4_09 — 動畫驅動源（E4-09）

- Date: 2026-07-24 (UTC+0) | Branch: feat/e4_09 | Risk: low | Implemented by: I1.22
- Skill: ai-sdlc-autopilot v1.1
- Unit: E4-09（動畫驅動源，engine 層 / render 繪製基座 / 平台無關純邏輯 / low）
- 相依上游：E5-04 心跳事件（已合併，可讀不可改）

## Motivation

tween / 幀動畫需要一個「時間推進」的來源：每過一段邏輯時間就被餵一次時間增量（dt），
據以更新插值進度。若各動畫各自綁真實時鐘或計時器，將無法在單元測試中重現、也違反 engine 層
「平台中立、換平台不動邏輯」。E4-09 提供一個平台中立的動畫驅動源：把 E5-04 心跳的週期脈衝
轉為對一組註冊動畫的時間推進，並支援暫停 / 繼續 / 移除。時間全以邏輯 tick 計，由所綁心跳
`advance(dt)` 注入，因此可完全以單元測試驗證，不依賴真實時鐘。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 驅動來源 | 建構時綁一個 `ds::events::HeartbeatSource&`，以 `pulse_interval`（tick）訂閱之 | 承 E5-04：不丟脈衝、不漂移；驅動源本身不推進時間 |
| 時間注入 | 一切由所綁心跳 `advance`/`tick` 觸發；一次脈衝餵 dt = 心跳間隔 | 單次 advance 跨多間隔 → 心跳多脈衝 → 驅動源多次派發，計次連續 |
| 動畫模型 | `add(cb)` 配發遞增 `AnimationId`（0 保留無效）；空回呼回 0 不註冊 | 純資料操作、id 單調不重用 |
| 幀資料 | `AnimationFrame`{ id, dt, elapsed, frame } | dt 供推進、elapsed 累計（不含暫停）、frame 自 1 起算 |
| 暫停 / 繼續 | 每動畫獨立 `pause`/`resume`/`is_paused`；另有整體 `pause_all`/`resume_all` | 暫停期間不餵 dt、不累計 elapsed 與 frame；回傳是否有狀態改變 |
| 移除 | `remove(id)` 回是否移除 | 移除後不再被推進 |
| 派發安全 | 兩階段：先結算狀態收集待呼叫幀，再統一觸發回呼 | 回呼中新增 / 移除 / 暫停不破壞本次派發（承 E5-04 手法） |
| 生命週期 | 解構自動 `unsubscribe`；刪除複製 / 移動建構 | 訂閱閉包持有 `this`，禁止移動以免懸空指標 |
| 邊界 | `pulse_interval == 0` 夾到 1（心跳不收間隔 0） | 越界輸入永遠安全 |

介面平台中立：無 `#ifdef _WIN32` / `win32` / `cocoa` 等平台分支、不綁真實時鐘 / 計時器 / 繪製後端。
無絕對座標、無數字 z-order、無能力閘控呼叫（NFR-02 / NFR-03 不涉及本單元）。
