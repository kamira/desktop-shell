# CHG-20260724-e7_05 — 公式運算引擎（E7-05）

- Date: 2026-07-24 | Branch: feat/e7_05 | Risk: low | Implemented by: I1.35

- Unit: E7-05（公式運算引擎，engine 層 / 描述子系統 / low；相依已合併的 E7-02）

## Motivation

宣告式格式（E7-01）與變數系統（E7-02）讓設定 / profile / 版面能宣告具名值並複用。
但實務上常需以**既有值推導新值**：邊界 `width = base + 8`、可見性 `visible = count > 0`、
比例 `half = total / 2`。若只能寫死常數，改一處要重算多處、易漂移。**公式運算引擎**
讓宣告式格式的值可承載**運算式字串**，解析並求值為一個 `Value`。

本單元建構於 E7-02 之上、**消費其 `VariableScope`**（且傳遞取得 E7-01 的 `Value`），
不重造型別 / 作用域模型：只新增運算式的詞法切分、遞迴下降解析與樹走求值。

依 NFR-04 精神「不靜默失敗」：語法錯誤、未定義變數、除零 / 對零取模、型別誤用——
一律回傳帶**位置（欄）＋ 訊息**的 `EvalError`，絕不安靜回預設值。本單元屬 engine 層
（平台中立純邏輯）：無任何 `#ifdef` / 系統呼叫 / 真實後端，可完全單元測試。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 求值架構 | Tokenizer（帶位置）→ 遞迴下降解析 + 樹走求值 | 標準、可讀、優先序以文法層級自然表達 |
| 變數來源 | 消費 E7-02 的 `VariableScope`（`find` 含父鏈上溯 / 遮蔽） | 不重造作用域；與變數系統一致的查找語意 |
| 數值模型 | 沿用 E7-01 `Value`（帶「是否整數」旗標） | 不重造型別；整數 / 浮點型別在結果中保留 |
| 型別保留 | `+ - *` 兩整數 → 整數；含浮點 → 浮點 | 直觀；讓尺寸 / 計數等整數語意不被意外浮點化 |
| 除法 | `/` 兩整數且整除 → 整數，否則浮點；除數 0 → **錯誤** | `6/2=3`、`7/2=3.5`；除零明確報錯（NFR-04） |
| 取模 | `%` 僅整數；對零取模 → 錯誤 | 整數語意清楚；不靜默 |
| 比較 / 邏輯 | `< <= > >=`（數值）、`== !=`（數值 / 布林）、`&& \|\| !`（真值：Bool 原樣 / Number 非零為真） | 讓公式可表達條件（可見性 / 開關）；真值規則最小且明確 |
| 優先序 | `\|\|` < `&&` < `== !=` < 比較 < `+ -` < `* / %` < 一元 < 括號 / 字面 / 變數 | 慣例優先序；括號可覆寫 |
| 裸變數 | 單一識別字原樣回傳其 `Value`（可為字串 / 容器） | 「引用變數值」的直觀語意；但參與運算而非數值 / 布林 → 型別錯誤 |
| 公式標記 | `is_formula` / `formula_body` 辨識前導 `=` 或 `${ ... }` 包裹 | 讓引擎可直接吃宣告式格式的字串值 |
| 錯誤模型 | `EvalError{position, message}`；`EvalResult`（Value / EvalError 二選一） | 對齊 E7-01 `ParseResult` 風格；帶欄位置定位 |
| 錯誤傳遞 | 遞迴內部以受控例外 `EvalException` 拋 `EvalError`，於 `evaluate()` 邊界捕捉轉 failure | 讓遞迴下降碼乾淨；對外仍為無例外的結果物件（沿用 E7-02 手法） |

介面平台中立：無 `#ifdef _WIN32` 等平台分支、不綁任何真實後端，符合相位 1（Mac/null）約束。
engine 層與平台無關（非 `src/kernel/backend/`，不涉 backend_guard）。不含能力閘控呼叫（純格式邏輯），
無 `has()` 降級路徑需求。

## Impact

### 1. `engine/format/e7_05/formula.hpp`（新增）
- `EvalError{position, message}`；`EvalResult`（成功持 `Value` / 失敗持 `EvalError`）。
