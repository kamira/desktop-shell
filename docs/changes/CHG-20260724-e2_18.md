# CHG-20260724-e2_18 — 效能計數器（任意）（E2-18）

- Date: 2026-07-24 | Branch: feat/e2_18 | Risk: low | Implemented by: I1.68
- Skill: ai-sdlc-autopilot

## Motivation
E2-18「效能計數器（任意）」是 module 層（子系統 sysinfo）的一個**泛用指標提供者**：透過
**E2-01 統一指標介面**（擴充點 1 契約）把**任意具名效能計數器**掛成一個指標。讓外部以字串
鍵註冊感興趣的計數器（如 Windows PerfCounter 路徑 `\Processor(_Total)\% Processor Time`、
macOS 統計鍵、任意自訂鍵），提供者透過**可注入的來源**讀取每個計數器目前值並以 E2-01 指標
暴露（**每計數器一實例**），以 **E2-02 採集頻率分級** 決定採樣節奏。這正是「新增指標 =
新增 `MetricProvider`、掛件一行不動」機制的又一個具體提供者，且刻意做成「任意鍵」的泛用
收集器——它**消費 E2-01 / E2-02 契約、不自造指標模型或排程器**。支援瞬時值與可選累積差分
（速率）。相位 1（Mac / null 期）只提供平台中立介面 + null / 假來源，**絕不接任何真實效能
計數器 API**（無 PDH / `\Processor(...)` / `sysctl` / `#ifdef`）；真實後端留待相位 2+。
查無鍵 / 無讀值誠實 invalid、不靜默當成 0。

## Impact

### 新增 `modules/sysinfo/e2_18/`（module 層 / 子系統 sysinfo）
- `perf_counter.hpp` / `perf_counter.cpp`（`namespace ds::sysinfo`）：
  - `CounterMode` enum：`Instant`（瞬時值原樣暴露）/ `Rate`（累積計數器兩次取樣差分算
    速率 = 每次取樣間隔的增量）；`to_string()` 診斷字串。
  - `PerfCounterSource` 抽象來源：`read(key) → optional<double>`（nullopt = 無讀值 /
    查無鍵，誠實表達未知）+ `available_keys() → vector<string>`（列舉可用鍵，供發現）。
    `read` 非 const（序列型來源每次讀取推進游標）。真實平台後端（相位 2+）於此接 PDH /
    sysctl / 自訂統計；提供者只依賴此抽象。
  - `NullPerfCounterSource` null / 假來源：**不接任何真實 API**。以「鍵→固定值 / 序列」
    注入（`set_value` / `set_sequence` / `remove` / `clear` / `has`）；固定值原樣回、序列
    每讀推進（列盡回最後一份、空列 / 查無鍵回 nullopt）；`available_keys` 依注入順序
    （決定性）。預設空來源（Mac / null 期誠實預設）。
  - `PerfCounterInstance : public ds::metrics::MetricInstance`：單一具名計數器的可讀實例，
    持目前值 + 歷史環 + 模式；`observe(optional<double>)` 餵入讀數（Instant 原樣入歷史；
    Rate 首份設基準回未知、其後差分入歷史，計數器重置 curr<prev 保守回 0；無讀值 → 未知、
    不動歷史 / 不動基準）。
  - `PerfCounterMetric : public ds::metrics::Metric`：一組具名計數器組成的指標，**自訂
    以支援執行期動態新增 / 移除實例**（E2-01 的 `InMemoryMetric` 不支援移除）；實例以
    `unique_ptr` 持有（新增不使既有位置失效）、`add` / `remove` / `find` / `mutable_instance`。
  - `PerfCounterProvider : public ds::metrics::MetricProvider`（消費 E2-01 契約）：
    `provider_id()=="sysinfo.perf"`；`add_counter(key,label,mode)` / `remove_counter(key)`
    註冊 / 移除感興趣的鍵（`register_metrics` 前暫存於待掛佇列、之後動態掛上 / 卸下實例並
    立即讀初值）；`register_metrics(registry)` 掛上單一指標 `"perf.counters"`（name=
    "Performance Counters"、unit=""（異質無統一單位）、range=`unbounded()`）；`sample()`
    重讀來源更新各實例；`available_keys()` 轉發來源；以 E2-02 週期分級採集（`sampling_tier()`
    預設 `Normal`，可覆寫）。source 為 null → 各實例保守未知、不崩。空鍵 / 重複鍵註冊保守
    拒絕。
  - `CMakeLists.txt`：`add_library(e2_18 STATIC perf_counter.cpp)` **PUBLIC 連上游 `e2_01`
    `e2_02`**（標頭 include `metric.hpp` / `sampling.hpp`，須傳遞 include 目錄）；
    `test_e2_18` + `add_test(NAME e2_18)`。
- 上游相依：E2-01 統一指標介面 + E2-02 採集頻率分級（`ds::metrics::MetricProvider` /
  `MetricRegistry` / `Metric` / `MetricInstance` / `MetricValue` / `MetricHistory` /
  `SamplingScheduler` / `SamplingTier`，可讀不可改）。
- **無** `#ifdef` / win32 / cocoa / PDH / sysctl / 真實計數器 API（backend_guard 綠燈）。
  純邏輯、平台中立。

### 測試 `tests/e2/test_e2_18.cpp`（gtest，29 案例）
- 提供者身分（3）：`provider_id`/`kMetricId`/`kMetricName`/`kUnit` 穩定；可上轉為 E2-01
  `MetricProvider`；預設分級 Normal、可覆寫。
- 註冊具名計數器→讀值（1）：以任意字串鍵（Windows PerfCounter 路徑）註冊、讀出值。
- 多計數器（1）：三個計數器依註冊順序列舉、各讀值。
- 瞬時值（1）：Instant 模式原樣暴露序列讀數、全部入歷史。
- 累積差分速率（2）：Rate 模式兩次取樣差分（首份未知、其後增量入歷史）；計數器重置保守 0。
- 查無鍵 invalid（1）：註冊來源沒有的鍵 → 誠實未知、歷史空、不當 0。
- 無讀值 invalid（2）：空序列 → 未知；無讀值不污染歷史（維持既有歷史、不謊報 0）。
- 動態新增 / 移除鍵（4）：register 後動態新增（立即讀初值）/ 移除（實例卸下）；register 前
  暫存佇列增刪；空鍵 / 重複鍵保守拒絕。
- 經 E2-02 採樣（2）：以 `SamplingScheduler` 週期採樣（Normal 間隔 8，32 tick → 4 次差分入
  歷史）；除頻多消費者合併、最高頻者供給。
- null 來源（3）：null source 各實例保守未知、不崩；空提供者掛空指標；sample 未 register
  為 no-op。
- 範圍 / 消費者範式 / 重複註冊（3）：`unbounded`；掛件風格消費者只走 E2-01 registry /
  Metric 抽象介面；同 id 第二次註冊保守拒絕。
- NullPerfCounterSource 單元（4）：固定值不推進、序列推進後持最後一份、remove/clear/
  available_keys、空序列回 nullopt。
- 其他（2）：`available_keys` 轉發來源；`CounterMode` 字串穩定。
