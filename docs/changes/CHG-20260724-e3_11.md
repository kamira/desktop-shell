# CHG-20260724-e3_11 — 螢幕擷取致動器（E3-11）

- Date: 2026-07-24 | Branch: feat/e3_11 | Risk: low | Implemented by: I1.45
- Skill: ai-sdlc-autopilot
- Unit: E3-11（螢幕擷取，module 層 / actuators / stage D / low）
- 相依：E6-01 命令匯流排（已合併，可讀不可改）——三個具名命令掛上匯流排、參數重用其穩定值型別。

## Motivation

桌面殼需要「螢幕截圖」這個致動能力：全螢幕、指定區域、指定視窗擷取，輸出影像參照或存檔路徑。
若一開始就綁死 `CGWindowListCreateImage` / `BitBlt` / cocoa，擷取語意會被平台細節污染、無法以
單元測試驗證，且呼叫端會被迫相依具體致動器。

E3-11 走 E6-01「擴充點 3：動作」的既定路線（與 E3-02 啟動致動器同構）：把螢幕擷取以三個具名命令
（`screen.capture.full` / `screen.capture.region` / `screen.capture.window`）掛上命令匯流排，呼叫端只需
命令 id + 具名參數即可觸發，不需相依本致動器或任何 OS 擷取 API。相位 1（Mac / null 期）**絕不呼叫
真實螢幕擷取 API**——所有擷取請求交由可注入的 `ScreenCaptureBackend` 承接，預設 `NullScreenCaptureBackend`
只回一張「注入的假影像」（並記錄請求）供測試 / 診斷驗證。相位 2 換上真實平台後端（win32 / cocoa）時，
本致動器與命令契約一行不動。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 命令 id | 具名字串 `screen.capture.full` / `.region` / `.window`（非數字 opcode） | 穩定、可讀、跨邊界不變形；與 E6-01 CommandId 取捨一致 |
| 掛載方式 | `ScreenCaptureActuator::register_on(CommandBus&)` 註冊三個具名命令 | 呼叫端經 `bus.dispatch(id, args)` 觸發，零相依本型別 |
| 副作用抽象 | `ScreenCaptureBackend` 純虛介面 + `capture(CaptureSpec)→CaptureResult` | 相位 1 null、相位 2 真實後端可注入抽換，介面不動 |
| 相位 1 後端 | `NullScreenCaptureBackend`：不觸碰螢幕，回注入的假影像 + 記錄請求（有序 vector） | 讓「註冊→分派→回假影像」完整跑通並可單元驗證；**絕不呼叫真實擷取 API** |
| 請求型別 | `CaptureSpec{kind, display, region, window, save_path}`（平台中立） | 不含 OS handle / 螢幕假設；承載呼叫端意圖交後端實現 |
| 結果型別 | `CaptureResult{width, height, image_ref, path}`（影像參照或存檔路徑二擇一） | 結果尺寸回報 + 輸出型式解耦於平台 |
| 參數契約 | `full`: 選用 `display`(int)/`path`(str)；`region`: 必填 `x/y/width/height`(int)/選用 `path`；`window`: 必填 `window`(str)/選用 `path` | 皆以 E6-01 `CommandArgs` 承載 |
| 無效區域 | `width`/`height` 須為正；否則回 `CommandResult{Failed}`（不觸及後端） | 「無效區域報錯」；x/y 可為負（多螢幕虛擬座標由後端解讀） |
| 必填保護 | 以 `args.has()` + `get_int()/get_string()` 保護，缺漏 / 空值 / 型別不符回 `Failed` | 不崩潰、不丟例外、不記錄無效請求（NFR-03 has() 保護取捨一致） |
| 註冊回滾 | `register_on` 任一命令掛失敗即回滾本次成功者並回 false | 不留半掛狀態、不遮蔽既有其他致動器 |
| 契約版本 | `screen_capture_contract_version()` = "e3_11/1.0.0" | **前綴命名**避免與 E3-02 同命名空間 `contract_version()` 符號衝突 |

介面平台中立：無 `#ifdef _WIN32` / `cocoa` / `__APPLE__` / `darwin` / `CGWindowListCreateImage` / 真實擷取呼叫；
唯一 `#ifndef` 為 header guard、唯一提及平台 API 字樣者皆為註解（說明「絕不做什麼」）。
