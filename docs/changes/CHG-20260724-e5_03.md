# CHG-20260724-e5_03 — 生命週期事件（E5-03）

- Date: 2026-07-24 (UTC+0) | Branch: feat/e5_03 | Risk: low | Implemented by: I1.8

- Unit: E5-03（生命週期事件，engine 層 / 事件 / low）

## Motivation

上層（開場 / 收場動畫、資源釋放、焦點管理、快取失效等）需要得知每個 surface / profile
進入了哪個生命週期相位——已建立、已顯示、已隱藏、已啟用 / 停用、已銷毀。這些狀態轉換
的語意跨平台一致，但若直接綁真實視窗系統的生命週期回呼，邏輯就無法在單元測試中重現
（轉換不可注入、事件不可斷言），也違反 engine 層「平台中立、換平台一行不動」的分層要求。

E5-03 提供一個平台中立的生命週期來源：狀態轉換由呼叫端驅動（`transition()`），到達
的訂閱者以事件形式被通知。相位 2 的真實後端只需在 OS 生命週期回呼到達時呼叫同一個
transition 路徑，介面與分派 / 驗證語意一行不動。合法轉換以固定狀態機約束（如已 destroyed
不能再 shown），非法轉換被拒絕、不改狀態、不發事件。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 相位集合 | `enum class LifecyclePhase`（Created/Shown/Hidden/Activated/Deactivated/Destroyed） | 跨平台一致的生命週期語意；各平台以自身機制觸發同一相位 |
| 事件承載 | `LifecycleEvent{ surface, from, to }`，純資料 | 不綁任何 OS 原生型別 / 視窗控制代碼，換平台不動 |
| 狀態驅動 | `create(surface)` 登記為 Created；`transition(surface, to)` 驅動轉換 | engine 層須可注入、可斷言；時鐘 / OS 來源與邏輯解耦 |
| 合法轉換 | 固定狀態機表 `is_legal_transition(from, to)`；Destroyed 為終端 | 明確約束（如 destroyed→shown 非法）、可窮舉測試 |
| 自我轉換 | `from == to` 一律非法 | 無實質轉換、不發假事件 |
| 訂閱模型 | `std::function` 回呼 + `SubscriptionId` | 解耦訂閱者；代號供精準解除訂閱 |
| 分派順序 | 依 `SubscriptionId` 遞增（訂閱順序），以有序 `std::map` 保存 | 順序穩定、可測 |
| 回呼中改動訂閱 | 分派前先取快照 | listener 在回呼內訂閱 / 解除訂閱不影響本輪、避免疊代中改容器的 UB |
| 無效輸入 | 空 listener 回 0；未登記 surface / 非法轉換 / 未知 id 皆回 false（no-op） | 呼叫端永遠安全，語意保守 |

介面平台中立：無 `#ifdef _WIN32` 等平台分支、不綁任何真實視窗系統 / 後端，符合相位 1（Mac/null）約束。

合法轉換邊：
Created→Shown|Destroyed；Shown→Activated|Deactivated|Hidden|Destroyed；
Hidden→Shown|Destroyed；Activated→Deactivated|Hidden|Destroyed；
Deactivated→Activated|Shown|Hidden|Destroyed；Destroyed→（終端，無）。
