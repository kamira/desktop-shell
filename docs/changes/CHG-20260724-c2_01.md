## Motivation

C2-01「時鐘」widget：把當前時間以文字排版顯示在桌面角色皮膚（C1-01 基底）之上。這是一個
**組裝型 artifact/widgets 單元**（非新引擎邏輯），把四個已合併的擴充點組成單一具體 widget +
行為（`configure(Value)` / `tick(注入時間)` / `display_text` / `refresh`）。相位 1：注入式時鐘
來源、平台中立，無真實 GUI。

組裝的四個擴充點：
- **C1-01**（`ds::profiles::SkinProfile`）：掛載基底 —— 時鐘顯示綁定於一個**已載入**的 skin
  profile 之具名 surface（`base.id()`），不自建 surface / 圖層 / 輸入策略。
- **E2-10**（`ds::sysinfo::TimeSource` / `CivilTime` / `civil_from_epoch_seconds`）：時間指標來源
  —— 消費注入式 `TimeSource`，無真實壁鐘；相位 1 / 測試以 `FixedTimeSource` 餵入固定時間點。
- **E4-01**（`ds::render::TextLayout` / `FontMetrics`）：文字排版 —— 格式化後的時間字串交給
  注入式 `FontMetrics` 排版為相對佈局 `LayoutResult`（NFR-02：無絕對座標），目標具名 surface
  綁定為基底 `base.id()`。
- **E7-01**（`ds::format::Value`）：宣告式格式定義 —— `configure(Value)` 消費一份宣告式文件的
  內容根（Map），解讀 12/24 時制、是否顯示秒、對齊、排版寬度等顯示樣式欄位。

## Impact

### 新增 `content/widgets/c2_01/`
- `clock_widget.hpp` / `.cpp`：`namespace ds::widgets`。
  - `ClockWidget`：注入式相依 `ds::profiles::SkinProfile&`（掛載基底）+
    `std::shared_ptr<ds::sysinfo::TimeSource>`（時間來源，可為空）+
    `const ds::render::FontMetrics&`（排版度量）。
  - `configure(const ds::format::Value&)`：從宣告式定義（E7-01 Map，通常為 `Document::root`）
    解讀 `format`（"24h"|"12h"）/ `seconds`（bool）/ `align`（"left"|"center"|"right"）/
    `width`（非負有限數字，0=無界）。流程：id 為空 → Invalid；定義非 Map / 已知欄位型別或具名值
    不合法 → Invalid（不改任何狀態）；掛載基底未載入（`!base.is_loaded()`）→ Unsupported
    （不提交任何設定）；全數成功 → 提交顯示樣式、state() 轉為 Configured，並儘力做一次初次取樣
    （無時間來源時不視為失敗，僅暫不產生顯示，回傳恆為 Ok）。
  - `tick()`：重新取樣注入時間來源、更新 `display_text()`、重新排版。未 configure →
    NotConfigured；無時間來源 → Unsupported（既有顯示不變）；成功 → Ok。
  - `refresh()`：以目前 `display_text()` 與目前樣式（align / width）重新跑一次 E4-01 排版，
    **不重新取樣時間**。未 configure → NotConfigured；成功 → Ok。
  - 查詢：`display_text()` / `layout_result()` / `state()` / `is_configured()` / `id()` /
    `hour_format()` / `show_seconds()` / `align()` / `max_width()` / `has_sampled()`。
  - 具名列舉：`ClockState`（Unconfigured / Configured）、`ClockStatus`（Ok / Invalid /
    Unsupported / NotConfigured）、`ClockHourFormat`（H24 / H12），各附 `to_string()`（NFR-02）。
  - 時間格式化：24h 為 "HH:MM[:SS]"；12h 為 "hh:MM[:SS] AM|PM"（0 時 → 12 AM、12 時 → 12 PM），
    純算術（`std::snprintf`），不呼叫任何 OS 時區 / 曆法 / wall-clock API。
- `CMakeLists.txt`：`add_library(c2_01 STATIC)` + `target_link_libraries(c2_01 PUBLIC c1_01 e2_10
  e4_01 e7_01)` + `test_c2_01`（`tests/c2/test_c2_01.cpp`）+ `add_test(NAME c2_01)`。

### 相位 1 約束遵循
