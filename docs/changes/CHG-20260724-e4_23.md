# CHG-20260724-e4_23 — 容器裁切與遮罩（E4-23）

- Date: 2026-07-24 | Branch: feat/e4_23 | Risk: low | Implemented by: I1.108
- Skill: ai-sdlc-autopilot
- Unit: E4-23（容器裁切與遮罩，engine 層 / 子系統 render / phase 1 / low）
- depends_on: E1-03

## Motivation

渲染層需要一套**裁切（clip）與遮罩（mask）**工具：子內容裁切在容器邊界內（矩形 /
圓角矩形 / 任意路徑），並以 alpha 遮罩控制可見區域（如淡出邊緣、局部隱藏）。目前缺此
宣告式裁切 / 遮罩描述基座，各處若各自手刻裁切判定邏輯易不一致且難測試。

E4-23 提供 `ds::render::ClipMaskService`：以**具名容器 id**（沿用上游 E1-03 的
`ds::kernel::SurfaceId` 具名指涉慣例）記錄每個容器的裁切區域、遮罩來源、巢狀父容器
關係，並提供命中 / 可見判定（`is_visible`）與供渲染管線消費的宣告式快照
（`render_model`）。不綁任何真實繪圖 API，純平台中立記憶體狀態。

NFR-02 合規：所有幾何一律以**容器自身局部正規化座標** [0,1]x[0,1] 表達，不是絕對
螢幕像素座標；圓角半徑以容器短邊的比例表達；沒有任何數字 z-order（疊層順序不在本單元
語意內）。無效裁切區域（`set_clip`）**明確以 `ClipStatus::Invalid` 回報**，絕不靜默
接受、絕不留下半份狀態。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 容器指涉 | 具名 `ContainerId`（= 上游 `ds::kernel::SurfaceId`） | 沿用 NFR-02 具名指涉慣例，不用數字 handle |
| 幾何座標系 | 容器局部正規化 [0,1]x[0,1]（`NormPoint`/`NormRect`） | 相對比例，非絕對螢幕座標；容器尺寸無關 |
| 裁切形狀 | `ClipShape`{Rect, RoundedRect, Path} + `ClipRegion`（依 shape 取用不同欄位） | 一個結構涵蓋三種形狀，呼叫端依語意建構 |
| 圓角半徑 | 容器短邊 `min(width,height)` 的比例 [0,0.5] | 比例值而非像素，隨容器縮放自動適配 |
| Path 裁切 | `>=3` 正規化點，隱含首尾相連封閉多邊形；ray-casting 判定 | 支援任意形狀裁切，不限於矩形家族 |
| 遮罩 | `MaskKind`{Uniform, NamedPattern} + `coverage`（clamp [0,1]） | Uniform 為單一 alpha 乘數；NamedPattern 供具名圖樣（如 "fade-edge"）延伸 |
| 巢狀裁切 | `set_parent` 具名父代鏈；`is_visible` 沿鏈疊加祖先裁切 | 巢狀容器語意；迴圈父代在 `set_parent` 時即被偵測拒絕 |
| 巢狀座標假設 | 同一 point 同時檢驗自身與祖先鏈裁切形狀（不做座標系轉換） | 宣告式描述服務範圍；真實跨容器座標轉換屬渲染管線 / 變形數學職責 |
| 無效裁切明確報錯 | `set_clip`/`apply_mask` 驗證失敗回 `Invalid`，不落地任何狀態 | 呼叫端可靠地依回傳值判斷是否生效，不會有「看似成功但半殘」的狀態 |
| render_model | `std::map` 依容器具名鍵字典序聚合輸出 | **決定性**輸出，不依賴插入順序 / 數字 index |

純邏輯：無 `#ifdef _WIN32` / `win32` / `cocoa` 平台分支、不綁任何真實繪圖 API 或 OS、
不含硬編絕對座標 / 數字 z-order。相同輸入必得相同輸出，可完全單元測試。

## Impact

### 1. `engine/render/e4_23/clip_mask.hpp`（新增）
- `ContainerId`（= `ds::kernel::SurfaceId`）；`ClipShape`{Rect, RoundedRect, Path}；
  `ClipStatus`{Ok, Invalid}；`NormPoint`{x,y}；`NormRect`{x0,y0,x1,y1}；
  `ClipRegion`{shape, rect, corner_radius, path}；`MaskKind`{Uniform, NamedPattern}；
  `MaskSource`{kind, coverage, pattern_name}。
- `ClipMaskService`：`set_clip`/`clear_clip`/`has_clip`/`clip_region`、
  `set_parent`/`clear_parent`/`parent_of`、`apply_mask`/`clear_mask`/`has_mask`/
  `mask_source`、`is_visible(container, point)`、`render_model()` → `RenderEntry` 向量。
- 純函式幾何工具：`is_valid_clip_region`、`point_in_clip_region`（供實作與測試共用）。

### 2. `engine/render/e4_23/clip_mask.cpp`（新增）
- 裁切區域結構驗證（依 shape）、矩形 / 圓角矩形（bounding-box + 角落圓弧距離）/ path
  （ray-casting 點在多邊形內）命中測試、巢狀裁切（沿父代鏈疊加祖先裁切、`set_parent`
  時迴圈偵測拒絕）、遮罩 coverage 驗證與 clamp、`render_model` 決定性快照聚合之實作。

### 3. `engine/render/e4_23/CMakeLists.txt`（新增）

  自動 glob 收入（`engine/*/*/CMakeLists.txt`）。

### 4. `tests/e4/test_e4_23.cpp`（新增）
- 29 個 gtest 案例：矩形裁切（設定 / 內外可見判定 / 無裁切全域可見 / 清除還原）、
  圓角矩形（中心與邊中點可見、角落越出半徑被裁、角落落在半徑內可見、半徑 0 退化為
  一般矩形）、path 裁切（三角形內外判定）、alpha 遮罩（uniform coverage clamp、

  明確報錯（空容器 id、退化矩形、越界矩形、圓角半徑越界、path 點數不足 / 點越界、
  非有限值）、render_model（含 clip+mask+parent 混合快照、空狀態、僅父代關係條目）。
