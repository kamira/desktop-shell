# CHG-20260723-11 — src/ 平台中立邏輯遷至 engine/（第二批 23 項，遷移完成）

- Date: 2026-07-24 (UTC+0) | Branch: claude/ai-sdlc-handshake-validation-380ada | Risk: low | Implemented by: I1
- Skill: ai-sdlc-autopilot v1.1

## Motivation
承 CHG-10，把 `src/` 內剩餘的平台中立 core 單元全部遷至 `engine/`，
使 `src/` 只留「對系統的操作」，跨平台適配面最小且顯而易見。

## Impact

### 本批遷移（23 項，`src/` → `engine/`）
| 目的地 | 項 | 來源 |
|---|---|---|
| `engine/events/` | 11 | `src/events/`（E5 非全域事件：滑鼠 / 懸停 / 心跳 / 滾輪 / 拖曳判定 / 計時器…） |
| `engine/render/` | 8 | `src/render/`（E4 繪製基座） |
| `engine/sensors/` | 2 | `src/sensors/`（E2-01 指標介面契約、E2-02 採集頻率） |
| `engine/common/` | 2 | `src/common/`（E12-01 idle 資源門檻、E12-02 多語系） |

`E5` 事件子系統為混合，逐單元判定：**3 個全域事件**（E5-05 全域熱鍵、E5-08 系統事件、
E5-12 全域指標手勢，皆語意分歧）留在 `src/events/`；**11 個非全域事件**（平台中立）遷 `engine/events/`。
目錄位置即標示是否需要 per-platform 後端。

### 「26 項」中未遷移的 3 項（特例）
| 單元 | 原因 |
|---|---|
| `E1-24` null 後端參考實作 | 雖平台中立，但它是後端契約的第一個實作，與 win32/cocoa 同屬後端家族；`backend_guard.py` 以 `src/kernel/backend/*` 執行相位閘門。**留在 `src/kernel/backend/null/`** |
| `E1-25` kernel 後端契約測試組 | `write_scope` 為 `tests/contract/**`，**本就不在 `src/`**，無可搬 |
| `E1-26` 後端白名單 lint | `write_scope` 為 `scripts/backend_guard.py`（治理工具本體），**本就不在 `src/`**，無可搬 |

### 遷移完成後的最終佈局
| 目錄 | 條 | 內容 |
|---|---|---|
| `src/` | 30 | 29 項對系統的操作（kernel 23 / 全域 events 3 / host 3）+ `E1-24` null 後端 |
| `engine/` | 62 | 平台中立引擎邏輯（9 個子目錄） |
| `modules/` | 58 | sysinfo 25 / elements 22 / actuators 11 |
| `content/`+`apps/` | 24 | artifact |

**核心成果：`src/` 的平台耦合分佈 = 29 語意分歧 + 1 中立（僅 null 後端）。**
換平台時需要重寫的就是 `src/` 這 30 條，`engine/`+`modules/`+`artifact` 共 144 項一行不動。
這也讓 A1（Qt/QML 語言選擇）的驗證範圍收斂到最小。

### 未變動
- G4 已於 CHG-09/10 涵蓋 `^(src|engine|modules)/`，本批全走 `engine/`，無需再改
- `tests/` 路徑不動；`layer`/`stage`/`module`/`depends_on` 全不動
