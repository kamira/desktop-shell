# CHG-20260723-04 — 系統識別改名 ai-sdlc → ai-sdlc-autopilot、AGENTS.md 重構、修正不一致數字

## Motivation
本 repo 的治理機制早已是 autopilot 形態（`plan.py` 自動排程派工、`governance.yml` 七道 CI 閘門、
停點契約），但文件仍以上游 base `ai-sdlc` 的「人工四階段」措辭書寫，系統識別與實際機制不符。
同時盤點出多處與 `units.json` 對不上的數字。本 CHG 統一系統識別、重構進場文件、修正數字。

## Scope（本次做什麼）
1. **系統識別改名**：`ai-sdlc` → `ai-sdlc-autopilot`（僅限指涉「本治理系統」之處）
2. **AGENTS.md 重構**：改寫為 autopilot 形態的進場契約
3. **修正不一致數字**：以 `docs/backlog/units.json` 為唯一真實來源

### 明確不改
- **歷史 CHG 記錄**（`CHG-20260723-01/-02/-03`）的 `Skill:` 標頭一律不動——它們記錄當時為真的狀態，不改寫歷史
- **上游 base skill 的引用**：`bootstrap.sh` 的 `/path/to/ai-sdlc-skill`、`RUNBOOK` 的
  「來自 ai-sdlc skill」指的是**提供 `halt_gate.py` / `halt_policy.json` 的上游 base skill**，
  不是本系統識別，改了會讓指令失去意義，故保留並加註「上游 base」
- **契約固定詞**「四把鑰匙」「scoped ack」本身不含 `ai-sdlc` 字串，未受影響
