# CHG-20260724-e7_13 — 階層式項目結構（E7-13）

- Date: 2026-07-24 (UTC+0) | Branch: feat/e7_13 | Risk: low | Implemented by: I1.24
- Skill: ai-sdlc-autopilot
- Unit: E7-13（階層式項目結構，engine 層 / 描述子系統 / 相依 E7-01）

## Motivation

E7-01 提供宣告式格式的**根契約**（`Value` / `Document` / `FormatVersion` + `parse()` 文字→模型），
是一個與領域無關的通用資料模型。多個上層 UI 單元都需要**同一種階層式項目結構**：啟動器選單樹、
對話本、清單等，本質都是「帶 id / 顯示字串 / 附帶酬載 / 子項目」的樹。

本單元把這個共用形狀抽成一個**與領域無關的 `Item` 樹**，供上述單元共用，避免各自重造。
不自造格式模型——完全消費 E7-01 契約，是「更通用格式」的一個應用（項目樹）。屬 engine 層
（平台中立純邏輯）：無任何 `#ifdef` / 系統呼叫 / 真實後端，可完全單元測試。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 節點模型 | `Item` = `id` + `label` + `value`（附帶酬載）+ 有序 `children`（遞迴） | 涵蓋選單樹 / 清單 / 對話本共通所需；`value` 承載領域酬載，結構本身與領域無關 |
| 值語意 | `Item` 可複製、以 vector 遞迴持有子項目；`value` 為 E7-01 `Value` | 與 E7-01 不可變 Value 值語意一致；易測、無別名副作用 |
| 宣告式建構契約 | 每項目 = 一個 Map，保留鍵僅 `id` / `label` / `value` / `children`；其餘鍵**報錯** | 明確契約；拒絕未知鍵可攔拼字錯誤，不靜默 |
| id | 必填、非空字串、**整棵樹 / 整座森林唯一** | 依 id 尋址要有意義即需唯一；重複即明確失敗 |
| label | 選填字串；省略則為空字串（**不自 id 臆造**） | 顯示字串是呼叫端決定的，不無中生有 |
| value | 選填任意 `Value`（純量 / list / map） | 附帶酬載完全自由，交由消費端解讀 |
| children | 選填 list，每元素為項目 Map（遞迴） | 樹狀巢狀；有序保留宣告順序 |
| 尋址 | `find(id)`（前序、含自身）/ `contains(id)` | id 唯一故至多一個相符；const 與非 const 兩版 |
| 遍歷 | `for_each_preorder(root, visit(node, depth))` 自由函式 | 前序 + depth，涵蓋選單縮排 / 攤平清單等用途 |
| 森林 | `build_forest(list)` 建多頂層根（清單 / 選單多根） | 「清單」用途需要多根；id 於整座森林唯一 |
| 錯誤模型 | 建構失敗回傳帶可定位訊息的 `BuildError`（`ItemResult` / `ForestResult`） | 承 E7-01 NFR-04「不靜默失敗」；與 `ParseResult` 風格一致 |

介面平台中立：無平台分支、不綁真實後端，符合相位 1（Mac/null）。engine 層與平台無關
（非 `src/kernel/backend/`，不涉 backend_guard）。

### 已知限制（明確記錄，非靜默）

- **空 `children:`（其下無更深縮排）於 E7-01 解析為 Null（非空 List）**，故此寫法會被本單元
  當成型別錯誤回報，而非「零子項目」。要表達葉節點，直接**省略** `children` 鍵即可。
- **依 id 尋址假設 id 唯一**：宣告式 / 森林建構會強制唯一（重複即失敗）；若以程式化 API
  （`add_child`）手動建出重複 id 的樹，`find` 回傳前序第一個相符者（不強制唯一）。
