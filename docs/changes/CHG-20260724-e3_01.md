# CHG-20260724-e3_01 — 外部命令執行致動器（E3-01）

- Date: 2026-07-24 | Branch: feat/e3_01 | Risk: low | Implemented by: I1.42
- Skill: ai-sdlc-autopilot
- Unit: E3-01（外部命令執行，modules 層 / actuators / low）
- 相依：E6-01 命令匯流排（已合併，可讀不可改）——`command.run` 具名命令掛上匯流排、參數重用其穩定值型別。

## Motivation

桌面殼需要「執行外部命令 / 行程」這種副作用：以指定的可執行檔、命令列參數、工作目錄與環境
變數啟動一個行程並取得結果。若一開始就綁死 `system` / `exec` / `fork` / `CreateProcess`，動作語意
會被平台細節污染、無法以單元測試驗證，且呼叫端會被迫相依具體致動器。

E3-01 走 E6-01「擴充點 3：動作」的既定路線（比照已合併的 E3-02 樣式）：把「執行外部命令」
以具名命令 `command.run` 掛上命令匯流排，呼叫端只需 命令 id + 具名參數即可觸發，不需相依本
致動器或任何 OS API。相位 1（Mac / null 期）**絕不真的 spawn 行程**——所有請求交由可抽換的
`CommandRunner`（`run(spec)->RunResult`）承接，預設 `NullCommandRunner` 只把請求記錄下來並回
可注入的結果（預設 no-op 成功）。相位 2 換上真實平台後端（win32 / cocoa）時，本致動器與命令
契約一行不動。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 命令 id | 具名字串 `command.run`（非數字 opcode） | 穩定、可讀、跨邊界不變形；與 E6-01 CommandId 取捨一致 |
| 掛載方式 | `CommandActuator::register_on(CommandBus&)` 註冊 `command.run` | 呼叫端經 `bus.dispatch(id, args)` 觸發，零相依本型別 |
| 執行抽象 | `CommandRunner` 純虛介面 + `run(CommandSpec)→RunResult` | 相位 1 null、相位 2 真實後端可抽換，介面不動；致動器邏輯（參數組裝 / 分派 / 結果回報）與後端解耦 |
| 相位 1 執行器 | `NullCommandRunner`：不觸碰 OS，只記錄請求並回可注入 `RunResult`（未注入 → 預設 exit 0 no-op 成功） | 讓「註冊→分派→記錄→回報」完整跑通並可單元驗證；可模擬成功 / 非零 exit 失敗；**絕不 spawn / exec / fork / system** |
| 請求型別 | `CommandSpec{program, arguments, working_directory, environment}`（平台中立） | 不含 OS / process handle 假設；承載命令列 / 參數 / 工作目錄 / 環境交後端實現 |
| 結果型別 | `RunResult{exit_code, stdout_text, stderr_text}`（POSIX 慣例 0 = 成功） | 平台中立地承載退出碼與輸出 |
| 參數契約 | `command.run`: 必填 `program`(str, 非空)；選用 `args`(str, 空白分隔為多參)、`cwd`(str)、`env`(str, "K=V") | 皆以 E6-01 `CommandArgs` 承載 |
| 結果對映 | exit_code 0 → `CommandResult{Ok}`（value=exit_code、message=stdout）；非零 → `Failed`（value=exit_code、message=stderr） | 「執行有進行」與「命令回報失敗」清楚區分：後者仍是一次成功的分派 + 執行 |
| 必填保護 | 以 `args.has()` + `get_string()` 保護，缺漏 / 空值 / 型別不符回 `CommandResult{Failed}` 且不觸及執行器 | 不崩潰、不丟例外、不執行無效請求（NFR-03 has() 保護取捨一致） |
| 契約版本 | `command_actuator_contract_version()` = "e3_01/1.0.0"（具名以免與同命名空間 E3-02 的 `contract_version()` 衝突） | 承重抽象，供相位 2 換後端時相容判斷 |

介面平台中立：無 `#ifdef _WIN32` / `cocoa` / `__APPLE__` / `darwin` / `system` / `exec` / `fork` /
`spawn` / `CreateProcess`；唯一 `#ifndef` 為 header guard、唯一 `#ifdef` 字樣為註解說明。
