## Motivation
C1-05「召喚面板 profile」：召喚面板（summon panel / command palette / spotlight）——以全域
熱鍵叫出、用畢即收起的臨時面板，內含可篩選 / 可選取的階層式選項清單。這是一個**組裝型
artifact 單元**：不新增引擎邏輯，而是把四個已合併的擴充點（E1-02 輸入策略四態、E1-14
短暫 profile 生命週期、E5-05 全域熱鍵註冊、E7-13 階層式項目結構）組成單一應用 profile +
行為（open / filter / select / close）。相位 1：純資料 / 邏輯組裝，無真實 GUI。

## Impact

### 新增 `content/profiles/c1_05/`
- `summon_panel_profile.hpp` / `.cpp`：`namespace ds::profiles`。
  - `SummonPanelProfile`：注入式相依 `ds::kernel::TransientProfileManager&`（E1-14）+
    `ds::events::GlobalHotkeys&`（E5-05），建構時另帶 `ds::kernel::InputStrategy`（E1-02，
    預設 `Capture`）。
  - 組裝入口：`set_items(Value)`（E7-13 `build_forest`，失敗回 false 且保留原有選項並記錄
    `BuildError`）/ `set_items(vector<Item>)`（程式化）/ `bind_hotkey(Hotkey, ttl)` `unbind_hotkey()`
    （E5-05，`has()` 閘控 NFR-03）/ `backend_input_policy()` `hit_result()`（直接透傳 E1-02
    純函式 `to_backend_policy` / `hit_result`，供驗證組裝正確）。
  - 行為：`open(ttl)`（= E1-14 `create()`，強制 `Ephemeral` + 設定 `Overlay` 圖層）/ `close()`
    （= `expire()`，`CloseReason::Manual`）/ `filter(query)`（E7-13 `for_each_preorder` 於整座
    森林比對 id / label 子字串，面板未開啟回空）/ `select(id, out)`（E7-13 `Item::find`，成功
    則觸發 `on_select` 並以 `CloseReason::Selected` 收起面板）。
  - 生命週期整合：建構時向 `TransientProfileManager::on_expire()` 登記一個以 `id_` 過濾的回呼，
    逾時自動收起（`CloseReason::Timeout`）；管理器可與其他短暫 profile 共用，互不干擾。
  - 解構安全：若面板仍開啟，dtor 強制 `close()`（避免懸置於管理器上的計時器 / 回呼指向已
    銷毀物件——E1-14 `on_expire()` 無移除回呼 API，此為已知限制，已於標頭註解記錄）；若曾
    綁定熱鍵，dtor 解除註冊。
  - 具名結果 / 狀態列舉：`PanelState`（Closed / Open）、`CloseReason`（Manual / Timeout /
    Selected）、`SelectResult`（Selected / NotFound / PanelClosed），各附 `to_string()`（NFR-02）。
- `CMakeLists.txt`：`add_library(c1_05 STATIC)` + `target_link_libraries(c1_05 PUBLIC e1_02
  e1_14 e5_05 e7_13)` + `test_c1_05`（`tests/c1/test_c1_05.cpp`）+ `add_test(NAME c1_05)`。
