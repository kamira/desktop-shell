## Motivation

C2-09「行事曆 / 待辦」：一個顯示待辦事項清單 / 行事曆項目的桌面 widget——事項依**日期分組**
顯示，可勾選完成。這是一個**組裝型 artifact 單元**（非新引擎邏輯，lb=0，不被其他單元依賴），
把四個已合併的擴充點組成單一 widget + 行為（`load` / `add_item` / `toggle_done` / `list_items`
/ `save` / `render_model`）。相位 1：純資料 / 邏輯組裝，無真實 GUI。

組裝的四個擴充點：
- **C1-01**（`ds::profiles::SkinProfile`）：widget 的桌面殼層基底（圖層 / 定位 / 拖曳），
  透過 `shell()` 暴露，由呼叫端直接驅動。
- **E7-13**（`ds::format::Item` / `build_forest`）：以樹狀結構表達「日期分組 → 事項」——
  森林的每個頂層節點是一個日期分組，其 `children` 為該日期下的事項。
- **E7-12**（`ds::format::serialize`）：`save()` 把目前森林序列化回 E7-01 可再解析的文字。
- **E4-01**（`ds::render::TextLayout`）：`render_model()` 以文字呈現目前的行事曆 / 待辦清單。

## Impact

### 新增 `content/widgets/c2_09/`
- `calendar_todo_widget.hpp` / `.cpp`：`namespace ds::widgets`。
  - `CalendarTodoWidget`：注入式相依 `ds::kernel::KernelBackend&` + `ds::kernel::LayerStack&`
    （透傳給內部自持的 C1-01 `SkinProfile` 殼層）+ `ds::render::FontMetrics&`（`render_model()`
    排版所需）。
  - `load(text)`：以 E7-01 `parse()` 解析文字，取根層 `days` 鍵（選填；缺省或（E7-12 已知的
    空容器 round-trip 限制所致的）顯式 `null` 皆視為空清單）交給 E7-13 `build_forest` 建樹。
    解析失敗 → `ParseError`；森林建構契約違反（非 list / 重複 id / 型別錯 / 未知鍵）→
    `Invalid`。兩者皆不改動既有狀態；成功則整份取代（非合併）。
  - `add_item(date, item_id, text)`：日期分組不存在則建立（`label` = 日期字串），事項附加於
    該分組尾端，預設 `done=false`。`date` / `item_id` 為空 → `Invalid`；`item_id` 與既有任何
    節點（事項或日期分組）id 衝突 → `DuplicateId`（不改動狀態）。
  - `toggle_done(item_id)`：翻轉事項完成狀態（缺 `done` 鍵視為 `false`）。對日期分組本身呼叫
    → `Invalid`（分組無完成狀態語意）；找不到 → `NotFound`。
  - `list_items(date)`：查詢指定日期分組下的事項；日期不存在 → 空清單（非錯誤）。
  - `save()`：把目前森林重建為 E7-01 `Value` 樹（保留鍵 `id`/`label`/`value`/`children`，空
    `children` / Null `value` 省略對應鍵以避免空容器 round-trip 陷阱）並以 E7-12 `serialize`
    輸出文字；`load()` 可再解析為等價森林（`Item::operator==` 深層相等驗證）。
  - `render_model(constraints)`：每個日期分組一行標題，其下每個事項一行 `[x] ` / `[ ] ` 前綴 +
    文字，交給 E4-01 `TextLayout`（排版目標 surface 綁定 `shell().id()`）排版。空森林 → 空
    字串 → 空排版結果。
  - 查詢：`shell()` / `id()` / `days()` / `dates()` / `has_date()` / `date_count()` /
    `item_count()` / `empty()` / `contains()` / `is_done(id, out)`。
  - 具名結果 `TodoStatus`（Ok / Invalid / NotFound / DuplicateId / ParseError），附 `to_string()`
    （NFR-02）。
- `CMakeLists.txt`：`add_library(c2_09 STATIC)` + `target_link_libraries(c2_09 PUBLIC c1_01 e4_01
  e7_12 e7_13)` + `test_c2_09`（`tests/c2/test_c2_09.cpp`）+ `add_test(NAME c2_09)`。
