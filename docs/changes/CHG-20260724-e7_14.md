# CHG-20260724-e7_14 — 圖形化設定與就地編輯（E7-14）

- Date: 2026-07-24 | Branch: feat/e7_14 | Risk: low | Implemented by: I1.85
- Skill: ai-sdlc-autopilot
- Unit: E7-14（圖形化設定與就地編輯，engine 層 / 描述子系統 / 相依 E7-12，經其相依 E7-01）

## Motivation

E7-01 提供宣告式格式的**讀**（`parse` 文字→`Value` 樹），E7-12 提供**寫回**（`set_value` 就
路徑更新 / 新增，`serialize` 回文字並保留格式）。但兩者都以「路徑 + 值」為介面，缺乏描述
**「一份設定有哪些可編輯欄位、各是什麼控制項、當前值與約束為何」**的資料模型——那正是一個
圖形化設定面板（GUI）背後所需的模型層。

本單元補上這一層：把宣告式設定的每個可編輯欄位描述成一個**編輯控制項模型**（型別 = 文字 /
數字 / 整數 / 布林 / 列舉 / 顏色、當前值、標籤、約束），使用者編輯後經 **E7-12 `set_value`**
就地寫回原文件並保留格式（round-trip 一致）。**這是資料模型層，非真實 GUI**：不綁任何視窗 /
繪圖 / 平台框架，可完全單元測試。屬 engine 層（平台中立純邏輯），無任何 `#ifdef` / 系統呼叫 /
真實後端，符合相位 1（Mac / null）。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 欄位模型 | `EditableField{ path, label, kind, current, constraints }` | 一個純量葉 = 一個可編輯欄位；帶 GUI 呈現所需的全部描述 |
| 控制項型別 | `EditKind{ Text, Integer, Number, Boolean, Enum, Color }` | 涵蓋設定常見編輯器種類 |
| 建模 | `build_editor_model(Value/Document) -> vector<EditableField>` 前序走訪、保序 | 把整棵設定樹攤平成欄位清單；容器遞迴，空容器不產欄位 |
| 型別推斷 | Bool→Boolean；整數 Number→Integer；非整數 Number→Number；`#RGB`/`#RRGGBB` 字串→Color；其餘字串→Text；Null→Text | 由 `Value` 可直接推得的型別自動歸類 |
| Enum / 範圍 / 標籤 | 無法由 `Value` 推得，改由 `EditorSchema`（`FieldHint` 依路徑對應）覆寫 | 列舉選項 / 數值範圍 / 自訂標籤是外加語意；schema 命中則覆寫，未命中走推斷 |
| 約束 | `EditConstraints{ min/max（數值範圍）, enum_options }` + 便捷建構子 | 數值範圍與列舉選項的宣告 |
| 驗證 | `validate_edit(field, new_value)`：型別不符 / 越界 / 非列舉選項 → throw `std::runtime_error`（訊息含欄位路徑） | 承 E7-01/E7-12 的 NFR-04「不靜默失敗」；無效編輯明確報錯 |
| 就地套用 | `apply_edit(root, field, new_value)`：先驗證再經 **E7-12 `set_value`** 寫回，回傳**新** Value 樹 | 不就地改寫（承 E7-01 不可變 Value）；呼叫端再 `serialize` 即保留格式 |
| 便捷多載 | `apply_edit(root, path/字串, new_value)`：由當前值推型別後型別驗證再寫回；路徑不存在 → throw | 對應規格 `apply_edit(doc, field_path, new_value)` 的路徑式呼叫 |
| 尋址 | `find_field(model, path/字串)` 由路徑取回欄位描述 | 呼叫端由 GUI 事件的路徑回查欄位再套用編輯 |

介面平台中立：無平台分支、不綁真實後端，符合相位 1（Mac / null）。engine 層與平台無關
（非 `src/kernel/backend/`，不涉 backend_guard）。不自造格式模型——完全消費 E7-01 / E7-12 契約。

### 已知限制（明確記錄，非靜默）

- **Enum / 數值範圍 / 顏色以外的自訂語意須由 schema 提供**：`Value` 本身無此資訊，未給 schema
  時列舉字串會被歸為 Text（可編輯但不受選項約束）。這是設計取捨，非靜默失敗。
- **顏色判定限十六進位字面值**（`#RGB` / `#RRGGBB`）：具名顏色（如 `red`）視為 Text，除非
  以 schema 標為 Color 並自備驗證語意。
- **格式保留承 E7-12 的 round-trip 語意**：`serialize` 為每層 2 空白的正規化輸出，「保留格式」
  意指型別 / 其餘欄位不漂移且可再解析，非位元組級原文保留（見 E7-12 CHG 的空容器 / 引號限制）。
