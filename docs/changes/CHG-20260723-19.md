# CHG-20260723-19 — workflow 加 permissions（讓自動合併有寫入權）

- Date: 2026-07-24 (UTC+0) | Branch: chore/ci-permissions | Risk: low | Implemented by: I1
- Skill: ai-sdlc-autopilot v1.1

## Motivation
CHG-18 改用 `--auto` 後，E1-21(#5) 重跑：八道閘門仍全過，但 `gh pr merge --auto`
失敗於 `GraphQL: Resource not accessible by integration (enablePullRequestAutoMerge)`。
原因：repo 的 `default_workflow_permissions` 為 **read**（唯讀），GITHUB_TOKEN 無權啟用 auto-merge。

## Impact
`.github/workflows/governance.yml` 新增 workflow 層級 `permissions` 區塊：
```yaml
permissions:
  contents: write
  pull-requests: write
```
以 workflow 層級最小權限授予自動合併所需的寫入，不動 repo 全域 Actions 設定。

## 若仍失敗（備援）
若加此區塊後 `--auto` 仍回 `Resource not accessible`，代表 repo 的 Actions 設定把
workflow 權限**硬性上限**設為唯讀。屆時需由具 admin 的人在
**Settings → Actions → General → Workflow permissions** 改為
「Read and write permissions」——此為 repo 設定，非 workflow 可自解，需人工處理。
