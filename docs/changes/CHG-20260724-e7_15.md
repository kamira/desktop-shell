# CHG-20260724-e7_15 — 拖放產生設定項（E7-15）

- Date: 2026-07-24 | Branch: feat/e7_15 | Risk: low | Implemented by: I1.86
- Skill: ai-sdlc-autopilot
- Unit: E7-15（拖放產生設定項，engine 層 / 描述子系統 / 相依 E7-12、E5-08）

## Motivation

E7-12 提供設定值「寫回」宣告式文件的能力，E5-08 提供平台中立的系統事件分派。使用者以
**拖放**互動快速建立設定是常見需求（拖入圖片設背景、拖入 URL 建連結…）。本單元把兩者接起來：
把拖放進來的抽象內容，依內容類型推斷，**產生對應的設定項**，再經 E7-12 寫入設定文件。

相位 1（Mac / null 期）**不接真實 OS 拖放**：拖放內容以抽象資料 `DropContent` 表示，經 E5-08
的事件分派「手動注入」。相位 2 換真實拖放後端時，偵測 / 產生 / 寫回語意一行不動——後端只需在
拖放到達時走同一條分派路徑。屬 engine 層純邏輯：無任何 `#ifdef` / 系統呼叫 / 真實後端。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 內容抽象 | `DropContent{ DropKind kind; std::string payload }` + 明確工廠（`file/url/text/color`）與推斷工廠（`detect`） | 平台已知 flavor 時明確給定；只有一段字串（如 E5-08 事件 detail）時推斷 |
| 類型偵測 | `detect_drop_kind`：控制位元組 / 空 → Unknown；`#hex(3/4/6/8)` → Color；`http/https/ftp://` → Url；絕對路徑 / `file://` / 具副檔名無空白 → File；其餘 → Text | 純字串啟發式，可完全單元測試；無法辨識明確落 Unknown |
| 設定項 | `ConfigItem{ std::string path; Value value }`（E7-12 路徑 + 值） | 產生設定項需同時決定「寫到哪」與「寫什麼」；path 交給 E7-12 `set_value` |
| 內容→設定映射 | 圖片檔→`background.image`、一般檔→`file.path`、URL→`link.url`、顏色→`color`、文字→`text` | 落實「拖入圖片→背景設定、拖入 URL→連結元件」；映射集中於 `generate_config_item` 單一事實來源 |
| 圖片判定 | `is_image_path`：副檔名 png/jpg/jpeg/gif/bmp/webp/svg/tiff/tif/ico（大小寫不敏感） | 圖片檔對應背景設定，與一般檔區隔 |
| 寫回 | `apply_drop(doc/root, drop)` 經 E7-12 `set_value`，純函式回傳新樹 / 新文件；`apply_drops` 多筆疊加 | 承 E7-12 不可變值語意；多項拖放為常見情境 |
| E5-08 整合 | `drop_from_system_event(event)`（以 `detail` 推斷）、`subscribe_drops(source, handler)`（包裝 subscribe，事件→DropContent→handler） | 相位 1 內容經事件分派注入；相位 2 後端沿同路徑，語意不動 |
| 錯誤模型 | 無法辨識內容 → `DropKind::Unknown` 明確回報；`generate_config_item` / `apply_drop*` 遇 Unknown throw `std::runtime_error` | 承 E7-01 / E7-12 NFR-04「不靜默失敗」；不安靜產出可疑結果 |

介面平台中立：無平台分支、不綁真實後端，符合相位 1（Mac/null）。engine 層與平台無關
（非 `src/kernel/backend/`，不涉 backend_guard）。

### 已知限制 / 決策（明確記錄，非靜默）

- **E5-08 目前無專屬拖放事件型別**：其事件種類為睡眠 / 喚醒 / 顯示器 / session / 電源。本橋接
  以事件 `detail` 承載拖放內容字串（與其 null 後端「事件由注入手動觸發」的相位 1 模型一致）。
  相位 2 若 E5-08 新增拖放型別，`drop_from_system_event` 可改讀該型別，`generate_config_item` /
  `apply_drop*` 一行不動。
- **推斷工廠的文字判定**：`detect` 對「非 url/color/file 的可列印字串」歸為 Text；空 / 僅空白 /
  含控制位元組（二進位）明確歸為 Unknown。平台若已知拖放 flavor，應優先用明確工廠避免誤判。
