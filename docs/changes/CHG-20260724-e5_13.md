# CHG-20260724-e5_13 — 鍵盤與輸入提交事件（E5-13）

- Unit: E5-13（鍵盤與輸入提交事件，engine 層 / 事件 / low）

## Motivation

桌面外殼需要處理鍵盤按鍵與文字輸入提交：按鍵事件（具名鍵 + 修飾鍵 + press/release）
與文字輸入提交（如就地輸入框按 Enter 送出整段文字的 commit）。這層語意**跨平台一致**，
但各平台的來源機制不同（macOS 的 `NSEvent` / `NSTextInputClient`、Windows 的
`WM_KEYDOWN` / `WM_CHAR` / IME 組字…）。

本單元屬 engine 層（平台中立純邏輯），把這層語意先定稿為平台中立介面：鍵以**具名鍵**
表達（非平台掃描碼 / virtual-key code），事件由呼叫端 / 測試注入。上層現在就能寫好訂閱者；
相位 2 接真實鍵盤後端時，介面與分派語意一行不動，後端只需把 OS 鍵盤事件轉為
`KeyEvent` / `TextInputEvent` 並呼叫既有 inject 路徑。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 鍵表達 | `enum class Key`（字母 / 數字 / 編輯鍵 / 導覽鍵 / F1–F12 / 修飾鍵），未知映 `Unknown` | **具名鍵、非平台掃描碼**；跨平台語意一致 |
| 修飾鍵 | `enum class Modifier` 位元遮罩（Shift/Control/Alt/Meta）+ `\|` `&` `\|=` 運算子 + `has_modifier()` | 多修飾鍵可組合、可精準查詢；Meta = Command/Super/Windows 統一語意 |
| 按鍵事件 | `KeyEvent{ key, modifiers, action }`，`KeyAction`＝Press/Release | 純資料、平台中立，不含 OS 型別 / 掃描碼 |
| 文字提交事件 | `TextInputEvent{ text }`（平台中立 UTF-8 字串，可為空） | 承載就地輸入框 commit 的整段文字；空字串仍為有效提交 |
| 派發模型 | `KeyboardInputSource`：兩條獨立頻道（按鍵 / 文字），各自 `std::function` 回呼 + `SubscriptionId` | 解耦訂閱者；兩頻道隔離，跨頻道不誤收 |
| id 空間 | 兩頻道**共用**遞增 id，`unsubscribe(id)` 自動判別頻道 | 單一 unsubscribe 介面永不歧義 |
| 分派順序 | 依 `SubscriptionId` 遞增（即訂閱順序），以有序 `std::map` 保存 | 順序穩定、可測 |
| 回呼中改動訂閱 | 分派前先取快照 | listener 在回呼內訂閱 / 取消訂閱不影響本輪、避免疊代中改容器的 UB |
| 空 listener / 未知 id | 空 listener 回 0（無效訂閱）；未知 id 取消為 no-op 回 false | 呼叫端永遠安全，語意保守 |

介面平台中立：無 `#ifdef _WIN32` 等平台分支、不綁任何真實鍵盤後端，符合相位 1（Mac/null）約束。
engine 層與平台無關，照常實作（非 `src/kernel/backend/`，不涉 backend_guard）。
