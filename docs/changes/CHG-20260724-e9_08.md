# CHG-20260724-e9_08 — 圖形安裝器（E9-08）

- Date: 2026-07-24 | Branch: feat/e9_08 | Risk: low | Implemented by: I1.91
- Skill: ai-sdlc-autopilot
- Unit: E9-08（圖形安裝器 / engine 層 / 子系統 package / stage A / phase 1）
- Depends on: E9-07（拖放安裝，已合併）
  — `target_link_libraries(e9_08 PUBLIC e9_07)`；經 E9-07 傳遞 E9-01 / E9-02 / E5-08。

## Motivation

E9-07 把「拖放一個套件來源 → 安裝」模型化為安裝生命週期（Received → Resolved → Parsed →
Validated → Registered）+ `InstallRegistry`。E9-08 在其上建立**圖形化安裝流程的資料模型 / 狀態機**
（**非真實 GUI**）：把該生命週期包裝成適合 UI 呈現的**多步驟安裝精靈**——步驟列（歡迎 / 授權 /
選項 / 進度 / 完成）、每步呈現狀態、可前進 / 後退 / 取消、進度百分比與訊息，並把使用者選項
（安裝路徑 / 元件勾選）餵給 E9-07 安裝。相位 1 平台中立：純記憶體狀態，無真實 GUI / 檔案 I/O。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 命名空間 | `ds::package`（與 E9-07 / E9-01 一致） | 依規格「命名空間與 E9-07 一致」 |
| 步驟列 | `WizardStep` Welcome→License→Options→Progress→Complete（固定序列） | 規格指定的五步精靈頁面 |
| 每步狀態 | `StepState` Upcoming / Active / Done（`step_state(step)`） | 供 UI 畫步驟列進度 |
| 整體結果 | `WizardOutcome` InProgress / Installed / Failed / Cancelled | 完成 / 失敗 / 取消明確可查 |
| 導覽 | `next()` / `back()` / `cancel()` 回傳 `StepTransition`（ok + step + message） | 非法轉移 / 授權未接受 / 取消一律明確報錯、不靜默 |
| 授權閘門 | License 步驟須 `accept_license()` 才能 `next()` 前進 | 典型安裝精靈語意；未接受明確擋下 |
| 選項 | `InstallOptions`{ install_path, selected_components }（純資料字串） | 平台中立；相位 1 不做真實檔案 I/O |
| 安裝委派 | `begin_install(source, options)` 於 Options 步驟**委派** E9-07 `DropInstaller::handle_drop` | 真連結：以選項組成 `DropEvent`（選項摘要放入 `DropEvent.detail`）並跑完 E9-07 生命週期 |
| 進度回報 | 期間掛上 E9-07 `InstallLifecycleListener`，將 `InstallStage` 映射為百分比（10/30/55/80/100）+ 訊息；`WizardProgressListener` 對外回報 | 實際使用 E9-07 逐階段回報路徑，非另造 |
| 成功 / 失敗 | 成功→前進 Complete（outcome=Installed，100%）；失敗→停於 Progress（outcome=Failed，可 `back()` 退回 Options 重試） | 失敗不靜默、不假裝完成；保留重試路徑 |

平台中立：無 `#ifdef`、無 `win32`/`cocoa`、無真實 GUI、無真實檔案 I/O，符合 engine 層
「換平台一行不動」與相位 1 約束。相位 2 換真實 UI 時由 UI 事件驅動既有 API，狀態機一行不動。
