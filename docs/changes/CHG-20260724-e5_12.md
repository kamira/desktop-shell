# CHG-20260724-e5_12 — 全域指標手勢（E5-12）

- Date: 2026-07-24 (UTC+0) | Branch: feat/e5_12 | Risk: medium | Implemented by: I1.15
- Skill: ai-sdlc-autopilot

## Motivation
E5-12「全域指標手勢」是 platform 層的**能力閘控項**：全域指標（滑鼠/觸控）手勢辨識
（全域滑動、螢幕角落觸發、縮放）在某些平台/權限下並不存在（無觸控裝置、系統未授予
全域指標監聽權限）。依 NFR-03，此類能力必須以 `has()` 閘控，呼叫端須備妥**降級路徑**。
相位 1（Mac/null 期）只提供平台中立介面 + null 後端，不綁任何真實 OS 後端。

## Impact

### 新增 `src/events/e5_12/`（platform 層）
- `global_gesture.hpp` / `global_gesture.cpp`（`namespace ds::events`）：
  - `GestureType` enum class：具名手勢 —— SwipeLeft/Right/Up/Down、
    CornerTopLeft/TopRight/BottomLeft/BottomRight、PinchIn/PinchOut。
  - `Gesture` struct：具名手勢 + 平台中立正規化參數 `magnitude` + 人類可讀 `detail`。
    刻意不含絕對座標（NFR-02）—— 角落以具名 CornerX 表達，非螢幕像素。
  - `GlobalGestures` 抽象介面：`has()`（唯一能力閘控入口）、
    `subscribe(gesture, cb)→id`、`unsubscribe(id)`、`listener_count()`。
  - `NullGlobalGestures` null 後端：`inject(gesture)` 模擬手勢（只分派給訂閱對應
    類型者、依訂閱順序、快照語意）；可用性由建構決定，或 `from_capability(matrix, id)`
    以 E1-21 能力矩陣為單一資料來源（`kGestureCapability = "input.gesture"`）。
  - `CMakeLists.txt`：`add_library(e5_12)` PUBLIC 連上游 `e1_21`；`test_e5_12` + `add_test`。
- 上游相依：E1-21 能力矩陣（`ds::kernel::CapabilityMatrix`，可讀不可改）—— has() 的資料來源。
- **無** `#ifdef` / win32 / cocoa / 真實 OS 呼叫（backend_guard 綠燈）。

### 降級契約（medium 驗收關鍵）
`has()==false` 時：`subscribe` 一律回 0（拒絕，明確回報不可用）、`listener_count` 恆 0、
`inject` 為 no-op（不誤觸）。即使呼叫端漏查 `has()` 而嘗試訂閱，也絕不會建立假訂閱或誤觸回呼。

### 測試 `tests/e5/test_e5_12.cpp`（gtest，18 案例）
- 能力可用路徑（9）：訂閱→注入→收到、依手勢類型分派、多訂閱者、解除訂閱、
  未知 id no-op、空 listener 拒絕、分派順序、回呼中自解除、各手勢型別。
- 能力矩陣整合（3）：矩陣宣告可用/不可用/未宣告 → has() 對應 true/false/false。
- **降級路徑測試群 `GlobalGestureDegradation`（6，驗收硬性要求）**：
  1. has() 明確回報不可用；2. 不可用時 subscribe 被拒回 0、不佔槽；
  3. 不可用時 inject 絕不誤觸（即使有瑕疵呼叫端嘗試訂閱）；
  4. 不可用時所有操作皆安全不崩（EXPECT_NO_THROW）；
  5. 正規呼叫端範式：以 has() 閘控選主路徑/降級路徑，不可用時乾淨走 fallback；
  6. 由能力矩陣端到端判定不可用 → 呼叫端降級。
