# CHG-20260724-e4_17 — 直方圖（E4-17）

- Date: 2026-07-24 | Branch: feat/e4_17 | Risk: low | Implemented by: I1.102
- Skill: ai-sdlc-autopilot
- Unit: E4-17（直方圖，module 層 / 子系統 elements / phase 1 / low）
- depends_on: E1-03（逐像素 alpha surface）、E7-03（段落變數）

## Motivation

最終的 CPU / GPU Widget 需要把一序列歷史用量（如每秒取樣的 CPU%）以直方圖 / 時序長條呈現。
繪製本身屬後續相位；相位 1 需先有一個**平台中立、可單元測試**的「渲染描述模型」——把一序列
數值映射成長條的正規化描述（每個 bin / 樣本 → 一根長條），供繪製層日後消費。

若在此階段就綁真實繪圖（座標、像素、z-order），將無法在單元測試中重現，也違反 module 層
「平台中立、換平台不動邏輯」與 NFR-02（無絕對座標 / 無數字 z-order）。E4-17 因此只產出
**渲染描述**：正規化幅值 + 清單順序，全程無真實繪製。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 元件 | `HistogramElement`：累積樣本 → `render_model()` 產出 `HistogramRenderModel` | 純邏輯、可測；繪製層日後消費描述 |
| y 軸縮放 | `set_range(min,max)`；`magnitude = (v-min)/(max-min)` ∈ [0,1] | NFR-02：長條以**比例**表達，非像素座標 |
| 長條順序 | `bars` 依時間序（清單 index = 最舊→最新） | NFR-02：順序是語意排序，非數字 z-order |
| 滾動視窗 | `set_capacity(N)`（0 = 無上限）；push / set_series 超出即丟最舊留最新 N | 時序 widget 只顯示最近 N 筆 |
| 閾值線 | `set_threshold(v)` / `clear_threshold()`；描述為正規化幅值 | 如「用量 80% 警戒線」 |
| 合成描述 | 沿用上游 E1-03 `AlphaProfile`（mode + opacity[0,1]） | 半透明桌面 widget 如何被合成；opacity 為比例（符 NFR-02） |
| 超範圍 | 夾限至 [0,1] 並標記 `clamped=true`，原始 `value` 保留 | 明確不靜默；繪製層可辨識溢出 |
| 空序列 | `render_model().empty=true` 且 `bars` 為空 | 明確不靜默假裝有資料 |
| 非法輸入 | 非有限值 / 無效值域 → `HistogramStatus::Invalid`，不部分套用 | 不靜默改成預設值 |
| 設定驅動 | `configure(Value)` / `configure_from_document(Document)` | 後者**先以 E7-03 `expand()` 展開段落變數**再設定 |

平台中立：無 `#ifdef` / `win32` / `cocoa` / 真實繪圖 API；NFR-02 無絕對座標 / 無數字 z-order。
