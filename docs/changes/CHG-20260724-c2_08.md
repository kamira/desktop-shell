## Motivation

C2-08「筆記」：桌面「筆記」widget——一張可編輯的便條，內容經序列化持久化（存 / 載）。這是一個
**組裝型 artifact 單元**（非新引擎邏輯），把四個已合併的擴充點組成一個具體 widget：

- **C1-01**（`ds::profiles::SkinProfile`）：筆記的桌面存在基底——具名圖層歸屬、可互動、具透明
  外形、可自由拖曳 + 位置記憶，其定義可由宣告式 skin 檔載入。
- **E4-15**（`ds::elements::TextInputElement`）：筆記內容的**可編輯**文字狀態機——游標 / 選取 /
  插入 / 刪除。
- **E4-01**（`ds::render::TextLayout`，經 E4-15 內部持有）：筆記文字的**排版顯示**。
- **E7-12**（`ds::format::set_value` / `serialize`，消費 E7-01 `Value`）：把筆記內容序列化為
  宣告式文字（`save()`）並反向還原（`load()`），供持久化——**內容**持久化與 C1-01 的**位置**
  持久化（`save_position` / `load_position`）分離、各自獨立序列化。

相位 1：純資料 / 邏輯組裝，無真實 GUI、無平台分支、注入式儲存（`load()` / `save()` 以字串
進出，不觸碰真實檔案 IO）。

## Impact

### 新增 `content/widgets/c2_08/`
- `note_widget.hpp` / `.cpp`：`namespace ds::widgets`。
  - `NoteWidget`：注入式相依 `ds::kernel::KernelBackend&` + `ds::kernel::LayerStack&`
    （皆轉交內部自持的 C1-01 `SkinProfile`）+ `ds::render::FontMetrics&`（轉交內部自持的
    E4-15 `TextInputElement`，經其 E4-01 排版）。constraints 預設沿用 E4-15
    `single_line_constraints()`（`WrapMode::None`：僅顯式 `'\n'` 產生新行，適合筆記）。
  - **基底（C1-01）全數透傳**：`load_base(Value)` / `unload_base()` / `is_base_loaded()` /
    `base_state()` / `id()` / `place(AnchorSpec)` / `begin_drag` / `drag_to` / `end_drag` /
    `cancel_drag` / `is_dragging()`，皆委派 `SkinProfile`，保留其精確結果碼（`SkinStatus` /
    `DragStatus`）。
  - **編輯（E4-15）全數透傳**：`set_text` / `insert` / `backspace` / `erase_forward` / `text()` /
    `length()`，委派 `TextInputElement`（非法 UTF-8 → `std::invalid_argument`，透傳不吞）。
  - **內容持久化（E7-12，經 E7-01）**：
    - `load(const std::string& serialized_text) → NoteStatus`：解析 E7-01 文字，取根 Map 的
      `text` 欄位（字串）還原內容（`set_text`）。`text` 欄位缺席 → 視為空筆記（`Ok`，內容清空，
      非錯誤）。文字無法解析（E7-01 語法錯誤 / 版本不相容）、`text` 欄位型別非字串、或 `text`
      欄位為合法字串但非合法 UTF-8（罕見：手工 / 損壞的序列化文字，攔截 E4-15 例外轉譯為具名
      結果）→ `Invalid`，**內容不變**（全有或全無，不靜默）。
    - `save() const → std::string`：把目前內容包成 `Value::map({{"text", Value::string(...)}})`，
      經 `ds::format::serialize(root, kSupportedFormat)` 序列化（首行 `format_version: 1.0`）。
      空筆記序列化為 `text: ""`（合法 String，非空容器，不落入 E7-12 空容器不 round-trip 的
      限制）。多行 / 含引號 / 反斜線 / Tab 等內容經 E7-12 字串引號化 + 轉義規則保證
      `save()` → `load()` round-trip 一致。
  - **顯示（E4-01，經 E4-15）**：`render_model() const → TextInputRenderModel`——直接委派
    `TextInputElement::render_model()`（文字排版 + 游標 + 選取，全相對佈局，NFR-02）。
  - 具名結果：`NoteStatus`（Ok / Invalid），附 `to_string()`（NFR-02）。
- `CMakeLists.txt`：`add_library(c2_08 STATIC)` + `target_link_libraries(c2_08 PUBLIC c1_01 e4_01
