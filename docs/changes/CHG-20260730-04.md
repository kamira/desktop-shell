## Motivation
使用者指定的**最終交付**：依使用環境建置一個 CPU/GPU Usage Widget 驗證器並實際執行測試、產出可檢視畫面。
目的是證明：全部 176 個擴充點單元合併後，**真的能被外部（不改任何 `src/`）組裝出一個可運作的桌面 widget**。

## Impact（新增 `examples/`，不改任何既有單元）
- `examples/cpu_gpu_validator/main.cpp`：獨立 `main()`，純**組裝**擴充點：
  - **C2-02** `SystemStatusWidget`（系統狀態 widget）為核心，`configure()` 以 **E7-01** `Value` 宣告式
    選定 CPU / GPU / RAM 三個指標（`kind` 各為 gauge / bar / progress，驗證多型呈現）。
  - **E2-01** `MetricRegistry` + `InMemoryMetric` 為注入式指標來源；widget 只依賴 E2-01 抽象介面，
    不寫死任何具體感測器（新增指標僅需在 `metrics:` 清單多一筆）。
  - 每幀更新指標 → `widget.refresh()` → `widget.render()` → 取 widget 產出的 **E4-03** 量表
    `render_model`（`fill_ratio` + 格式化 `display_text`）畫成 ASCII 量表「螢幕」，跑 12 幀 live 迴圈。
  - **指標來源**：CPU 讀**真實主機負載**（`getloadavg` + `sysconf(_SC_NPROCESSORS_ONLN)`，可攜 Mac/Linux）；
    GPU / RAM 以動態 sweep 模擬（相位 1 無 sudo-free 的 GPU / 精確記憶體 API）。
  - 收尾以 exit code 回報驗收：三指標皆 `available` 且 `fill_ratio ∈ [0,1]` → 0（PASS）。
- `examples/cpu_gpu_validator/CMakeLists.txt`：`add_executable(cpu_gpu_validator main.cpp)` +
  `target_link_libraries(... PRIVATE c2_02)`（連 C2-02 即遞移取得完整依賴閉包）+
  `add_test(NAME cpu_gpu_validator)`（驗證器即一個 CTest）。
- root `CMakeLists.txt`：GLOB 增收 `examples/*/CMakeLists.txt`（`docs/architecture.md` 早已指定
  `examples/` 為驗證器 / 範例的目標位置）。
- `docs/structure/directory.md`：記錄新增的 `examples/` 頂層與本驗證器。
