# CHG-20260724-e4_28 — 透視與景深呈現（E4-28）

- Date: 2026-07-24 | Branch: feat/e4_28 | Risk: low | Implemented by: I1.141
- Skill: ai-sdlc-autopilot
- Unit: E4-28（透視與景深呈現，module 層 / 子系統 elements / phase 1 / low，depends_on=[E4-22]）

## Motivation

桌面外殼的部分視覺元件（背景層視差捲動、卡片堆疊、裝飾層次感等）需要「2.5D 透視」效果——
遠處的元素縮小並朝消失點方向偏移、近處的元素放大，營造深度感，但本專案 module 層是純邏輯、
平台中立，不能綁真實 3D 渲染管線。E4-28 以上游 E4-22 `Transform2D` 2D 仿射變形矩陣為數學
基礎，把「相對深度」換算成「縮放 + 視差位移」的 2D 變形，並可選附加景深模糊(depth of
field)量，產出一份供後續相位繪製層消費的透視渲染描述。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 深度表達 | 相對浮點值 `depth`：0=基準面，正值更遠，負值更近 | NFR-02：深度只有相對大小意義，非絕對座標 / 非數字 z-order |
| 消失點 | 具名九宮格 `VanishingPoint`（center/top/.../bottom-right） | 沿用 E4-19 `RotationPivot` / E2-27 `ScreenAnchor` 具名錨點精神，不暴露座標數字 |
| 縮放公式 | `scale(d) = 1 / (1 + perspective_strength * d)` | 確定性、單調（越遠越小），d=0 時為 1（無變化） |
| 視差位移 | `offset = vanishing_point_direction * parallax_strength * (1 - scale(d))` | 基準面無位移；越遠越朝消失點方向位移，模擬透視匯聚 |
| 變形產出 | `translate(offset) ∘ scale(s,s)`（E4-22 `Transform2D::compose`） | 先縮放再位移；唯一幾何輸出是矩陣，呼叫端自行套用，符合 NFR-02 |
| 退化判定 | `(1 + perspective_strength*d) <= kMinPerspectiveDenominator(1e-3)` → `Invalid` | 深度達到/超越與消失點重合的臨界點時明確拒絕，不回傳 NaN/Inf 或無意義巨大縮放 |
| 不變量維護 | `set_depth` / `set_perspective_strength` 互相校驗對方，拒絕會使組合退化的設定 | 保證 `transform()` / `render_model()` 恆可安全取值，無需呼叫端額外檢查狀態 |
| 查任意深度 | `transform_for_depth(d)` 回傳 `PerspectiveTransformResult{status, transform, scale}` | 純函式、不改狀態；無效深度明確回報，不靜默（同 E4-22 `InverseResult` 精神） |
| 景深模糊（可選） | `depth_blur = blur_strength * |depth - focal_depth|`；預設關閉 | 相對量而非像素半徑；關閉時恆為 0，不影響既有渲染描述語意 |

介面平台中立：無 `#ifdef _WIN32` / `win32` / `cocoa` 等平台分支，只依賴 E4-22 純數學變形矩陣。
