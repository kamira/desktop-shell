### K-010：CI 產物「上傳成功」不等於「拿得到」

`CHG-20260829-03` 踩到的：`upload-artifact` 全綠、log 寫 `successfully uploaded`、
給了下載 URL，但 agent 取用回 **403**——下載端點要互動式工作階段或另一組憑證，
而 proxy 注入的是 git 協定憑證，套不上去。

根因不只是憑證：**`upload-artifact` 預設的消費者是坐在瀏覽器前面的人**。
在 agent 操作的 repo 裡，「要人點一下才拿得到」等於這條路只走得完一半，
而且會偽裝成成功——失敗發生在下游，workflow 仍是綠的。

依 `AGENTS.md` §4「錯誤要記錄錯誤 + 根因 + 解法」收錄。
