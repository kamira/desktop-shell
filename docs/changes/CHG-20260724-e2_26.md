# CHG-20260724-e2_26 — RSS / 標題抓取（E2-26）

- Date: 2026-07-24 | Branch: feat/e2_26 | Risk: low | Implemented by: I1.90
- Skill: ai-sdlc-autopilot

## Motivation
E2-26「RSS / 標題抓取」是 module 層（子系統 sysinfo）的一個**指標提供者**：透過 **E2-14 的
HTTP 取得機制**（可注入 `HttpTransport` + `NullHttpTransport`）抓取 **RSS/Atom feed 或網頁**內容，
解析出 feed 項目（標題 / 連結 / 時間）或網頁 `<title>`，並以 **E2-01 的 `MetricProvider` 介面**
暴露（每項目一實例、最新 N 筆）。這是「新增指標 = 新增 `MetricProvider`、掛件一行不動」機制的
又一具體實例——它**消費 E2-01 / E2-14 契約、不自造指標模型、不自造 HTTP 傳輸**。相位 1（Mac /
null 期）沿用 E2-14 的 null 傳輸，**不真的發網路請求**（回注入的固定回應或「無後端」空回應）；
真實網路後端留待後端相位。RSS / Atom / HTML 標題解析為**純文字處理**，可完全單元測試。

## Impact

### 新增 `modules/sysinfo/e2_26/`（module 層 / 子系統 sysinfo）
- `feed_fetch.hpp` / `feed_fetch.cpp`（`namespace ds::sysinfo`）：
  - **結構化解析**（自帶輕量標記掃描器，純文字處理，不引入 depends_on 外相依）：
    - `FeedType`（Rss / Atom / Html / Unknown）、`FeedItem{title, link, time}`、
      `FeedDocument{type, title, items}`。
    - `parse_feed(markup) → FeedParseResult`：掃描標記（含註解 / CDATA / 宣告 / 屬性）、解碼常見
      XML/HTML 實體（`&amp; &lt; &gt; &quot; &apos; &#nn; &#xNN;`）、抽出 feed/channel 標題與各
      項目（RSS `<item>` / Atom `<entry>`；Atom `<link href>`、RSS `<link>` 文字；`pubDate`/
      `published`/`updated` 時間文字）。型別由 root（`<rss>`/`<rdf:RDF>`/`<feed>`/`<html>`）或
      項目元素回推。**空 feed（無項目）為成功（0 項目）；malformed 標記（未結束標籤 / 註解 /
      CDATA、或完全無法辨識的內容）為失敗**（帶訊息，不靜默——NFR-04 精神）。
  - `FeedFetchProvider : public ds::metrics::MetricProvider`（消費 E2-01 契約、沿用 E2-14 傳輸）：
    `provider_id()=="sysinfo.feed:<metric_id>"`；`register_metrics(registry)` 掛上單一指標並
    預配置 **N 個 slot 實例**（最新 N 筆，slot 0 = 最新，識別碼 `item0..item{N-1}`）。`sample()`：
    經注入 `HttpTransport` GET url →（2xx）`parse_feed()` → 取最新 N 筆填入 slot
    （value.text = 標題、value.number = slot 序位、value.valid = 該 slot 有項目）、多出的 slot
    標為 unknown。連結 / 時間經 `items()`（`FeedItem`）暴露，比照 E2-14 `last_document()`（因
    E2-01 實例只承載 number + 可選 text，完整結構由提供者側暴露）。網頁 HTML（無 feed 項目、
    僅 `<title>`）合成單一項目。
  - 保守設計：transport 為 null、未 register、非 2xx、解析失敗（malformed）時 `sample()` 回 false
    並把所有 slot 標為 unknown（不崩、不污染）；**空 feed 回 true 且 `item_count()==0`**（與
    malformed 明確區分）。重複 id 由 E2-01 註冊表保守拒絕，掛上失敗時不保留參照（`sample()`
    隨即 no-op）。`max_items==0` 保守夾為 1。診斷：`last_status()` / `last_parse_ok()` /
    `last_error()` / `last_document()` / `items()` / `item_count()`。
  - `CMakeLists.txt`：`add_library(e2_26 STATIC feed_fetch.cpp)` **PUBLIC 連上游 `e2_01` `e2_14`**
    （標頭 include `metric.hpp` 與 `http_fetch.hpp`，須傳遞 include 目錄；e2_14 又 PUBLIC 傳遞
    e2_02）；`test_e2_26` + `add_test(NAME e2_26)`。
- 上游相依：E2-01 統一指標介面、E2-14 HTTP 取得與結構化解析（皆可讀不可改）。
- **無** `#ifdef` / win32 / cocoa / socket / 真實網路呼叫（backend_guard 綠燈）。純邏輯、平台中立。

### 測試 `tests/e2/test_e2_26.cpp`（gtest，32 案例）
- `parse_feed` RSS（2）：項目標題 / 連結 / 時間；`<rdf:RDF>` 判為 RSS。
- `parse_feed` Atom（1）：`<entry>`、`<link href>` 連結、`published`/`updated` 時間。
- `parse_feed` HTML / 標題（2）：網頁 `<title>`（含實體解碼）；裸 `<title>` 也可辨識。
- 實體 / CDATA / 註解（3）：具名 + 數值實體解碼；CDATA 原樣保留；註解 / 宣告跳過。
- 多項目（1）：5 項目保序。
- 空 feed（1）：成功、0 項目。
- malformed 報錯（5）：未結束標籤 / 註解 / CDATA、純文字無標記、空輸入——皆非靜默（訊息非空）。
- 提供者身分 / 註冊（3）：`provider_id`、可上轉 E2-01 `MetricProvider`；掛上 N 個 slot、採集前
  皆 unknown；`max_items==0` 夾為 1。
- 注入 RSS / Atom → slot（2）：解析入 slot（text=標題、number=序位）、`items()` 連結；Atom href。
- 最新 N 筆截斷（1）：10 項目、3 slot → 取前 3。
- 網頁 HTML → 單一 slot（1）：合成單一項目。
- 空 feed 經 provider（1）：成功、無有效 slot。
- 重新採集清舊（1）：上一輪 slot 於本輪空 feed 時被清為 unknown。
- 非 2xx（2）：404 保持 unknown、不解析；先成功後 500 清 slot。
- 解析錯誤（1）：malformed body → unknown 且記錄可讀錯誤。
- null / 保守（4）：null 傳輸無後端、nullptr 傳輸、未 register 就 sample、重複 id 皆 no-op 不崩。
- 消費者範式（1）：掛件風格消費者只走 E2-01 registry / Metric 介面（含 `find_instance`），全程無
  sysinfo / FeedItem 型別。
