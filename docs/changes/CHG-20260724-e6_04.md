# CHG-20260724-e6_04 — 延遲與批次執行（E6-04）

- Date: 2026-07-24 | Branch: feat/e6_04 | Risk: low | Implemented by: I1.50
- Skill: ai-sdlc-autopilot
- Unit: E6-04（延遲與批次執行，engine 層 / 命令子系統 / low；相依已合併的 E6-01）

## Motivation

E6-01 命令匯流排提供「即時分派」——呼叫 `dispatch(id, args)` 立刻執行處理器。但真實桌面殼層需要
兩種**非即時**的執行語意：

- **延遲執行**：把一個命令排在「N 個時間單位後」觸發（如手勢釋放後延遲收合、去抖動、逾時動作）。
- **批次執行**：把多個命令組成一個序列一次提交、保證依序執行，並在其中一步失敗時能明確得知
  **是哪一步**失敗，而非靜默略過。

E6-04 在 E6-01 契約之上補齊這兩者，且維持 engine 層的核心原則：**平台中立、可完全單元測試、
時間可注入**。時間刻意採**邏輯 tick + 外部 `advance()` 驅動**，不綁真實 wall-clock、不 `sleep`、
不開 thread——相位 1 測試可決定性地推進時間；相位 2 若要真實計時，只需由外部（如事件迴圈）驅動
`advance()`，本邏輯一行不動。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 命名空間 | `ds::command`（與 E6-01 一致） | 同一命令子系統的延伸，消費者無需跨命名空間 |
| 時鐘模型 | 邏輯 `Tick`（`int64`）+ `advance(ticks)` 外部推進 | **不用真實時間 / sleep / thread**；決定性、可注入、平台中立 |
| 延遲語意 | `schedule(delay, cmd)` 排在 `now()+delay`；`delay` 須 >= 1 | 「N 個時間單位後」；`delay < 1` 非未來，拒絕回 `kInvalidDeferredId`（不靜默） |
| 到期觸發 | `advance(ticks)` 執行所有 `due <= now` 者，回 `vector<DeferredDispatch>` | 到期才分派；一次 advance 可跨多個 tick 一併觸發 |
| 到期順序 | 先到期（`due` 小）先執行；同 tick 依排程序號（`seq`）FIFO | 決定性順序；不因容器實作而變 |
| 取消 | `cancel(id)` 移除未執行排程；回是否確有移除 | 到期前可撤銷；未知 / 已執行 / 無效 id 回 false，不崩潰 |
| 逆行保護 | `advance(ticks<0)` 為 no-op（不倒轉、不執行） | 邏輯時鐘單調；不製造時間旅行語意 |
| 批次模式 | `BatchMode{Atomic, Continue}` | Atomic=首個失敗即中止並定位失敗步；Continue=跑完全部逐步回報 |
| 「原子」語意 | 首次失敗即**中止後續**並回報 `failed_index` | 一般命令匯流排無法補償 / 回滾已發生的副作用，故原子=abort-on-failure + 明確定位（非事務回滾），文件明載避免誤解 |
| 批次順序 | 嚴格依提交順序分派 | 順序保證 |
| 失敗回報 | 未知命令沿用 E6-01 `NotFound`；批次視為失敗步、延遲如實帶回 | 不靜默（與 E6-01 一致） |
| 結果型別 | `DeferredDispatch` / `BatchResult` / `BatchStepResult` 皆值型別，內嵌 E6-01 `CommandResult` | 跨模組邊界穩定；不重造結果模型 |

介面平台中立：無 `#ifdef _WIN32` 等平台分支、不綁任何真實時間 / 執行緒 / 後端，符合相位 1（Mac / null 期）。

## 對外介面（`namespace ds::command`）

延遲：
- `using Tick = std::int64_t;` / `using DeferredId = std::uint64_t;` / `kInvalidDeferredId`。
- `DeferredScheduler(const CommandBus&)`：`schedule(delay, cmd)` / `schedule(delay, id, args)` /
  `cancel(id)` / `advance(ticks)` / `advance_to(target)` / `now()` / `pending()` / `has(id)`。
- `struct DeferredDispatch{ id, due, command_id, result; ok(); }`。

批次：
- `enum class BatchMode{ Atomic, Continue };`
- `class Batch{ add(cmd); add(id, args); commands(); size(); empty(); clear(); }`。
- `run_batch(bus, vector<Command>, mode=Atomic)` / `run_batch(bus, Batch, mode=Atomic)`。
- `struct BatchStepResult{ index, command_id, result; ok(); }`。
- `struct BatchResult{ ok, executed, total, failed_index, steps; aborted(); }`。

契約版本：`deferred_batch_contract_version()` → `"e6_04/1.0.0"`。
