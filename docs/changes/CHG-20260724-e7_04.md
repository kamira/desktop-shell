# CHG-20260724-e7_04 — 動態變數與執行期重算（E7-04）

- Date: 2026-07-24 | Branch: feat/e7_04 | Risk: low | Implemented by: I1.73

- Unit: E7-04（動態變數與執行期重算，engine 層 / 描述子系統 / low；相依已合併的 E7-02）

## Motivation

E7-02 的變數系統讓「宣告一次、處處引用」——但那是**靜態**替換：一次求值、結果固定。
描述子系統常需要**執行期可變**的值（視窗尺寸、主題色、使用者偏好），且凡由它衍生出的
值（`half_width = width / 2`、`title = "n=" + count`）都應在來源變更時**自動重算**，
毋須呼叫端手動追蹤誰依賴誰、也毋須整份重解析。

本單元在 E7-02 之上加**反應式變數**：註冊動態來源變數、定義依賴其他變數的衍生變數，
並以**相依追蹤 + 髒標記傳播 + 拓撲重算**，在來源變更時**只重算受影響者**，同時提供
**變更通知 / 訂閱**與**循環相依偵測**。值型別沿用 E7-01 的 `Value`，不重造輪子。

依 NFR-04 精神「不靜默失敗」：循環相依、未知變數、對衍生變數 set、相依不存在——
一律回傳帶訊息（含肇因變數名）的 `ReactiveError`，絕不靜默接受、也不無限遞迴。
本單元屬 engine 層（平台中立純邏輯）：無任何 `#ifdef` / 系統呼叫 / 真實後端，可完全單元測試。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 反應式作用域 | `ReactiveScope`：節點池 + 相依圖（正向 deps / 反向 dependents）+ 每節點快取值 / 髒標記 | 一站式承載相依追蹤與重算，狀態集中、可測 |
| 來源變數 | `set(name, value)`：不存在則建立、存在則更新；回傳新值 | 執行期可變的根本入口；對衍生變數 set → 明確拒絕 |
| 衍生變數 | `define_derived(name, deps, compute)`：值由 compute 依 deps 算出 | 宣告式相依；deps 顯式列出使相依可追蹤 |
| 計算輸入 | `compute` 只能透過 `DerivedInputs` 讀取**已宣告的** deps；讀未宣告名 → throw | 強制相依關係誠實（否則追蹤失真、重算漏算） |
| 相依追蹤 | 反向邊 `dependents`；`set` 時沿反向邊 BFS 標髒下游 | O(受影響子圖) 傳播，不掃全表 |
| 只重算受影響者 | 髒標記 gate：`ensure_computed` 對「已算過且不髒」的衍生直接回快取 | 未受影響者零重算（測試以 compute 計數驗證） |
| 拓撲重算 | `ensure_computed` 遞迴先求值 deps 再算本節點；菱形相依只算一次（髒標記去重） | 遞迴下降天然即拓撲序；無需顯式排序 |
| 變更通知 | `on_change(cb)`；一次傳播中**值實際改變**的節點，依建立序（來源優先）觸發回呼 | 值未變不擾民（見「同值 set 不通知」測試）；順序可重現 |
| 循環偵測 | `define_derived` 於**改動狀態前**以 DFS（name 的 adjacency = new_deps）檢查可達自身 | 明確報錯、狀態不變；另有執行期 `computing_` 堆疊防禦性再守一道 |
| 錯誤模型 | `ReactiveError{message, variable}` + `ReactiveResult`（Value / error 二選一） | 對齊 E7-02 `ResolveResult` 風格；帶肇因變數名 |
| 錯誤傳遞 | 遞迴內部以受控例外 `ReactiveException` 承載，於公開邊界捕捉轉 failure | 讓遞迴下降碼乾淨；對外仍為無例外的結果物件 |
| 延遲 get | `get` 對髒衍生就地重算（`const` + 快取為邏輯常量，內部 `const_cast`） | 支援延遲求值路徑；set/define 亦已即時傳播 |

介面平台中立：無 `#ifdef _WIN32` 等平台分支、不綁任何真實後端，符合相位 1（Mac/null）約束。
engine 層與平台無關（非 `src/kernel/backend/`，不涉 backend_guard）。不含能力閘控呼叫（純格式邏輯），
無 `has()` 降級路徑需求。
