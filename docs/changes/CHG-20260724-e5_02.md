# CHG-20260724-e5_02 — 懸停進出事件（E5-02）

- Date: 2026-07-24 | Branch: feat/e5_02 | Risk: low | Implemented by: I1.125
- Skill: ai-sdlc-autopilot
- Unit: E5-02（懸停進出事件，engine 層 / 事件 / low，depends_on=[E1-04]）

## Motivation

上層（hover 高亮、tooltip、游標樣式切換等）需要在滑鼠移入 / 移出某個 surface 時得到明確的
事件通知，並能查詢「目前滑鼠懸停在哪個 surface 上」。這個語意跨平台一致，但若直接綁真實
滑鼠 / 視窗系統事件（`WM_MOUSEMOVE`、`NSTrackingArea` 等），邏輯就無法在單元測試中重現，
也違反 engine 層「平台中立、換平台一行不動」的分層要求。

E5-02 提供一個平台中立的懸停追蹤器：滑鼠移動由呼叫端驅動（`inject_move(point)`），命中
判定完全委由上游 E1-04 `HitTester::topmost_hit`（幾何命中 + 具名圖層優先），追蹤器僅負責
比較「這次命中的最上層 surface」與「先前懸停的 surface」，據以分派 Enter / Leave / Move。
相位 2 的真實後端只需在 OS 滑鼠移動回呼到達時呼叫同一個 `inject_move` 路徑，介面與分派語意
一行不動。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 命中判定 | 委由 E1-04 `HitTester::topmost_hit(point, surfaces)` | 不重新實作幾何 / 圖層優先邏輯；換平台一行不動 |
| 座標 / surface 型別 | 直接沿用 `ds::kernel::LocalPoint` / `ds::kernel::SurfaceId` | 與 E1-04 無縫互通，NFR-02 本地座標一路貫穿 |
| 事件種類 | `HoverEventKind{Enter, Leave, Move}` | 進 / 出 / 同 surface 內移動的語意各自獨立、可分別訂閱處理 |
| 事件承載 | `HoverEvent{kind, surface, point}`，純資料 | 不綁任何 OS 原生事件型別，換平台不動 |
| 狀態驅動 | `inject_move(point)` 為唯一驅動入口 | engine 層須可注入、可斷言；真實滑鼠來源與邏輯解耦 |
| 跨 surface 移動 | 先分派 Leave（舊）、後分派 Enter（新） | 對訂閱者而言「先離開再進入」語意自然、順序固定可測 |
| 同 surface 內移動 | 不重發 Enter，改發 Move | 避免高亮 / tooltip 等訂閱者被重複觸發進場動畫 |
| 無命中 | 先前有懸停→分派 Leave 並清空；先前本就無懸停→no-op 不分派 | 不發假事件；「無命中處理」須報錯不靜默地被覆蓋 |
| hit-test 回 Invalid | `inject_move` 回傳 false，不改狀態、不分派事件 | 與 E1-04「報錯不靜默」一致，呼叫端可據回傳值察覺形狀 / 座標錯誤 |
| surface 登記 | `add_surface` / `remove_surface`（依 `HitSurface.id`） | 追蹤器需自行持有待命中測試的 surface 集合；沿用 E1-04 `HitSurface` 型別，不另建重複資料結構 |
| 移除目前懸停中的 surface | 僅清除內部懸停狀態，不合成 Leave | 沒有真實注入座標可供該事件使用，避免捏造事件內容 |
| 訂閱模型 | `std::function` 回呼 + `SubscriptionId` | 與 E5-03/E5-04 一致的訂閱慣例；解耦訂閱者 |
| 分派順序 | 依 `SubscriptionId` 遞增（訂閱順序），有序 `std::map` 保存 | 順序穩定、可測 |
| 回呼中改動訂閱 | 分派前先取快照 | listener 在回呼內訂閱 / 解除訂閱不影響本輪、避免疊代中改容器的 UB |

介面平台中立：無 `#ifdef _WIN32` 等平台分支、不綁任何真實滑鼠 / 視窗系統 API，符合相位 1
（Mac/null）約束。

## Impact

### 1. `engine/events/e5_02/hover_tracker.hpp`（新增）
- `SubscriptionId`（0 保留為無效）、`HoverEventKind`（Enter/Leave/Move）、
  `HoverEvent{kind, surface, point}`、`HoverListener`。
- `HoverTracker`：`subscribe()` / `unsubscribe()` / `add_surface()` / `remove_surface()` /
  `inject_move()` / `current_hover()` / `listener_count()` / `surface_count()`。
- 型別直接沿用 E1-04 `ds::kernel::LocalPoint` / `ds::kernel::SurfaceId` / `ds::kernel::HitSurface`。

### 2. `engine/events/e5_02/hover_tracker.cpp`（新增）
- `inject_move` 呼叫 E1-04 `HitTester::topmost_hit` 判定命中，依前次懸停狀態分派
  Enter / Leave / Move（詳見上表）；`Invalid` hit-test 不改狀態不分派；分派前取訂閱快照。
  無任何平台分支。

### 3. `engine/events/e5_02/CMakeLists.txt`（新增）
- `add_library(e5_02 STATIC hover_tracker.cpp)` + `target_link_libraries(e5_02 PUBLIC e1_04)` +
  `test_e5_02` executable + `add_test(NAME e5_02)`，依 BUILD.md 樣板；根 CMakeLists 自動 glob
  收入（`engine/*/*/CMakeLists.txt`）。

### 4. `tests/e5/test_e5_02.cpp`（新增）
- 14 個 gtest 案例：移入發 Enter（含事件內容）、移出發 Leave、跨 surface 移動發
  Leave→Enter（順序驗證）、同 surface 內移動不重發 Enter（改發 Move）、當前懸停查詢隨狀態
  變化、未登記任何 surface 時永不分派、已在無命中處再次無命中維持靜默、hit-test 回 Invalid
  時不分派不改狀態、空 listener 拒收、解除訂閱後不再收、多訂閱者依序分派、`add_surface`
  新增 / 覆蓋回傳值、移除未知 surface no-op、移除目前懸停中的 surface 會清除懸停狀態。

### 5. `docs/structure/units/e5_02.md`（新增；G4 同步）
- 依 BUILD.md 最新慣例，寫**每單元獨立**的結構註記；**不動共用的 `directory.md`**（避免並行衝突）。

## 不含（避免越界）

- **不綁任何真實滑鼠 / 視窗系統 API**（win32/cocoa）；相位 1 僅平台中立介面 + 呼叫端注入。
