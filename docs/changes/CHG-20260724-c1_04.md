## Motivation
C1-04「OSD 浮層 profile」：OSD（On-Screen Display）浮層——短暫顯示的通知 / 狀態浮層
（如音量 / 亮度調整提示），顯示數秒（邏輯 tick）後自動消失，且不搶走使用者操作焦點。
這是一個**組裝型 artifact 單元**：不新增引擎邏輯，而是把三個已合併的擴充點（E1-14
短暫 profile 生命週期、E1-01 具名圖層列舉與 z-order 維持、E1-02 輸入策略四態）組成單一
應用 profile + 行為（show(message, ttl) / update(message) / dismiss()）。相位 1：純資料 /
邏輯組裝，無真實 GUI。

## Impact

### 新增 `content/profiles/c1_04/`
- `osd_overlay_profile.hpp` / `.cpp`：`namespace ds::profiles`。
  - `OsdOverlayProfile`：注入式相依 `ds::kernel::TransientProfileManager&`（E1-14）+
    `ds::kernel::LayerStack&`（E1-01），建構時另帶 `ds::kernel::InputStrategy`（E1-02，
    預設 `ClickThrough`——不擋下方操作的 OSD 慣例）。
  - 行為：`show(message, ttl)`（= E1-14 `create()`，強制 `Ephemeral` + 設定
    `TransientProfile.surface.layer = Overlay`；成功後再 E1-01 `layers.assign(id, Overlay)`
    指派具名頂層——若 assign 因空 id / 能力不可用而拒絕，回滾剛建立的 E1-14 條目
    `lifecycle_.expire(id)`，回 false，不留殘留狀態）/ `update(message)`（顯示中更新內容，
    不觸碰生命週期計時器；未顯示回 false）/ `dismiss()`（= `expire()`，觸發
    `DismissReason::Manual`，連動 E1-01 `layers.remove(id)`）。
  - 組裝入口：`backend_input_policy()` / `hit_result()`（直接透傳 E1-02 純函式
    `to_backend_policy` / `hit_result`）、`layer()` / `layer_name()`（透傳 E1-01
    `layer_name()`，固定回報 `SurfaceLayer::Overlay` / `"layer.overlay"`）、
    `assigned_to_layer_stack()`（查詢是否已指派於注入的 `LayerStack`）。
  - 生命週期整合：建構時向 `TransientProfileManager::on_expire()` 登記一個以 `id_` 過濾的
    回呼，逾時自動觸發 `DismissReason::Timeout` 並連動 `layers.remove(id)`；管理器 /
    圖層堆疊可與其他 OSD（或其他短暫 profile）共用同一實例，互不干擾。回呼內另有狀態
    守衛：`show()` 內回滾觸發的 `expire()` 因本物件尚未進入 `Showing` 狀態而被靜默忽略，
    不誤發使用者可感知的 `on_dismiss`。
  - 解構安全：若 OSD 仍顯示中，dtor 強制 `dismiss()`（避免懸置於 E1-14 管理器 / E1-01
    圖層堆疊上的條目指向已銷毀物件——與 C1-05 `SummonPanelProfile` 相同的已知限制：
    E1-14 `on_expire()` 無移除回呼 API）。
  - 具名狀態 / 原因列舉：`OsdState`（Hidden / Showing）、`DismissReason`（Manual /
    Timeout），各附 `to_string()`（NFR-02）。
- `CMakeLists.txt`：`add_library(c1_04 STATIC)` + `target_link_libraries(c1_04 PUBLIC e1_01
  e1_02 e1_14)` + `test_c1_04`（`tests/c1/test_c1_04.cpp`）+ `add_test(NAME c1_04)`。
