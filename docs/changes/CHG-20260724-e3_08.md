# CHG-20260724-e3_08 — 網路 / 藍牙開關（E3-08）

- Date: 2026-07-24 | Branch: feat/e3_08 | Risk: low | Implemented by: I1.53
- Skill: ai-sdlc-autopilot

## Motivation
E3-08「網路 / 藍牙開關」是 modules/actuators（動作層 / 子系統 actuators）的一個**無線電
開關致動器**：把「切換網路介面（Wi-Fi）與藍牙 開 / 關 / 切換 / 查詢狀態」這組副作用，以
具名命令掛上 **E6-01 命令匯流排**（擴充點 3「動作」契約）。呼叫端只需 命令 id 即可觸發，
**不需相依本致動器或任何 OS 網路 / 藍牙 API**——與已合併的 E3-05（音量設定）採同一
「注入式後端 + null 樣式」範式。相位 1（Mac / null 期）**絕不呼叫真實 OS 網路 / 藍牙 API**
（不含 CoreWLAN / IOBluetooth / `networksetup` 等），只提供**平台中立介面 + null / 假後端
（純記憶體狀態模擬）+ 契約測試**；真實平台後端留待相位 2，屆時致動器與命令契約一行不動。

## Impact

### 新增 `modules/actuators/e3_08/`（module 層 / 子系統 actuators）
- `radio_actuator.hpp` / `radio_actuator.cpp`（`namespace ds::actuators`，與 e3_05 一致）：
  - 八個具名命令 id（穩定可讀字串，不用數字 opcode；無線電種類與操作皆編碼於命令名）：
    `net.wifi.on` / `net.wifi.off` / `net.wifi.toggle` / `net.wifi.status`、
    `net.bluetooth.on` / `net.bluetooth.off` / `net.bluetooth.toggle` / `net.bluetooth.status`。
  - `Radio` 列舉（`Wifi` / `Bluetooth`）+ `is_valid_radio(Radio)` + `radio_name(Radio)`
    （非法值回 nullptr）：致動器層唯一的「合法化」點（防止越界列舉值進入後端）。
  - `RadioOp` 列舉（`On` / `Off` / `Toggle` / `Status`）。
  - `RadioState` struct：`wifi` + `bluetooth` 兩布林 + `enabled(Radio)`；含相等運算子，
    供查詢 / 內省。
  - `RadioBackend` 抽象後端：最小介面 `set_enabled(Radio,bool)` / `is_enabled(Radio)`。
    相位 2+ 由平台後端以真實網路 / 藍牙 API 實作；致動器只依賴此抽象。契約：傳入的 radio
    已由致動器驗證為合法值（後端可信任）。
  - `NullRadioBackend`（相位 1 預設後端）：**不接真實系統網路 / 藍牙 API**，以純記憶體狀態
    （每個無線電一個布林旗標）模擬；初值可注入（預設 Wi-Fi / 藍牙皆關）；`state()` 內省。
    讓致動器在無真實後端時仍可完整跑通、狀態一致。
  - `radio_command_table()`：八個具名命令 → (無線電, 操作) 的單一來源對照表，供 register /
    unregister 共用。
  - `RadioActuator`：建構綁定一個 `RadioBackend`（預設 NullRadioBackend）。
    `register_on(bus)` 把八個具名命令註冊到 E6-01 匯流排（全成功才 true；任一失敗回滾
    已掛者、不遮蔽既有致動器；無後端回 false）；`unregister_from(bus)` 回移除數（0..8）。
    處理器 `handle(Radio, RadioOp, args)` 亦可直接呼叫（測試不經匯流排也能驗證語意）：
    - `net.<radio>.on`：啟用該無線電（已啟用維持啟用 → **冪等**）；回啟用後狀態（bool）。
    - `net.<radio>.off`：停用該無線電（已停用維持停用 → **冪等**）；回啟用後狀態（bool）。
    - `net.<radio>.toggle`：翻轉該無線電開關；回翻轉後狀態（bool）。
    - `net.<radio>.status`：查詢是否啟用（**不改狀態**）；回目前狀態（bool）。
    無效 radio（越界列舉值）/ 無後端 → `CommandResult{Failed}`（不崩潰、不改後端狀態、
    不丟例外）。所有成功結果的 `value` 皆為該無線電操作後的啟用狀態（bool），訊息帶
    `"<radio> on/off"`。兩無線電互不干擾（操作其一不影響另一）。
  - `radio_toggle_contract_version()`：契約版本標記 `"e3_08/1.0.0"`（定義在 .cpp，使 STATIC
    程式庫非空並集中版本字串；命名加 `radio_` 前綴避免與同命名空間其他致動器的版本函式衝突）。
  - `CMakeLists.txt`：`add_library(e3_08 STATIC radio_actuator.cpp)` **PUBLIC 連上游
    `e6_01`**（標頭 include `command_bus.hpp`，須傳遞 include 目錄）；
    `test_e3_08`（`tests/e3/test_e3_08.cpp`）+ `add_test(NAME e3_08)`。
- 上游相依：E6-01 命令匯流排（`ds::command::CommandBus` / `CommandArgs` / `CommandResult` /
  `CommandValue`），可讀不可改——消費擴充點 3「動作」契約，不自造匯流排或值型別。
- **無** `#ifdef` / win32 / cocoa / CoreWLAN / IOBluetooth / `networksetup` 等真實 API
  （backend_guard 綠燈）。致動器邏輯（無線電合法化、分派、切換 / 查詢、結果回報）與後端
  完全解耦、純邏輯、平台中立、可注入。

### 測試 `tests/e3/test_e3_08.cpp`（gtest，20 案例）
- 註冊 / 反註冊（4）：八命令全掛、重複註冊回滾且不改既有、null 後端不可註冊、
  unregister 移除全八個且再呼叫回 0。
- Wi-Fi 分派 + null 後端一致（3）：on 啟用、off 停用（藍牙不受影響）、status 不改狀態。
- 藍牙分派（2）：on/off（Wi-Fi 不受影響）、status 查詢。
- 切換冪等性（4）：on 冪等、off 冪等、toggle 每次翻轉、藍牙 toggle 與 Wi-Fi 獨立。
- 無效 radio（2）：越界列舉值 → Failed 且不改後端狀態；合法值輔助函式驗證。
- 無後端（1）：各處理器回 Failed。
- 未知命令（1）：匯流排回 NotFound（不崩潰）。
- null 後端序列一致（1）：連續 set / 查詢後兩無線電狀態一致。
- 直接呼叫處理器（1）：語意等價。
- 契約版本標記（1）。
