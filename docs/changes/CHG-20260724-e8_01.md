# CHG-20260724-e8_01 — 腳本引擎（QML/JS）（E8-01）

- Date: 2026-07-24 | Branch: feat/e8_01 | Risk: low | Implemented by: I1.83
- Skill: ai-sdlc-autopilot
- Unit: E8-01（腳本引擎（QML/JS），engine 層 / 描述子系統 / low；相依已合併的 E6-01）

## Motivation

命令匯流排（E6-01）讓任意致動器以具名命令掛上匯流排、呼叫端只憑 id + 參數即可觸發副作用。
但要讓**使用者 / 佈景 / 模組以腳本（概念上 QML/JS 風格）描述行為**，還需要一個能**載入、
執行腳本、並讓腳本與宿主互動**的引擎：宿主把具名函式綁上引擎、暴露 / 讀寫全域變數、腳本
呼叫綁定的函式——並於其中經 E6-01 分派命令，形成「腳本 → 宿主 → 命令」的嵌入契約。

**相位 1 不綁任何真實 JS 引擎**（無 V8 / QuickJS / QJSEngine / `#ifdef`）：本單元只定義
**可插拔的 `ScriptEngine` 抽象介面** + 相位 1 的最小 / mock 後端，把嵌入 API 的形狀先立好、
可完全單元測試；真實 QML/JS 後端留待相位 2 掛上同一介面即可。屬 engine 層（平台中立純邏輯）。

依 NFR-04 精神「不靜默失敗」：語法錯誤（載入 / 求值，帶行號）、執行期錯誤（未定義全域、
未綁定函式、宿主函式失敗、命令分派失敗、後端不支援）一律帶明確種類 + 訊息回報，絕不安靜略過。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 核心抽象 | `ScriptEngine`（純虛介面：evaluate / bind_function / set_global / get_global / call / has_function / backend_name） | 宿主只相依抽象；相位 2 真實 QML/JS 後端掛同一介面即「可插拔替換」 |
| 腳本值型別 | `using ScriptValue = ds::command::CommandValue`（沿用 E6-01） | 穩定值型別（null/bool/int/double/string）跨腳本 / 宿主 / 命令邊界不變形；不重造 |
| 宿主函式 | `HostFunction = function<HostResult(const vector<ScriptValue>&)>` | 腳本 → 宿主回呼；`HostResult{ok,value,message}` 讓宿主失敗**明確**上浮為腳本執行期錯誤 |
| 相位 1 後端 A | `MiniScriptEngine`：最小內建直譯器 | 足以驗證嵌入契約（綁函式→腳本呼叫→分派命令）；不需真實 JS 引擎 |
| Mini 腳本語法 | 逐行：`set <name>=<expr>` / `<name>=<expr>` / `<call>` / 裸 `<expr>`；`#` 註解 | 極簡、完備到驗證契約；字面值（int/double/string/bool/null）+ 全域參照 + 具名呼叫 |
| 相位 1 後端 B | `NullScriptEngine`：null/mock 後端 | 實作同一介面（保存全域 / 綁定 / 可 call 宿主函式）；`evaluate` 明確回 `Unsupported` |
| E6-01 橋接 | `make_command_binding(bus, cmd_id, arg_names)` / `bind_command(engine, fn, bus, cmd_id, arg_names)` | 一行式把命令暴露為腳本函式；位置引數對映具名參數，`CommandResult`→`HostResult` |
| 錯誤模型 | `EvalResult`（二選一：值 / `ScriptError` 種類 + 訊息 + 行號） | 對齊 E8-02 `RunResult` / E6-01 `CommandResult`；語法 / 執行期錯誤帶定位、不靜默 |
| 重複綁定 | 拒絕（回 false），不靜默覆蓋 | 與 E6-01 `register_command` 一致：避免致動器 / 函式被無聲遮蔽 |

介面平台中立：無 `#ifdef _WIN32` 等平台分支、無 V8 / QuickJS / QJSEngine / 真實 JS 後端，
符合相位 1（Mac/null）約束。engine 層與平台無關（非 `src/kernel/backend/`，不涉 backend_guard）。
純邏輯、無能力閘控呼叫（副作用經 E6-01 命令，命令端自負能力保護），無 `has()` 降級路徑需求。
API 面不含絕對座標 / 數字 z-order（NFR-02 不適用於腳本引擎）。
