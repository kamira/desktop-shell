# CHG-20260724-e5_14 — 碰撞區域名事件參數（E5-14）

- Date: 2026-07-24 | Branch: feat/e5_14 | Risk: low | Implemented by: I1.136
- Skill: ai-sdlc-autopilot
- Unit: E5-14（碰撞區域名事件參數，engine 層 / 角色 / low，depends_on=[E5-01, E1-05]）

## Motivation

E5-01 已交付「滑鼠事件命中哪個具名 surface」的注入 / 路由 / 訂閱，E1-05 已交付「一個 surface
本地座標系內，某點命中哪個具名子區域（+ 其參數）」。但兩者目前互不相通：訂閱 E5-01 事件的一方
只知道「點了哪個 surface」，不知道 surface 內部更細緻的具名子區域（例如按鈕的不同部位、地圖的
不同區塊）——這正是 E1-05 已能查詢、卻沒有管道自動帶入事件的資訊。

E5-14 把兩者橋接起來：當滑鼠事件命中某具名 surface 後，若該 surface 另外登記了一組 E1-05
`NamedRegionMap` 具名子區域，就把該子區域的具名 id + 參數附加到派發給訂閱者的事件上。未登記
子區域、或命中 surface 但未命中任一子區域，事件仍正常派發（不附加區域參數）——不悄悄丟棄「無
區域資訊」這個合法情形。

本單元**不重新實作任何幾何或按鍵語意**——命中判定、多擊追蹤、底層訂閱派發完全委派已合併的
E5-01 `MouseEventRouter`；子區域查詢完全委派已合併的 E1-05 `NamedRegionMap`。新增的邏輯只有
「橋接」本身：對照表（surface → 子區域集合）+ 把兩邊結果組成新的事件型別再分派。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 橋接方式 | `RegionEventDispatcher` 內部持有一個 E5-01 `MouseEventRouter` 實例，`set_surfaces()` 換手時對每個具名 surface（去重）各訂閱一次內部橋接回呼 `bridge()` | 因為 E5-01 的 `subscribe()` 綁定特定具名 surface，若要「不論哪個 surface 命中都攔截得到事件」，只能對清單裡每個 surface 各訂閱一次；此法完全透過既有 public API 達成，不需修改 / 派生 E5-01 |
| 事件型別 | `RegionEvent{ MouseButtonEvent mouse, bool region_hit, std::string region_name, RegionParams region_params }` | 保留原始 E5-01 事件完整欄位（button/action/position/click_count/target），另外用旗標 + 具名 id + 參數表達區域資訊，未命中時三者皆為結構化空值（同 E1-05 `RegionHit` 慣例） |
| 區域對照 | `std::map<SurfaceId, NamedRegionMap>`：`set_regions(surface, regions)` 逐 surface 登記 | 一個 surface 對應一組獨立的具名子區域集合；未登記的 surface 視為「無子區域」，查詢時直接落到「不附加區域參數」分支，不特別報錯（這是合法情形，不是缺陷） |
| 未命中子區域語意 | `region_hit=false`、`region_name` 空、`region_params` 空字典；事件**仍分派** | 呼應題目「無區域命中的事件正常派（無區域參數）」——不能因為沒有具名區域資訊就悄悄不分派原始滑鼠事件 |
| 轉呼注入介面 | `inject_button()` / `inject_down()` / `inject_up()` / `inject_click()` 皆透傳給內部 router 同名方法，回傳同一個 `RouteStatus` | 呼叫端使用體驗與 E5-01 一致；命中判定 / 多擊游標狀態機完全在內部 router，本單元不重複維護任何按鍵狀態 |
| 自身訂閱表 | 本類別維護獨立的 `subscribe()` / `unsubscribe()` / `listener_count()`（`RegionEvent` 訂閱者），與內部 router 的訂閱表（`MouseButtonEvent`，僅供橋接回呼使用）分離 | 呼叫端只看得到 / 訂閱得到橋接後的 `RegionEvent`，不會意外拿到未附加區域資訊的原始事件；兩張表各自的空 target / 空 listener 拒絕規則、快照分派慣例與 E5-01 一致 |
| `set_surfaces()` 換手 | 每次呼叫先取消先前對內部 router 的全部橋接訂閱，再對新清單重新訂閱 | 整組取代語意（比照 E5-01 `set_surfaces` 本身）；避免舊 surface 訂閱殘留造成重複橋接或洩漏 |
| 命名空間 | `ds::events`（同 E5-01），透過 include 取得 `ds::kernel::NamedRegionMap` / `RegionParams`（E1-05） | 本單元屬 engine/事件層；沿用既有事件系統的命名空間慣例 |

介面平台中立：無 `#ifdef _WIN32` 等平台分支、不綁任何真實滑鼠後端，符合相位 1（Mac/null）約束。
engine 層與平台無關（非 `src/kernel/backend/`，不涉 backend_guard）。
