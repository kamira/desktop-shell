# CHG-20260724-e1_18 — 具名螢幕與每螢幕實例（E1-18）

- Date: 2026-07-24 (UTC+0) | Branch: feat/e1_18 | Risk: low | Implemented by: I1.23
- Skill: ai-sdlc-autopilot
- Unit: E1-18（具名螢幕與每螢幕實例，platform 層 / kernel / low，相依已合併 E1-17 DPI 感知）

## Motivation

多螢幕環境下需要**列舉螢幕**、並為每一螢幕保存**彼此獨立的狀態**。若以數字索引指涉螢幕、
或以絕對 (x,y) 座標 / 數字 z-order 表達佈局，換平台 / 換排列時會失準且違反 NFR-02。
E1-18 提供一組平台中立介面：以**具名 ScreenId**（非數字索引）列舉螢幕，幾何以**具名角色 +
具名相對錨點**表達（不得絕對座標 / 數字 z-order），並以 `PerScreen<T>` 為各具名螢幕保存
獨立的每螢幕實例狀態，可與 E1-17 的每螢幕縮放搭配（例如 `PerScreen<double>` 存 scale_factor）。

相位 1（Mac / null 期）尚無真實多螢幕列舉：只寫介面 + null 後端（單一具名主螢幕，不真的
查詢 OS）；真實後端上線後由後端以實際列舉覆寫。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 螢幕指涉 / 列舉 | 具名 `ScreenId`（字串），`ids()` 依宣告順序列舉 | NFR-02 禁止數字 index / 絕對座標；具名跨平台一致、與實體排列無關 |
| z-order / 主次 | 具名 `ScreenRole`（Primary / Secondary），非數字層級 | NFR-02 禁止數字 z-order |
| 幾何佈局 | 具名 `ScreenAnchor`（Center/Left/Right/Above/Below），非 (x,y) | NFR-02 禁止絕對座標；只描述相對方向 |
| 每螢幕實例 | `PerScreen<T>`：以具名 ScreenId 為鍵的獨立狀態容器 | 各螢幕狀態彼此獨立；未知螢幕保守回 nullptr / fallback |
| 未知螢幕語意 | `find` 回 nullptr、`is_primary` 回 false、`anchor_of` 回 Center | 保守：呼叫端永遠安全 |
| 主螢幕決策 | 第一個 Primary 勝出；無 Primary 退回第一個；空拓撲回 nullptr | 以具名角色決定，不用數字層級 |
| 重複 id | 後定義者為準 | 讓後端能覆寫先前宣告 |
| 與 E1-17 搭配 | `PerScreen<double>` 存各螢幕縮放；CMake 可選 link e1_17 | 相同 `ScreenId` 型別，兩單元具名螢幕互通；不強制依賴 |

介面平台中立：無 `#ifdef _WIN32` 等平台分支、不綁任何真實後端、無 `setPosition(x,y)` 式 API、
無 `src/kernel/backend/`，符合相位 1（Mac/null）與 NFR-02 約束。

## Impact

### 1. `src/kernel/e1_18/named_screens.hpp`（新增）
- `ScreenId`（具名字串識別碼別名，與 E1-17 同型別）。
- `ScreenRole`{ Primary, Secondary }、`ScreenAnchor`{ Center, Left, Right, Above, Below }。
- `Screen`{ id, description, role, anchor } —— 幾何僅以具名角色 + 具名相對錨點表達。
- `ScreenRegistry`：`defaults()` 內嵌預設拓撲、`ScreenRegistry(screens)` 由外部宣告建構；
  列舉 / 查詢介面 `is_known()` / `find()` / `ids()` / `screens()` / `size()` / `empty()` /
  `primary()` / `is_primary()` / `anchor_of()`。
- `PerScreen<T>`（標頭內樣板）：每螢幕獨立實例狀態，以具名 ScreenId 為鍵；
  `set()` / `has()` / `find()` / `get_or()` / `erase()` / `ids()` / `size()` / `empty()` / `clear()`。

### 2. `src/kernel/e1_18/named_screens.cpp`（新增）
- 內嵌預設拓撲（單一具名主螢幕 `screen.primary`，角色 Primary、錨點 Center）。
- `ScreenRegistry` 查詢邏輯：具名列舉、未知螢幕保守、主螢幕以具名角色決定、重複 id 後定義者為準。

### 3. `src/kernel/e1_18/CMakeLists.txt`（新增）

  主螢幕挑選 / 保守退回、未知螢幕保守、空拓撲安全、重複 id 後定義者為準、每螢幕實例獨立、
  每螢幕實例未知保守、覆蓋 / erase / clear、與 E1-17 每螢幕縮放搭配（`PerScreen<double>`）。

## 不含（避免越界）

- **不實作任何真實平台後端**（win32/cocoa）；相位 1 僅介面 + null 宣告行為。
- **無任何絕對座標 / (x,y) / 數字 z-order API**（NFR-02）；幾何只以具名角色與具名相對錨點表達。
