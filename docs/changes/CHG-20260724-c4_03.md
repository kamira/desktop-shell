# CHG-20260724-c4_03 — 實作 C4-03 取色器（artifact 層 / apps，相位 1 純邏輯組裝）

- Date: 2026-07-24 | Branch: feat/c4_03 | Risk: low | Implemented by: I1.149
- Skill: ai-sdlc-autopilot

## Motivation
C4-03「取色器」（color picker / eyedropper）：讓使用者從螢幕任一像素取色，取到後顯示
RGB / HEX 值並可複製。這是一個**組裝型 artifact app**：不新增引擎邏輯，而是把兩個已合併
的擴充點組成單一應用 + 行為（`pick_at(point) -> color` / `magnify` / `copy`）：

- **E2-27**（`ds::sysinfo::PixelSampleSource` / `PixelColor`）：於某具名 `ScreenAnchor`
  讀該點目前像素顏色。
- **E4-30**（`ds::elements::DimOverlayElement`）：全螢幕調光覆蓋，本單元借它組出**放大鏡 /
  取色游標**——顯示覆蓋層並在目前取樣點挖一個具名「不調光」區域。

相位 1：純資料 / 邏輯組裝，無真實螢幕擷取（僅注入式像素來源）、無真實系統剪貼簿。

## Impact

### 新增 `apps/c4_03/`
- `color_picker.hpp` / `.cpp`：`namespace ds::apps`。
  - `ColorPickerApp`：以 `shared_ptr<ds::sysinfo::PixelSampleSource>`（可 null，沿用 E2-27
    `ScreenPixelProvider` 的相依風格）+ `ds::elements::DimOverlayElement&`（不取得所有權）
    建構。
  - `pick_at(ScreenAnchor)`：呼叫 `PixelSampleSource::sample()` 取色 →
    `PickStatus::Ok`（成功，`current()` 更新 RGB/HEX）/ `NoSource`（來源為 null）/
    `NoReading`（該點目前無讀值，即「無效點」）。失敗一律**不動**既有取色狀態
    （不靜默清空已成功取到的顏色）。
  - `ColorPick`：`anchor` + `PixelColor` + `hex`（沿用 `PixelColor::hex()` 的
    `"#RRGGBB"`）+ `rgb_text`（本單元新增的 `"rgb(R, G, B)"` 格式，供另一種顯示）。
  - `magnify()` / `dismiss_magnifier()`：組裝 E4-30 ——`show()` + `add_cutout(region)`（區域名
    = `"region.magnifier." + to_string(anchor)`，NFR-02 具名而非座標）；尚未取色即放大鏡回
    `DimStatus::Invalid`；換取樣點再放大鏡會先清舊挖洞（不累積）；能力不可用時委派 E4-30
    降級為 `Unsupported`（取色 / 複製不受影響）。`dismiss_magnifier()` 移除挖洞並 `hide()`，
    恆安全。
  - `copy()`：複製目前 `current().hex` 到內部 `clipboard_`（相位 1：不接系統剪貼簿）；尚未
    取色 → false（no-op）。
  - 具名結果 `PickStatus`（Ok / NoSource / NoReading）附 `to_string()`（NFR-02）。
- `CMakeLists.txt`：`add_library(c4_03 STATIC)` + `target_link_libraries(c4_03 PUBLIC e2_27
  e4_30)` + `test_c4_03`（`tests/c4/test_c4_03.cpp`）+ `add_test(NAME c4_03)`。

### 新增 `tests/c4/test_c4_03.cpp`（gtest，13 案例）
涵蓋：`pick_at` 取色成功（RGB / HEX 轉換，不同 anchor 取不同色）、無效點（`NoReading`，不
清空既有取色）、無來源（`NoSource`）、複製（尚未取色 no-op / 成功複製 HEX / 覆寫為最新）、
放大鏡（尚未取色 `Invalid` / 顯示覆蓋層 + 挖洞 / 換點清舊挖洞不累積 / 收起移除挖洞並隱藏 /
未曾顯示即收起安全）、NFR-03 降級（alpha 能力不可用 → `magnify()` 回 `Unsupported`，取色 /
複製不受影響）、`to_string(PickStatus)` 穩定字串。

### 相位 1 約束遵循
- 純資料 / 邏輯組裝，無真實螢幕擷取、無真實系統剪貼簿；無平台分支（無 `#ifdef` / win32 /
  cocoa）。
- 核心 API 無絕對座標、無數字 z-order（NFR-02）：取樣點沿用 E2-27 具名 `ScreenAnchor`，放大
  鏡挖洞區域以具名字串表達。
- 能力閘控（`magnify()` 建立 / 改動半透明覆蓋層）委派 E4-30 既有的 `AlphaSurfaceService::
  supported()` 閘控（NFR-03），本單元不重造閘控邏輯。
- 無效操作一律明確回具名結果，不靜默（無來源、無效點、尚未取色即放大鏡 / 複製）。
