# CHG-20260724-c1_07 — 全螢幕調光層 profile（C1-07）

- Date: 2026-07-24 | Branch: feat/c1_07 | Risk: low | Implemented by: I1.147
- Skill: ai-sdlc-autopilot
- Unit: C1-07（全螢幕調光層 profile，artifact 層 / 應用 profile / low）
- 依賴：E4-30（全螢幕調光覆蓋 `DimOverlayElement`）、E1-01（具名圖層 `LayerStack`）

## Motivation

專注模式、夜間調光、彈窗背景變暗這三個常見產品情境，共用同一份底層機制——E4-30
`DimOverlayElement` 提供的全螢幕半透明調光覆蓋（強度 / 顏色 / 淡入淡出 / 挖洞），以
E1-01 具名頂層置頂。但每個情境各自的預設強度、預設色調、以及「啟用 / 停用」的語意
若讓每個呼叫端各自組裝，容易散落重複程式碼、且無單一資料來源核對三情境的預設值是否
合理。C1-07 把這份組裝收斂為一個 artifact 層 profile：`DimOverlayProfile`，以具名情境
（`DimProfileKind`）攜帶各自預設值，並收斂成三個行為動詞 `activate` / `deactivate` /
`fade`。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 情境列舉 | `DimProfileKind{ Focus, NightShift, PopupBackdrop }` | NFR-02：具名情境，非數字；對應語意需求三種常見場景 |
| 預設值 | `default_preset(kind)` 單一資料來源：Focus(0.6, 黑) / NightShift(0.3, 暖色調) / PopupBackdrop(0.7, 黑) | 各情境獨立可調、可測；暖色調降低夜間藍光觀感 |
| 行為介面 | `activate(intensity)` / `activate()`（用預設強度）/ `deactivate()` / `fade(target)` | 收斂為語意清楚的三動詞：套用情境 vs. 任意淡變 |
| activate 語意 | 套用情境預設顏色 + 淡入至目標強度（委派 E4-30 `fade_to`） | 每次啟用都重申「這是哪個情境」，不殘留上次顏色 |
| deactivate 語意 | 委派 `fade_to(0)`（隱藏） | 與 E4-30 既有「淡出至 0 = 隱藏」語意一致，不重造規則 |
| fade 語意 | 直接透傳 `fade_to(target)`，**不**套用情境顏色 | 供呼叫端自訂漸變終點 / 手動微調，不強制重申情境色 |
| 挖洞 / 查詢 / 頂層 / 能力閘控 | 全數透傳 E4-30（`add_cutout` / `layer()` / `alpha_supported()` / `render_model()`） | 不重造已驗證的邏輯，只做應用層收斂 |
| 狀態 | `DimProfileState{ Inactive, Active }` 直接映射底層 `visible()` | 單一事實來源，profile 不維護獨立的影子狀態 |
| 無效參數 | 非有限強度 / 目標 → `DimStatus::Invalid`，不改狀態；空挖洞名同 | 委派 E4-30 既有「報錯不靜默」語意 |

介面平台中立：無 `#ifdef` / `win32` / `cocoa` 等平台分支，無絕對座標 / 數字 z-order（NFR-02）；
建立 / 改動半透明 surface 的操作經 E4-30 內建的 per-pixel alpha 能力閘控（NFR-03），能力不可用
回 `Unsupported`、不改狀態。
