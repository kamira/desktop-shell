# CHG-20260724-e5_10 — 逾時計時器（E5-10）

- Date: 2026-07-24 (UTC+0) | Branch: feat/e5_10 | Risk: low | Implemented by: I1.27
- Skill: ai-sdlc-autopilot

## Motivation
E5-10「逾時計時器」是 engine 層的平台中立純邏輯：供閒置動畫、定時輪詢等消費者
設定一個逾時（以 tick 計），時間到即觸發回呼 —— 支援一次性 timeout 與可選重複 interval。
與 E5-04 心跳相同，時間以邏輯 tick 計、由呼叫端注入推進，**不綁任何真實 OS 計時器 / 時鐘**，
因此決定性、可完全以單元測試驗證。相依已合併之 E5-04（沿用其 `ds::events::Tick` 型別）。

## Impact

### 新增 `engine/events/e5_10/`（engine 層）
- `timeout_timer.hpp` / `timeout_timer.cpp`（`namespace ds::events`）：
  - `TimerId`（單調遞增；0 保留為無效）、`TimerEvent`（id / now / count / repeating）、
    `TimerCallback`。
  - `TimeoutTimer` 服務：
    - `set_timeout(delay, cb)→id`：一次性逾時，到期觸發一次後**自動移除**。
    - `set_interval(interval, cb)→id`：重複逾時，每 interval 週期觸發直到取消。
    - `cancel(id)→bool`：取消計時器。
    - `advance(dt)→size_t` / `tick()`：注入邏輯時間，回傳本次總觸發次數。
    - `remaining(id)→optional<Tick>`：距下次觸發還需幾個 tick（未知 id 回 nullopt）。
    - `is_active(id)` / `now()` / `active_count()`：查詢。
  - `CMakeLists.txt`：`add_library(e5_10)` **PUBLIC 連上游 `e5_04`**；`test_e5_10` + `add_test(NAME e5_10)`。
- 上游相依：E5-04 心跳（`heartbeat_source.hpp` 的 `ds::events::Tick`，可讀不可改）。
- **無** `#ifdef` / win32 / cocoa / 真實 OS 呼叫（backend_guard 綠燈）；無絕對座標 / z-order（NFR-02 不適用亦不違反）。

### 語意保證
- 推進未達逾時不觸發；重複計時器累計跨過即觸發，**餘量保留至下次（不漂移）**。
- 單次 `advance(dt)` 跨越多個 interval 週期時，同一重複計時器連續多次觸發，計次連續。
- 一次性 timeout 觸發一次後移除，該次 advance 縱有餘量也不再觸發（餘量丟棄）。
- 兩階段派發：先結算所有計時器狀態、移除到期一次性計時器，**再統一觸發回呼**；
  於回呼中設定 / 取消計時器不會破壞本次派發、不使容器失效。
- 無效逾時（delay/interval == 0）拒絕、回無效 id 0；`advance(0)` 為 no-op。

### 測試 `tests/e5/test_e5_10.cpp`（gtest，13 案例）
一次性觸發後自動移除、一次性餘量丟棄、重複週期觸發、單次跨多週期多觸發、
重複餘量保留不漂移、剩餘查詢（建立/推進/未知/移除後）、取消停止觸發、
多計時器獨立（一次性+重複並存）、tick 等同 advance(1)、無效逾時拒絕、
advance(0) no-op、回呼中取消他者安全、回呼中新增計時器安全。
