# CHG-20260724-e4_05 — 過場動畫與緩動（E4-05）

- Date: 2026-07-24 (UTC+0) | Branch: feat/e4_05 | Risk: low | Implemented by: I1.7
- Skill: ai-sdlc-autopilot v1.1
- Unit: E4-05（過場動畫與緩動，engine 層 / render 繪製基座 / low）

## Motivation

桌面外殼的視窗過場、面板展開、焦點高亮等視覺變化需要平滑的動畫，而非瞬間跳變。
動畫的兩個核心組件是**緩動曲線**（把線性時間進度重新映射成有加減速感的進度）與
**時間插值**（在給定時長內把某數值從起點過場到終點）。

這兩者都是**純數學**：不依賴真實時鐘、不綁繪製後端、跨平台語意完全一致。因此本單元
屬 engine 層（繪製基座），可在相位 1 就完整定稿並完全單元測試——只要餵入正規化進度 t
或絕對時間，就能確定性地驗證輸出值。真實的每幀時間來源、與畫面合成的接線由上層負責，
本單元只保證「給定時間 → 值」的映射正確。

## 設計（可覆核可改）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 緩動曲線集 | `EasingType` enum class：Linear + In/Out/InOut × {Quad, Cubic, Sine} 共 10 種 | 涵蓋最常用曲線；封閉形式、無外部相依 |
| 緩動 API | `Easing` 靜態純函式 + `apply(type, t)` 分派 | 無狀態、可獨立測單條曲線，也可用列舉動態選擇 |
| 定義域保護 | 所有曲線先 `clamp01(t)` 把 t 夾到 [0,1] | 越界輸入（advance 過頭）永遠安全；保證 f(0)=0、f(1)=1 |
| 未知列舉 | `apply` 回退 linear，不丟例外 | `noexcept`、呼叫端永遠安全 |
| 插值器 | `Tween{from, to, duration, easing}` | 一個物件描述一段過場；value type 為 double |
| 絕對查詢 | `at(time)` 純函式，不改狀態 | 確定性、可隨機存取任一時間點；便於測試與 scrubbing |
| 增量推進 | `advance(dt)` 累加內部經過時間並回當前值 | 逐幀更新的常見用法；經過時間單調不減（負 dt 視為 0） |
| 邊界語意 | time 夾到 [0, duration]；`duration<=0` 視為瞬間完成（恆回 to、done 恆真） | 除以零與退化區間都有明確且安全的行為 |
| 輔助查詢 | `progress()`（未經 easing 的線性比例）、`done()`、`reset()`、存取器 | 供上層判斷動畫是否結束、重播 |

平台中立：無 `#ifdef _WIN32` / win32 / cocoa 等平台分支，不綁任何真實時鐘或繪製後端，
時間單位為呼叫端傳入的秒（double）。符合 engine 層與相位 1 約束。

NFR 對照：本單元核心 API 不含絕對座標，也不含數字 z-order（NFR-02 不適用於數值插值），
且無能力閘控呼叫（NFR-03 不適用）——為純數學工具單元。

## Impact

### 1. `engine/render/e4_05/easing.hpp` / `easing.cpp`（新增）
- `EasingType`（enum class，10 種曲線）。
- `Easing`：`clamp01` + 各曲線靜態純函式（linear / in|out|in_out × quad|cubic|sine）+ `apply(type, t)` 分派。
- 全部 `noexcept`；sine 曲線用 `<cmath>` 的 `std::cos`/`std::sin`，其餘為多項式。

### 2. `engine/render/e4_05/tween.hpp` / `tween.cpp`（新增）
- `Tween`：`at(time)` 絕對查詢、`advance(dt)` 增量推進、`value()` / `progress()` / `done()` / `reset()` 與存取器。
- `duration<=0` 瞬間完成；time 與 progress 皆夾在合理域。

### 3. `engine/render/e4_05/CMakeLists.txt`（新增）
- `add_library(e4_05 STATIC easing.cpp tween.cpp)` + `test_e4_05` executable + `add_test(NAME e4_05)`，
  依 BUILD.md 樣板；根 CMakeLists 自動 glob 收入（`engine/*/*/CMakeLists.txt`）。

### 4. `tests/e4/test_e4_05.cpp`（新增）
- 17 個 gtest 案例：曲線端點精確（f(0)=0、f(1)=1）、越界夾住、單調不減、linear 恆等、
  In 慢入 / Out 快入、InOut 對稱與中點=0.5、In/Out 對偶；
  Tween 起訖精確、線性中點、easing 影響、反向、advance 累加與單調、progress 語意、reset 重播、
  duration<=0 瞬間完成、存取器。

### 5. `docs/structure/units/e4_05.md`（新增；G4 要求）
- 每單元獨立結構註記（依 CHG-20260723-20 新慣例，不動共用 `directory.md`）。

## 不含（避免越界）
