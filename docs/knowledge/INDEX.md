# 知識庫 INDEX

AGENTS.md §1 進場握手第 2 步要求讀本檔——**前人踩過的坑，不要重踩**。

## 檔案

| 檔 | 內容 | 誰可以寫 |
|---|---|---|
| [`errors.md`](errors.md) | 踩過的錯誤，每條記「**錯誤 + 根因 + 解法**」 | **任何單元分支皆可寫**（在 `scope_check.py` 的 `COMMON` 白名單內） |
| 本檔 `INDEX.md` | 慣例說明與導覽 | 僅 infra CHG（**不在** `COMMON` 內，單元分支寫了會被 G1 擋） |

> 本檔刻意設計成**不隨每條錯誤更新**：新錯誤一律往 `errors.md` 追加即可，
> 不必回頭改 INDEX。否則單元分支會被 G1 `scope_check` 夾殺（`COMMON` 只放行 `errors.md`）。

## 寫入規則（AGENTS.md §4）

- 錯誤要記「**錯誤 + 根因 + 解法**」三件齊全。只記現象不記根因的條目沒有價值。
- **機密只記位置不記值**（記「憑證在哪個設定鍵」，不記憑證本身）。
- 新條目**追加在 `errors.md` 最前面**（新的在上），附日期與來源 CHG。
