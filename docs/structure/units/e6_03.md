# 結構註記 — E6-03 條件動作與去抖

- 單元：E6-03（engine 層 / command / Risk: low / depends_on=[E6-01, E7-05]）
- 目錄位置：`engine/command/e6_03/`（平台中立引擎邏輯，換平台一行不動）
- 測試：`tests/e6/test_e6_03.cpp`（CTest 名 `e6_03`）

## 放了什麼
- `conditional_action.hpp`：條件動作與去抖 / 節流契約 ——
  - `value_truthiness(Value, bool&)`：E7-05 求值結果 → 布林真值（Bool / Number；其餘型別回 false）。
  - `ConditionalStatus` / `ConditionalOutcome`（Dispatched / Skipped / ConditionError + 工廠）。
  - `ConditionalAction`{condition_expr, command, args}：`evaluate_and_dispatch(bus, scope)` /
    無作用域多載 `evaluate_and_dispatch(bus)`。
  - `Tick`（注入式邏輯時鐘）、`Debouncer`（尾緣 / 合併）、`Throttler`（前緣 / 頻率限制）。
- `conditional_action.cpp`：`conditional_contract_version()`（"e6_03/1.0.0"）、`value_truthiness`、
  `ConditionalAction::evaluate_and_dispatch` 編排邏輯；Debouncer / Throttler 為 header inline。
- `CMakeLists.txt`：`add_library(e6_03)` + `target_link_libraries(PUBLIC e6_01 e7_05)` + `test_e6_03`
  + `add_test(NAME e6_03)`。

## 對外介面（一句話）
`ds::command::ConditionalAction::evaluate_and_dispatch(bus, scope)`：以 E7-05 公式求條件、成立才經
E6-01 分派命令，求值失敗明確回 `ConditionError`（不靜默）；`Debouncer` / `Throttler` 以注入式邏輯
`Tick` 抑制過頻觸發（`trigger(tick)->bool 是否放行`、`advance(tick)`），去抖合併為一次、節流限制頻率。
