# 結構註記 — C1-04 OSD 浮層 profile

- 單元：C1-04（artifact 層 / 應用 profile / Risk: low）
- 目錄位置：`content/profiles/c1_04/`
- 測試：`tests/c1/test_c1_04.cpp`（CTest 名 `c1_04`，14 個 gtest 案例）

## 放了什麼
- `osd_overlay_profile.hpp` / `.cpp`：**組裝型**單元（非新引擎邏輯）——把三個已合併的
  擴充點組成「OSD（On-Screen Display）浮層」（音量 / 亮度調整提示等短暫通知）應用
  profile：
  - E1-14 `TransientProfileManager`：OSD 短暫生命週期（顯示 ttl 個 tick 後自動消失、
    可手動提早收起）。
  - E1-01 `LayerStack`：OSD 顯示期間具名頂層歸屬（固定 `SurfaceLayer::Overlay`）。
  - E1-02 `InputStrategy`：OSD 參與輸入的方式（預設 `ClickThrough` 點擊穿透，不擋下方
    操作）。
- `CMakeLists.txt`：`add_library(c1_04)` + `target_link_libraries(c1_04 PUBLIC e1_01 e1_02
  e1_14)` + `test_c1_04`（`tests/c1/test_c1_04.cpp`）+ `add_test(NAME c1_04)`。

## 對外介面（一句話）
`ds::profiles::OsdOverlayProfile`：`show(message, ttl)`（= E1-14 `create()` + E1-01
`assign(Overlay)`，任一步失敗即回滾）/ `update(message)`（顯示中更新內容，不動生命週期）/
`dismiss()`（= E1-14 `expire()` + E1-01 `remove()`）/ `on_show` `on_update` `on_dismiss`
事件掛勾 / `backend_input_policy()` `hit_result()` 驗證 E1-02 組裝 / `layer()` `layer_name()`
驗證 E1-01 組裝。相位 1：純資料 / 邏輯組裝，無真實 GUI、無平台分支（無 `#ifdef` / win32 /
cocoa）、無絕對座標 / 數字 z-order（NFR-02）。
