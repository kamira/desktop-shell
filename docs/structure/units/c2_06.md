# 結構註記 — C2-06 動畫 / 序列圖 widget

- 單元：C2-06（artifact 層 / widgets 子系統 / Risk: low）
- 目錄位置：`content/widgets/c2_06/`
- 測試：`tests/c2/test_c2_06.cpp`（CTest 名 `c2_06`，20 個 gtest 案例）

## 放了什麼
- `animation_widget.hpp` / `.cpp`：**組裝型**單元（非新引擎邏輯）——桌面小工具「動畫 / 序列
  圖」：把已合併的 C1-01（掛載基底）與 E4-07（幀序列動畫本體）組起來。
  - `AnimationWidget`：注入式相依 `ds::profiles::SkinProfile&`（C1-01，不取得其所有權，須比
    本物件活得久）。建構時立即把渲染輸出目標綁定為所掛載 skin 的具名 id（`skin.id()`，
    NFR-02：具名，非數字 handle）。內部自持一個 `ds::elements::FrameAnimationElement`（E4-07）。
  - `configure(const ds::format::Value&)`：宣告式設定（E7-01 Map）——`frames`（List，必填，
    每項 `{ref, width, height}`）/ `fps`（選填 Number > 0）/ `loop`（選填 Bool）。先整批驗證
    再委派 E4-07 `set_frames`/`set_fps`/`set_loop`（不部分套用，具名結果 `AnimationWidgetStatus`
    Ok/Invalid）。
  - `play()`/`pause()`/`is_playing()`/`advance(Tick)`/`reset()`/`current_frame()`/
    `frame_count()`/`fps()`/`loop()`/`is_finished()`/`render_model()`：皆為 E4-07 對應介面的
    薄封裝。`skin()`：唯讀存取所掛載的 C1-01 基底。
- `CMakeLists.txt`：`add_library(c2_06)` + `target_link_libraries(c2_06 PUBLIC c1_01 e4_07)` +
  `test_c2_06`（`tests/c2/test_c2_06.cpp`）+ `add_test(NAME c2_06)`。

## 對外介面（一句話）
`ds::widgets::AnimationWidget`（注入 `SkinProfile&`）：`configure(Value)` 宣告式設定幀清單 /
fps / 循環（全有或全無）/ `play`·`pause`·`advance(tick)` 播放控制 / `current_frame`·
`frame_count`·`fps`·`loop`·`is_finished` 查詢 / `render_model()` 產出目前幀渲染描述（目標
綁定所掛載 C1-01 基底的具名 surface id）。相位 1：純資料 / 邏輯組裝，無真實 GUI、無平台分支
（無 `#ifdef` / win32 / cocoa）、無絕對座標 / 數字 z-order（NFR-02）、時間全注入式 tick；
未設定幀（空幀）時所有查詢 / 播放操作安全降級。
