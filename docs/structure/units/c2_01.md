# 結構註記 — C2-01 時鐘 widget

- 單元：C2-01（artifact/widgets 層 / 組裝型 / Risk: low / phase 1）
- 目錄位置：`content/widgets/c2_01/`
- 測試：`tests/c2/test_c2_01.cpp`（CTest 名 `c2_01`，29 個 gtest 案例）

## 放了什麼
- `clock_widget.hpp` / `.cpp`：**組裝型**單元（非新引擎邏輯）——把四個已合併的擴充點組成
  「時鐘 widget」：
  - C1-01 `SkinProfile`：掛載基底，時鐘顯示綁定其具名 surface id（`base.id()`）。
  - E2-10 `TimeSource` / `CivilTime` / `civil_from_epoch_seconds`：注入式時間指標來源
    （相位 1 無真實壁鐘）。
  - E4-01 `TextLayout` / `FontMetrics`：文字排版為相對佈局 `LayoutResult`（NFR-02）。
  - E7-01 `Value`：宣告式時鐘格式定義（`configure` 消費）——`format`(24h/12h) / `seconds` /
    `align` / `width`。
- `CMakeLists.txt`：`add_library(c2_01)` + `target_link_libraries(c2_01 PUBLIC c1_01 e2_10 e4_01
  e7_01)` + `test_c2_01`（`tests/c2/test_c2_01.cpp`）+ `add_test(NAME c2_01)`。

## 對外介面（一句話）
`ds::widgets::ClockWidget`（注入 `SkinProfile&` + `shared_ptr<TimeSource>` + `FontMetrics&`）：
`configure(Value)` 套用顯示樣式並嘗試初次取樣 / `tick()` 重新取樣注入時間來源並重排版 /
`refresh()` 純重排版（不重新取樣）/ `display_text()` 目前格式化時間文字 / `layout_result()`
E4-01 排版結果。相位 1：純資料 / 邏輯組裝，時間一律經注入式 `TimeSource`（無 wall-clock），
無真實 GUI、無平台分支（無 `#ifdef` / win32 / cocoa）、無絕對座標 / 數字 z-order（NFR-02）。
