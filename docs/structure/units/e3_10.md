# 結構註記 — E3-10 桌布設定

- 層級：module(動作層致動器)／子系統 actuators
- 目錄位置：`modules/actuators/e3_10/`
  - `wallpaper_actuator.hpp` / `wallpaper_actuator.cpp` — 介面 + null 後端 + 規格 / 模式模型
    + 致動器實作
  - `CMakeLists.txt` — `add_library(e3_10)` **PUBLIC 連上游 `e6_01`**；`test_e3_10`
    (`tests/e3/test_e3_10.cpp`) + `add_test(NAME e3_10)`
- 測試：`tests/e3/test_e3_10.cpp`（gtest，28 案例）
- 上游相依：E6-01 命令匯流排（`engine/command/e6_01`），可讀不可改——消費擴充點 3
  「動作」契約（`CommandBus` / `CommandArgs` / `CommandResult` / `CommandValue`），
  不自造匯流排或值型別。範式與已合併的 E3-05（注入式後端 + null 樣式）一致。
- 對外介面（`namespace ds::actuators`）：一個桌面桌布致動器，把「設定指定顯示器 / 所有
  顯示器的桌布影像路徑 + 縮放模式（fill/fit/stretch/center）／查詢目前桌布」透過
  **E6-01 具名命令**掛上匯流排（`wallpaper.set` / `wallpaper.get`），呼叫端只需 命令 id +
  具名參數即可觸發，不需相依本致動器。
  - `ScaleMode`（Fill/Fit/Stretch/Center）+ `scale_mode_to_string` / `scale_mode_from_string`
    （字串 <-> 列舉；未知字串回 nullopt，據此回報無效模式）；`kDefaultScaleMode = Fill`。
  - `kAllDisplays = -1`：display 缺席時套用所有顯示器（display 為相對索引，非絕對座標 / z-order）。
  - `WallpaperSpec`（path 不透明字串 + mode；含相等運算子）。
  - `WallpaperBackend`（抽象後端：`display_count`/`set(display,spec)`/`get(display)`）、
    `NullWallpaperBackend`（相位 1 null 後端：**不接真實系統桌布 API**，每顯示器一份規格的
    純記憶體狀態模擬、顯示器數可注入、`set_count()` 內省）。
  - `WallpaperActuator`：`register_on(bus)` 掛兩命令（回滾語意）、`unregister_from(bus)`、
    兩個處理器（`wallpaper.set` 必填 path 非空 + 選填 mode/display，缺席 display → 全部；
    `wallpaper.get` 選填 display，未設定回 "unset"；缺 / 型別錯 / 無效值回 Failed 且不改後端，
    `has()`/`get_*` 保護）、`current_spec(display)` 內省。
  - 核心性質：相位 1（Mac/null 期）平台中立、無 `#ifdef` / win32 / cocoa / NSWorkspace /
    SystemParametersInfo 等真實桌布 API；致動器邏輯（參數驗證 /「所有顯示器」展開 /
    經 E6-01 分派 / 結果回報）與後端完全解耦，換後端不動致動器；null 後端狀態一致。
