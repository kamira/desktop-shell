# 結構註記 — E1-15 視窗級透明度與懸停淡變

- 層級：platform（相位 1 = Mac / null 期）／子系統 kernel／單元 e1_15
- 目錄位置：`src/kernel/e1_15/`（根 CMakeLists 以層級 GLOB `src/*/*/CMakeLists.txt` 深度 2 自動收入）
  - `window_opacity.hpp` — 型別 `WindowOpacityStatus`{Ok, Invalid, Unsupported}（轉發自
    E1-03 `AlphaStatus`）、類別 `WindowOpacity`（視窗 / surface 級整體透明度 + 懸停淡變）
  - `window_opacity.cpp` — 線性淡變插值 + E5-02 懸停事件驅動起停 + 透過 E1-03
    `AlphaSurfaceService::set_opacity` 實際套用
  - `CMakeLists.txt` — `add_library(e1_15 STATIC window_opacity.cpp)` +
    `target_link_libraries(e1_15 PUBLIC e1_03 e5_02)` + `test_e1_15`
    （`tests/e1/test_e1_15.cpp`）+ `add_test(NAME e1_15)`
- 測試：`tests/e1/test_e1_15.cpp`（gtest，12 案例）
- 上游相依（可讀不可改）：E1-03 `AlphaSurfaceService` / `AlphaProfile` / `AlphaStatus`
  （整體不透明度套用 + 能力閘控，NFR-03）；E5-02 `HoverTracker` / `HoverEvent`
  （懸停 Enter / Leave 事件驅動淡變起停）。
- 對外介面（`namespace ds::kernel`）：`WindowOpacity(alpha_service, surface, fade_seconds=0.2)`：
  - `set_base_opacity(opacity)` / `set_hover_opacity(opacity)`：設定未懸停 / 懸停中目標不透明
    度比例 [0,1]；非有限值回 `Invalid` 且不套用（不靜默）；有限值 clamp 至 [0,1]。
  - `attach(hover)`：訂閱 E5-02 `HoverTracker`，本 surface 的 Enter → 淡入（往
    `hover_opacity()`）、Leave → 淡出（往 `base_opacity()`）；其餘事件 / 其他 surface 忽略。
  - `advance(dt_seconds)`：注入式時間推進淡變（dt<0 視為 0），線性插值後透過 E1-03
    `set_opacity` 套用至 surface，回傳轉發自 E1-03 的結果（Ok/Unsupported/Invalid）。
  - `current_opacity()`：純查詢目前（動畫中）不透明度比例，不改狀態。
- 相位 1 約束：無平台分支（無 `#ifdef`）、無真實 OS 時鐘 / 繪圖 API、無
  `src/kernel/backend/win32|cocoa/`；不透明度以正規化比例表達（NFR-02：非座標 / 非數字
  z-order）；時間全注入式（`advance(dt)` 由呼叫端 / 測試提供，不綁真實牆鐘）。
