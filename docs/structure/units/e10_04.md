# 結構註記 — E10-04 事件廣播型模組協定

- 單元：E10-04（engine 層 / ipc / Risk: low）
- 目錄位置：`engine/ipc/e10_04/`（平台中立引擎邏輯，換平台一行不動）
- 測試：`tests/e10/test_e10_04.cpp`（CTest 名 `e10_04`）
- 相依：E10-01 本機 IPC 通道 + E8-04 行程內模組載入
  （`target_link_libraries(e10_04 PUBLIC e10_01 e8_04)`）。

## 放了什麼
- `event_broadcast.hpp`：事件廣播協定 —— `Topic` / `ModuleId` / `Event`（主題 + 酬載 + 來源）/
  `EventHandler` / `EventBroadcast`。`EventBroadcast` 內部持有 E10-01 `MessageChannel` 做
  依主題路由 / 依註冊序扇出 / 投遞計數，在其上加「模組維度」（訂閱歸屬模組、卸載清理）與
  主題宣告（publish/subscribe 內省）。相位 1 為純記憶體事件匯流排，不綁真實網路 / IPC。
- `event_broadcast.cpp`：`event_broadcast_contract_version()`（"e10_04/1.0.0"）；其餘 header-only inline。
- `CMakeLists.txt`：`add_library(e10_04)` + `PUBLIC e10_01 e8_04` + `test_e10_04` + `add_test(NAME e10_04)`。

## 對外介面（一句話）
`ds::ipc::EventBroadcast` 讓載入的模組以發布-訂閱互通：`subscribe(module, topic, handler)` /
`unsubscribe(module, id)` / `unsubscribe_module(module)`（卸載清理）/ `publish(topic, event)→投遞數`
（依主題廣播、多訂閱者、依註冊序、無訂閱者回 0 不崩潰）/ `declare_publish|subscribe`（主題宣告內省），
實際扇出委派 E10-01 `MessageChannel`，酬載重用 E6-01 值型別，ModuleId 對接 E8-04 manifest.name。
