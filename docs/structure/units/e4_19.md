# 結構註記 — E4-19 旋轉元件

- 目錄位置：`modules/elements/e4_19/`（module 層 / elements 子系統 / 平台無關純邏輯）。
- 內容：`rotatable_element.hpp|cpp`（`RotatableElement`：內部持有一個 E4-02
  `ImageElement`（顯示旋轉對象）；`set_angle`/`angle()`/`rotate_by` 設定 / 疊加角度（弳度，
  正規化至 `[0, 2π)`，非有限值回 `RotateStatus::Invalid` 不套用）；`set_angular_velocity`/
  `angular_velocity()`/`advance(dt)` 支援連續旋轉（跨越多整圈）；`set_pivot`/`pivot()` 設定
  具名九宮格旋轉中心 `RotationPivot`（Center/TopLeft/TopCenter/TopRight/CenterLeft/
  CenterRight/BottomLeft/BottomCenter/BottomRight）；`transform()` 以 E4-22 `Transform2D`
  組出繞 pivot（換算自來源固有尺寸）旋轉 angle 的仿射矩陣；`set_source`/`set_scale_mode`/
  `set_opacity`/`set_target` 等透傳給內部 `ImageElement`；`render_model()` 打包
  `RotatedRenderModel{ image, transform, angle_radians, pivot }`）、`CMakeLists.txt`
  （`add_library(e4_19)` + `target_link_libraries(e4_19 PUBLIC e4_02 e4_22)` + `test_e4_19`，
  根層自動 glob 收入）。
- 相依：上游 E4-02 圖片元件（`modules/elements/e4_02/`，可讀不可改；提供圖片顯示與渲染
  描述模型）、上游 E4-22 2D 變形矩陣（`engine/render/e4_22/`，可讀不可改；提供
  `Transform2D` 平移 / 旋轉 / 組合等仿射變形數學）。
- 對外介面：命名空間 `ds::elements`；呼叫端設定角度（`set_angle`/`rotate_by`）與具名旋轉
  中心（`set_pivot`），或以 `set_angular_velocity` + `advance(dt)` 驅動連續旋轉，
  `render_model()` 取得含旋轉變形矩陣的渲染描述（NFR-02：角度為弳度語意輸出、pivot 為具名
  列舉，無絕對座標 / 數字 z-order）；不做真實旋轉繪製、不綁真實時鐘 / 計時器 / 繪製後端。
- 測試：`tests/e4/test_e4_19.cpp`（19 個 gtest 案例，`add_test(NAME e4_19)`）。
