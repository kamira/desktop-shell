# 結構註記 — C4-05 AI 對話面板

- 單元：C4-05（artifact 層 / apps / 組裝型 / Risk: low）
- 目錄位置：`apps/c4_05/`
- 測試：`tests/c4/test_c4_05.cpp`（CTest 名 `c4_05`，24 個 gtest 案例）

## 放了什麼

- `chat_panel.hpp` / `.cpp`：**組裝型**單元（非新引擎邏輯）——把四個已合併的擴充點/
  元件組成「AI 對話面板」（聊天氣泡對話框）應用 + 行為：
  - C1-05 `SummonPanelProfile`：面板召喚 / 收起生命週期（`open`/`close`/`is_open`），
    `submit_input()` 委派其開啟狀態閘控。
  - E4-01 `TextLayout`/`FontMetrics`：文字排版；亦直接用於 `measure_draft()` 量測草稿。
  - E4-11 `TypewriterElement`：對話串每則訊息的顯示元素（逐字顯示，內部消費 E4-01）。
  - E2-14 `HttpFetchProvider`：上下文指標來源（`refresh_context()` / `context_value()`）。
- `CMakeLists.txt`：`add_library(c4_05)` + `target_link_libraries(c4_05 PUBLIC c1_05
  e2_14 e4_01 e4_11)` + `test_c4_05`（`tests/c4/test_c4_05.cpp`）+
  `add_test(NAME c4_05)`。

## 對外介面（一句話）

`ds::apps::ChatPanelApp`：`load_conversation(turns)` / `append_message(role, text)`
（附加訊息，auto_scroll 跟進最新）/ `submit_input(text) -> SubmitStatus`（面板未開啟 →
`PanelClosed`；空白 → `Empty`；否則附加使用者訊息 + 注入式 stub 助理回應 → `Ok`）/
`scroll_to` `scroll_by` `scroll_to_latest`（依訊息序數，非絕對座標）/ `render_message(i)`
（E4-01/E4-11 渲染描述）/ `measure_draft(text)`（E4-01 直接量測）/ `refresh_context()`
`context_value()`（E2-14）。相位 1：純資料 / 邏輯組裝，僅注入式回應與 HTTP 傳輸，**無
真實 LLM 呼叫、無真實網路**；無平台分支（無 `#ifdef` / win32 / cocoa）、無絕對座標 /
數字 z-order（NFR-02）。
