# 結構註記 — E2-06 儲存容量

- 層級：module(平台無關指標提供者)／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_06/`
  - `storage_capacity.hpp` / `storage_capacity.cpp` — 使用率演算法 + 抽象/注入式來源 + 值模型 + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_06)` **PUBLIC 連上游 `e2_01` `e2_02`**；`test_e2_06`
    (`tests/e2/test_e2_06.cpp`) + `add_test(NAME e2_06)`
- 測試：`tests/e2/test_e2_06.cpp`（gtest，22 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`）＋ E2-02 採集頻率分級
  （`engine/metrics/e2_02`），皆可讀不可改——消費 `MetricProvider` 契約與 `SamplingTier` 分級，
  不自造指標模型或排程器。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「儲存容量」（每個磁碟 / 掛載點的
  總容量 / 已用 / 可用 bytes 與使用率 %）透過 **E2-01 的 `MetricProvider`** 掛成一組指標，並以
  **E2-02 的頻率分級**決定採樣節奏。本單元是最終 Disk/Storage Widget 的核心資料來源。
  - 值模型：`DiskCapacity`（單磁碟 id/name + total/used/free bytes + valid；工廠 `of` / `unknown`；
    成員 `usage_ratio()`）。
  - 使用率演算法（自由函式，獨立可測）：`disk_usage_ratio(used,total)`＝used/total 夾 [0,1]
    （防 total==0 / used>total）。
  - 容量來源：抽象 `StorageStatSource::enumerate() const → vector<DiskCapacity>`；`NullStorageStatSource`
    （相位 1 null/假來源，可注入固定磁碟清單，預設空列＝無磁碟）。
  - `StorageCapacityProvider : ds::metrics::MetricProvider`：`register_metrics()` 掛上**四個平行指標**
    `storage.usage`(unit="%"、range=`bounded[0,100]`) / `storage.capacity.total|used|free`(unit="B"、
    range=`at_least(0)`)，四者共用同一組每磁碟實例（instance_id=磁碟 id、label=磁碟名，各保留歷史環）；
    `sample()` 重新讀來源更新各實例（推入歷史，磁碟數增則動態新增實例、減則多出者設未知）；
    `sampling_tier()` 回建議採集分級（預設 Low——容量變動慢），供 `SamplingScheduler::add_demand`。
  - 核心性質：相位 1（Mac/null 期）平台中立、**無 `#ifdef` / statvfs / GetDiskFreeSpace / mach /
    win32 / cocoa** 等真實磁碟 API；無讀值時以 valid==false（未知）誠實表達、不謊報 0；消費者只透過
    E2-01 抽象介面走訪，新增此指標掛件一行不動。
