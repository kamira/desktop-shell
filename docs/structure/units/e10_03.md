# 結構註記 — E10-03 HTTP 端點

- 單元：E10-03（engine 層 / ipc / Risk: low）
- 目錄位置：`engine/ipc/e10_03/`（平台中立引擎邏輯，換平台一行不動）
- 測試：`tests/e10/test_e10_03.cpp`（CTest 名 `e10_03`）
- 相依：E10-01 本機 IPC 訊息通道（`target_link_libraries(e10_03 PUBLIC e10_01)`）——
  並經 e10_01 傳遞相依 E6-01；請求 / 回應酬載重用其穩定值型別 `CommandArgs`。

## 放了什麼
- `http_router.hpp`：HTTP 端點契約——`HttpMethod`（+ 字串互轉）、`status::*` 具名狀態碼、
  `HttpRequest`（method/path/query/params/headers/body；`parse` / `parse_query`）、
  `HttpResponse`（狀態 + 標頭 + 主體；具名工廠）、`HttpRouter`（`route` / `get`/`post`/`put`/`del` /
  `handle` / `has_path` / `allowed_methods`），以及映射到 E6-01 命令 / E10-01 訊息通道的薄轉接
  （`to_command` / `to_message` / `map_command_result` / `dispatch_request` / `command_dispatcher`）。
  相位 1 為「可注入請求輸入」，不開真實 socket/listen/port。
- `http_router.cpp`：`contract_version()` 契約版本標記（"e10_03/1.0.0"）；其餘邏輯 header-only inline。
- `CMakeLists.txt`：`add_library(e10_03)` + `PUBLIC e10_01` + `test_e10_03` + `add_test(NAME e10_03)`。

## 對外介面（一句話）
`ds::ipc::http::HttpRouter` 以 `route(method, pattern, handler)` 註冊路由（`:name` 段擷取路徑參數）、
以 `handle(HttpRequest)->HttpResponse` 做匹配與分派（路徑不符回 404、方法不符回 405 並帶 `Allow`，
皆明確不靜默），並提供把請求映射為 E6-01 具名命令（交 `CommandBus` 分派）或封成 E10-01 `Message`
（send/publish 到 `MessageChannel`）的薄轉接；相位 1 平台中立，真實網路綁定留待相位 2。
