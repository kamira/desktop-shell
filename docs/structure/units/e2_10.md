# 結構註記 — E2-10 時間與日期

- 層級：module（平台無關指標提供者）／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_10/`
  - `time_date.hpp` / `time_date.cpp` — 時鐘介面 + 注入來源 + 曆法分解 / 格式化 + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_10)` **PUBLIC 連上游 `e2_01`**；`test_e2_10`
    （`tests/e2/test_e2_10.cpp`）+ `add_test(NAME e2_10)`
- 測試：`tests/e2/test_e2_10.cpp`（gtest，19 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`，可讀不可改）——消費 `MetricProvider`
  契約、不自造指標模型。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「當前時間／日期」
  透過 **E2-01 的 `MetricProvider`** 掛成指標 `time.now`。
  - `TimeSource`（抽象可覆寫時鐘介面 `now()`）、`FixedTimeSource`（注入固定時間點，相位 1
    預設 / 測試用：不讀真實時鐘、決定性）。
  - `CivilTime` + `civil_from_epoch_seconds` / `civil_from_time_point`：UTC 曆法純算術分解
    （Howard Hinnant civil-from-days，無 OS 相依）；`format_iso8601` / `format_date` /
    `format_clock` 固定寬度格式化。
  - `TimeDateProvider : ds::metrics::MetricProvider`：`register_metrics()` 把當前時間的三個
    面向（`epoch` / `date` / `time`）各建成一個 `MetricInstance`（各 number = 數值維度、
    text = 人類可讀表述；history_capacity=0）。
  - 核心性質：相位 1（Mac/null 期）平台中立、無 `#ifdef` / win32 / cocoa / `gmtime` / 時區換算
    （一律 UTC）；時間來源可注入故測試決定性；消費者只透過 E2-01 抽象介面走訪，新增此指標掛件一行不動。
