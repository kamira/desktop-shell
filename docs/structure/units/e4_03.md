# 結構註記 — E4-03 長條 / 進度 / 量表

- 目錄位置：`modules/elements/e4_03/`（module 層 / 子系統 elements / phase 1 / 平台中立純邏輯）。
- 內容：`bar_gauge.hpp|cpp`（`ElementKind` / `Orientation` / `Range` / `RenderModel` / `ConfigStatus`；
  基底 `RangedElement`（值↔範圍映射、夾限、具名 surface+slot、顏色語彙、標籤）；
  `BarElement`（值→長度比例）、`ProgressElement`（0–100%）、`GaugeElement`（值→角度 / 弧）；
  E7-03 驅動的 `load_bar_config` / `load_progress_config` / `load_gauge_config`），
  `CMakeLists.txt`（`add_library(e4_03)` PUBLIC 連 `e1_03`+`e7_03`，`test_e4_03`，根層自動 glob 收入）。
- 對外介面：命名空間 `ds::elements`；各元件以 `set_value` / `set_range`（Gauge 另 `set_arc`）設定，
  `render_model()` 產出供繪製層消費的**渲染描述**（相位 1 不做真實繪製）。設定可用 E7-03 宣告式
  變數段落文件驅動；元件位置以 E1-03 具名 `ds::kernel::SurfaceId` + 具名 slot 指涉。
- NFR-02：`RenderModel` 無絕對座標 / 像素尺寸 / 數字 z-order——位置具名、尺寸以比例 [0,1]、量表以角度表達。
- 錯誤不靜默：非有限值 / 退化範圍 / 退化弧 → `std::invalid_argument`；設定型別不符 / 變數展開失敗 → `ConfigStatus`。
- 測試：`tests/e4/test_e4_03.cpp`（26 個 gtest 案例，`add_test(NAME e4_03)`）。
