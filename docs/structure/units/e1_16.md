# E1-16 螢幕邊緣熱區 — 結構註記

- 位置：`src/kernel/e1_16/`（`edge_hot_zone.hpp` / `edge_hot_zone.cpp` / `CMakeLists.txt`），
  測試於 `tests/e1/test_e1_16.cpp`。
- 放了什麼：`EdgeHotZone`（8 個具名邊/角）+ `ScreenExtent`（螢幕尺寸）+ `HotZoneAction`
  （具名動作標籤）+ `EdgeHotZoneRegistry`（`register_zone` 註冊、`test` 判定，複用上游
  E1-04 `HitTester` 做矩形點內判定）。
- 對外介面一句話：呼叫端以具名邊/角 + 螢幕比例厚度註冊熱區，傳入本地滑鼠點與螢幕尺寸即可
  問「觸發了哪個熱區」（角落優先於邊），本單元只回報觸發、不執行實際動作。
- 相依：`e1_04`（幾何命中測試，PUBLIC 連結）；不依賴任何其他 e1_* 單元或平台後端。
