# 結構註記 — E8-04 行程內模組載入（擴充點 5「腳本 / 模組」的載入機制）

- 單元：E8-04（engine 層 / script / Risk: low）
- 目錄位置：`engine/script/e8_04/`（平台中立引擎邏輯，換平台一行不動）
- 測試：`tests/e8/test_e8_04.cpp`（CTest 名 `e8_04`）
- 相依：`e9_02`（manifest；`target_link_libraries(e8_04 PUBLIC e9_02)`）

## 放了什麼
- `module_loader.hpp`：擴充點 5 的載入契約 —— `CapabilityKind`（Sensor/Component/Action，
  對應擴充點 1/2/3）、`Capability{kind,id}`、`HostEnvironment`（host 提供的能力 + 授予的權限）、
  `ModuleContext`（模組註冊面）、`Module{manifest,on_register,on_unload}`（相位 1 行程內模組）、
  `LoadStatus`/`LoadResult`、`ModuleLoader`。
- `module_loader.cpp`：`contract_version()`（"e8_04/1.0.0"）、`to_string`、`ModuleLoader::load`
  （驗證 → requires/permissions 閘控 → 呼叫註冊入口 → 跨模組衝突檢查 → 整批提交）、`unload`。
- `CMakeLists.txt`：`add_library(e8_04)` + `PUBLIC e9_02` + `test_e8_04` + `add_test(NAME e8_04)`。

## 對外介面（一句話）
`ds::ext::ModuleLoader`：`load(Module)→LoadResult`（驗 manifest 的 requires/permissions，
不滿足即明確拒絕不靜默；呼叫模組註冊入口登記其感測器/元件/動作；跨模組能力衝突拒絕）/
`unload(name)→bool`（呼叫 on_unload + 精準移除能力，可重載）/ `is_loaded` / `provides` /
`provider_of` / `loaded_names`；讓第三方模組以 E9-02 manifest 描述、行程內掛上其提供的能力。
