## 放了什麼
- `command_bus.hpp`：擴充點 3「動作」契約 —— `CommandValue`（穩定值型別：null/bool/int/double/string）、
  `CommandArgs`（具名參數字典 + 型別安全 getter）、`CommandResult` / `CommandStatus`（Ok/NotFound/Failed）、
  `CommandHandler`、`Command`（id+args 打包）、`CommandBus`。
- `command_bus.cpp`：`contract_version()` 契約版本標記（"e6_01/1.0.0"）；其餘邏輯為 header-only inline。
- `CMakeLists.txt`：`add_library(e6_01)` + `test_e6_01` + `add_test(NAME e6_01)`。

## 對外介面（一句話）
`ds::command::CommandBus`：`register_command(id, handler)→bool`（空 id / 空 handler / 重複 id 拒絕、不覆蓋）/
`dispatch(id, args)→CommandResult`（未知命令回 NotFound，不崩潰）/ `unregister(id)` / `has_command(id)` /
`command_count()` / `command_ids()`；讓致動器以具名命令掛上、呼叫端以 id+參數觸發而不相依具體致動器。
