# 結構註記 — E4-18 徑向線 / 指針

- 目錄位置：`modules/elements/e4_18/`（module 層 / 子系統 elements / phase 1 / 平台中立純邏輯）。
- 內容：`radial_pointer.hpp|cpp`（`RenderModel` / `ConfigStatus`；`RadialPointerElement`——
  值↔範圍映射與夾限、弧幾何（起始角 + 角度跨距）、值→角度映射、指針長度 / 粗細比例、
  具名顏色語彙、具名 surface+slot 佈局；E7-03 驅動的 `load_radial_pointer_config`），
  `CMakeLists.txt`（`add_library(e4_18)` PUBLIC 連 `e1_03`+`e7_03`，`test_e4_18`，根層自動 glob 收入）。
- 對外介面：命名空間 `ds::elements`；以 `set_value` / `set_range` / `set_angle_span` 設定，
  `render_model()` 產出供繪製層消費的**渲染描述**（相位 1 不做真實繪製）。設定可用 E7-03 宣告式
  變數段落文件驅動；元件位置以 E1-03 具名 `ds::kernel::SurfaceId` + 具名 slot 指涉。
- NFR-02：`RenderModel` 無絕對座標 / 像素尺寸 / 數字 z-order——位置具名、長度 / 粗細以比例
  [0,1]、指針角度以值→角度的語意輸出表達。
- 錯誤不靜默：非有限值 / 退化範圍 / 退化角度跨距 / 非有限長度或粗細比例 →
  `std::invalid_argument`；設定型別不符 / 變數展開失敗 → `ConfigStatus`。
- 測試：`tests/e4/test_e4_18.cpp`（23 個 gtest 案例，`add_test(NAME e4_18)`）。
