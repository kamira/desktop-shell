# 結構註記 — E8-02 對話腳本直譯器

- 層級：engine(平台中立純邏輯)；描述子系統的**對話 / 腳本直譯層**（相依已合併的 E7-05，
  傳遞取得 E7-02 的 `VariableScope` / E7-01 的 `Value`）。
- 目錄位置：`engine/script/e8_02/`
  - `interpreter.hpp` / `interpreter.cpp` — 實作
  - `CMakeLists.txt` — `add_library(e8_02)` + `target_link_libraries(e8_02 PUBLIC e7_05)`（消費上游）
    + `test_e8_02`（`tests/e8/test_e8_02.cpp`）+ `add_test(NAME e8_02)`
- 測試：`tests/e8/test_e8_02.cpp`（gtest，27 案例）
- 對外介面（`namespace ds::script`）：逐步執行以宣告式格式撰寫的對話 / 腳本。
  - `Step`（opcode 字串 + `target` / `arg`）；工廠 `set` / `say` / `if_goto` / `goto_label` / `label`。
  - `Script`：有序步驟序列（`add()` 串接）。
  - `OutputSink`（可注入抽象副作用接收端）；現成 `RecordingSink`（緩衝式，供測試 / 批次消費）。
  - `ExecutionContext`：跨步延續的 `VariableScope` + 程式計數器（pc）+ 已執行步數。
  - `Interpreter`：`step()` 逐步 / `run()` 一次跑完；可選父作用域（預注入變數）；
    `set_step_budget()` 防無窮迴圈。
  - `ScriptError{step, message}`（0-based 步驟索引）；`StepResult` / `RunResult`（二選一結果物件）。
  - `value_to_text`：把 `Value` 決定性呈現為輸出文字。
  - 指令集：`set <name>=<expr>`（E7-05 求值並定義變數）、`say <text>`（E7-02 `${var}` 內插後
    emit 至 sink）、`if <cond> goto <label>`（E7-05 求值條件、真值分支）、`goto <label>`、`label <name>`。
- 定位：消費 E7-05 的公式引擎求值運算式 / 條件，把宣告式格式的步驟序列直譯為可逐步執行、
  變數跨步延續、可分支 / 跳轉的腳本；副作用一律走注入式 sink（不綁真實後端）。
- **未知指令 / 求值失敗 / 未知標籤 / 條件型別誤用 / 重複標籤 / 疑似無窮迴圈一律明確回報
  （帶步驟索引）、不靜默**（NFR-04 精神）。平台中立、無 `#ifdef`。
