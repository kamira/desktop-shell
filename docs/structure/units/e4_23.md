# 結構註記 — E4-23 容器裁切與遮罩

- 層級：engine（phase 1，平台中立宣告式狀態）／子系統 render／單元 e4_23
- 目錄位置：`engine/render/e4_23/`（根 CMakeLists 以層級 GLOB `engine/*/*/CMakeLists.txt` 自動收入）
  - `clip_mask.hpp` — 介面：`ContainerId`（= 上游 `ds::kernel::SurfaceId`）；
    `ClipShape`{Rect, RoundedRect, Path}；`ClipStatus`{Ok, Invalid}；`NormPoint`{x,y}；
    `NormRect`{x0,y0,x1,y1}；`ClipRegion`{shape, rect, corner_radius, path}；
    `MaskKind`{Uniform, NamedPattern}；`MaskSource`{kind, coverage, pattern_name}；
    類別 `ClipMaskService`；純函式 `is_valid_clip_region` / `point_in_clip_region`
  - `clip_mask.cpp` — 裁切區域驗證、矩形 / 圓角矩形 / path 命中測試、巢狀裁切（父代鏈 +
    迴圈偵測）、遮罩 coverage clamp、render_model 決定性快照聚合之實作
  - `CMakeLists.txt` — `add_library(e4_23 STATIC clip_mask.cpp)` +
    `target_link_libraries(e4_23 PUBLIC e1_03)` + `test_e4_23`（`tests/e4/test_e4_23.cpp`）+
    `add_test(NAME e4_23)`
- 測試：`tests/e4/test_e4_23.cpp`（gtest，29 案例）
- 上游相依（可讀不可改）：E1-03（逐像素 alpha surface / surface 具名指涉慣例）——本單元
  沿用其 `ds::kernel::SurfaceId` 作為 `ContainerId`（PUBLIC 連結傳遞）。
- 對外介面（`namespace ds::render`）：容器裁切與遮罩的宣告式渲染工具。
  - `ClipMaskService`：以具名 `ContainerId` 記錄每個容器的狀態。
    - 裁切：`set_clip(container, region)` / `clear_clip` / `has_clip` / `clip_region`——
      `ClipRegion` 依 `shape` 取用 `rect`（Rect/RoundedRect）/ `corner_radius`
      （RoundedRect，容器短邊比例 [0,0.5]）/ `path`（Path，>=3 正規化點）。
    - 巢狀：`set_parent(container, parent)` / `clear_parent` / `parent_of`——自我父代 /
      迴圈父代鏈於設定時即回 `Invalid` 並拒絕建立。
    - 遮罩：`apply_mask(container, mask)` / `clear_mask` / `has_mask` / `mask_source`——
      `MaskSource.coverage` 正規化 [0,1]（自動 clamp）；`NamedPattern` 需非空
      `pattern_name`。
    - 命中：`is_visible(container, point)`——point 為容器局部正規化座標 [0,1]x[0,1]；
      同時檢驗自身 + 沿父代鏈祖先裁切區域，並檢查遮罩 coverage > 0。
    - 快照：`render_model()` → `RenderEntry` 向量，依容器具名鍵字典序排序（決定性）。
  - phase 1 約束：純記憶體宣告式狀態，無平台分支（無 `#ifdef`）、無真實繪圖 API / OS；
    幾何一律容器局部正規化座標，無絕對畫面座標 / 數字 z-order（NFR-02 合規）；無效裁切
    區域 / 無效遮罩明確回 `ClipStatus::Invalid`，不靜默、不留半份狀態。
