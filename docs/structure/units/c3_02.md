# 結構註記 — C3-02 角色對話本

- 單元：C3-02（artifact 層 / 應用 profile / Risk: low，最後一個單元）
- 目錄位置：`content/c3_02/`
- 測試：`tests/c3/test_c3_02.cpp`（CTest 名 `c3_02`，24 個 gtest 案例）

## 放了什麼
- `dialogue_book.hpp` / `.cpp`：**組裝型**單元（非新引擎邏輯）——把三個已合併的擴充點組成
  「角色對話本」應用 profile + 行為：
  - E8-02 `Interpreter` / `Script` / `Step`：台詞（`say`）+ 條件分支 / 跳轉（`if goto` /
    `goto` / `label`）+ 變數（`set`，跨步延續）。
  - E8-03 `PresentationController` / `PresentationSink`：舞台指示（`show` / `hide` /
    `switch_surface` / `transition` / `wait`）——`say` 文字若符合舞台指示語法，經注入的
    E6-01 `CommandBus` 分派（`switch_surface` 委派 E4-06 `SurfaceSwitcher`），不算一句台詞。
  - C1-03 `BalloonProfile`：逐句顯示——每次前進到下一句台詞，經 `show_balloon(speaker,
    line, ttl)` 顯示於依附角色旁。
  - `class DialogueBook`：`load_script(script)` / `start(speaker, ttl)` /
    `advance(speaker, ttl)` / `tick(dt)` / `reset()` / 查詢（`current_line()` /
    `is_finished()` / `is_active()` / `is_showing()` / `last_error()` / `presentation()` /
    `ready()` / `registration_error()`）。
  - `DialogueBook::LineSink`（內部 pimpl 巢狀類別）：E8-02 `OutputSink` 實作，負責「台詞 /
    舞台指示」分流——第一個 token 命中五個已知舞台指示名稱之一即轉交 E8-03
    `PresentationSink`，否則記為待顯示台詞。
  - 具名結果列舉 `DialogueStatus`（Ok / Invalid / ScriptError / Finished），附
    `to_string()`（NFR-02）。
- **自查確認**：任務提示的既有 HitResult 命名碰撞（C1-03 透過 E1-14 / C1-02 觸及）**不波及**
  本單元——C1-03 `balloon_profile.hpp` 已自行以橋接層 + pimpl 隔離乾淨，E8-02 / E8-03 的
  上游鏈亦不涉及 `input_strategy.hpp` / `hit_test.hpp`（詳見
  `docs/worklog/I1.177-c3_02.md` 的遞移 include 樹分析）。本單元因此**不需要**額外的
  pimpl / 橋接層。
- `CMakeLists.txt`：`add_library(c3_02 STATIC dialogue_book.cpp)` +
  `target_link_libraries(c3_02 PUBLIC c1_03 e8_02 e8_03)` + `test_c3_02`
  （`tests/c3/test_c3_02.cpp`）+ `add_test(NAME c3_02)`。

## 對外介面（一句話）
`ds::content::DialogueBook`：`load_script(script)` 載入台詞 / 分支定義 / `start(speaker,
ttl)` 顯示第一句台詞 / `advance(speaker, ttl)` 推進到下一句（略過舞台指示）並經 C1-03 氣球
顯示 / `tick(dt)` 推進氣球逐字進度與存活倒數 / `current_line()` `is_finished()`
`is_active()` `is_showing()` 查詢 / `reset()` 收掉氣球並捨棄執行進度（腳本定義保留可重新
`start`）。相位 1：純資料 / 邏輯組裝，無真實 GUI、無平台分支（無 `#ifdef` / win32 / cocoa）、
無絕對座標 / 數字 z-order（NFR-02）。
