# 結構註記 — E5-01 基本滑鼠按鍵事件

- 層級：engine（平台中立純邏輯）
- 目錄位置：`engine/events/e5_01/`
  - `mouse_button_input.hpp` / `mouse_button_input.cpp` — 實作
  - `CMakeLists.txt` — `add_library(e5_01)`（`PUBLIC` 連上游 `e1_04`）+
    `test_e5_01`（`tests/e5/test_e5_01.cpp`）+ `add_test(NAME e5_01)`
- 測試：`tests/e5/test_e5_01.cpp`（gtest，19 案例）
- 對外介面（`namespace ds::events`）：`MouseEventRouter` —— 滑鼠按鍵事件（down / up / click，
  左 / 中 / 右鍵，多擊 double/triple）的注入 / 命中路由 / 訂閱派發：`set_surfaces()` 設定參與
  命中測試的具名 surface、`subscribe()` / `unsubscribe()` 訂閱特定 surface、
  `inject_button()` / `inject_down()` / `inject_up()` / `inject_click()` 注入事件。
  命中判定完全委由上游 E1-04 `HitTester::topmost_hit()`（具名圖層 + 宣告順序，無數字 z-order），
  事件位置以 E1-04 `LocalPoint`（本地 / 相對座標，NFR-02）表達；只分派給命中之 surface 的
  訂閱者，未命中不分派給任何人（`RouteStatus::NoHit`），上游判定形狀無效時回
  `RouteStatus::Invalid`（報錯不靜默）。事件由呼叫端 / 測試注入，不接真實滑鼠。
