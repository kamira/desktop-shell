# 結構註記 — E2-17 主機板感測器（溫度 / 風扇 / 電壓）

- 層級：module(平台無關指標提供者)／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_17/`
  - `board_sensors.hpp` / `board_sensors.cpp` — 感測器值模型 + 類型輔助 + 抽象/注入式來源
    + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_17)` **PUBLIC 連上游 `e2_01` `e2_02`**、**PRIVATE 連
    宣告相依 `e10_01`**；`test_e2_17`（`tests/e2/test_e2_17.cpp`）+ `add_test(NAME e2_17)`
- 測試：`tests/e2/test_e2_17.cpp`（gtest，27 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`）＋ E2-02 採集頻率分級
  （`engine/metrics/e2_02`）＋ E10-01 本機 IPC（`engine/ipc/e10_01`），皆可讀不可改。
  消費 E2-01 `MetricProvider` 契約與 E2-02 `SamplingTier` 分級，不自造指標模型或排程器。
  **E10-01 為本機 IPC 訊息通道、非感測器/裝置列舉基礎設施**，故本單元感測器列舉自帶可注入
  抽象、不 include 其標頭；CMakeLists 仍 PRIVATE 連結 e10_01 以忠實反映宣告的相依邊。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「主機板/硬體感測器」
  ——溫度(°C 多點) / 風扇轉速(RPM) / 電壓軌(V)——透過 **E2-01 的 `MetricProvider`** 掛成
  **三個指標**，各以對應類型的每顆感測器為一個**可列舉實例（附名稱與類型）**。
  - 類型：`SensorType`（Temperature/Fan/Voltage）＋自由函式 `unit_for()`（"°C"/"RPM"/"V"）、
    `to_string()`（"temperature"/"fan"/"voltage"），獨立可測。
  - 值模型：`SensorReading`（單顆感測器一份讀值：name 名稱 / value 數值（°C|RPM|V）/ valid
    旗標；含 `of()`/`unknown()` 工廠與相等運算子）、`BoardSensorSample`（某時刻全感測器快照，
    依類型分三組 `temperatures`/`fans`/`voltages`，各類數量可在取樣間獨立變動）。
  - 讀值來源：抽象 `BoardSensorSource::sample()→BoardSensorSample`（列舉全部感測器）；
    `NullBoardSensorSource`（相位 1 null/假來源，注入**固定**單份或**序列**多份，列盡回最後
    一份、空列回空快照，預設「無感測器/無讀值」；`set_fixed`/`set_sequence`/`push_sample`/
    `reset`/`clear` 注入）。
  - `BoardSensorsProvider : ds::metrics::MetricProvider`：`provider_id()=="sysinfo.board"`；
    `register_metrics()` 掛上三指標 `board.temp`(unit "°C"、range `at_least(0)`) /
    `board.fan`(unit "RPM"、range `at_least(0)`) / `board.voltage`(unit "V"、range
    `unbounded`——支援負軌如 -12V)；各類感測器各自一組實例（溫度 `temp0`/…、風扇 `fan0`/…、
    電壓 `volt0`/…，label 取感測器名稱、未命名以 "Temp 0"/"Fan 0"/"Voltage 0" 補位），各實例
    保留歷史環；`sample()` 重新讀來源更新各實例（有效值推入歷史，某類數量增則動態新增實例、
    減則多出者設未知）；`sampling_tier()` 回建議採集分級（預設 `Low`——主機板感測器變動慢），
    供 `SamplingScheduler::add_demand`。
  - 核心性質：相位 1（Mac/null 期）平台中立、**無 `#ifdef` / SMC / lm-sensors / IOKit /
    win32 / cocoa** 等真實感測器 API；某顆無讀值以 valid==false（未知）誠實表達、不謊報 0；
    source 為 null 亦保守不崩（三指標皆 0 實例）；消費者只透過 E2-01 抽象介面走訪，新增此
    指標掛件一行不動。
