# 結構註記 — E1-01 具名圖層列舉與 z-order 維持

- 層級：platform（相位 1 = Mac / null 期）／子系統 kernel／單元 slug `e1_01`
- 目錄位置：`src/kernel/e1_01/`
  - `layer_stack.hpp` — 具名圖層列舉（`layers_bottom_to_top` / `layer_name`）、圖層相對順序
    （`LayerRelation` / `compare_layers`）、`LayerAssign` 結果碼、`LayerStack` 堆疊維護器、
    `layer_capability()`（NFR-03 閘控用能力 id "kernel.surface"）。
  - `layer_stack.cpp` — 圖層語意序單一資料來源；堆疊順序由「具名圖層清單 × 加入序」重新導出。
  - `CMakeLists.txt` — `add_library(e1_01 STATIC layer_stack.cpp)`
    + `target_link_libraries(e1_01 PUBLIC e1_21 backend_null)` + `test_e1_01`
    （`tests/e1/test_e1_01.cpp`）+ `add_test(NAME e1_01)`。
- 測試：`tests/e1/test_e1_01.cpp`（gtest，17 案例）。
- 上游相依（可讀不可改）：E1-24 null 後端（`SurfaceLayer` 具名圖層 / `SurfaceId`）、
  E1-21 能力矩陣（`CapabilityMatrix` / `has()`）。
- 對外介面（`namespace ds::kernel`）：具名圖層的列舉與堆疊順序維護。
  - `layers_bottom_to_top()`：由底到頂的具名圖層語意序（單一資料來源）；`layer_name()`：
    圖層穩定字串名（如 `layer.wallpaper`）；`compare_layers()`：兩圖層相對順序（Below / Same / Above）。
  - `LayerStack`：把具名 surface 指派到具名圖層（`assign` → `LayerAssign`，經 `has()` 閘控）、
    移除（`remove`，經閘控）、查詢（`contains` / `layer_of` / `count_in`）、堆疊順序維持與查詢
    （`stacking_order` / `ids_in` / `topmost` / `bottommost` / `is_above` / `is_below`）。
  - 核心不變式：**圖層語意優先於加入序**——跨層依圖層語意、同層依加入序（穩定）。
  - 硬約束：NFR-02 對外只有具名圖層 / 具名關係，無數字 z-order / 絕對座標（內部語意序 private，
    不對外當數字層級用）；NFR-03 改動狀態操作先 `has("kernel.surface")` 閘控、未知能力保守回 false；
    相位 1 無平台分支（無 `#ifdef` / win32 / cocoa）、無真實 OS API。
