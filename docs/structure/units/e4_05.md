# 結構註記 — E4-05 過場動畫與緩動

- 目錄位置：`engine/render/e4_05/`（engine 層 / render 繪製基座 / 平台無關純邏輯）。
- 內容：`easing.hpp|cpp`（`EasingType` + `Easing` 一組緩動曲線靜態純函式，10 種曲線 + `apply` 分派）、
  `tween.hpp|cpp`（`Tween` 時間插值器：`at(t)` 絕對查詢 / `advance(dt)` 增量推進 / `progress` / `done`）、
  `CMakeLists.txt`（`add_library(e4_05)` + `test_e4_05`，根層自動 glob 收入）。
- 對外介面：命名空間 `ds::render`；輸入正規化進度 t∈[0,1] 或絕對時間（秒）回確定性 eased/插值值，
  不綁真實時鐘與繪製後端。
- 測試：`tests/e4/test_e4_05.cpp`（17 個 gtest 案例，`add_test(NAME e4_05)`）。
