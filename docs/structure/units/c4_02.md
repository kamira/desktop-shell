# 結構註記 — C4-02 截圖與標註

- 單元：C4-02（artifact 層 / apps / 組裝型 / Risk: low）
- 目錄位置：`apps/c4_02/`
- 測試：`tests/c4/test_c4_02.cpp`（CTest 名 `c4_02`，25 個 gtest 案例）

## 放了什麼
- `screenshot_annotator.hpp` / `.cpp`：**組裝型**單元（非新引擎邏輯）——把三個已合併
  的擴充點 / 元件組成「截圖與標註」（screenshot & annotate）應用 + 行為：
  - E3-11 `ScreenCaptureBackend` / `CaptureSpec` / `CaptureRegion` / `CaptureResult`：
    以注入式後端擷取指定區域。
  - E4-20 `VectorGraphic` / `Shape` / `build_shape_path`：把箭頭（相位 1 簡化為直線）/
    框（矩形）標註轉為向量渲染描述；文字標註不經向量路徑（僅位置 + 內容）。
  - E4-30 `DimOverlayElement`：全螢幕調光覆蓋，本單元借它組出選取框覆蓋（顯示覆蓋層 +
    於固定具名區域 `kSelectionRegionName` 挖不調光洞，凸顯剛截取的畫面）。
- `CMakeLists.txt`：`add_library(c4_02)` +
  `target_link_libraries(c4_02 PUBLIC e3_11 e4_30 e4_20)` + `test_c4_02`
  （`tests/c4/test_c4_02.cpp`）+ `add_test(NAME c4_02)`。

## 對外介面（一句話）
`ds::apps::ScreenshotAnnotatorApp`：`capture(CaptureRegion, save_path="") ->
CaptureStatus`（擷取，`current_capture()` 讀尺寸 / 影像參照或路徑）/
`annotate_arrow(from,to)` `annotate_box(origin,w,h)` `annotate_text(pos,text) ->
AnnotateStatus`（新增標註，`annotations()` 讀清單，新擷取自動重置）/
`show_selection()` `hide_selection()`（選取框覆蓋顯隱，回傳 E4-30 `DimStatus`）/
`export_result() -> ExportResult`（尺寸 + 影像參照 / 路徑 + 標註數量的描述性 bundle）。
相位 1：純資料 / 邏輯組裝，僅注入式擷取後端，不接真實螢幕擷取、不做真實影像合成 /
檔案匯出；無平台分支（無 `#ifdef` / win32 / cocoa）、無絕對座標 / 數字 z-order
（NFR-02，選取框以固定具名挖洞表達）。
