# 結構註記 — E2-24 Wi-Fi 狀態

- 層級：module(平台無關指標提供者)／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_24/`
  - `wifi_status.hpp` / `wifi_status.cpp` — 值模型 + 抽象/注入式來源 + null/序列來源 +
    RSSI→% 換算 + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_24)` **PUBLIC 連上游 `e2_01` `e2_02`**；`test_e2_24`
    (`tests/e2/test_e2_24.cpp`) + `add_test(NAME e2_24)`
- 測試：`tests/e2/test_e2_24.cpp`（gtest，26 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`）＋ E2-02 採集頻率分級
  （`engine/metrics/e2_02`），皆可讀不可改——消費 `MetricProvider` 契約與 `SamplingTier`
  分級，不自造指標模型或排程器（範式同 E2-03 CPU 負載、E2-08 網路流量）。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「Wi-Fi 連線狀態」透過
  **E2-01 的 `MetricProvider`** 掛成七個面向指標，各以單一 Wi-Fi 介面（`wifi0`）為可列舉
  實例，並以 **E2-02 的頻率分級**決定採樣節奏。**無差分**：Wi-Fi 狀態是直接讀的瞬時快照。
  - 值模型：`WifiStatus`（connected / ssid / rssi_dbm / signal_percent / link_rate_mbps /
    channel / band / security + valid；含 `unknown()` / `connected_to()` / `not_connected()`
    工廠與相等運算子）；列舉 `WifiBand`（Unknown/2.4/5/6 GHz）、`WifiSecurity`
    （Unknown/Open/WEP/WPA/WPA2/WPA3/Enterprise），各附 `to_string`。
  - 純算術自由函式（獨立可測）：`rssi_to_percent(dbm)`＝clamp(2*(dbm+100), 0, 100)
    （-100 dBm→0%、-50 dBm→100%，超界夾住）。
  - Wi-Fi 來源：抽象 `WifiSource::sample()→WifiStatus`；`NullWifiSource`（相位 1 null/假
    來源，可注入**固定**一份或整條**序列**——模擬連線變動/掉線，列盡回最後一份，預設無讀值）。
  - `WifiStatusProvider : ds::metrics::MetricProvider`：`register_metrics()` 掛上七個指標
    `wifi.connected`(bounded[0,1])、`wifi.ssid`(unbounded, 文字)、`wifi.rssi`(dBm,
    bounded[-100,0])、`wifi.signal`(%, bounded[0,100])、`wifi.rate`(Mbps, at_least 0)、
    `wifi.channel`(at_least 0, +頻段文字)、`wifi.security`(unbounded, ordinal+文字)，各建單一
    `wifi0`(label "Wi-Fi") 實例；`sample()` 重新讀來源更新各實例（數值面向 RSSI/訊號/速率/
    頻道推入歷史，categorical 面向 ssid/security 只設值不污染歷史）；`sampling_tier()` 回建議
    採集分級（預設 Normal），供 `SamplingScheduler::add_demand`。
  - 無讀值 / 未連線語意：整體無讀值（source null / unknown）時**所有面向**誠實 `valid==false`
    （未知）；**未連線**時「是否已連線」面向仍有效（值=0/"Disconnected"），但**連線相依面向**
    （SSID/RSSI/訊號/速率/頻道/安全）誠實未知——不謊報 0。
  - 核心性質：相位 1（Mac/null 期）平台中立、**無 `#ifdef` / CoreWLAN / `CWInterface` /
    `airport` / win32 / cocoa** 等真實 Wi-Fi API；僅注入式來源。真實後端留待相位 2，屆時
    另實作 `WifiSource`，提供者一行不動；消費者只透過 E2-01 抽象介面走訪。
