# 結構註記 — E5-12 全域指標手勢

- 層級：platform（對系統的操作 — 全域指標監聽需 OS 後端）
- 目錄位置：`src/events/e5_12/`
  - `global_gesture.hpp` / `global_gesture.cpp` — 介面 + null 後端實作
  - `CMakeLists.txt` — `add_library(e5_12)`（PUBLIC 連 `e1_21` 能力矩陣）+ `test_e5_12`（`tests/e5/test_e5_12.cpp`）+ `add_test(NAME e5_12)`
- 測試：`tests/e5/test_e5_12.cpp`（gtest，18 案例，含 6 案降級路徑測試群 `GlobalGestureDegradation`）
- 對外介面（`namespace ds::events`）：`GlobalGestures` —— 全域指標（滑鼠/觸控）手勢辨識來源。
  具名手勢 `Gesture`（`GestureType` 全域滑動 SwipeX / 角落觸發 CornerX / 縮放 PinchIn·Out
  + 平台中立正規化參數 `magnitude` + `detail`）。**能力閘控項（NFR-03）**：`has()` 為唯一閘控入口，
  可用性單一資料來源為 E1-21 能力矩陣（`kGestureCapability = "input.gesture"`）；`subscribe(gesture, cb)→id`
  只在 `has()==true` 時受理，否則回 0；`unsubscribe`。null 後端 `NullGlobalGestures` 由 `inject(gesture)`
  模擬手勢（只分派給訂閱對應類型者），不綁真實 OS。**降級契約**：`has()==false` 時 subscribe 一律回 0、
  listener_count 恆 0、inject 為 no-op —— 不崩、不誤觸、明確回報不可用。
