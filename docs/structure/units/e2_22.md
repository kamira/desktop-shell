# 結構註記 — E2-22 登錄檔讀取

- 層級：module（平台無關指標提供者）／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_22/`
  - `registry_read.hpp` / `registry_read.cpp` — 型別載體 + 抽象來源 + null/假來源 + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_22)` **PUBLIC 連上游 `e2_01`**；`test_e2_22`
    （`tests/e2/test_e2_22.cpp`）+ `add_test(NAME e2_22)`
- 測試：`tests/e2/test_e2_22.cpp`（gtest，24 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`，可讀不可改）——消費 `MetricProvider`
  契約、不自造指標模型。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「系統設定登錄／組態儲存」
  （Windows Registry 概念的跨平台抽象——鍵路徑→值的階層式查詢）查得的值，透過
  **E2-01 的 `MetricProvider`** 掛成指標 `registry.values`。
  - `RegistryType`（String/Integer/Binary）、`RegistryValue`（型別標記載體，具型別存取器
    型別不符回 `nullopt` = 明確回報型別錯）。
  - `RegistrySource`（抽象後端：`read(path)->optional<RegistryValue>`、
    `enumerate(path)->vector<string>`，路徑以 `/` 分段）。
  - `NullRegistrySource`（相位 1 null/假來源：記憶體樹；`set_value`/`remove`/`clear` 注入；
    查無鍵回 `nullopt`、`enumerate` 由前綴推導直屬子項、決定性字典序）。
  - `registryValueToMetric()`：查無鍵→未知、Integer→數值+文字、String→文字、Binary→位元組數描述。
  - `RegistryReaderProvider : ds::metrics::MetricProvider`：`register_metrics()` 把每個
    選定鍵建成一個 `MetricInstance`（清單=列舉實例、數量=`instance_count()`）。
  - 核心性質：相位 1（Mac/null 期）平台中立、**無 `#ifdef` / win32 / cocoa / RegOpenKey /
    `defaults` / 真實登錄 API**；查無鍵／型別錯不靜默；消費者只透過 E2-01 抽象介面走訪，
    新增此指標掛件一行不動。
