# 結構註記 — E7-02 變數系統

- 層級：engine(平台中立純邏輯)；描述子系統的**變數層**（相依已合併的 E7-01）。
- 目錄位置：`engine/format/e7_02/`
  - `variables.hpp` / `variables.cpp` — 實作
  - `CMakeLists.txt` — `add_library(e7_02)` + `target_link_libraries(e7_02 PUBLIC e7_01)`（消費上游）
    + `test_e7_02`（`tests/e7/test_e7_02.cpp`）+ `add_test(NAME e7_02)`
- 測試：`tests/e7/test_e7_02.cpp`（gtest，21 案例）
- 對外介面（`namespace ds::format`）：宣告式格式的變數定義與 `${name}` 引用替換。
  - `VariableScope`：名稱→`Value` 有序表、鍵唯一、可帶父作用域；`define` / `find` / `has`
    （含父鏈上溯、子層遮蔽）/ `has_local` / `names` / `size` / `parent`。
  - `ResolveError{message, variable}`；`ResolveResult`（成功持 `Value` / 失敗持 `ResolveError`）；
    `DocumentResolveResult`（成功持 `Document` / 失敗持 `ResolveError`）。
  - `resolve(const Value&, const VariableScope&)` / `resolve(const Document&, const VariableScope&)`：
    遞迴替換節點樹內的引用。整串單一引用保留變數值原生型別；內嵌引用以字串呈現替換；
    `$$` 跳脫為字面 `$`。巢狀引用遞迴求值、循環引用偵測；遞迴進入 List / Map（**鍵不替換**）；
    Document 版本欄位原樣保留。
  - **未定義 / 循環 / 未終止 `${` / 空名 / 容器內嵌字串化一律明確回報、不靜默**（NFR-04 精神）。
- 定位：消費 E7-01 的 `Value` / `Document`，為其上的變數複用層；眾多格式 / 設定單元可先解析
  再以本層替換變數。平台中立、無 `#ifdef`。
