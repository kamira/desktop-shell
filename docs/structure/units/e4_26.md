# 結構註記 — E4-26 音效播放

- 目錄位置：`modules/elements/e4_26/`（module 層 / 子系統 elements / 非視覺 / 平台中立純邏輯）。
- 內容：`audio_player.hpp|cpp`（`SoundId` + `SoundClip` 音效資源引用、`SoundLibrary` 登錄簿、
  `AudioPlayer` 播放介面 play/stop/stop_all/set_volume/volume/is_playing、`NullAudioPlayer` null 後端），
  `CMakeLists.txt`（`add_library(e4_26)` + `test_e4_26`，根層自動 glob 收入）。

  `NullAudioPlayer` 記錄呼叫並維護播放狀態但不出聲、不綁任何真實音訊裝置（真實後端後續相位另實作同介面）。
