# 結構註記 — E2-14 HTTP 取得與結構化解析

- 層級：module（平台無關指標提供者）／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_14/`
  - `http_fetch.hpp` / `http_fetch.cpp` — HTTP 取得抽象 + null 傳輸 + 輕量 JSON 解析 + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_14)` **PUBLIC 連上游 `e2_01` `e2_02`**；`test_e2_14`
    （`tests/e2/test_e2_14.cpp`）+ `add_test(NAME e2_14)`
- 測試：`tests/e2/test_e2_14.cpp`（gtest，41 案例）
- 上游相依：
  - E2-01 統一指標介面（`engine/metrics/e2_01`，可讀不可改）——消費 `MetricProvider` 契約。
  - E2-02 採集頻率分級（`engine/metrics/e2_02`，可讀不可改）——以 `SamplingScheduler` 登記
    低頻採集需求，不自造排程。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「HTTP 端點回傳的結構化
  資料中的某數值欄位」透過 **E2-01 的 `MetricProvider`** 掛成指標（單一實例：value.number =
  取出的數值欄位、history = 該數值時序）。
  - `HttpResponse`（status/headers/body、`is_success()`、大小寫不敏感 `header()`）、
    `HttpTransport`（抽象後端 `get(url)`）、`NullHttpTransport`（相位 1 null 傳輸：不發網路，
    回注入的固定回應或「無後端」空回應）。
  - 結構化解析（自帶輕量 JSON，不消費 E7-01 縮排式宣告格式）：`JsonValue`（可查詢多型節點，
    型別誤用 throw）、`PathSeg`/`JsonPath` + `seek()`（欄位鍵/陣列索引走訪）、
    `parse_json() → JsonParseResult`（錯誤可定位、不靜默；NFR-04）。
  - `HttpFetchProvider : ds::metrics::MetricProvider`：`register_metrics()` 掛上指標；
    `sample()` GET→（2xx）解析→依 `value_path` 取數值→更新 value/歷史；`register_demand()`
    以 `SamplingTier::Low` 把本指標登記進 E2-02 排程器（除頻沿用 E2-02）。
  - 核心性質：相位 1（Mac/null 期）平台中立、無 `#ifdef` / win32 / cocoa / socket / 真實網路；
    非 2xx / 解析失敗 / 路徑缺失皆保守留 value 為 unknown、不污染歷史；消費者只透過 E2-01
    抽象介面走訪，新增此指標掛件一行不動。
