# 結構註記 — E5-13 鍵盤與輸入提交事件

- 層級：engine（平台中立純邏輯）
- 目錄位置：`engine/events/e5_13/`
  - `keyboard_input.hpp` / `keyboard_input.cpp` — 實作
  - `CMakeLists.txt` — `add_library(e5_13)` + `test_e5_13`（`tests/e5/test_e5_13.cpp`）+ `add_test(NAME e5_13)`
- 測試：`tests/e5/test_e5_13.cpp`（gtest，12 案例）
- 對外介面（`namespace ds::events`）：`KeyboardInputSource` —— 兩條頻道的鍵盤與輸入提交事件來源：
  按鍵事件 `KeyEvent`（具名鍵 `Key` + 修飾鍵遮罩 `Modifiers` + `KeyAction` press/release）與
  文字提交事件 `TextInputEvent`（提交文字，如就地輸入框 commit），提供 `subscribe_key` /
  `subscribe_text` / `unsubscribe` 與 `inject_*` / `submit_text` 派發。鍵以具名鍵表達（非平台掃描碼），
  事件由呼叫端 / 測試注入，不綁真實 OS 鍵盤。
