# 結構註記 — C2-08 筆記 widget

- 單元：C2-08（artifact 層 / widgets / 組裝型 / Risk: low / phase 1）
- 目錄位置：`content/widgets/c2_08/`
- 測試：`tests/c2/test_c2_08.cpp`（CTest 名 `c2_08`，18 個 gtest 案例）

## 放了什麼
- `note_widget.hpp` / `.cpp`：**組裝型**單元（非新引擎邏輯）——把四個已合併的擴充點組成
  「筆記」widget（可編輯便條，內容經序列化持久化）：
  - C1-01 `SkinProfile`：桌面存在基底（具名圖層歸屬 / 可互動 / 透明外形 / 自由拖曳 + 位置
    記憶），全數透傳。
  - E4-15 `TextInputElement`：筆記內容的編輯狀態機（游標 / 選取 / 插入 / 刪除），全數透傳。
  - E4-01 `TextLayout`（經 E4-15 內部持有）：筆記文字排版顯示，經 `render_model()` 取得。
  - E7-12 `set_value` / `serialize`（消費 E7-01 `Value`）：筆記**內容**序列化 / 還原
    （`save()` / `load()`），與 C1-01 的**位置**持久化分離。
- `CMakeLists.txt`：`add_library(c2_08)` + `target_link_libraries(c2_08 PUBLIC c1_01 e4_01
  e4_15 e7_12)` + `test_c2_08`（`tests/c2/test_c2_08.cpp`）+ `add_test(NAME c2_08)`。

## 對外介面（一句話）
`ds::widgets::NoteWidget`（注入 `KernelBackend&` + `LayerStack&` + `FontMetrics&`）：基底
透傳——`load_base(Value)` / `unload_base()` / `is_base_loaded()` / `base_state()` / `id()` /
`place` / `begin_drag`·`drag_to`·`end_drag`·`cancel_drag` / `is_dragging()`；編輯透傳——
`set_text` / `insert` / `backspace` / `erase_forward` / `text()` / `length()`；內容持久化——
`load(序列化文字)→NoteStatus`（Ok/Invalid，全有或全無）/ `save()→序列化文字`（round-trip）；
顯示——`render_model()`（透傳 E4-15 `TextInputRenderModel`）。相位 1：純資料 / 邏輯組裝，
無真實 GUI、無平台分支（無 `#ifdef` / win32 / cocoa）、無絕對座標 / 數字 z-order（NFR-02，
承上游）、注入式儲存（`load`/`save` 以字串進出，不觸碰真實檔案 IO）。
