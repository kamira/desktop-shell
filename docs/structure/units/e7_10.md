# 結構註記 — E7-10 字串處理

- 層級：engine(平台中立純邏輯)；描述子系統的**字串運算層**（相依已合併的 E7-05，傳遞取得 E7-02 / E7-01）。
- 目錄位置：`engine/format/e7_10/`
  - `strings.hpp` / `strings.cpp` — 實作
  - `CMakeLists.txt` — `add_library(e7_10)` + `target_link_libraries(e7_10 PUBLIC e7_05)`（消費上游）
    + `test_e7_10`（`tests/e7/test_e7_10.cpp`）+ `add_test(NAME e7_10)`
- 測試：`tests/e7/test_e7_10.cpp`（gtest，48 案例）
- 對外介面（`namespace ds::format::strings`）：可在公式 / 格式脈絡使用的字串處理函式庫。
  輸入 / 輸出以 E7-01 `Value` 表達，結果 / 錯誤沿用 E7-05 `EvalResult` / `EvalError`。
  - 查詢 / 轉換：`length`（UTF-8 碼位數）、`upper` / `lower`（僅折疊 ASCII）、`trim`（外緣 ASCII 空白）。
  - 拼接 / 切分：`concat`（變參）、`substring`（碼位單位，2 或 3 引數）、`replace`（全域）、
    `split`（空分隔 → 逐碼位）、`join`。
  - 判斷：`contains` / `starts_with` / `ends_with`（回 Bool）。
  - 版面：`pad_left` / `pad_right`（碼位寬度、pad 循環填補）、`format`（`{i}` 索引佔位 + `{{` / `}}` 轉義，
    各 Value 型別字串化；容器不可字串化）。
  - 函式表：`function_table()`（名稱 → 變參 `StringFn`）、`find_function(name)`——供 E7-05 未來的函式呼叫
    擴充（或任一上層）以名稱分派接入；表項內建元數檢查。
- 定位：消費 E7-05 的結果 / 錯誤模型，為公式 / 格式值提供字串推導能力（拼路徑、切標籤、補寬度、依樣板組字）。
  **不靜默（NFR-04）**：型別誤用 / 索引越界 / 空填充 / 佔位越界一律回帶訊息的 `EvalError`。
  平台中立、無 `#ifdef`。**未動 `directory.md`**（G4 以本單元檔滿足）。
