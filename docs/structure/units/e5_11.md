# 結構註記 — E5-11 可點區段選取事件

- 層級：engine（平台中立純邏輯，橋接上游 E5-01 + E4-12）
- 目錄位置：`engine/events/e5_11/`
  - `span_selection_dispatcher.hpp` / `span_selection_dispatcher.cpp` — 實作
  - `CMakeLists.txt` — `add_library(e5_11)`（`PUBLIC` 連上游 `e4_12` + `e5_01`）+
    `test_e5_11`（`tests/e5/test_e5_11.cpp`）+ `add_test(NAME e5_11)`
- 測試：`tests/e5/test_e5_11.cpp`（gtest，15 案例）
- 對外介面（`namespace ds::events`）：`SpanSelectionDispatcher` —— 橋接 E5-01
  `MouseEventRouter`（滑鼠事件注入 / 命中路由）與 E4-12 `ClickableTextElement`（可點文字區段
  命中查詢）：`set_surfaces()` 轉呼 E5-01 設定參與命中測試的具名 surface；
  `bind_span_source(surface, element)` / `has_span_source()` / `unbind_span_source()` 為指定
  具名 surface 綁定（或移除）其 E4-12 `ClickableTextElement`（不取得所有權，呼叫端須保證生命
  週期）；`subscribe()` / `unsubscribe()` / `listener_count()` 訂閱橋接後的
  `SpanSelectionEvent`；`inject_button()` / `inject_down()` / `inject_up()` / `inject_click()`
  轉呼內部 `MouseEventRouter` 注入。僅 `MouseAction::Click` 事件命中已綁定 surface 時，才以
  事件本地座標對該元件做 `hit_span()` 查詢；命中已標記區段則把區段具名 id 併入
  `SpanSelectionEvent{ mouse, span_id }` 分派給訂閱者；未綁定 / 未命中區段 / 未命中任何
  surface 皆**不分派**（規格明定：無區段命中的點擊不發選取事件）。命中判定 / 多擊追蹤 / 區段
  幾何命中完全委派上游既有實作，本單元只新增「surface → 區段來源」對照與事件組裝橋接邏輯。
