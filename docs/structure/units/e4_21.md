# 結構註記 — E4-21 漸層填色

- 目錄位置：`modules/elements/e4_21/`（module 層 / 子系統 elements / 非視覺 / 平台中立純邏輯）。
- 內容：`gradient_fill.hpp|cpp`（`GradientType{Linear,Radial}`、`Color` 正規化 RGBA、
  `GradientStop` 位置比例 [0,1] → 顏色、`GradientRenderModel` 渲染描述、`GradientFill` 建構者：
  `add_stop` / `set_angle` / `set_composite` / `sample(t)` / `render_model()`），
  `CMakeLists.txt`（`add_library(e4_21)` PUBLIC 連 E1-03 + `test_e4_21`，根層自動 glob 收入）。
- 對外介面：命名空間 `ds::elements`；以 `GradientFill` 累積色停靠點（依位置自動排序）與方向角度，
  `sample(t)` 可直接內插取色，`render_model()` 產出供後續相位繪製層消費的漸層渲染描述
  （相位 1 不含真實繪製）；合成描述沿用上游 E1-03 `AlphaProfile`。
- NFR-02：色停靠點位置、顏色分量、合成 opacity 皆為 [0,1] 比例；方向以角度（`angle_degrees`，
  正規化至 [0,360)）具名量度表達；停靠點清單依位置排序，無絕對座標 / 無數字 z-order。
- 測試：`tests/e4/test_e4_21.cpp`（26 個 gtest 案例，`add_test(NAME e4_21)`）。
