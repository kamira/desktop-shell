# 結構註記 — E3-08 網路 / 藍牙開關

- 層級：module(動作層致動器)／子系統 actuators
- 目錄位置：`modules/actuators/e3_08/`
  - `radio_actuator.hpp` / `radio_actuator.cpp` — 介面 + null 後端 + 狀態模型 + 致動器實作
  - `CMakeLists.txt` — `add_library(e3_08)` **PUBLIC 連上游 `e6_01`**；`test_e3_08`
    (`tests/e3/test_e3_08.cpp`) + `add_test(NAME e3_08)`
- 測試：`tests/e3/test_e3_08.cpp`（gtest，20 案例）
- 上游相依：E6-01 命令匯流排（`engine/command/e6_01`），可讀不可改——消費擴充點 3
  「動作」契約（`CommandBus` / `CommandArgs` / `CommandResult` / `CommandValue`），
  不自造匯流排或值型別。範式與已合併的 E3-05（注入式後端 + null 樣式）一致。
- 對外介面（`namespace ds::actuators`）：一個無線電開關致動器，把「切換網路介面（Wi-Fi）
  與藍牙 開 / 關 / 切換 / 查詢狀態」透過 **E6-01 具名命令**掛上匯流排
  （`net.wifi.on/off/toggle/status`、`net.bluetooth.on/off/toggle/status`），呼叫端只需
  命令 id 即可觸發，不需相依本致動器。
  - `Radio`（`Wifi` / `Bluetooth`）+ `is_valid_radio` / `radio_name`：致動器層唯一的無線電
    合法化點（非法值回 nullptr / Failed，不進後端）。
  - `RadioOp`（`On` / `Off` / `Toggle` / `Status`）。
  - `RadioState`（`wifi` + `bluetooth` 兩布林 + `enabled(Radio)`；含相等運算子）。
  - `RadioBackend`（抽象後端：`set_enabled(Radio,bool)` / `is_enabled(Radio)`）、
    `NullRadioBackend`（相位 1 null / 假後端：**不接真實系統網路 / 藍牙 API**，純記憶體
    每無線電一布林旗標、初值可注入）。
  - `RadioActuator`：`register_on(bus)` 掛八命令（回滾語意）、`unregister_from(bus)`、
    `handle(Radio, RadioOp, args)`（無效 radio / 無後端回 Failed；成功回操作後啟用狀態
    bool）、`current_state()` 內省。
  - 核心性質：相位 1（Mac/null 期）平台中立、無 `#ifdef` / win32 / cocoa / CoreWLAN /
    IOBluetooth / `networksetup` 等真實 API；致動器邏輯（無線電合法化 / 經 E6-01 分派 /
    切換 / 查詢 / 結果回報）與後端完全解耦，換後端不動致動器；on/off 冪等、toggle 翻轉；
    兩無線電互不干擾；null 後端狀態一致。
