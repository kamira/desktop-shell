## 放了什麼
- `cross_surface_controller.hpp`：跨 surface 命令控制契約 —— `TargetDispatchStatus`
  （Ok/Failed/CommandNotFound/UnknownTarget）+ `to_string()`、`TargetResult`（單一目標結果）、
  `CrossDispatchReport`（逐目標結果 + `all_ok`/`ok_count`/`failed_count` 聚合）、
  `CrossSurfaceController`（`broadcast` / `send_to` / `send_to_group`）。
- `cross_surface_controller.cpp`：`cross_surface_contract_version()`（"e6_05/1.0.0"）、
  `to_string()`、共用的逐目標分派實作（先經 E1-13 `contains()` 驗證，再併入 `"target"`
  參數交給 E6-01 `CommandBus::dispatch`）。
- `CMakeLists.txt`：`add_library(e6_05)` + `target_link_libraries(e6_05 PUBLIC e6_01 e1_13)` +
  `test_e6_05` + `add_test(NAME e6_05)`。

## 對外介面（一句話）
`ds::command::CrossSurfaceController(bus, registry)`：`broadcast(command,args)` 對 E1-13
目前列舉的全部存活實例送命令、`send_to(target,command,args)` 送到單一具名目標
（未知目標回 `UnknownTarget`、不呼叫匯流排）、`send_to_group(targets,command,args)` 送到
一組具名目標（各自獨立判定，互不連坐）；三者皆回逐目標 `TargetResult` / `CrossDispatchReport`，
目標一律以 E1-13 具名 `InstanceId` 指涉（NFR-02：無數字索引 / handle）。
