# 結構註記 — E4-28 透視與景深呈現

- 目錄位置：`modules/elements/e4_28/`（module 層 / 子系統 elements / phase 1 / 平台中立純邏輯，
  depends_on=[E4-22]）。
- 內容：`perspective_element.hpp|cpp`（`PerspectiveStatus`、九宮格具名 `VanishingPoint`、
  `PerspectiveTransformResult`{ status, transform, scale }、`PerspectiveRenderModel`{ transform,
  depth, scale, depth_blur }、`PerspectiveElement` 主類別：`set_depth`/`depth`、
  `set_vanishing_point`/`vanishing_point`、`set_parallax_strength`、`set_perspective_strength`、
  景深模糊參數（`set_depth_of_field_enabled`/`set_focal_depth`/`set_blur_strength`）、
  `transform_for_depth(depth)`、`transform()`、`render_model()`），`CMakeLists.txt`
  （`add_library(e4_28)` + `test_e4_28`，根層自動 glob 收入）。
- 對外介面：命名空間 `ds::elements`；依相對深度換算縮放（`scale(d)=1/(1+perspective_strength*d)`）
  與朝具名消失點方向的視差位移，以上游 E4-22 `ds::render::Transform2D` 產出透視變形矩陣；
  無效深度（非有限值 / 使透視退化）由 `transform_for_depth` / `set_depth` 明確回報
  `PerspectiveStatus::Invalid`，不靜默。NFR-02：深度為相對值、消失點為具名九宮格方向，
  無絕對畫面座標或數字 z-order。
- 測試：`tests/e4/test_e4_28.cpp`（19 個 gtest 案例，`add_test(NAME e4_28)`）。
