# 結構註記 — E2-21 使用者文字輸入值

- 層級：module(平台無關指標提供者)／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_21/`
  - `user_text_input.hpp` / `user_text_input.cpp` — 提供者實作
  - `CMakeLists.txt` — `add_library(e2_21)` **PUBLIC 連上游 `e2_01` + `e4_15`**；
    `test_e2_21`（`tests/e2/test_e2_21.cpp`）+ `add_test(NAME e2_21)`
- 測試：`tests/e2/test_e2_21.cpp`（gtest，14 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`，可讀不可改）——消費
  `MetricProvider` 契約、不自造指標模型；E4-15 就地輸入框
  （`modules/elements/e4_15`，可讀不可改）——只讀 `TextInputElement::text()`，不驅動
  其編輯（本單元是 provider 讀值，非致動器）。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「使用者在 E4-15 就地
  輸入框目前輸入的文字」（如搜尋框內容、參數輸入）透過 **E2-01 的 `MetricProvider`**
  掛成指標 `input.text`。
  - `UserTextInputProvider : ds::metrics::MetricProvider`：`bind(key, label, element)`
    綁定一個輸入框（不取得所有權）、`unbind(key)` 解除綁定、`register_metrics()` 把每個
    已綁定輸入框建成一個 `MetricInstance`（輸入框集=列舉實例、輸入框數=
    `instance_count()`；純文字值，number 恆 0.0，history_capacity=0）、`refresh()`
    重新讀各已綁定輸入框目前文字並更新（pull 模型，呼叫端判定時機呼叫）。
  - 誠實處理：無輸入框 → `instance_count()==0`；已綁定輸入框空值 `""` →
    `valid==true`（非 unknown）；unbind 後既有實例設為 unknown、不再隨 refresh 更新。
  - 核心性質：相位 1（Mac/null 期）平台中立、無 `#ifdef` / win32 / cocoa / 任何真實輸入
    裝置；消費者只透過 E2-01 抽象介面走訪，新增此指標掛件一行不動。
