# 結構註記 — E5-10 逾時計時器

- 層級：engine（平台中立純邏輯 — 不綁真實時鐘，邏輯 tick 由呼叫端注入）
- 目錄位置：`engine/events/e5_10/`
  - `timeout_timer.hpp` / `timeout_timer.cpp` — 介面 + 實作
  - `CMakeLists.txt` — `add_library(e5_10)`（**PUBLIC 連上游 `e5_04`**，沿用其 `ds::events::Tick`）
    + `test_e5_10`（`tests/e5/test_e5_10.cpp`）+ `add_test(NAME e5_10)`
- 測試：`tests/e5/test_e5_10.cpp`（gtest，13 案例：一次性/重複觸發、自動移除、取消、
  剩餘查詢、多計時器、跨多週期、餘量不漂移、回呼中 set/cancel 安全）
- 對外介面（`namespace ds::events`）：`TimeoutTimer` —— 逾時計時器。
  `set_timeout(delay, cb)→id` 一次性（到期觸發一次後自動移除）、`set_interval(interval, cb)→id`
  重複（每週期觸發至取消）、`cancel(id)`、`advance(dt)`/`tick()` 注入邏輯時間並回傳觸發次數、
  `remaining(id)→std::optional<Tick>` 查距下次觸發的 tick、`is_active`/`now`/`active_count`。
  事件 `TimerEvent`（id / now / count / repeating）。**倒數餘量模型**保證重複計時器不漂移；
  **兩階段派發**（先結算狀態+移除到期一次性者，再觸發回呼）使回呼中 set/cancel 安全。
  相依上游 E5-04 心跳（`Tick` 型別，可讀不可改）。無 `#ifdef` / 平台後端。
