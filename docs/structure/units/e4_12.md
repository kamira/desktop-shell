# 結構註記 — E4-12 可點文字區段

- 目錄位置：`modules/elements/e4_12/`（module 層 / 子系統 elements / phase 1 / 平台無關純邏輯）。
- 內容：`clickable_text.hpp|cpp`（`ClickableTextElement`：`set_text` 設定 UTF-8 文字並委派
  E4-01 排版建立字元→字符確定性映射；`add_span(start,end,id)` 以碼位範圍標記具名可點區段
  （越界 / 反轉範圍 / 空 id / 重疊皆報錯不靜默）；`clear_spans` / `span_count` / `text_length`
  查詢與控制；`render_model()` 回傳 E4-01 相對佈局渲染描述；`hit_span(point)` 以 E1-04
  `HitTester` 對區段涵蓋字元的字符矩形做幾何命中，回傳命中區段的具名 id 或 `std::nullopt`），
  `CMakeLists.txt`（`add_library(e4_12)` + `target_link_libraries(e4_12 PUBLIC e4_01 e1_04)` +
  `test_e4_12`，根層自動 glob 收入）。
- 相依：上游 E4-01 文字排版（`engine/render/e4_01/`，可讀不可改；提供排版引擎、字符相對幾何
  與 UTF-8 解碼）、上游 E1-04 幾何命中測試（`src/kernel/e1_04/`，可讀不可改；提供
  `HitTester` / `LocalPoint` / `Shape::Rect` 幾何命中判定）。
- 設計限制：本單元固定要求排版約束 `wrap == WrapMode::None` 且 `ellipsis == false`（建構期
  驗證，否則 `std::invalid_argument`）——兩者若啟用會使 E4-01 排版輸出的字符序列與原始文字
  不再一一對應，破壞本單元依賴的「字元範圍 → 字符幾何」確定性映射。
- 對外介面：命名空間 `ds::elements`；`ClickableTextElement` 以字元範圍 + 具名 id 標記可點區段，
  `render_model()` / `hit_span()` 全程沿用相對佈局與本地相對座標（NFR-02：無絕對座標 / 數字
  z-order）；不綁任何真實輸入裝置 / 繪製後端。
- 測試：`tests/e4/test_e4_12.cpp`（14 個 gtest 案例，`add_test(NAME e4_12)`）。
