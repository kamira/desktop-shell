# 結構註記 — E1-11 從屬 surface 相對定位

- 層級：platform（相位 1 = Mac / null 期）／子系統 kernel／單元 e1_11
- 目錄位置：`src/kernel/e1_11/`（根 CMakeLists 以層級 GLOB `src/*/*/CMakeLists.txt` 深度 2 自動收入）
  - `subordinate_layout.hpp` — 介面：`SubordinateLayout`（父子附著 + 相對定位服務）：
    `attach(child, parent, spec)` / `detach(child)` / `reposition(child, spec)` /
    `close_parent(id)` / `resolve_child(child, parent_placement, child_element, out)`；
    查詢 `is_attached` / `attachment_count` / `parent_of` / `spec_of` / `has_children`
  - `subordinate_layout.cpp` — 父子附著記錄的記憶體實作 + 委由上游 E1-07 `resolve()` 做相對佈局計算
  - `CMakeLists.txt` — `add_library(e1_11 STATIC subordinate_layout.cpp)` +
    `target_link_libraries(e1_11 PUBLIC e1_07)` + `test_e1_11`（`tests/e1/test_e1_11.cpp`）+
    `add_test(NAME e1_11)`
- 測試：`tests/e1/test_e1_11.cpp`（gtest，21 案例）
- 上游相依（可讀不可改）：E1-07（`PUBLIC` 連結）→ 傳遞取得 `Anchor` / `AnchorSpec` / `Size` /
  `ResolvedPlacement` / `AnchorStatus` / `resolve()` 及具名 `SurfaceId` 模型（經 E1-03 / E1-24 傳遞）。
- 對外介面（`namespace ds::kernel`）：**從屬（子）surface 相對父 surface 的定位模型**——
  tooltip / 下拉選單 / 子面板等依附於某個父 surface 的 surface，以 E1-07 具名 anchor + 相對偏移
  相對父定位（NFR-02：附著記錄本身不含絕對座標）。
  - `attach`：建立（或就地更新，同 child 再次呼叫可換 parent / spec）父子附著；child/parent 空、
    自附（child==parent）、或會造成循環附著（沿既有附著鏈往上追溯繞回 child）→ `Invalid` 不記錄，
    不靜默。
  - `resolve_child`：把父的**已解析矩形**當作 E1-07 `resolve()` 的 container，在其局部座標系解出
    子位置後平移 `(+parent.x, +parent.y)`；不快取絕對座標——父矩形改變後重新呼叫即得子的新位置
    （父移動子跟隨的實作方式）。
  - `close_parent`：遞迴清除該 id 自身（若也是別人的子）與其下所有直接 / 間接子附著，回傳清除筆數
    （父關閉子連帶，不留孤兒附著；支援任意深度巢狀從屬鏈）。
  - `detach`：僅移除單一附著（不連帶子孫）；`reposition`：只更新定位規格，不改變 parent。
  - 錯誤：未知 child / 非有限父矩形或子元件尺寸 / 無效 spec →
    `AnchorStatus::Invalid`（復用 E1-07 結果碼，不新增列舉），不靜默、不寫 out、不崩潰。
  - 相位 1 約束：無平台分支（無 `#ifdef`）、無真實 OS / 視窗 / 繪圖 API、
    無 `src/kernel/backend/win32|cocoa/`；純記憶體 / 純佈局邏輯。
