# 結構註記 — E2-08 網路流量

- 層級：module（平台無關指標提供者）／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_08/`
  - `network_traffic.hpp` / `network_traffic.cpp` — 差分演算法 + 抽象/注入式來源 + 值模型
    + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_08)` **PUBLIC 連上游 `e2_01` `e2_02`**；`test_e2_08`
    (`tests/e2/test_e2_08.cpp`) + `add_test(NAME e2_08)`
- 測試：`tests/e2/test_e2_08.cpp`（gtest，28 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`）＋ E2-02 採集頻率分級
  （`engine/metrics/e2_02`），皆可讀不可改——消費 `MetricProvider` 契約與 `SamplingTier`
  分級，不自造指標模型或排程器（範式與 E2-03 CPU 負載一致）。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「網路流量」（每網路
  介面的 上傳/下載速率 bytes/sec、累積收發位元組、收發封包數，支援多介面）透過 **E2-01
  的 `MetricProvider`** 掛成**六個**指標，各以每網路介面為可列舉實例，並以 **E2-02 的頻率
  分級**決定採樣節奏。
  - 值模型：`NetInterfaceCounters`（單介面累積 rx/tx 位元組 + 封包）、
    `NetInterfaceCounterEntry`（含介面名）、`NetCountersSample`（某時刻全介面累積計數快照
    + 單調秒數時戳）、`NetTrafficSample`（每介面 速率 + 累積 + `rate_valid`；整體 `valid`）。
  - 差分演算法（自由函式，獨立可測、純算術）：`rate_from_delta(prev,curr,dt)`＝bytes/sec
    =（位元組Δ / dt），防護：dt<=0→0、計數器重置（curr<prev）→0；
    `traffic_from_delta(prev,curr)`＝逐介面**按名對齊**、以時戳差算 rx/tx 速率、累積取自
    curr；`traffic_from_snapshot(curr)`＝單一快照（累積有效、速率 `rate_valid`==false）。
  - 流量來源：抽象 `NetworkStatSource::sample()→NetTrafficSample`；`NullNetworkStatSource`
    （相位 1 null/假「直接流量」來源，可注入固定/每介面讀值，預設無讀值）。
  - 累積計數來源 + 差分轉接：抽象 `NetCounterSource::read()→NetCountersSample`；
    `NullNetCounterSource`（注入累積計數序列，列盡回最後一份）；
    `DifferencingNetworkStatSource`（把計數來源以「兩次取樣差分」轉成 `NetworkStatSource`，
    首次取樣速率回未知——**速率**差分至少需兩份，累積首份即有效）。
  - `NetworkTrafficProvider : ds::metrics::MetricProvider`：`register_metrics()` 掛上六個
    指標——`net.rx.rate`/`net.tx.rate`(unit "B/s")、`net.rx.bytes`/`net.tx.bytes`(unit "B")、
    `net.rx.packets`/`net.tx.packets`(unit "packets")，值域皆 `at_least(0)`（上無界）；六者
    共用同一組介面實例（同名、首見序列舉，各保留歷史環）；`sample()` 重新讀來源更新各
    實例（有效值推入歷史，新介面動態新增實例、消失者設未知）；`sampling_tier()` 回建議
    採集分級（預設 Normal），供 `SamplingScheduler::add_demand`。
  - 核心性質：相位 1（Mac/null 期）平台中立、**無 `#ifdef` / getifaddrs / /proc/net/dev /
    mach / win32 / cocoa** 等真實網路 API；速率無讀值時以 `rate_valid`==false 誠實表達、
    整體無讀值時全面向 valid==false（不謊報 0）；累積計數直接可讀（一有讀值即有效）；
    消費者只透過 E2-01 抽象介面走訪，新增此指標掛件一行不動。
