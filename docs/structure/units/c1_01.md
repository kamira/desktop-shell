## 放了什麼
- `skin_profile.hpp` / `.cpp`：**組裝型**單元（非新引擎邏輯）——把六個已合併的擴充點組成
  「Skin profile」（桌面寵物 / 角色皮膚基底），作為多個具體 skin 的共用基底：
  - E7-01 `Value`：宣告式 skin 定義的資料模型（`load_skin` 消費）。
  - E1-03 `AlphaSurfaceService`：逐像素 alpha 透明外形（可選能力，`has()` 閘控 NFR-03）。
  - E1-01 `LayerStack`：具名圖層歸屬（NFR-02 具名非數字 z-order）。
  - E1-02 `InputStrategyController`：可互動的具名輸入策略。
  - E1-07 `AnchorSpec` / `resolve`：anchor 定位（九宮錨點 + 正規化偏移）。
  - E1-08 `DraggableSurface`：自由拖曳狀態機 + 位置記憶持久化（序列化回 E7-01 文字）。
- `CMakeLists.txt`：`add_library(c1_01)` + `target_link_libraries(c1_01 PUBLIC e1_01 e1_02
  e1_03 e1_07 e1_08 e7_01)` + `test_c1_01`（`tests/c1/test_c1_01.cpp`）+ `add_test(NAME c1_01)`。
