# 結構註記 — E3-06 亮度設定

- 層級：module(動作層致動器)／子系統 actuators
- 目錄位置：`modules/actuators/e3_06/`
  - `brightness_actuator.hpp` / `brightness_actuator.cpp` — 介面 + null 後端 + 狀態模型 + 致動器實作
  - `CMakeLists.txt` — `add_library(e3_06)` **PUBLIC 連上游 `e6_01`**；`test_e3_06`
    (`tests/e3/test_e3_06.cpp`) + `add_test(NAME e3_06)`
- 測試：`tests/e3/test_e3_06.cpp`（gtest，27 案例）
- 上游相依：E6-01 命令匯流排（`engine/command/e6_01`），可讀不可改——消費擴充點 3
  「動作」契約（`CommandBus` / `CommandArgs` / `CommandResult` / `CommandValue`），
  不自造匯流排或值型別。範式與已合併的 E3-05（音量設定）、E3-02（注入式後端 + null 樣式）一致。
- 對外介面（`namespace ds::actuators`）：一個螢幕亮度致動器，把「設定亮度 0–100 /
  相對增減 / 查詢目前亮度，皆可指定顯示器索引」透過 **E6-01 具名命令**掛上匯流排
  （`brightness.set` / `brightness.get` / `brightness.adjust`），呼叫端只需 命令 id +
  具名參數即可觸發，不需相依本致動器。
  - `kBrightnessMin=0` / `kBrightnessMax=100` / `clamp_brightness(int)`：致動器層唯一的
    夾限點（相對值域，非絕對座標 / z-order）。
  - `kDisplayDefault=0`：未指定 `display` 時的預設顯示器索引。
  - `BrightnessState`（display 恆 >= 0 + level 恆在 [0,100]；含相等運算子）。
  - `BrightnessBackend`（抽象後端：`set(display, level)` / `get(display)`，以顯示器索引定址）、
    `NullBrightnessBackend`（相位 1 null / 假後端：**不接真實系統亮度 API**，每顯示器一個
    記憶體亮度值、未設定過回可注入預設、`set()` 自夾限、`known_displays()` 內省）。
  - `BrightnessActuator`：`register_on(bus)` 掛三命令（回滾語意）、`unregister_from(bus)`、
    三個處理器（缺 / 型別錯必填參數或 display 型別錯 / 為負回 Failed，`has()`/`get_int` 保護；
    成功回夾限後亮度、訊息帶 `display=<索引>`）、`current_state(display)` 內省。
  - 核心性質：相位 1（Mac/null 期）平台中立、無 `#ifdef` / win32 / cocoa / IOKit /
    DisplayServices 等真實亮度 API；致動器邏輯（夾限 / 顯示器索引驗證 / 經 E6-01 分派 /
    結果回報）與後端完全解耦，換後端不動致動器；多顯示器索引互不干擾；null 後端狀態一致。
