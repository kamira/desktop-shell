# 結構註記 — E12-02 多語系

- 層級：engine（平台中立純邏輯）／子系統 common／相依 E4-01（`PUBLIC e4_01`，在地化
  文字為其排版輸入；標頭層無 include 相依）
- 目錄位置：`engine/common/e12_02/`
  - `locale_catalog.hpp` / `locale_catalog.cpp` — 多語系翻譯目錄 `LocaleCatalog`
  - `CMakeLists.txt` — `add_library(e12_02)` + `target_link_libraries(e12_02 PUBLIC e4_01)` +
    `test_e12_02`（`tests/e12/test_e12_02.cpp`）+ `add_test(NAME e12_02)`
- 測試：`tests/e12/test_e12_02.cpp`（gtest，31 案例）
- 對外介面（`namespace ds::common`）：具名訊息鍵（`MessageKey`）→ 各語系（`LocaleId`）
  翻譯字串的查詢、當前語系切換、缺翻譯回退、參數化訊息（佔位替換）、可選複數形式。
  - 型別：`TranslationStatus`（Exact / LocaleFallback / KeyFallback）+ `to_string`；
    `TranslationResult{text, status, locale_used}`。
  - `LocaleCatalog`：`add_translation(locale, key, text)` / `add_plural(locale, key,
    singular, plural)`（皆鏈式）；`set_locale` / `current_locale()` / `default_locale()`；
    `has_key(locale, key)` / `has_key(key)`；`translate(key, args={})` /
    `translate_detailed(key, args={})` / `translate_plural(key, count, args={})`。
  - 自由函式：`substitute_placeholders(text, args)`（`{name}` 佔位替換）。
  - 核心性質：**缺鍵 / 缺語系明確可見回退**——current_locale 缺鍵退 default_locale
    （`LocaleFallback`），default_locale 亦缺則退可見標記 `[missing:key]`（`KeyFallback`）；
    查詢路徑絕不擲例外（僅空 locale / key 等契約違反才擲）。純邏輯、翻譯資料由呼叫端
    注入、無平台分支 / 無真實 locale·ICU·OS API。
