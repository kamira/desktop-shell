# 結構註記 — E4-25 背景模式

- 目錄位置：`modules/elements/e4_25/`（module 層 / 子系統 elements / phase 1 / risk=low /
  平台中立純邏輯）。
- 內容：`background_element.hpp|cpp`（`BackgroundMode{Solid,Gradient,Image,Blur,
  Transparent}`；`GradientDirection{Vertical,Horizontal,Diagonal}`；`Color`（RGBA [0,1]）；
  `GradientStop`（正規化位置 + 顏色）；`BorderStyle`（顏色 + 寬度）；`BackgroundElement`：
  `set_mode/mode`、`set_color/color`、
  `add_gradient_stop/clear_gradient_stops/gradient_stops`、
  `set_gradient_direction/gradient_direction`、`set_image/clear_image/image()`（重用
  E4-02 `ImageElement`）、`set_blur_radius/blur_radius`、`set_opacity/opacity/alpha`、
  `set_corner_radius/corner_radius`、`set_border/clear_border/border`、
  `set_target/clear_target/target`，`render_model()` 產出 `BackgroundRenderModel`），
  `CMakeLists.txt`（`add_library(e4_25)` PUBLIC 連 `e1_03` + `e4_02` + `test_e4_25`，根層
  自動 glob 收入）。
- 對外介面：命名空間 `ds::elements`；元件 / 面板的背景呈現模式——選擇純色 / 漸層(可選) /
  圖片(重用 E4-02) / 模糊 / 透明，設定圓角、邊框、整體透明度，`render_model()` 產出背景
  渲染描述（模式 + 純色 + 漸層停駐點與方向 + 圖片渲染描述 + 模糊半徑 + 圓角 + 邊框 +
  透明度 + 目標具名 surface）。相位 1 不做真實繪製 / 模糊 / 影像解碼。
- NFR-02（無絕對座標 / 無數字 z-order）：目標以具名 `ds::kernel::SurfaceId` 指涉；漸層
  停駐點位置為正規化比例 [0,1]；漸層方向 / 背景模式皆為具名列舉；透明度為比例；圓角
  半徑 / 邊框寬度為背景自身外觀尺寸（非螢幕位置）；本單元不提供任何 (x,y) 螢幕位置或
  疊放層級欄位。
- 不靜默：未知 / 越界 `BackgroundMode` / `GradientDirection`、非有限顏色分量 / 漸層位置 /
  模糊半徑 / 圓角 / 邊框寬度 / 不透明度、負值尺寸、空目標名一律回
  `BackgroundStatus::Invalid`，不套用、不靜默改值（且不部分套用）。圖片來源無效直接
  透傳 E4-02 `ImageStatus`。
- 依賴：E1-03（`AlphaProfile` 透明度合成描述；並透過其標頭傳遞 `ds::kernel::SurfaceId`）、
  E4-02（`ImageElement`/`ImageSource`/`ImageRenderModel`，圖片背景直接重用不重造邏輯）。
- 測試：`tests/e4/test_e4_25.cpp`（52 個 gtest 案例，`add_test(NAME e4_25)`）。
