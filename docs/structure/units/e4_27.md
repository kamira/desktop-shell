# 結構註記 — E4-27 綁定式合成（著替）

- 單元：E4-27（module 層 / elements / phase 1 / Risk: low，depends_on=[E4-08]）
- 目錄位置：`modules/elements/e4_27/`（平台中立 module 層邏輯，換平台一行不動）
- 測試：`tests/e4/test_e4_27.cpp`（CTest 名 `e4_27`）

## 放了什麼

- `bound_composite.hpp`：`BindStatus`（Ok/Invalid/NotFound）、`SlotId`/`PartId`（string
  別名）、`PartOption`（part_id + surface_id + blend_mode + opacity）、`CompositeResult`
  （包裝上游 E4-08 的 `CompositeStatus` + `CompositionPlan`）、`BoundComposite` ——
  綁定式合成（著替）的槽位管理器 + 合成計畫產出器。
- `bound_composite.cpp`：`BoundComposite` 各方法實作（具名鍵線性尋找，同 E4-06 / E4-08
  慣例）；`compose()` 內建立一個暫用的 E4-08 `LayerCompositor` 完成實際合成計畫產出。
- `CMakeLists.txt`：`add_library(e4_27)` + `PUBLIC` 連 `e4_08` + `test_e4_27` +
  `add_test(NAME e4_27)`。

## 對外介面（一句話）

`ds::elements::BoundComposite(SurfaceSwitcher&)`：`define_slot(slot, parts)` 宣告一個
具名合成槽與其候選部件集 / `bind(slot, part_id)` 綁定該槽目前顯示哪個候選 /
`rebind(slot, part_id)`（要求槽已有既存綁定）切換綁定 = 著替 / `compose()` 依**槽定義
順序**把已綁定槽位交給 E4-08 `LayerCompositor` 產出 `CompositionPlan`——未綁定槽明確
跳過、疊放順序純以具名槽定義順序表達，全程不對外暴露任何數字索引 / z-order（NFR-02）。
