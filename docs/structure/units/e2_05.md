# 結構註記 — E2-05 GPU 使用率 / VRAM / 溫度

- 層級：module(平台無關指標提供者)／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_05/`
  - `gpu_stats.hpp` / `gpu_stats.cpp` — GPU 值模型 + 抽象/注入式來源 + VRAM 比率/格式化
    自由函式 + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_05)` **PUBLIC 連上游 `e2_01` `e2_02`**；`test_e2_05`
    (`tests/e2/test_e2_05.cpp`) + `add_test(NAME e2_05)`
- 測試：`tests/e2/test_e2_05.cpp`（gtest，27 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`）＋ E2-02 採集頻率分級
  （`engine/metrics/e2_02`），皆可讀不可改——消費 `MetricProvider` 契約與 `SamplingTier`
  分級，不自造指標模型或排程器。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「GPU 使用率 / VRAM /
  溫度」透過 **E2-01 的 `MetricProvider`** 掛成**三個指標**，各以每張 GPU 為一個可列舉實例
  （多 GPU 支援）。本單元是最終 CPU/GPU Usage Widget 的 **GPU 資料源**，介面刻意乾淨易組合。
  - 值模型：`GpuStat`（單張 GPU 一份讀值：usage 比率[0,1] / vram_used,vram_total bytes /
    temperature °C，三組**各帶 valid 旗標**可獨立缺讀；含 `unknown()`/`of()` 工廠與相等
    運算子）、`GpuStatSample`（全 GPU 快照，gpus 每張一筆，GPU 數可在取樣間變動）。
  - 自由函式（獨立可測，純算術/格式化）：`vram_ratio(used,total)`＝used/total 夾 [0,1]
    （total==0→0、used>total→1.0）；`humanize_bytes(bytes)`＝bytes→"8.0 GiB"/"512 MiB"
    類人類可讀字串（供 VRAM 實例值 text 顯示，不依賴 `<sstream>`/locale）。
  - GPU 讀值來源：抽象 `GpuStatSource::sample()→GpuStatSample`（列舉所有 GPU）；
    `NullGpuStatSource`（相位 1 null/假來源，注入**固定**單份或**序列**多份，列盡回最後一份、
    空列回空快照，預設「無 GPU/無讀值」；`set_fixed`/`set_gpus`/`set_sequence`/`push_sample`/
    `reset`/`clear` 注入）。
  - `GpuStatsProvider : ds::metrics::MetricProvider`：`provider_id()=="sysinfo.gpu"`；
    `register_metrics()` 掛上三指標 `gpu.usage`(unit "%"、range `bounded[0,100]`) /
    `gpu.vram`(unit "%"、range `bounded[0,100]`，主維度為使用率 %、已用/總量 bytes 置於實例值
    text) / `gpu.temp`(unit "°C"、range `at_least(0)`——溫度無自然上界)；三指標共用同一 GPU
    列舉，實例 `gpu0`/`gpu1`/…(label "GPU 0"/…) 依取樣 GPU 數建立（各保留歷史環）；
    `sample()` 重新讀來源更新各實例（有效值推入歷史，GPU 數增則動態新增實例、減則多出者
    三欄設未知）；`sampling_tier()` 回建議採集分級（預設 Normal），供 `SamplingScheduler::
    add_demand`。
  - 核心性質：相位 1（Mac/null 期）平台中立、**無 `#ifdef` / Metal / IOKit / nvml / win32 /
    cocoa** 等真實 GPU API；某欄無讀值（含 VRAM 總量 0）以 valid==false（未知）誠實表達、
    不謊報 0；source 為 null 亦保守不崩（三指標皆 0 實例）；消費者只透過 E2-01 抽象介面走訪，
    新增此指標掛件一行不動。
