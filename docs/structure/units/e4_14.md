# 結構註記 — E4-14 長文捲動與分頁

- 目錄位置：`modules/elements/e4_14/`（module 層 / 子系統 elements / phase 1 / 平台中立純邏輯）。
- 內容：`scroll_view.hpp|cpp`（`VisibleRange` / `VisibleLine` / `ScrollPosition` / `RenderModel`；
  `ScrollView` 核心：`set_content(layout)`（綁定 E4-01 `LayoutResult` 的行數）、
  `set_viewport_lines(n)`（可視區高度，行數）、`scroll_by` / `scroll_to`（逐行捲動，越界夾限）、
  `page_next` / `page_prev`（以 viewport 為一頁的翻頁，等價於 `scroll_by(±viewport_lines)`）、
  `visible_range()`（目前可見內容行的半開區間）、`render_model()`（可見行對應 + 捲動位置 + 分頁
  指示）），`CMakeLists.txt`（`add_library(e4_14)` PUBLIC 連 `e4_01`，`test_e4_14`，根層自動 glob 收入）。
- 對外介面：命名空間 `ds::elements`。`ScrollView::set_content` 只取用上游 `LayoutResult::lines.size()`
  作為捲動範圍，不重複儲存像素幾何；`render_model()` 產出的 `VisibleLine::content_line` 指向上游
  `LayoutResult::lines` 索引，供繪製層回查實際 glyph / 佈局細節。
- NFR-02：`RenderModel` / `ScrollPosition` 全以**行索引**（`std::size_t`）與**比例**（`ratio` ∈ [0,1]）
  表達，無絕對像素座標 / 數字 z-order。
- 錯誤不靜默：`set_viewport_lines(0)` 或尚未設定 viewport 即呼叫捲動 / 分頁 / `visible_range()` /
  `render_model()` → `std::invalid_argument`（無效視窗不可靜默）。**捲動越界則夾限**（非錯誤）：
  `scroll_by` / `scroll_to` / `page_next` / `page_prev` 一律夾限於 `[0, max_offset_lines()]`。
- 測試：`tests/e4/test_e4_14.cpp`（30 個 gtest 案例，`add_test(NAME e4_14)`）。
