# 結構註記 — E2-04 記憶體使用量（實體/交換）

- 層級：module(平台無關指標提供者)／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_04/`
  - `memory_usage.hpp` / `memory_usage.cpp` — 值模型 + 抽象/注入式來源 + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_04)` **PUBLIC 連上游 `e2_01` `e2_02`**；`test_e2_04`
    (`tests/e2/test_e2_04.cpp`) + `add_test(NAME e2_04)`
- 測試：`tests/e2/test_e2_04.cpp`（gtest，24 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`）＋ E2-02 採集頻率分級
  （`engine/metrics/e2_02`），皆可讀不可改——消費 `MetricProvider` 契約與 `SamplingTier`
  分級，不自造指標模型或排程器。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「記憶體使用量」——實體
  記憶體（總量／已用／可用 bytes、使用率 %）與交換空間 swap（總量／已用）——透過 **E2-01 的
  `MetricProvider`** 掛成指標 `memory.stats`（各記憶體欄位為可列舉 instances），並以 **E2-02
  的頻率分級**決定採樣節奏。
  - 值模型：`MemoryStats`（`physical_total/used/available` + `swap_total/used` + `valid`，皆
    bytes）；`from_physical(total,used,...)` 便利工廠（available=total-used 夾 >=0）；
    `usage_percent()`＝used/total*100 夾 [0,100]（total==0→0）、`swap_usage_percent()`（除零
    保護）。used 與 available 由來源分別給出，不臆造 `used+available==total`。
  - 記憶體來源：抽象 `MemoryStatSource::read()→MemoryStats`（非 const，序列型取樣有副作用）；
    `NullMemoryStatSource`（相位 1 null/假來源，以注入快照列表達——固定值=一元素序列、序列
    模擬時間推進；列盡回最後一份、空列回 unknown；`set_stats`/`set_sequence`/`push_sample`/
    `reset`/`clear`）。
  - `MemoryProvider : ds::metrics::MetricProvider`：`register_metrics()` 掛上 `memory.stats`
    （unit=""、range unbounded——欄位異質），固定 6 欄位為可列舉實例
    （`memory.physical.total/used/available`、`memory.usage.percent`、`memory.swap.total/used`；
    變動欄位保留歷史環、靜態欄位無歷史）；`sample()` 重新讀來源更新各實例（變動欄位推入
    歷史，register 前為 no-op）；`sampling_tier()` 回建議採集分級（預設 Normal），供
    `SamplingScheduler::add_demand`。
  - 核心性質：相位 1（Mac/null 期）平台中立、**無 `#ifdef` / host_statistics / sysctl /
    /proc/meminfo / mach / win32 / cocoa** 等真實記憶體 API；無讀值時以 valid==false（未知）
    誠實表達、不謊報 0（total==0 時使用率欄位亦未知）；消費者只透過 E2-01 抽象介面走訪，
    新增此指標掛件一行不動。
