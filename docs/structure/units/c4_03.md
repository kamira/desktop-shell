## 放了什麼
- `color_picker.hpp` / `.cpp`：**組裝型**單元（非新引擎邏輯）——把兩個已合併的擴充點/
  元件組成「取色器」（color picker / eyedropper）應用 + 行為：
  - E2-27 `PixelSampleSource` / `PixelColor`：於具名 `ScreenAnchor` 讀該點像素顏色。
  - E4-30 `DimOverlayElement`：全螢幕調光覆蓋，本單元借它組出放大鏡 / 取色游標
    （顯示覆蓋層 + 於目前取樣點挖具名不調光區域）。
- `CMakeLists.txt`：`add_library(c4_03)` + `target_link_libraries(c4_03 PUBLIC e2_27 e4_30)`
  + `test_c4_03`（`tests/c4/test_c4_03.cpp`）+ `add_test(NAME c4_03)`。

## 對外介面（一句話）
`ds::apps::ColorPickerApp`：`pick_at(ScreenAnchor) -> PickStatus`（取色，`current()` 讀
RGB/HEX）/ `magnify()` `dismiss_magnifier()`（放大鏡覆蓋顯隱，回傳 E4-30 `DimStatus`）/
`copy()`（複製目前 HEX 至內部 `clipboard()`）。相位 1：純資料 / 邏輯組裝，僅注入式像素
來源，不接真實螢幕擷取；無平台分支（無 `#ifdef` / win32 / cocoa）、無絕對座標 / 數字
z-order（NFR-02）。
