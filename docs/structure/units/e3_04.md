# 結構註記 — E3-04 電源動作

- 單元：E3-04（modules 層 / actuators / Risk: low）
- 目錄位置：`modules/actuators/e3_04/`（透過 E6-01 契約掛命令，相位 1 無真實後端）
- 測試：`tests/e3/test_e3_04.cpp`（CTest 名 `e3_04`）
- 相依：E6-01 命令匯流排（`target_link_libraries(e3_04 PUBLIC e6_01)`）——具名電源命令掛匯流排、結果重用穩定值型別。

## 放了什麼
- `power_actuator.hpp`：致動器契約 —— `PowerAction`（Sleep/Lock/Logout/Restart/Shutdown/Unknown）、
  `PowerRequest`（平台中立請求：action）、`PowerBackend`（純虛後端）、
  `NullPowerBackend`（相位 1：不觸碰 OS、不執行任何電源操作，只記錄請求）、
  `PowerActuator`（掛命令 + `handle_action` 處理器）、五命令 id 常數（`power.sleep` /
  `power.lock` / `power.logout` / `power.restart` / `power.shutdown`）、動作 ↔ 字串 / 命令 id 互轉輔助。
- `power_actuator.cpp`：`contract_version()` 契約版本標記（"e3_04/1.0.0"）；其餘邏輯 header-only inline。
- `CMakeLists.txt`：`add_library(e3_04)` + `PUBLIC e6_01` + `test_e3_04` + `add_test(NAME e3_04)`。

## 對外介面（一句話）
`ds::actuators::PowerActuator::register_on(CommandBus&)` 把 `power.sleep` / `power.lock` /
`power.logout` / `power.restart` / `power.shutdown` 五個具名命令掛上 E6-01 匯流排；呼叫端以
`bus.dispatch(id)` 觸發（電源動作無需參數），相位 1 交 `NullPowerBackend` 記錄請求供驗證且
**絕不真的執行電源操作或呼叫任何 OS 電源 API**，無效 / 未知動作回 `CommandResult{Failed}` 不崩潰，
相位 2 換真實平台後端時介面與命令契約不動。
