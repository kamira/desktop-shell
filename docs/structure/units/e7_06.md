# 結構註記 — E7-06 錯誤可見性

- 層級：engine(平台中立純邏輯)；描述子系統的**錯誤呈現層**（相依已合併的 E7-01）。
- 目錄位置：`engine/format/e7_06/`
  - `visibility.hpp` / `visibility.cpp` — 實作
  - `CMakeLists.txt` — `add_library(e7_06)` + `target_link_libraries(e7_06 PUBLIC e7_01)`（消費上游）
    + `test_e7_06`（`tests/e7/test_e7_06.cpp`）+ `add_test(NAME e7_06)`
- 測試：`tests/e7/test_e7_06.cpp`（gtest，25 案例）
- 對外介面（`namespace ds::format`）：把 E7-01 解析/驗證錯誤呈現為人類可讀、定位到行/欄的診斷（NFR-04）。
  - `Severity{Error, Warning, Note}` + `severity_label(Severity)`。
  - `Diagnostic{severity, line, column, message}`；`from_parse_error(e[, column])` 由 E7-01 `ParseError` 轉入
    （line 沿用 1-based / 0=非特定行語意；column 1-based / 0=未知）。
  - `FormatOptions{show_context, show_caret}`（預設全開、無顏色、輸出決定性）。
  - `format_diagnostic` / `format_error`（單筆，Rust 式：`severity: message` + `--> line L:C` + 側欄來源行 + `^` 插字符）。
  - `format_report` / `format_errors`（彙整多筆：標頭載明筆數、各筆空行分隔、順序保持、全數原封輸出）。
  - `DiagnosticReport`：`add` / `add_parse_error` / `size` / `error_count` / `ok`（iff 無 Error）/ `empty` /
    `diagnostics` / `render`。
  - **不靜默（NFR-04）**：空集合回 `no diagnostics`（非空字串）；line 0 仍印訊息；行號超範圍不硬造上下文
    但保留訊息與行號；訊息永不遺漏。
- 定位：消費 E7-01 的 `ParseError` / `ParseResult`，為其上的錯誤呈現層；任何消費 `parse()` 的單元
  失敗時可用本層把錯誤印給人看。平台中立、無 `#ifdef`。
