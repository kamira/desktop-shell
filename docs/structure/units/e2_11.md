# 結構註記 — E2-11 系統運行時間

- 層級：module(平台無關指標提供者)／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_11/`
  - `uptime.hpp` / `uptime.cpp` — 值模型 + 格式化自由函式 + 抽象/注入式來源 + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_11)` **PUBLIC 連上游 `e2_01` `e2_02`**；`test_e2_11`
    (`tests/e2/test_e2_11.cpp`) + `add_test(NAME e2_11)`
- 測試：`tests/e2/test_e2_11.cpp`（gtest，26 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`）＋ E2-02 採集頻率分級
  （`engine/metrics/e2_02`），皆可讀不可改——消費 `MetricProvider` 契約與 `SamplingTier`
  分級，不自造指標模型或排程器。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「系統運行時間 uptime」
  （開機至今秒數，可衍生天/時/分格式化文字；可選帶開機時間戳）透過 **E2-01 的
  `MetricProvider`** 掛成指標 `system.uptime`（一個 uptime 實例 + 可選 boot.time 實例），
  並以 **E2-02 的頻率分級**決定採樣節奏（uptime 變動緩慢，預設 Low）。
  - 值模型：`UptimeReading`（`seconds` 開機至今秒數 + 可選 `boot_unix_time` 開機時間戳
    + `valid`；`of()` / `unknown()` 工廠 + 相等運算子）。
  - 格式化（自由函式，獨立可測）：`format_uptime(seconds)`＝把秒數格式化為 "Nd HH:MM:SS"
    （天數任意位數、時/分/秒補零兩位；負值視為 0、小數截斷）。
  - uptime 來源：抽象 `UptimeSource::read()→UptimeReading`；`NullUptimeSource`（相位 1
    null/假來源，可注入**固定值**或**遞增序列**——序列非空優先、列盡回最後一份；預設無讀值）。
  - `UptimeProvider : ds::metrics::MetricProvider`：`register_metrics()` 掛上 `system.uptime`
    （unit="s"、range=`at_least(0)` 下界 0 上無界），uptime 實例 `uptime`(label "System
    Uptime") 恆存在並保留歷史環，開機時間戳實例 `boot.time`(label "Boot Time") **可選**——
    僅當來源提供開機時間戳時動態新增（靜態值，無歷史）；`sample()` 重新讀來源更新實例
    （uptime 推入歷史、開機時間戳只設值）；`sampling_tier()` 回建議採集分級（預設 Low），
    供 `SamplingScheduler::add_demand`；`has_boot_time()` 查是否已建開機時間戳實例。
  - 核心性質：相位 1（Mac/null 期）平台中立、**無 `#ifdef` / sysctl kern.boottime /
    /proc/uptime / GetTickCount / mach / win32 / cocoa** 等真實時間 API；無讀值時以
    valid==false（未知）誠實表達、不謊報 0 秒；消費者只透過 E2-01 抽象介面走訪，新增此
    指標掛件一行不動。
