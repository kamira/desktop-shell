# 結構註記 — E3-02 啟動程式 / 開檔 / 網頁搜尋

- 單元：E3-02（modules 層 / actuators / Risk: low）
- 目錄位置：`modules/actuators/e3_02/`（透過 E6-01 契約掛命令，相位 1 無真實後端）
- 測試：`tests/e3/test_e3_02.cpp`（CTest 名 `e3_02`）
- 相依：E6-01 命令匯流排（`target_link_libraries(e3_02 PUBLIC e6_01)`）——具名命令掛匯流排、參數重用穩定值型別。

## 放了什麼
- `launch_actuator.hpp`：致動器契約 —— `LaunchKind`（Program/File/WebSearch）、
  `LaunchRequest`（平台中立請求：kind/target/arguments/engine）、`LaunchBackend`（純虛後端）、
  `NullLaunchBackend`（相位 1：不觸碰 OS，只記錄請求）、`LaunchActuator`（掛命令 + 處理器）、
  三命令 id 常數（`launch.program` / `open.file` / `web.search`）。
- `launch_actuator.cpp`：`contract_version()` 契約版本標記（"e3_02/1.0.0"）；其餘邏輯 header-only inline。
- `CMakeLists.txt`：`add_library(e3_02)` + `PUBLIC e6_01` + `test_e3_02` + `add_test(NAME e3_02)`。

## 對外介面（一句話）
`ds::actuators::LaunchActuator::register_on(CommandBus&)` 把 `launch.program` / `open.file` /
`web.search` 三個具名命令掛上 E6-01 匯流排；呼叫端以 `bus.dispatch(id, args)` 觸發（參數：
program/args、path、query/engine），相位 1 交 `NullLaunchBackend` 記錄請求供驗證，必填缺漏回
`CommandResult{Failed}` 不崩潰，相位 2 換真實平台後端時介面與命令契約不動。
