# 結構註記 — C2-07 媒體控制 widget

- 單元：C2-07（artifact 層 / widget / Risk: low）
- 目錄位置：`content/widgets/c2_07/`
- 測試：`tests/c2/test_c2_07.cpp`（CTest 名 `c2_07`，13 個 gtest 案例）

## 放了什麼

- `media_control_widget.hpp` / `.cpp`：`namespace ds::widgets`。**組裝型**單元（非新引擎
  邏輯）——桌面「媒體控制」widget，把五個已合併的擴充點組成一個具名 widget：
  - C1-01 `SkinProfile`：桌面基底（具名圖層歸屬 / 輸入策略 / 透明外形 / 自由拖曳皆透傳，
    以 `base()` 存取，本單元不重造）。
  - E2-13：注入式 `MetricRegistry`，讀「media.nowplaying」指標的 state/title/artist/album/
    artwork 五個欄位實例；registry 為 null / 無指標 / 無播放中媒體皆走降級路徑（`Ok`，
    `has_media()==false`）；指標存在但欄位不齊全 → `Invalid`。
  - E3-03：`MediaControlActuator`（相位 1 為 `NullMediaControlBackend`）——四顆控制按鈕的
    `on_click` 直接呼叫其 `handle_play` / `handle_pause` / `handle_next` / `handle_prev`。
  - E4-02 `ImageElement`：把封面參照組裝為圖片渲染描述（`MemoryImageSource`，固有尺寸為
    描述性常數 `kArtworkSize`；空參照則 `has_source=false`）。
  - E4-04 `ButtonElement`：四顆具名控制按鈕（play/pause/prev/next），經本單元的
    `MediaControlButtonBridge` 橋接（見下）。
  - `CMakeLists.txt`：`add_library(c2_07 STATIC media_control_widget.cpp
    media_control_button_bridge.cpp)` + `target_link_libraries(c2_07 PUBLIC c1_01 e2_13 e3_03
    e4_02 e4_04)` + `test_c2_07`（`tests/c2/test_c2_07.cpp`）+ `add_test(NAME c2_07)`。
- `media_control_button_bridge.hpp` / `.cpp`：`namespace ds::widgets`。**內部橋接層**（pimpl）
  ——中立化 `MediaButtonState` / `MediaButtonRenderModel`，把實際 `#include "button_element.hpp"`
  （E4-04，transitively 帶入 E1-04 `hit_test.hpp`）隔離到獨立翻譯單元（僅 `.cpp` 才 include），
  避免與 C1-01 transitively 帶入的 E1-02 `input_strategy.hpp` 在同一翻譯單元內因
  `ds::kernel::HitResult` 同名不同型別（enum class 對 struct）而編譯失敗（此上游既有命名碰撞
  已由已合併的 C1-06 率先發現並確立此 pimpl 橋接範式，本單元依樣套用）。

## 對外介面（一句話）

`ds::widgets::MediaControlWidget`（注入 `KernelBackend&` + `LayerStack&` +
`shared_ptr<MetricRegistry>` + `shared_ptr<MediaControlActuator>`）：`refresh()` 經注入
registry 讀 E2-13「media.nowplaying」指標並組裝封面 / 文字 / 按鈕渲染描述（無媒體降級為 `Ok`
非錯誤；指標結構不齊全為 `Invalid`）；`play()` / `pause()` / `next()` / `prev()` 模擬對應按鈕
一次點擊，經 E3-03 注入後端執行（能力閘控 NFR-03：未注入時 `Unavailable`）；`render_model()`
查詢目前渲染描述。相位 1：純資料 / 邏輯組裝，無真實媒體 API / 影像解碼、無平台分支（無
`#ifdef` / win32 / cocoa）、無絕對座標 / 數字 z-order（NFR-02）。
