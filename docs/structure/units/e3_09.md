# 結構註記 — E3-09 系統旗標切換

- 層級：module(動作層致動器)／子系統 actuators
- 目錄位置：`modules/actuators/e3_09/`
  - `system_flag_actuator.hpp` / `system_flag_actuator.cpp` — 介面 + null 後端 + 旗標語意 + 致動器實作
  - `CMakeLists.txt` — `add_library(e3_09)` **PUBLIC 連上游 `e6_01`**；`test_e3_09`
    (`tests/e3/test_e3_09.cpp`) + `add_test(NAME e3_09)`
- 測試：`tests/e3/test_e3_09.cpp`（gtest，22 案例）
- 上游相依：E6-01 命令匯流排（`engine/command/e6_01`），可讀不可改——消費擴充點 3
  「動作」契約（`CommandBus` / `CommandArgs` / `CommandResult` / `CommandValue`），
  不自造匯流排或值型別。範式與已合併的 E3-05（注入式後端 + null 樣式）一致。
- 對外介面（`namespace ds::actuators`）：一個系統層級布林旗標 / 模式切換致動器，把「切換具名
  系統開關（勿擾模式 / 深色模式 / 夜覽 Night Shift / 飛航模式 / 螢幕自動旋轉鎖 等）」透過
  **E6-01 具名命令**掛上匯流排。每個具名旗標 `<name>` 提供四動詞命令
  `flag.<name>.on` / `flag.<name>.off` / `flag.<name>.toggle` / `flag.<name>.status`；呼叫端只需
  命令 id 即可觸發，不需相依本致動器。
  - `FlagVerb`（On/Off/Toggle/Status）/ `flag_verb_suffix` / `flag_command_id(name,verb)`：
    組裝穩定可讀命令 id（不用數字 opcode）。
  - `is_valid_flag_key(const std::string&)`：旗標鍵驗證（非空、僅 `[a-z0-9_]`、排除 `.`
    命令分隔符），致動器層唯一的合法化點。
  - `SystemFlagBackend`（抽象後端：`set(flag,bool)`/`get(flag)`，字串鍵）、
    `NullSystemFlagBackend`（相位 1 null 後端：**不接真實系統設定 API**，純記憶體 map 模擬、
    未設定視為關、初值可注入、`has`/`size` 內省）。
  - `SystemFlagActuator`：`add_flag(name)` 登記已知旗標（驗證 + 去重）、`register_on(bus)`
    掛四動詞命令（回滾語意）、`unregister_from(bus)`、四個處理器（未登記 / 無後端以
    `has_flag()` 保護回 Failed；成功回操作後布林狀態）、`current` / `flag_names` 內省。
  - 核心性質：相位 1（Mac/null 期）平台中立、無 `#ifdef` / win32 / cocoa / `defaults` /
    NSUserDefaults 等真實設定 API；致動器邏輯（旗標鍵驗證 / 命令 id 組裝 / 經 E6-01 分派 /
    結果回報）與後端完全解耦，換後端不動致動器；on/off 冪等、toggle 自逆、status 唯讀；
    未登記旗標鍵 dispatch 回 NotFound、直接呼叫回 Failed；null 後端狀態一致。
