# 結構註記 — E1-04 幾何命中測試

- 層級：platform（相位 1 = Mac / null 期）／子系統 kernel／單元 e1_04
- 目錄位置：`src/kernel/e1_04/`（根 CMakeLists 以層級 GLOB `src/*/*/CMakeLists.txt` 深度 2 自動收入）
  - `hit_test.hpp` — 介面：座標型別 `LocalPoint`（元件本地 / 相對，非畫面絕對）、形狀
    `Shape` + `ShapeKind`{Rect, RoundedRect, Circle, Polygon, Path} + `FillRule`{EvenOdd, NonZero}
    + 工廠 `make_rect` / `make_rounded_rect` / `make_circle` / `make_polygon` / `make_path`、
    結果 `HitStatus`{Ok, Invalid} / `HitResult` / `TopmostHit`、注入式 `AlphaQuery`
    （`std::function<float(const LocalPoint&)>`）、命中 surface `HitSurface`、服務 `HitTester`
  - `hit_test.cpp` — 純幾何點內判定（射線 even-odd / 環繞數 NonZero / 圓角四分圓 / 圓）
    + alpha 命中 + 具名圖層優先，實作
  - `CMakeLists.txt` — `add_library(e1_04 STATIC hit_test.cpp)` +
    `target_link_libraries(e1_04 PUBLIC e1_03)` + `test_e1_04`（`tests/e1/test_e1_04.cpp`）
    + `add_test(NAME e1_04)`
- 測試：`tests/e1/test_e1_04.cpp`（gtest，21 案例）
- 上游相依（可讀不可改）：E1-03 `AlphaMode` / `AlphaProfile`（合成模式 + 不透明度）；
  E1-24 `SurfaceId`（具名指涉）/ `SurfaceLayer`（具名圖層）/ `HitPolicy`（命中穿透）。
- 對外介面（`namespace ds::kernel`）：**幾何命中測試（hit testing）**——判定本地點是否落在
  surface / 形狀內，供輸入路由 / 點擊判定。
  - `HitTester`（無狀態，方法皆 const）：`is_valid`（形狀有效性）；`hit_test`（純幾何點內判定，
    矩形 / 圓角 / 圓 / 多邊形 / path，含邊界）；`hit_test_alpha`（幾何命中 + 逐像素 alpha：
    透明處不命中，Opaque 忽略 alpha，`HitPolicy::Transparent` 永不命中）；`topmost_hit`
    （多 surface 重疊依**具名圖層** + 宣告順序決定命中者）。
  - alpha 表述：per-pixel alpha 用 E1-03 的 `AlphaMode` / `AlphaProfile`（模式 + 整體 opacity），
    逐像素值由**注入式** `AlphaQuery` oracle 供給（相位 1 無真實像素）——**不修改** E1-03。
  - 相位 1 約束：純幾何邏輯 + 注入式 alpha 查詢，無真實視窗系統；無平台分支（無 `#ifdef`）、
    無真實 OS / 繪圖 API、無 `src/kernel/backend/win32|cocoa/`；座標本地 / 相對、優先序具名圖層
    + 宣告順序（無絕對座標 / 數字 z-order，NFR-02）；無效形狀 / 座標回 `HitStatus::Invalid`
    （報錯不靜默）。
