# 結構註記 — E3-11 螢幕擷取

- 單元：E3-11（module 層 / actuators / Risk: low / stage D）
- 目錄位置：`modules/actuators/e3_11/`（透過 E6-01 契約掛命令，相位 1 無真實後端）
- 測試：`tests/e3/test_e3_11.cpp`（CTest 名 `e3_11`）
- 相依：E6-01 命令匯流排（`target_link_libraries(e3_11 PUBLIC e6_01)`）——具名命令掛匯流排、參數重用穩定值型別。

## 放了什麼
- `screen_capture_actuator.hpp`：致動器契約 —— `CaptureKind`（FullScreen/Region/Window）、
  `CaptureRegion`（平台中立矩形 x/y/width/height + `valid()`）、`CaptureSpec`（kind/display/region/window/save_path）、
  `CaptureResult`（width/height/image_ref/path）、`ScreenCaptureBackend`（純虛後端）、
  `NullScreenCaptureBackend`（相位 1：不觸碰螢幕，回注入假影像並記錄請求）、
  `ScreenCaptureActuator`（掛命令 + 三個處理器）、三命令 id 常數
  （`screen.capture.full` / `screen.capture.region` / `screen.capture.window`）。
- `screen_capture_actuator.cpp`：`screen_capture_contract_version()` 契約版本標記（"e3_11/1.0.0"，前綴命名
  避免與 E3-02 `contract_version()` 衝突）；其餘邏輯 header-only inline。
- `CMakeLists.txt`：`add_library(e3_11)` + `PUBLIC e6_01` + `test_e3_11` + `add_test(NAME e3_11)`。

## 對外介面（一句話）
`ds::actuators::ScreenCaptureActuator::register_on(CommandBus&)` 把 `screen.capture.full` /
`.region` / `.window` 三個具名命令掛上 E6-01 匯流排；呼叫端以 `bus.dispatch(id, args)` 觸發
（參數：display / x·y·width·height / window，選用 path），相位 1 交可注入的 `NullScreenCaptureBackend`
回假影像並記錄請求供驗證，無效區域 / 缺參回 `CommandResult{Failed}` 不崩潰，結果以 `CaptureResult`
（尺寸 + image_ref 或 path）回報，相位 2 換真實平台後端時介面與命令契約不動。
