# 結構註記 — E1-08 自由拖曳與位置記憶

- 層級：platform（相位 1 = Mac / null 期）／子系統 kernel／單元 e1_08
- 目錄位置：`src/kernel/e1_08/`（根 CMakeLists 以層級 GLOB `src/*/*/CMakeLists.txt` 深度 2 自動收入）
  - `draggable_surface.hpp` — 介面：`DragStatus`{Ok, Invalid, NotDragging, AlreadyDragging}；
    自由函式 `anchor_to_name` / `anchor_from_name`（九宮具名錨點 ↔ 小寫連字號名稱）；
    服務 `DraggableSurface`
  - `draggable_surface.cpp` — 拖曳狀態機 + 具名鍵記憶體記錄 + E7-12/E7-01 持久化實作
  - `CMakeLists.txt` — `add_library(e1_08 STATIC draggable_surface.cpp)` +
    `target_link_libraries(e1_08 PUBLIC e1_03 e1_07 e7_12)` + `test_e1_08`
    （`tests/e1/test_e1_08.cpp`）+ `add_test(NAME e1_08)`
- 測試：`tests/e1/test_e1_08.cpp`（gtest，13 案例）
- 上游相依（可讀不可改）：
  - E1-03（`PUBLIC` 連結）→ 傳遞取得 E1-24 `KernelBackend` / `SurfaceId` surface 模型；拖曳以
    `backend.has_surface(id)` 閘控「只拖曳真實存在的 surface」。
  - E1-07（`PUBLIC` 連結）→ `AnchorSpec` / `resolve` / `is_valid_anchor`：位置的宣告式表達與落地。
  - E7-12（`PUBLIC` 連結，其上為 E7-01）→ `set_value` / `serialize` 存、`parse` + `Value` 取：
    位置記憶的持久化。
- 對外介面（`namespace ds::kernel`）：**自由拖曳 surface 並記憶其位置**——注入式拖曳狀態機 +
  以 anchor / 相對表達並持久化的位置記憶（NFR-02）。
  - 拖曳狀態機：`begin_drag(id)` → `drag_to(id, AnchorSpec)`（可多次，只更新 pending）→
    `end_drag(id)`（提交 pending 為記憶位置）/ `cancel_drag(id)`（放棄 pending，還原到拖曳前）。
    相位 1 無真實視窗拖曳 API，拖曳為注入式呼叫；目標位置以 E1-07 `AnchorSpec` 承載。
  - 位置：`set_position(id, spec)`（後端閘控 + 有效性驗證後登錄 / 就地更新）、`forget(id)`；
    `remembered_position(id)`（committed 記憶位置）/ `live_position(id)`（拖曳中回 pending、否則
    committed）；`resolve_live(id, container, element, out)` 委由 E1-07 `resolve` 落地為具體佈局。
  - 持久化：`serialize_positions()`（經 E7-12 `set_value` 顯式 Path 段逐欄寫入 + `serialize` 落回
    E7-01 文字，首行 `format_version`；每 surface 一 map 條目 `{ anchor, dx, dy }`）；
    `load_positions(text)`（E7-01 `parse` 讀回、逐條驗證後**全有或全無**套用）。
  - NFR-02：位置全為 E1-07 `AnchorSpec`（九宮具名錨點 + 容器尺寸正規化偏移），核心 API **無**
    絕對像素座標 / 數字 z-order；具體像素只在 `resolve_live` 計算邊界出現（呼叫端提供尺寸）。
    持久化欄位為具名 anchor + 正規化分數。
  - 錯誤：空 / 未知（後端無此）/ 未註冊 surface、越界 anchor、非有限 offset → `DragStatus::Invalid`；
    非拖曳中操作 → `NotDragging`；重複 begin → `AlreadyDragging`；無法解析 / 條目不合的持久化文字 →
    `Invalid` 且不套用任何條目。一律結構化回報，不靜默、不崩潰、不改狀態。
  - 相位 1 約束：無平台分支（無 `#ifdef`）、無真實 OS / 視窗 / 繪圖 API、
    無 `src/kernel/backend/win32|cocoa/`；純狀態機 + 純資料 + 純佈局落地。
