# 結構註記 — E7-01 宣告式格式核心 + 版本欄位

- 層級：engine（平台中立純邏輯）；**描述子系統的根契約**（load-bearing 11x）。
- 目錄位置：`engine/format/e7_01/`
  - `document.hpp` / `document.cpp` — 實作
  - `CMakeLists.txt` — `add_library(e7_01)` + `test_e7_01`（`tests/e7/test_e7_01.cpp`）+ `add_test(NAME e7_01)`
- 測試：`tests/e7/test_e7_01.cpp`（gtest，37 案例）
- 對外介面（`namespace ds::format`）：宣告式文件的資料模型與解析基座。
  - `Value` 多型節點（Null / Bool / Number〔帶整數旗標〕/ String / List〔有序〕/ Map〔有序、鍵唯一〕），
    附型別查詢、型別化存取（誤用即 throw）、Map 便捷查詢（`contains`/`find`/`at`/`keys`）與深層相等。
  - `FormatVersion{major,minor}` + `kSupportedFormat` + `is_format_compatible()`——**版本欄位**與相容判定
    （相容 iff major 相同且 minor ≤ 支援上限）；相容策略的基礎（ai-guideline Q3）。
  - `Document{format_version, root}`；`ParseResult`（成功持 Document / 失敗持 `ParseError{line,message}`）。
  - `parse(text)`：文字（縮排巢狀 key/value + list）→ Document，**錯誤定位到行、不靜默**（NFR-04 精神）。
  - `parse_scalar(token,out)`：純量型別推斷單元（供進階呼叫端 / 測試共用同一套推斷）。
- 定位：`E9-02` manifest 是本通用格式的一個應用；眾多格式 / 設定單元消費此根契約。平台中立、無 `#ifdef`。
