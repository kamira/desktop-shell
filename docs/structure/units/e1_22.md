- 目錄位置：`src/kernel/e1_22/`

  - `CMakeLists.txt` — `add_library(e1_22)` + `target_link_libraries(e1_22 PUBLIC e1_21)`

    違規清單（`LintDiagnostic`{rule, rule_id, 1-based line, message}），依行號遞增彙整、不靜默。
  - NFR-02：偵測數字 z-order（`z_order/z-index = 數字`）與絕對 / 像素座標（座標欄位指派數字、

    `CapabilityMatrix::defaults()` 的 optional 能力尾段導出（單一資料來源），亦可自訂名單。
  - 相位 1 約束：無平台分支、無真實後端、無絕對座標 / 數字 z-order；掃描前剝除註解。
