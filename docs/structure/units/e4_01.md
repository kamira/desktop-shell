# 結構註記 — E4-01 文字排版與渲染

- 層級：engine（平台中立純邏輯）／子系統 render／phase 1／risk=medium／lb=15 高影響
- 目錄位置：`engine/render/e4_01/`
  - `text_layout.hpp` / `text_layout.cpp` — 文字排版引擎 + 渲染描述
  - `CMakeLists.txt` — `add_library(e4_01)` + `target_link_libraries(e4_01 PUBLIC e1_03)`
    + `test_e4_01`（`tests/e4/test_e4_01.cpp`）+ `add_test(NAME e4_01)`
- 測試：`tests/e4/test_e4_01.cpp`（gtest，26 案例）
- 相依上游（可讀不可改）：**E1-03**（經 `alpha_surface.hpp` 帶入 `ds::kernel::SurfaceId`，
  以具名 surface 指涉排版目標；僅用型別、不呼叫其函式）。
- 對外介面（`namespace ds::render`）：把文字字串排版成一組**行/字符的渲染描述**。
  - 字型抽象：`FontMetrics`（純虛：`advance(cp)` / `line_height()` / `ascent()`）+ `FixedFontMetrics`
    （相位 1 等寬固定度量）。**相位 1 不觸碰真實字型引擎**——真實 FreeType/CoreText 於相位 2
    實作同一介面即可。
  - 排版入口：`TextLayout`——`layout(text, constraints) -> LayoutResult`、`measure(text, constraints) -> Size`。
  - 約束：`LayoutConstraints`{ `max_width`（<=0/inf=無界）、`max_lines`（0=無限）、`wrap`
    (`WrapMode::None`/`Word`)、`align`(`TextAlign::Left`/`Center`/`Right`)、`line_height`（覆寫）、
    `ellipsis` + `ellipsis_char` }。
  - 渲染描述：`LayoutResult`{ `lines`(`LineBox`[])、`glyphs`(`Glyph`[])、`size`、`truncated`、
    具名 `surface` }。`Glyph`{codepoint,x,advance,line}、`LineBox`{begin,count,x,y,width,baseline,ellipsized}。
  - 工具：`decode_utf8`（嚴格 UTF-8 → 碼位；非法序列擲 `std::invalid_argument`）。
  - **NFR-02**：位置全為相對偏移（glyph.x 盒內 / line.y = 行索引×行高 / baseline = y+ascent），
    surface 以具名 `SurfaceId` 指涉；**無畫面絕對座標、無數字 z-order**（型別上即不提供）。
  - 錯誤不靜默：非法 UTF-8 / 非有限（含 NaN）約束 / 度量回非有限或負值 → 擲例外；內容超界
    （過寬 / 超過 max_lines）非錯誤，依 `ellipsis` 裁切並以 `truncated` 標記。
  - 純邏輯、平台中立：無 `#ifdef` / win32 / cocoa / FreeType / CoreText / 真實 OS 或字型 API。
