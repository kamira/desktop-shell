# 結構註記 — E11-01 系統匣圖示與右鍵選單

- 單元：E11-01（platform 層 / 宿主 host / stage A / phase 1 / Risk: low / 承重 0x）
- 目錄位置：`src/host/e11_01/`（平台中立介面 + null 後端；相位 1 無真實匣後端）
- 依賴：E6-01（`engine/command/e6_01`，命令匯流排；`target_link_libraries(e11_01 PUBLIC e6_01)`）
- 測試：`tests/e11/test_e11_01.cpp`（CTest 名 `e11_01`）

## 放了什麼
- `tray.hpp`：系統匣介面 —— `TrayMenuItem`（Action/Separator/Checkbox/Submenu 四型別 + 工廠）、
  `TrayMenu`（有序項目樹 + 鏈式 add_* + `at_path` 索引路徑定位）、`TrayBackend` 抽象
  （set_icon/set_tooltip/set_menu/show/hide）、`NullTrayBackend`（記憶體狀態 + 呼叫計數）、
  `SystemTray` 控制器（圖示/提示/選單 + 點擊經 E6-01 分派 + 勾選切換）、
  `TrayClickResult`、`make_default_tray(bus)` 工廠。
- `tray.cpp`：`SystemTray::click()`（路徑定位→分派）與 `make_default_tray()`（相位 1 回 NullTrayBackend）。
- `CMakeLists.txt`：`add_library(e11_01)` + link `e6_01` + `test_e11_01` + `add_test(NAME e11_01)`。

## 對外介面（一句話）
`ds::host::SystemTray`：以可注入 `TrayBackend`（相位 1 = `NullTrayBackend`）設定匣圖示 / 提示 /
右鍵選單，選單項點擊經注入的 `ds::command::CommandBus`（E6-01）分派、勾選項切換後帶 `checked`
參數分派；選單邏輯與平台後端解耦，相位 1 無任何真實匣 API。
