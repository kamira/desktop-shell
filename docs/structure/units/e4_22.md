# 結構註記 — E4-22 2D 變形矩陣

- 層級：engine（phase 1，平台中立純數學）／子系統 render／單元 e4_22
- 目錄位置：`engine/render/e4_22/`（根 CMakeLists 以層級 GLOB `engine/*/*/CMakeLists.txt` 自動收入）
  - `transform2d.hpp` — 介面：`Vec2`{x, y}；`TransformStatus`{Ok, Singular}；`kSingularEpsilon`；
    `InverseResult`{status, matrix, ok()}；類別 `Transform2D`（6 係數 2x3 仿射矩陣）
  - `transform2d.cpp` — 具名工廠、矩陣乘法組合、點 / 向量變換、仿射反矩陣（奇異明確回報）實作
  - `CMakeLists.txt` — `add_library(e4_22 STATIC transform2d.cpp)` +
    `target_link_libraries(e4_22 PUBLIC e1_03)` + `test_e4_22`（`tests/e4/test_e4_22.cpp`）+
    `add_test(NAME e4_22)`
- 測試：`tests/e4/test_e4_22.cpp`（gtest，24 案例）
- 上游相依（可讀不可改）：E1-03（逐像素 alpha surface / surface 幾何模型）——本變形矩陣為供
  渲染層變形 surface 幾何的數學工具，宣告於 surface 模型之上（PUBLIC 連結傳遞）。
- 對外介面（`namespace ds::render`）：2D 仿射變形矩陣工具（純數學）。
  - `Transform2D`：以 6 係數 (a,b,c,d,e,f) 存 2x3 仿射（隱含末列 [0 0 1]），座標慣例同 SVG / Canvas
    `matrix(a,b,c,d,e,f)`：(x,y)→(ax+cy+e, bx+dy+f)。
    - 具名工廠：`identity` / `translate(tx,ty)` / `rotate(rad)`（逆時針正）/ `scale(sx,sy)`（含均勻多載）/
      `shear(shx,shy)`。
    - 組合：`compose(rhs)` / `operator*`——**右運算元先套用**（`a*b` = 先 b 後 a，符合矩陣乘法慣例）。
    - 變換：`apply_point`（含平移）/ `apply_vector`（忽略平移）。
    - 反矩陣：`determinant` / `is_invertible(eps)` / `inverse(eps)`→`InverseResult`；奇異
      （|det|≤eps）**明確回 `Singular` 不靜默**。
    - 比較：`approx_equals(other, eps)`；唯讀係數存取 `a()`..`f()`。
  - phase 1 約束：純數學，無平台分支（無 `#ifdef`）、無真實繪圖 API / OS；**相對變形數學**，
    不暴露硬編絕對座標 / 數字 z-order（NFR-02 合規）；確定性——相同輸入必得相同輸出。
