# 結構註記 — E2-18 效能計數器（任意）

- 層級：module(平台無關指標提供者)／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_18/`
  - `perf_counter.hpp` / `perf_counter.cpp` — 抽象來源 + null / 假來源 + 自訂 Metric/
    Instance + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_18)` **PUBLIC 連上游 `e2_01` `e2_02`**；
    `test_e2_18`（`tests/e2/test_e2_18.cpp`）+ `add_test(NAME e2_18)`
- 測試：`tests/e2/test_e2_18.cpp`（gtest，29 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`）+ E2-02 採集頻率分級
  （`engine/metrics/e2_02`），可讀不可改——消費 `MetricProvider` / 排程契約、不自造模型。
- 對外介面（`namespace ds::sysinfo`）：一個泛用 sysinfo 指標提供者，把**任意具名效能
  計數器**（Windows PerfCounter 路徑 / macOS 統計鍵 / 任意自訂鍵）透過 **E2-01 的
  `MetricProvider`** 掛成指標 `perf.counters`，**每個計數器一個可列舉實例**。
  - `CounterMode`（Instant 瞬時 / Rate 累積差分速率）、`PerfCounterSource`（抽象來源：
    `read(key)` + `available_keys()`）、`NullPerfCounterSource`（相位 1 null / 假來源：
    以鍵→固定值 / 序列注入，查無鍵回 nullopt）。
  - `PerfCounterInstance : ds::metrics::MetricInstance` + `PerfCounterMetric :
    ds::metrics::Metric`：自訂實作以支援**執行期動態新增 / 移除實例**（E2-01 InMemory*
    不支援移除），仍嚴格實作 E2-01 抽象契約。
  - `PerfCounterProvider : ds::metrics::MetricProvider`：`add_counter` / `remove_counter`
    註冊感興趣的鍵（register 前後皆可），`register_metrics()` 掛上指標、`sample()` 重讀
    更新（Instant 原樣入歷史、Rate 兩次取樣差分；有效值才入歷史）。以 E2-02 週期分級採集
    （預設 Normal）。
  - 核心性質：相位 1（Mac/null 期）平台中立、無 `#ifdef` / win32 / cocoa / PDH / sysctl /
    真實計數器 API；查無鍵 / 無讀值誠實 invalid、不靜默；消費者只透過 E2-01 抽象介面走訪，
    新增此指標掛件一行不動。
