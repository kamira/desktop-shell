# 結構註記 — E1-05 具名碰撞區域 → 事件參數

- 層級：platform（相位 1 = Mac / null 期）／子系統 kernel／單元 e1_05
- 目錄位置：`src/kernel/e1_05/`（根 CMakeLists 以層級 GLOB `src/*/*/CMakeLists.txt` 深度 2 自動收入）
  - `named_region_map.hpp` — 介面：`RegionParamValue`（封閉型別 variant：monostate / bool /
    int64_t / double / string）、`RegionParams`（`map<string, RegionParamValue>` 具名參數
    字典）、`RegionHit`（`HitStatus status` / `bool hit` / `string name` / `RegionParams params`
    結果結構）、服務 `NamedRegionMap`（`add_region` / `remove_region` / `has_region` /
    `region_count` / `hit`）
  - `named_region_map.cpp` — 實作：`add_region` 寫入時驗證（形狀 / 空具名 / 重複具名）、
    `hit()` 逐一委派 E1-04 `HitTester::hit_test` 並依加入序覆寫、`remove_region` /
    `has_region` 具名鍵線性尋找
  - `CMakeLists.txt` — `add_library(e1_05 STATIC named_region_map.cpp)` +
    `target_link_libraries(e1_05 PUBLIC e1_04)` + `test_e1_05`（`tests/e1/test_e1_05.cpp`）
    + `add_test(NAME e1_05)`
- 測試：`tests/e1/test_e1_05.cpp`（gtest，19 案例）
- 上游相依（可讀不可改）：E1-04 `hit_test.hpp` 之 `LocalPoint`（本地 / 相對座標）/ `Shape`
  （形狀）/ `HitStatus`（結果碼）/ `HitTester`（`is_valid` / `hit_test`）。
- 對外介面（`namespace ds::kernel`）：**具名碰撞區域集合**——在單一 surface 的本地座標系內
  登記一組具名區域（形狀 + 參數），命中查詢回傳命中區域的具名 id + 參數，供呼叫端組裝事件。
  - `NamedRegionMap::add_region(name, shape, params={})`：新增具名區域；`name` 為空、形狀
    無效（E1-04 `HitTester::is_valid`）、或 `name` 已存在 → 回 `false`（拒絕新增，報錯不靜默）。
  - `NamedRegionMap::remove_region(name)`：移除具名區域；未知 `name` 回 `false`，不崩潰；
    移除後同名可重新新增。
  - `NamedRegionMap::has_region(name)` / `region_count()`：查詢狀態輔助方法。
  - `NamedRegionMap::hit(point)` → `RegionHit`：查詢點非有限值 → `status=Invalid`（報錯不
    靜默）；否則 `status=Ok`，`hit` 表示是否有任一區域命中；重疊區域依**加入序**（後加入者
    為上）決定命中者；無命中為結構化空結果（`hit=false`、`name`/`params` 皆空）。
  - 相位 1 約束：純幾何邏輯完全委派 E1-04，無真實視窗系統；無平台分支（無 `#ifdef`）、無
    真實 OS / 繪圖 API、無 `src/kernel/backend/win32|cocoa/`；座標沿用 E1-04 本地 / 相對，
    區域一律具名，重疊優先僅用加入序（無絕對座標 / 數字 z-order / 數字 index，NFR-02）；
    參數為封閉型別 variant，非任意 blob。
