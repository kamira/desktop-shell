- 單元：E6-02（engine 層 / command / Risk: low / depends_on E6-01）
- 目錄位置：`engine/command/e6_02/`（平台中立引擎邏輯，換平台一行不動）

## 放了什麼
- `action_registry.hpp`：擴充點 3「動作」查詢層 —— `MatchKind`（Exact/Prefix/Substring/Fuzzy）、
  `Match`（id/kind/score/distance/title）、`ResolveStatus`（Dispatched/NotFound/Ambiguous）、
  `DispatchOutcome`（chosen/result/candidates）、`detail::edit_distance`（Levenshtein）、
  `detail::segments`（依 `.` 切段）、`ActionRegistry`。
- `action_registry.cpp`：`action_registry_contract_version()` 契約版本標記（"e6_02/1.0.0"）；其餘 header-only inline。
- `CMakeLists.txt`：`add_library(e6_02)` + `target_link_libraries(e6_02 PUBLIC e6_01)` + `test_e6_02` + `add_test(NAME e6_02)`。

## 對外介面（一句話）
`ds::command::ActionRegistry`：`add(id,title?)` / `sync_from(bus)` 建立可查詢的命令索引；
`resolve(query)→vector<Match>` 依相關度（精確>前綴>子字串>模糊，含編輯距離容錯）回排序候選；
`dispatch_best(bus,query,args)→DispatchOutcome` 取唯一最佳候選經 E6-01 CommandBus 實際分派——
歧義回候選清單、找不到回 NotFound，皆不亂猜不靜默。
