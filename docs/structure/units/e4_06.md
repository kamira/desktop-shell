## 對外介面（一句話）
`ds::render::SurfaceSwitcher`：`register_surface(id)` / `unregister_surface(id)` / `has(id)` /
`count()` / `list()`（依註冊順序的具名清單）/ `switch_to(id)`（未知 id 回 `NotFound`）/
`has_current()` / `current()` / `on_switch(listener)`；管理一組具名 surface（如多頁面 /
多狀態畫面），依名稱定址、切換目前顯示的是哪一個，並在切換時通知監聽者——全程具名 id，
不對外暴露任何數字索引 / z-order（NFR-02）。
