# 結構註記 — E7-07 熱重載

- 層級：engine(平台中立純邏輯)；描述子系統的**熱重載生命週期**（相依已合併的 E7-01 / E7-06）。
- 目錄位置：`engine/format/e7_07/`
  - `hot_reload.hpp` / `hot_reload.cpp` — 實作
  - `CMakeLists.txt` — `add_library(e7_07)` + `target_link_libraries(e7_07 PUBLIC e7_01 e7_06)`（消費上游）
    + `test_e7_07`（`tests/e7/test_e7_07.cpp`）+ `add_test(NAME e7_07)`
- 測試：`tests/e7/test_e7_07.cpp`（gtest，13 案例）
- 對外介面（`namespace ds::format`）：宣告式格式文件的熱重載——偵測來源變更、重新解析、成功替換 /
  失敗保舊值，並以 E7-06 診斷呈現錯誤（定位到行、不靜默）。
  - `ReloadSource`（抽象注入式來源）：`content()`（目前內容）+ `revision()`（單調遞增變更令牌，即相位 1
    的變更通知；**不接真實檔案監看**，無 inotify/FSEvents/`#ifdef`）。
  - `MemorySource`：相位 1 的純記憶體具體來源；`set_content()` 僅在內容確實不同時遞增 revision。
  - `ReloadStatus{Unchanged, Loaded, Failed}` + `ReloadResult{status, has_document, diagnostics, report,
    ok(), reloaded(), unchanged()}`。
  - `ReloadCallback`（成功，帶新 `Document`）/ `ReloadErrorCallback`（失敗，帶 `Diagnostic` 向量 + E7-06 報告）。
  - `HotReloader`：`poll()`（有變更才重載）/ `reload()`（強制）/ `has_document()` / `document()` / `root()` /
    `last_diagnostics()` / `last_report()` / `on_reload()` / `on_error()`。
- 狀態機語意：載入→解析→**成功替換當前 Value / 失敗保留舊有有效值**；未變更則 no-op 不觸發回呼；
  初次即失敗則無舊值可留（`has_document()` 為 false）。失敗一律以 E7-06 `format_report` 產生診斷（不靜默）。
- 定位：消費 E7-01 的 `Document` / `parse()` / `ParseError` 與 E7-06 的 `Diagnostic` / `format_report`；
  為描述子系統補上熱重載生命週期。平台中立、無 `#ifdef`；真實檔案監看留待相位 2（只需另寫一個
  綁平台 API 的 `ReloadSource` 具體類別，狀態機不動）。
