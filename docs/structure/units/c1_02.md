# 結構註記 — C1-02 立繪 profile

- 單元：C1-02（artifact 層 / 應用 profile / Risk: low）
- 目錄位置：`content/profiles/c1_02/`
- 測試：`tests/c1/test_c1_02.cpp`（CTest 名 `c1_02`，37 個 gtest 案例）

## 放了什麼
- `portrait_profile.hpp` / `.cpp`：**組裝型**單元（非新引擎邏輯）——把六個已合併的擴充點
  組成「角色立繪 / 桌寵靜態立繪」應用 profile：
  - E1-03 `AlphaSurfaceService`：逐像素 alpha 透明外形（可選能力，`Unsupported` 降級路徑）。
  - E1-01 `LayerStack`：具名圖層歸屬（注入的共用堆疊）。
  - E1-08 `DraggableSurface`：自由拖曳狀態機 + 位置記憶（序列化為 E7-01 文字）。
  - E4-06 `SurfaceSwitcher`：具名表情 / 狀態切換（「目前顯示哪一個表情」的狀態機）；每個
    具名表情另對應一份 E4-02（經 E4-06 標頭借道傳遞）`ImageElement` 圖片渲染描述。
  - E5-14 `RegionEventDispatcher`：立繪本體 surface 上的具名子區域點擊事件。
  - E7-01 `Value`：`load_portrait(Value)` 宣告式立繪定義（圖層 / alpha / 位置 / 表情清單）。
- `CMakeLists.txt`：`add_library(c1_02)` + `target_link_libraries(c1_02 PUBLIC e1_01 e1_03
  e1_08 e4_06 e5_14 e7_01)` + `test_c1_02`（`tests/c1/test_c1_02.cpp`）+
  `add_test(NAME c1_02)`。
