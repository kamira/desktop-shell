# 結構註記 — E1-24 null 後端參考實作

- 層級：platform（相位 1 = Mac / null 期，唯一允許的後端）／子系統 kernel／後端 null
- 目錄位置：`src/kernel/backend/null/`（後端家族不拆散；`backend_guard` G1b 以 `src/kernel/backend/*`
  執行相位閘門，放行 `null/`、只擋 `win32|cocoa/`）
  - `null_backend.hpp` — kernel 後端抽象介面 `KernelBackend` + 相位 1 參考實作 `NullKernelBackend`
    + 平台中立型別（`SurfaceId`、四參數 `SurfaceProfile`、具名列舉 `SurfaceLayer` / `InputPolicy`
    / `HitPolicy` / `SurfaceLifecycle`、`InputEvent`）
  - `null_backend.cpp` — `NullKernelBackend` 全部方法定義（no-op / 記憶體狀態）
  - `CMakeLists.txt` — `add_library(backend_null STATIC null_backend.cpp)`
    + `target_link_libraries(backend_null PUBLIC e1_21)` + `test_backend_null`
    （`tests/e1/test_backend_null.cpp`）+ `add_test(NAME backend_null)`
- 測試：`tests/e1/test_backend_null.cpp`（gtest，14 案例）
- 上游相依（可讀不可改）：E1-21 能力矩陣（`CapabilityMatrix` / `CapabilityId` / `has()`）。
- 對外介面（`namespace ds::kernel`）：kernel 平台後端的抽象契約與其 null 實作。
  - `KernelBackend`(抽象基底)：後端家族共同契約。`name()`；生命週期 `init` / `shutdown` /
    `is_initialized`；能力 `capabilities` / `has`（經 E1-21）；K1 surface kernel（`create_surface`
    / `destroy_surface` / `has_surface` / `show_surface` / `hide_surface` / `is_visible` /
    `surface_profile` / `surface_count`）；K2 繪製（`begin_frame` / `end_frame`）；K3 輸入
    （`set_input_policy` / `poll_input`）。
  - `NullKernelBackend`(final)：相位 1 預設後端、E1-25 契約測試的靶、其他後端的行為基準。
    所有操作 no-op / 記憶體狀態；以 E1-21 能力矩陣回報保守能力（預設 `defaults()`，可注入）；
    未知 / 空 / 重複 id 一律結構化回 false / nullptr，絕不崩潰；記錄呼叫計數與 surface 表供
    契約斷言。真實後端（相位 2+）實作同 `KernelBackend` 即可，呼叫端不變。
  - 相位 1 約束：無平台分支（無 `#ifdef`）、無真實 OS 視窗 API（NSWindow / CreateWindowEx…）、
    無 `src/kernel/backend/win32|cocoa/`、無絕對座標 / 數字 z-order（surface 具名指涉、圖層以
    具名角色表達，NFR-02）；能力查詢一律經 `has()` 保護（NFR-03）；狀態全存記憶體。
