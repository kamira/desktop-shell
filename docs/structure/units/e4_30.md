# 結構註記 — E4-30 全螢幕調光覆蓋

- 目錄位置：`modules/elements/e4_30/`（module 層 / 子系統 elements / phase 1 / 平台中立純邏輯）。
- 內容：`dim_overlay.hpp|cpp`（`DimColor`、`DimFade`、`DimStatus`、`DimRenderModel`；`DimOverlayElement`：
  set_intensity / set_color / show / hide / fade_to / add_cutout / remove_cutout / has_cutout / layer /
  alpha_supported / render_model），`CMakeLists.txt`（`add_library(e4_30)` + `PUBLIC e1_03 e1_01`
  + `test_e4_30`，根層自動 glob 收入）。
- 對外介面：命名空間 `ds::elements`。全螢幕半透明調光 / 遮罩覆蓋元件——半透明以上游 E1-03
  `AlphaSurfaceService`（per-pixel alpha surface，intensity → 不透明度）表達，置頂以上游 E1-01
  `LayerStack` 指派到**具名頂層** `SurfaceLayer::Topmost`（NFR-02：具名圖層置頂，非數字 z-order）。
  相位 1 不做真實繪製，核心產出為 `render_model()`（宣告式渲染描述）。強度 / 顏色夾限、非有限輸入報錯
  不靜默；建立 / 改動半透明 surface 的操作經 per-pixel alpha 能力閘控（NFR-03），能力不可用回 Unsupported、
  圖層置頂被拒則回滾。
- 相依（可讀不可改）：E1-03（`src/kernel/e1_03/`）、E1-01（`src/kernel/e1_01/`）及其傳遞相依
  E1-21 能力矩陣、E1-24 null 後端。
