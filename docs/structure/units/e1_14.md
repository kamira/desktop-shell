# 結構註記 — E1-14 短暫 profile 生命週期

- 層級：platform（相位 1 = Mac / null 期）／子系統 kernel；建於 E1-02（輸入策略四態）與
  E5-10（逾時計時器）之上。
- 目錄位置：`src/kernel/e1_14/`
  - `transient_profile.hpp` — `TransientId`（具名）、`ExpiryReason`（Timeout / Manual）+
    `to_string`、`TransientProfile`（`SurfaceProfile` + E1-02 `InputStrategy`）、`ExpiryCallback`、
    管理器 `TransientProfileManager`。
  - `transient_profile.cpp` — 管理器全方法（記憶體狀態；每 profile 一個 E5-10 一次性計時器）。
  - `CMakeLists.txt` — `add_library(e1_14 STATIC transient_profile.cpp)` +
    `target_link_libraries(e1_14 PUBLIC e1_02 e5_10)` + `test_e1_14`
    （`tests/e1/test_e1_14.cpp`）+ `add_test(NAME e1_14)`。
- 測試：`tests/e1/test_e1_14.cpp`（gtest，16 案例）。
- 上游相依（可讀不可改）：E1-02 `InputStrategy` / `kDefaultStrategy` / `to_backend_policy`
  （並透傳 E1-24 `SurfaceProfile` / `SurfaceLifecycle`）；E5-10 `TimeoutTimer` / `Tick` /
  `TimerId`（注入式邏輯計時）。
- 對外介面（`namespace ds::kernel`）：短暫 profile 的生命週期管理。
  - `TransientProfileManager`（持注入式 `ds::events::TimeoutTimer&`，不擁有）：
    `create(id, profile, ttl)`（強制 Ephemeral + 登記一次性計時器）/ `advance(ticks)`（委派計時器、
    回傳逾時過期數）/ `expire(id)`（手動提早，取消計時器）/ `on_expire(cb)` / `is_alive(id)` /
    `remaining(id)` / `profile(id)` / `input_strategy(id)`（E1-02 整合入口）/ `alive_count()`。
  - 生命週期：建立 → 存活 → (逾時 / 手動) 過期 → 清理（過期即移除記錄，同名可重建）。
    無效 id / 重複過期一律明確回 false，不靜默。
  - 相位 1 約束：無平台分支（無 `#ifdef` / win32 / cocoa）、無真實 OS API、時間全走 E5-10 注入式
    tick 無 wall-clock；profile / 原因 / 策略皆具名指涉，無絕對座標 / 數字 z-order（NFR-02）。
