# 結構註記 — E11-02 自繪選單呈現

- 單元：E11-02（platform 層 / 宿主 host / stage A / phase 1 / Risk: low）
- 目錄位置：`src/host/e11_02/`（平台中立介面 + 渲染描述模型；相位 1 無真實選單 API）
- 依賴：E1-03（`src/kernel/e1_03`，具名 SurfaceId）、E4-01（`engine/render/e4_01`，文字排版）、
  E7-13（`engine/format/e7_13`，階層式項目結構）；
  `target_link_libraries(e11_02 PUBLIC e1_03 e4_01 e7_13)`
- 測試：`tests/e11/test_e11_02.cpp`（CTest 名 `e11_02`，39 個 gtest 案例）

## 放了什麼
- `menu_renderer.hpp` / `.cpp`：
  - `MenuNodeKind`（Action/Separator/Checkbox/Submenu）+ `menu_item_keys`（Item::value() 的
    宣告式選單語意保留鍵：kind/checked/enabled）。
  - `MenuNode` / `MenuModel`：由 E7-13 Item 轉譯而成的選單樹（值語意），`at_path` 索引路徑定位。
  - `build_menu(forest|root)` + `MenuBuildResult`/`MenuBuildError`：宣告式建構，錯誤可定位不靜默。
  - `MenuRowRender` / `MenuPanelRender` / `MenuRenderModel`：全相對佈局的渲染描述（NFR-02）——
    面板以具名 SurfaceId（子面板尾碼取自擁有者子選單項的具名 id，非數字深度）指涉。
  - `CustomMenuRenderer`：綁定 E4-01 FontMetrics + 根面板 SurfaceId；`set_menu()` 建模、
    `move_next/move_prev/enter/exit/activate`（鍵盤）、`hover/select`（滑鼠）巡覽，
    `render_model()` 產出目前展開鏈的完整渲染描述。
- `CMakeLists.txt`：`add_library(e11_02)` + link `e1_03 e4_01 e7_13` + `test_e11_02` + `add_test`。

## 對外介面（一句話）
`ds::host::CustomMenuRenderer`：從 E7-13 Item 森林建自繪選單樹、以 E4-01 排版每列標籤、以
E1-03 具名 SurfaceId 表達展開面板，支援子選單 / 分隔線 / 勾選 / 停用態與鍵盤 / 滑鼠巡覽，
`render_model()` 回傳全相對佈局的渲染描述供後續相位的繪製層消費；相位 1 不含任何真實選單 API。
