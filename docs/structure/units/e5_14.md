# 結構註記 — E5-14 碰撞區域名事件參數

- 層級：engine（平台中立純邏輯，橋接上游 E5-01 + E1-05）
- 目錄位置：`engine/events/e5_14/`
  - `region_event_dispatcher.hpp` / `region_event_dispatcher.cpp` — 實作
  - `CMakeLists.txt` — `add_library(e5_14)`（`PUBLIC` 連上游 `e5_01` + `e1_05`）+
    `test_e5_14`（`tests/e5/test_e5_14.cpp`）+ `add_test(NAME e5_14)`
- 測試：`tests/e5/test_e5_14.cpp`（gtest，16 案例）
- 對外介面（`namespace ds::events`）：`RegionEventDispatcher` —— 橋接 E5-01
  `MouseEventRouter`（滑鼠事件注入 / 命中路由）與 E1-05 `NamedRegionMap`（具名子區域查詢）：
  `set_surfaces()` 轉呼 E5-01 設定參與命中測試的具名 surface；`set_regions(surface, regions)` /
  `has_regions()` / `remove_regions()` 為指定具名 surface 登記（或取代 / 移除）其 E1-05
  `NamedRegionMap` 子區域集合；`subscribe()` / `unsubscribe()` / `listener_count()` 訂閱橋接後
  的 `RegionEvent`；`inject_button()` / `inject_down()` / `inject_up()` / `inject_click()` 轉呼
  內部 `MouseEventRouter` 注入。事件命中具名 surface 後，若該 surface 有登記子區域集合，
  即以事件本地座標查詢子區域，把命中之具名 id + 參數併入 `RegionEvent`
  （`region_hit`/`region_name`/`region_params`）分派；未登記子區域 / 未命中子區域仍正常派發
  （`region_hit=false`，其餘欄位空）。命中判定 / 多擊追蹤 / 子區域查詢完全委派上游既有實作，
  本單元只新增「surface → 子區域集合」對照與事件組裝橋接邏輯。
