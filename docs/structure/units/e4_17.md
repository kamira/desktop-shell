# 結構註記 — E4-17 直方圖

- 目錄位置：`modules/elements/e4_17/`（module 層 / 子系統 elements / phase 1 / 平台中立純邏輯）。
- 內容：`histogram.hpp|cpp`（`HistogramElement`：累積樣本、y 軸縮放、滾動視窗保留最新 N、
  可選閾值線、合成描述；`HistogramRenderModel` / `HistogramBar` / `HistogramThreshold` /
  `HistogramRange` / `HistogramStatus`；宣告式設定 `configure` / `configure_from_document`），
  `CMakeLists.txt`（`add_library(e4_17)` PUBLIC 連 `e1_03`、`e7_03` + `test_e4_17`，根層自動 glob 收入）。
- 對外介面：命名空間 `ds::elements`；把一序列數值映射成直方圖 / 時序長條的**渲染描述模型**——
  每個樣本 → 一根正規化長條（magnitude ∈ [0,1] + 清單時間序，NFR-02 無絕對座標 / 無數字 z-order），
  相位 1 不做真實繪製。設定可由 E7-03 宣告式段落變數驅動；合成不透明度沿用 E1-03 `AlphaProfile`。
- 依賴：E1-03（`AlphaProfile` / `AlphaMode` 合成描述）、E7-03（段落變數 `expand()` 設定驅動）。
- 測試：`tests/e4/test_e4_17.cpp`（19 個 gtest 案例，`add_test(NAME e4_17)`）。
