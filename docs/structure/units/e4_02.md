# 結構註記 — E4-02 圖片元件

- 目錄位置：`modules/elements/e4_02/`（module 層 / 子系統 elements / phase 1 / risk=medium /
  平台中立純邏輯）。
- 內容：`image_element.hpp|cpp`（`ImageSource` 抽象介面 + `MemoryImageSource`（固定假資料）/
  `NullImageSource`（恆無效）；`ScaleMode{Fill,Fit,Stretch,Center,Tile}`；`ImageDimensions`；
  `CropRect`（正規化 [0,1] + `full()`）；`ImageElement`：`set_source/clear_source`、
  `set_scale_mode`、`set_crop/clear_crop`、`set_opacity`、`set_target/clear_target`，
  `render_model()` 產出 `ImageRenderModel`），`CMakeLists.txt`（`add_library(e4_02)` PUBLIC 連
  `e1_03` + `test_e4_02`，根層自動 glob 收入）。
- 對外介面：命名空間 `ds::elements`；圖片顯示元件——以**可注入的 `ImageSource`**（相位 1 不解碼
  PNG/JPEG，只提供固有尺寸 + 具名參照）載入圖片，選擇縮放模式(fill/fit/stretch/center/tile)、
  正規化裁切、整體透明度，`render_model()` 產出圖片渲染描述（來源參照 + 固有尺寸 + 縮放模式 +
  裁切 + 透明度 + 目標具名 surface）。相位 1 不做真實影像解碼 / 繪製。
- NFR-02（無絕對座標 / 無數字 z-order）：目標以具名 `ds::kernel::SurfaceId` 指涉（非數字
  handle）；裁切為正規化比例 [0,1]（非螢幕像素）；縮放為具名列舉；透明度為比例；本單元不提供
  任何 (x,y) 螢幕位置或疊放層級欄位。
- 不靜默：無效來源（`valid()==false`）、尺寸為零 / 負、越界 / 退化 / 非有限裁切、空目標名、
  非有限不透明度一律回 `ImageStatus::Invalid`，不套用、不靜默改值（且不部分套用）。
- 依賴：E1-03（`AlphaProfile` 透明度合成描述；並透過其標頭傳遞 `ds::kernel::SurfaceId`）。
- 測試：`tests/e4/test_e4_02.cpp`（32 個 gtest 案例，`add_test(NAME e4_02)`）。
