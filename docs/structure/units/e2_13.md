# 結構註記 — E2-13 媒體播放中繼資料

- 層級：module(平台無關指標提供者)／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_13/`
  - `media_metadata.hpp` / `media_metadata.cpp` — 介面 + null 來源 + 欄位模型 + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_13)` **PUBLIC 連上游 `e2_01` `e2_02`**；`test_e2_13`
    (`tests/e2/test_e2_13.cpp`) + `add_test(NAME e2_13)`
- 測試：`tests/e2/test_e2_13.cpp`（gtest，21 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`）＋ E2-02 採集頻率分級
  （`engine/metrics/e2_02`），皆可讀不可改——消費 `MetricProvider` 契約與 `SamplingTier`
  分級，不自造指標模型或排程器。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「目前媒體播放狀態的
  中繼資料」（曲名/演出者/專輯/播放狀態/進度/總長/封面參照）透過 **E2-01 的
  `MetricProvider`** 掛成指標 `media.nowplaying`，並以 **E2-02 的頻率分級**決定輪詢節奏。
  - `PlaybackState`（Stopped/Paused/Playing；`state_rank` / `to_string` 輔助）。
  - `MediaMetadata`（欄位模型：has_media/state/title/artist/album/position_seconds/
    duration_seconds/artwork_ref；`none()` = 無播放；含相等運算子）。
  - `MediaSource`（抽象來源 `snapshot()`）、`NullMediaSource`（相位 1 null/假來源：
    不接真實系統媒體 API，回注入的固定中繼資料或「無播放」；set_metadata/set_state/
    set_position/clear 注入 API）。
  - `MediaMetadataProvider : ds::metrics::MetricProvider`：`register_metrics()` 把七個
    中繼資料欄位各建成一個 `MetricInstance`（決定性列舉；進度欄位保留歷史環、其餘
    capacity=0）；`sample()` 重新查詢來源並更新各實例（進度推入歷史）；`sampling_tier()`
    回建議的 E2-02 採集分級（預設 Normal），供呼叫端 `SamplingScheduler::add_demand`。
  - 核心性質：相位 1（Mac/null 期）平台中立、無 `#ifdef` / win32 / cocoa /
    MediaRemote 等真實媒體 API；「無播放」時非狀態欄位以 valid==false（未知）誠實表達；
    消費者只透過 E2-01 抽象介面走訪，新增此指標掛件一行不動。
