# 結構註記 — E5-02 懸停進出事件

- 單元：E5-02（懸停進出事件，engine 層 / 事件 / low，depends_on=[E1-04]）
- 目錄位置：`engine/events/e5_02/`（平台中立純邏輯，非全域事件；換平台一行不動）
- 放了什麼：
  - `hover_tracker.hpp` / `.cpp`：`HoverEventKind` enum（Enter/Leave/Move）、
    `HoverEvent{ kind, surface, point }`、`HoverListener`、`SubscriptionId`，以及
    `HoverTracker`（add_surface / remove_surface / inject_move / subscribe /
    unsubscribe / current_hover）。命中判定委由上游 E1-04 `HitTester::topmost_hit`，
    型別直接沿用 E1-04 的 `LocalPoint` / `SurfaceId` / `HitSurface`。
  - `CMakeLists.txt`：`add_library(e5_02)` + `target_link_libraries(e5_02 PUBLIC e1_04)` +
    `test_e5_02` + `add_test(NAME e5_02)`。
- 對外介面一句話：注入式滑鼠移動 + E1-04 幾何命中判定，依懸停狀態轉換分派
  Enter / Leave / Move 事件，並提供當前懸停 surface 查詢。
- 測試：`tests/e5/test_e5_02.cpp`（14 個 gtest）。
