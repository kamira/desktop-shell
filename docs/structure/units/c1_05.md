## 放了什麼
- `summon_panel_profile.hpp` / `.cpp`：**組裝型**單元（非新引擎邏輯）——把四個已合併的
  擴充點組成「召喚面板」（summon panel / command palette / spotlight）應用 profile：
  - E1-14 `TransientProfileManager`：面板短暫生命週期（叫出→用完消失、逾時自動收起）。
  - E1-02 `InputStrategy`：面板參與輸入的方式（獨占 Capture / 穿透 ClickThrough 等）。
  - E7-13 `Item` / `build_forest`：面板內階層式選項清單（可宣告式建構）。
  - E5-05 `GlobalHotkeys`：事件驅動的召喚入口（熱鍵觸發自動叫出）。
- `CMakeLists.txt`：`add_library(c1_05)` + `target_link_libraries(c1_05 PUBLIC e1_02 e1_14
  e5_05 e7_13)` + `test_c1_05`（`tests/c1/test_c1_05.cpp`）+ `add_test(NAME c1_05)`。
