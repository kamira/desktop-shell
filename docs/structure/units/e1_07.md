# 結構註記 — E1-07 anchor 定位模型

- 層級：platform（相位 1 = Mac / null 期）／子系統 kernel／單元 e1_07
- 目錄位置：`src/kernel/e1_07/`（根 CMakeLists 以層級 GLOB `src/*/*/CMakeLists.txt` 深度 2 自動收入）
  - `anchor_model.hpp` — 介面：`Anchor`（九宮具名錨點 TopLeft…BottomRight）、`Spacing`（具名間距
    None…Spacious）、`Offset`{dx, dy 為容器尺寸正規化分數}、`AnchorSpec`{anchor, offset}、
    `Size`{width, height}、`ResolvedPlacement`{x, y, width, height}、`AnchorStatus`{Ok, Invalid}；
    自由函式 `is_valid_anchor` / `anchor_fraction` / `spacing_fraction` / `Offset::from_spacing` /
    `inset_from` / `is_finite_size` / `resolve` / `resolve_point`；服務 `AnchorLayout`
  - `anchor_model.cpp` — 純佈局計算 + `AnchorLayout` 記憶體實作
  - `CMakeLists.txt` — `add_library(e1_07 STATIC anchor_model.cpp)` +
    `target_link_libraries(e1_07 PUBLIC e1_03)` + `test_e1_07`（`tests/e1/test_e1_07.cpp`）+
    `add_test(NAME e1_07)`
- 測試：`tests/e1/test_e1_07.cpp`（gtest，23 案例）
- 上游相依（可讀不可改）：E1-03（`PUBLIC` 連結）→ 傳遞取得 E1-24 具名 `SurfaceId` 模型，
  供 `AnchorLayout` 以具名鍵配對定位規格。
- 對外介面（`namespace ds::kernel`）：以**具名錨點 + 相對偏移**表達元件 / surface 定位、
  取代絕對像素座標的**宣告式定位模型**（NFR-02 正解）。
  - 核心宣告式型別（`Anchor` / `AnchorSpec` / `Offset` / `Spacing`）**不含任何絕對像素座標**；
    位置以九宮具名錨點 + 容器尺寸正規化偏移（比例）或具名間距表達。
  - `resolve(spec, container, element, out)`：純佈局計算，把宣告式規格在給定容器 / 元件尺寸下
    解析為具體 `ResolvedPlacement`（`x = fx*(cw-ew) + dx*cw`）。角 / 邊錨點→邊緣對齊、置中→置中；
    具體像素只在此計算邊界出現（由呼叫端提供的尺寸推導）。`resolve_point`：元件視為零尺寸點。
  - `AnchorLayout`：以具名 `SurfaceId` 為鍵維護每 surface 的 `AnchorSpec`，`place` / `remove` /
    `resolve_for`；風格對齊 E1-03 `AlphaSurfaceService` 的記錄配對（純記憶體、純佈局）。
  - 錯誤：越界 anchor（int static_cast）/ 非有限 offset / 非有限或負尺寸 / 空 / 未知 SurfaceId →
    `AnchorStatus::Invalid` 且不寫 out（不靜默、不崩潰）。
  - 相位 1 約束：無平台分支（無 `#ifdef`）、無真實 OS / 視窗 / 繪圖 API、
    無 `src/kernel/backend/win32|cocoa/`；純平台中立佈局邏輯。
