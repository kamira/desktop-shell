# 結構註記 — C4-04 視窗總覽

- 單元：C4-04（artifact 層 / apps / 組裝型 / Risk: low）
- 目錄位置：`apps/c4_04/`
- 測試：`tests/c4/test_c4_04.cpp`（CTest 名 `c4_04`，30 個 gtest 案例）

## 放了什麼
- `window_overview.hpp` / `.cpp`：**組裝型**單元（非新引擎邏輯）——把兩個已合併的擴充點/
  元件組成「視窗總覽」（Exposé 式視窗縮圖總覽）應用 + 行為：
  - C1-05 `SummonPanelProfile`：總覽面板本身的基底 profile，借用其開啟 / 收起短暫生命週期
    （`show_overview()` / `close_overview()` 委派 `open()` / `close()`）。
  - E4-02 `ImageElement`：每個視窗一個縮圖渲染描述（佔位圖像參照，無真實截圖）。
- `CMakeLists.txt`：`add_library(c4_04)` + `target_link_libraries(c4_04 PUBLIC c1_05 e4_02)`
  + `test_c4_04`（`tests/c4/test_c4_04.cpp`）+ `add_test(NAME c4_04)`。

## 對外介面（一句話）
`ds::apps::WindowOverviewApp`：`load_windows(vector<WindowSpec>) -> LoadStatus`（載入視窗清單
+ 建 E4-02 縮圖 + 重新平鋪）/ `show_overview(ttl)` `close_overview()`（委派 C1-05 生命週期）/
`select(window_id) -> SelectStatus`（反白選取，不收起總覽）/
`activate(window_id, out) -> ActivateStatus`（切換視窗並收起總覽）/
`close_window(window_id) -> bool`（自清單移除該視窗並重新平鋪）。相位 1：純資料模型 + 注入式
視窗來源，無真實視窗列舉；無平台分支（無 `#ifdef` / win32 / cocoa）；平鋪版位以具名區域字串
+ 正規化比例 `[0,1]` 表達，無絕對座標 / 數字 z-order（NFR-02）。
