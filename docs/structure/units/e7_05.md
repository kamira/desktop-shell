# 結構註記 — E7-05 公式運算引擎

- 層級：engine(平台中立純邏輯)；描述子系統的**公式 / 運算式求值層**（相依已合併的 E7-02，傳遞取得 E7-01）。
- 目錄位置：`engine/format/e7_05/`
  - `formula.hpp` / `formula.cpp` — 實作
  - `CMakeLists.txt` — `add_library(e7_05)` + `target_link_libraries(e7_05 PUBLIC e7_02)`（消費上游）
    + `test_e7_05`（`tests/e7/test_e7_05.cpp`）+ `add_test(NAME e7_05)`
- 測試：`tests/e7/test_e7_05.cpp`（gtest，41 案例）
- 對外介面（`namespace ds::format`）：宣告式格式值中的公式 / 運算式求值。
  - `EvalError{position, message}`（0-based 欄位置，指向肇因 token）；`EvalResult`
    （成功持 `Value` / 失敗持 `EvalError`，對齊 E7-01 `ParseResult` 二選一風格）。
  - `Evaluator`：可選綁定 E7-02 的 `VariableScope`（不取得所有權）；`evaluate(expr)` 可重入。
  - 便捷入口 `evaluate(expr, scope)` / `evaluate(expr)`。
  - `is_formula` / `formula_body`：辨識並去除公式標記（前導 `=` 或 `${ ... }` 包裹）。
  - 語法：數值字面量（整數 / 浮點 / 指數）、四則 `+ - * /` + 取模 `%` + 括號、一元 `+ - !`、
    比較 `< <= > >= == !=`、邏輯 `&& ||`；變數引用自 `VariableScope`（含父鏈上溯）。
  - 型別規則：整數運算保留整數、含浮點轉浮點；`/` 整除得整數否則浮點。
  - **除零 / 對零取模 / 語法錯誤 / 未定義變數 / 型別誤用一律明確回報（帶位置）、不靜默**（NFR-04 精神）。
- 定位：消費 E7-02 的 `VariableScope` 與 E7-01 的 `Value`，為宣告式格式提供可運算、可組合的值層；
  設定 / profile / 版面可以既有值推導新值（如 `= base + 8`、`= count > 0`）。平台中立、無 `#ifdef`。
