# 結構註記 — E3-01 外部命令執行

- 單元：E3-01（modules 層 / actuators / Risk: low）
- 目錄位置：`modules/actuators/e3_01/`（透過 E6-01 契約掛命令，相位 1 無真實後端）
- 測試：`tests/e3/test_e3_01.cpp`（CTest 名 `e3_01`）
- 相依：E6-01 命令匯流排（`target_link_libraries(e3_01 PUBLIC e6_01)`）——具名命令掛匯流排、參數重用穩定值型別。

## 放了什麼
- `command_actuator.hpp`：致動器契約 —— `CommandSpec`（平台中立請求：program/arguments/
  working_directory/environment）、`EnvVar`、`RunResult`（exit_code/stdout/stderr）、
  `CommandRunner`（純虛執行器：`run(spec)->RunResult`）、`NullCommandRunner`（相位 1：
  不觸碰 OS，只記錄請求並回可注入結果 / 預設 no-op 成功）、`CommandActuator`（掛命令 + 處理器）、
  命令 id 常數（`command.run`）。
- `command_actuator.cpp`：`command_actuator_contract_version()` 契約版本標記（"e3_01/1.0.0"）；
  其餘邏輯 header-only inline。
- `CMakeLists.txt`：`add_library(e3_01)` + `PUBLIC e6_01` + `test_e3_01` + `add_test(NAME e3_01)`。

## 對外介面（一句話）
`ds::actuators::CommandActuator::register_on(CommandBus&)` 把 `command.run` 具名命令掛上 E6-01
匯流排；呼叫端以 `bus.dispatch("command.run", args)` 觸發（參數：program 必填、args/cwd/env 選用），
相位 1 交 `NullCommandRunner`（可注入 `RunResult`）記錄請求並回報，exit_code 0 → `CommandResult{Ok}`、
非零 → `Failed`，必填缺漏回 `Failed` 不崩潰；相位 2 換真實執行器（實作 `CommandRunner::run` 真的
spawn 行程）時介面與命令契約不動——**相位 1 絕不 spawn / exec / fork / system**。
