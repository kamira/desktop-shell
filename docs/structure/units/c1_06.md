# 結構註記 — C1-06 Dock profile

- 單元：C1-06（artifact 層 / 應用 profile / Risk: low）
- 目錄位置：`content/profiles/c1_06/`
- 測試：`tests/c1/test_c1_06.cpp`（CTest 名 `c1_06`，27 個 gtest 案例）

## 放了什麼
- `dock_profile.hpp` / `.cpp`：**組裝型**單元（非新引擎邏輯）——把三個已合併的擴充點
  組成「Dock」（程式塢 / 工作列）應用 profile：
  - E1-16（經 `dock_hot_zone_bridge` 橋接）：dock 固定邊緣的觸發熱區（`dock_to_edge` 註冊 /
    `probe_hot_zone` 探測命中）。
  - E1-01 `LayerStack`：dock 於堆疊上的頂層指派（`SurfaceLayer::Topmost`）。
  - E1-02 `InputStrategy`：dock 表面輸入策略（`backend_input_policy()` / `hit_result()`
    透傳驗證組裝正確）。
  - 行為：`dock_to_edge` / `undock` / `set_auto_hide` / `reveal` / `hide` / `probe_hot_zone` /
    `add_item`。
- `dock_hot_zone_bridge.hpp` / `.cpp`：內部橋接層，把 E1-16 `EdgeHotZoneRegistry` 包在
  不外洩 E1-04 型別的介面之後（pimpl）。**理由（已知上游命名碰撞，記錄備查）**：E1-02
  `input_strategy.hpp` 宣告 `enum class ds::kernel::HitResult`；E1-16 `edge_hot_zone.hpp`
  transitively include E1-04 `hit_test.hpp`，宣告**另一個不同型別**的
  `struct ds::kernel::HitResult`。兩者標頭同時出現於同一翻譯單元會編譯失敗（已於本機以
  g++ 實測重現：`use of 'HitResult' with tag type that does not match previous
  declaration`）。此橋接層的 `.cpp`（且僅有它）`#include "edge_hot_zone.hpp"`，藉此把兩個
  上游 include 樹隔離到不同翻譯單元，`dock_profile.hpp` 因此可安全地同時使用 E1-02 與
  E1-16。此為上游既有碰撞，非本單元 write_scope 可修復（不可改 e1_02 / e1_16 / e1_04）。
- `dock_types.hpp`：`DockEdge` / `DockPoint` / `DockScreenExtent` / `DockHotZoneStatus` /
  `DockTriggeredZone`——橋接層使用的中立值型別（鏡射 E1-16 對應型別，一一轉換）。
- `CMakeLists.txt`：`add_library(c1_06 dock_profile.cpp dock_hot_zone_bridge.cpp)` +
  `target_link_libraries(c1_06 PUBLIC e1_01 e1_02 e1_16)` + `test_c1_06`
  （`tests/c1/test_c1_06.cpp`）+ `add_test(NAME c1_06)`。

## 對外介面（一句話）
`ds::profiles::DockProfile`：`dock_to_edge(DockEdge, thickness_ratio)` 固定邊緣（組裝
E1-16 + E1-01）/ `undock()` / `set_auto_hide(bool)` `reveal()` `hide()` 可見性行為 /
`probe_hot_zone(DockPoint, DockScreenExtent)` 熱區叫出探測 / `add_item(id, label)` 固定
項目 / `backend_input_policy()` `hit_result()` 驗證 E1-02 組裝 / `on_reveal` `on_hide`
`on_item_added` 事件掛勾。相位 1：純資料 / 邏輯組裝，無真實 GUI、無平台分支（無 `#ifdef` /
win32 / cocoa）、無絕對座標 / 數字 z-order（NFR-02）。
