# 結構註記 — E8-05 外部模組開發介面（SDK）

- 單元：E8-05（engine 層 / 子系統 script / 擴充點 5「腳本 / 模組」的**開發面** / Risk: low）
- 目錄位置：`engine/script/e8_05/`（平台中立引擎邏輯，換平台一行不動）
- 測試：`tests/e8/test_e8_05.cpp`（CTest 名 `e8_05`，18 個 gtest）
- 相依：E8-04 行程內模組載入（`target_link_libraries(e8_05 PUBLIC e8_04)`）——建於其載入機制之上，
  並經其 PUBLIC 傳遞 E9-02 `ds::package` manifest 型別。

## 放了什麼
- `module_sdk.hpp`：SDK 契約核心 —— `IModule`（第三方要實作的抽象介面，生命週期
  init/start/stop/teardown + `info()` metadata 宣告）、`ModuleBase`（選用便利基底，實作生命週期
  狀態機與合法轉移防護，開發者只覆寫 `on_*` 鉤子）、`ModuleInfo`（metadata / 能力需求宣告，
  `to_manifest()` 橋接 E9-02）、`ModuleState`、`IHostService` / `HostServiceRegistry`（宿主服務登記處）、
  `ModuleContext`（SDK 面：`has_service`/`service<T>` 存取宿主服務 + 委派 E8-04 能力註冊；宿主服務
  存取一律以 `has()` 閘控，NFR-03）、`make_module`（把 `IModule` 轉接成 E8-04 `ds::ext::Module`）。
- `sample_module.hpp`：範例模組 `SampleSensorModule` + 示範宿主服務 `IClockService`/`FixedClock`，
  以最小具體實作驗證契約可用（宣告 requires、以 has() 閘控取宿主服務、登記感測器能力）。
- `module_sdk.cpp`：`contract_version()`（"e8_05/1.0.0"）、`to_string(ModuleState)`、`make_module`。
- `CMakeLists.txt`：`add_library(e8_05)` + `PUBLIC e8_04` + `test_e8_05` + `add_test(NAME e8_05)`。

## 對外介面（一句話）
`ds::ext::sdk`（與 E8-04 `ds::ext` 一致前綴，巢狀 `sdk` 子命名空間避免與 E8-04 既有
`ds::ext::ModuleContext` 衝突）提供第三方模組穩定開發介面：實作 `IModule`（或繼承 `ModuleBase`）宣告
metadata 與生命週期，經 `make_module(mod, host_services)` 交由 E8-04 `ds::ext::ModuleLoader` 載入，
載入器即驅動 init→start，卸載時 stop→teardown；模組於生命週期中透過 `ModuleContext` 以 `has()` 閘控
存取宿主服務並登記提供的能力。
