# 結構註記 — E4-11 逐字顯示

- 目錄位置：`modules/elements/e4_11/`（module 層 / elements 子系統 / 平台無關純邏輯）。
- 內容：`typewriter_element.hpp|cpp`（`TypewriterElement`：持有 UTF-8 文字與以碼位計數的
  「已顯示進度」；`set_text`/`set_speed`/`speed()` 設定；`advance(dt)` 以注入式 tick 累計
  進度；`attach(AnimationDriver&)` 綁 E4-09 動畫驅動源自動推進；`visible_count()`/
  `total_count()`/`is_complete()`/`reset()` 查詢與控制；`render_model()` 對已顯示前綴子字串
  委派 E4-01 `TextLayout::layout()` 排版，回傳相對佈局 `LayoutResult`）、`CMakeLists.txt`
  （`add_library(e4_11)` + `target_link_libraries(e4_11 PUBLIC e4_01 e4_09)` + `test_e4_11`，
  根層自動 glob 收入）。
- 相依：上游 E4-01 文字排版（`engine/render/e4_01/`，可讀不可改；提供排版引擎與 UTF-8
  解碼）、上游 E4-09 動畫驅動源（`engine/render/e4_09/`，可讀不可改；提供時間推進來源）。
- 對外介面：命名空間 `ds::elements`；由呼叫端注入邏輯時間（手動 `advance` 或 `attach` 到
  E4-09 `AnimationDriver`）推進「目前顯示到第 N 字」，以 `render_model()` 取得可繪製的相對
  佈局渲染描述（NFR-02：無絕對座標 / 數字 z-order）；不綁真實時鐘 / 計時器 / 繪製後端。
- 測試：`tests/e4/test_e4_11.cpp`（14 個 gtest 案例，`add_test(NAME e4_11)`）。
