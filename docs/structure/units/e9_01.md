# 結構註記 — E9-01 統一套件格式定義

- 目錄位置：`engine/package/e9_01/`（engine 層 / package 子系統）。
- 放了什麼：
  - `package.hpp` / `package.cpp` — 一個組件套件的整體結構定義：`Package`（`Manifest` +
    `PackageEntry` 內含項目清單）、`parse_package`（解析即驗證）、`validate_package`
    （記憶體內結構完整性驗證）、`is_valid_logical_path`（套件內相對路徑合法性）。
  - `CMakeLists.txt` — `add_library(e9_01 STATIC package.cpp)`，`target_link_libraries(e9_01 PUBLIC e9_02)`
    （複用 E9-02 manifest）；契約測試 `tests/e9/test_e9_01.cpp` 註冊為 CTest `e9_01`。
- 對外介面一句話：把「manifest（E9-02）+ 資源檔佈局 + 內容清單」統一成 `Package`，並提供
  平台中立、錯誤可定位的解析與結構完整性驗證。
- 平台中立：無 `#ifdef`、無系統呼叫、無平台分支；換平台一行不動。
