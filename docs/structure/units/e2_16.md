# 結構註記 — E2-16 已安裝應用列舉

- 層級：module（平台無關指標提供者）／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_16/`
  - `installed_apps.hpp` / `installed_apps.cpp` — 介面 + null 後端 + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_16)` **PUBLIC 連上游 `e2_01`**；`test_e2_16`
    （`tests/e2/test_e2_16.cpp`）+ `add_test(NAME e2_16)`
- 測試：`tests/e2/test_e2_16.cpp`（gtest，14 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`，可讀不可改）——消費 `MetricProvider`
  契約、不自造指標模型。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「已安裝應用清單／數量」
  透過 **E2-01 的 `MetricProvider`** 掛成指標 `apps.installed`。
  - `InstalledApp`（id/name/version）、`InstalledAppSource`（抽象後端 `enumerate()`）、
    `NullInstalledAppSource`（相位 1 null 後端：不掃描系統，回空清單或注入的假資料）。
  - `InstalledAppsProvider : ds::metrics::MetricProvider`：`register_metrics()` 把每個
    已安裝應用建成一個 `MetricInstance`（清單=列舉實例、數量=`instance_count()`）。
  - 核心性質：相位 1（Mac/null 期）平台中立、無 `#ifdef` / win32 / cocoa / 真實 OS 掃描；
    消費者只透過 E2-01 抽象介面走訪，新增此指標掛件一行不動。
