# 結構註記 — E9-08 圖形安裝器

- 目錄位置：`engine/package/e9_08/`（engine 層 / package 子系統）。
- 放了什麼：
  - `install_wizard.hpp` / `install_wizard.cpp` — 把 E9-07 的安裝生命週期包裝成適合 UI 呈現的
    **多步驟安裝精靈狀態機**（非真實 GUI）：
    - `WizardStep`（Welcome / License / Options / Progress / Complete）+ `StepState`（Upcoming /
      Active / Done）+ `WizardOutcome`（InProgress / Installed / Failed / Cancelled）。
    - `InstallOptions`（安裝路徑 / 元件勾選，純資料）、`StepTransition`（導覽結果，失敗帶原因）、
      `WizardProgress` / `WizardProgressListener`（進度回報）。
    - `InstallWizard`：`steps()` / `current_step()` / `step_state()`、`next()` / `back()` / `cancel()`
      導覽、授權閘門（`accept_license()`）、`begin_install(source, options)` 於「進度」步驟**委派**
      E9-07 `DropInstaller::handle_drop`，成功→Complete、失敗→停於 Progress（可退回重試）。
  - `CMakeLists.txt` — `add_library(e9_08 STATIC install_wizard.cpp)`，
    `target_link_libraries(e9_08 PUBLIC e9_07)`；契約測試 `tests/e9/test_e9_08.cpp` 註冊為 CTest `e9_08`。
- 對外介面一句話：把 E9-07 安裝生命週期包裝為多步驟精靈的資料模型 / 狀態機，供 UI 呈現與驅動；
  平台中立、錯誤 / 取消明確回報不靜默。
- 與 E9-07 的關係：`InstallWizard` 建構時注入一個 E9-07 `DropInstaller`；`begin_install` 以使用者選項
  組成 `DropEvent`（選項摘要放入 `DropEvent.detail`）並實際委派 `handle_drop`，期間掛上 E9-07
  `InstallLifecycleListener` 將每個 `InstallStage` 映射為精靈進度百分比（真連結，非空連結）。
- 平台中立：無 `#ifdef`、無 `win32`/`cocoa`、無真實 GUI、無真實檔案 I/O；相位 2 換真實 UI 一行不動。
