# 結構註記 — E9-09 動態配色生成

- **目錄位置**：`engine/package/e9_09/`（layer=engine，stage=D）。
- **放了什麼**：
  - `palette.hpp` / `palette.cpp` — 動態配色 API：平台中立色彩型別 `RgbColor` / `HslColor`、方案列舉 `ColorScheme{Complementary, Analogous, Triadic, Monochromatic}`、結果型別 `ColorPalette` / `PaletteResult`；色彩工具自由函式（`is_valid_color`、`rgb_to_hsl`、`hsl_to_rgb`、`to_hex`、`from_hex`、`relative_luminance`、`contrast_ratio`、`lightness_scale`）；以及 `PaletteGenerator` 類別（`generate(seed, scheme)`、`generate_from_hex`、`to_theme_data(palette, name)` 橋接 E9-04）。
  - `CMakeLists.txt` — `add_library(e9_09)`，`target_link_libraries(e9_09 PUBLIC e9_04)`；註冊 `test_e9_09`。
- **對外介面（一句話）**：從一個種子顏色依色相環關係（互補/類比/三分/單色）動態生成一整套協調配色（主/次/強調/背景/前景/成功/警告/錯誤/資訊），以 WCAG 對比度保證前景可讀，決定性且無效種子色明確報錯；`to_theme_data()` 把配色轉為 E9-04 的 `ThemeData`（各色角色 → hex 字串的宣告式 `Value` Map）直接餵入 `ThemeManager`。
- **相依**：上游 E9-04（`engine/package/e9_04/`，主題切換 / `ThemeData`；經其再傳遞 E9-03/E7-07 → E9-01/E9-02/E7-01）。命名空間 `ds::package`，與 E9-01~E9-04 一致。
- **平台中立**：純邏輯 / 純計算，無任何 `#ifdef` / 平台分支 / 真實繪圖 API；顏色以 RGB/HSL 數值或 hex 字串表示，不綁圖形框架型別；API 面不出現絕對座標與數字 z-order（NFR-02）。
- **測試**：`tests/e9/test_e9_09.cpp`（gtest，20 個案例）。
