# 結構註記 — E2-26 RSS / 標題抓取

- 層級：module（平台無關指標提供者）／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_26/`
  - `feed_fetch.hpp` / `feed_fetch.cpp` — RSS / Atom / HTML 標題解析（輕量標記掃描器）+ 提供者實作
  - `CMakeLists.txt` — `add_library(e2_26)` **PUBLIC 連上游 `e2_01` `e2_14`**；`test_e2_26`
    （`tests/e2/test_e2_26.cpp`）+ `add_test(NAME e2_26)`
- 測試：`tests/e2/test_e2_26.cpp`（gtest，32 案例）
- 上游相依：
  - E2-01 統一指標介面（`engine/metrics/e2_01`，可讀不可改）——消費 `MetricProvider` 契約。
  - E2-14 HTTP 取得與結構化解析（`modules/sysinfo/e2_14`，可讀不可改）——沿用其可注入
    `HttpTransport` / `NullHttpTransport` / `HttpResponse` 抓內容（不自造 HTTP 傳輸；e2_14 又
    PUBLIC 傳遞 e2_02）。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「RSS/Atom feed 項目或網頁
  `<title>`」透過 **E2-01 的 `MetricProvider`** 掛成指標（多實例：最新 N 筆，slot 0 = 最新，
  value.text = 標題、value.number = slot 序位；連結 / 時間經 `items()` 暴露）。
  - `FeedType` / `FeedItem{title,link,time}` / `FeedDocument{type,title,items}`；
    `parse_feed(markup) → FeedParseResult`（純文字掃描：RSS `<item>` / Atom `<entry>` /
    HTML `<title>`，解碼實體、支援 CDATA / 註解；**空 feed = 成功 0 項目、malformed = 失敗且
    帶訊息不靜默**，NFR-04）。
  - `FeedFetchProvider : ds::metrics::MetricProvider`：`register_metrics()` 掛上指標並預配置
    N 個 slot 實例；`sample()` GET→（2xx）`parse_feed()`→取最新 N 筆填 slot、其餘 unknown；
    網頁 HTML 合成單一項目。
  - 核心性質：相位 1（Mac/null 期）平台中立、無 `#ifdef` / win32 / cocoa / socket / 真實網路
    （沿用 E2-14 注入式 null 傳輸）；非 2xx / 解析失敗 / 無後端皆保守把所有 slot 留為 unknown、
    不崩；空 feed 與 malformed 明確區分（前者 sample() 回 true 且 item_count()==0）；消費者只透過
    E2-01 抽象介面走訪，新增此指標掛件一行不動。
