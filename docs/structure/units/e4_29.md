# 結構註記 — E4-29 折線圖

- 目錄位置：`modules/elements/e4_29/`（module 層 / 子系統 elements / phase 1 / 平台中立純邏輯）。
- 內容：`line_chart.hpp|cpp`（`LineChartElement`：累積一或多序列樣本、y 軸縮放、滾動視窗保留
  最新 N（多序列共用容量）、可選多序列（`add_series`）、可選平滑（移動平均）、可選下方填充、
  合成描述；`LineChartRenderModel` / `LineChartSeriesModel` / `LineChartPoint` / `LineChartFill`；
  `LineChartRange` / `LineChartStatus` 直接沿用上游 E4-17 `HistogramRange` / `HistogramStatus`），
  `CMakeLists.txt`（`add_library(e4_29)` PUBLIC 連 `e4_17` + `test_e4_29`，根層自動 glob 收入）。
- 對外介面：命名空間 `ds::elements`；把一或多序列數值映射成折線圖的**渲染描述模型**——每個
  樣本 → 一個正規化折線點（`(x,y) ∈ [0,1]`，NFR-02 無絕對座標 / 無數字 z-order；多序列疊加
  順序 = 清單順序），相位 1 不做真實繪製。合成不透明度沿用 E1-03 `AlphaProfile`（經 E4-17 傳遞）。
- 依賴：E4-17（直方圖 — 沿用其 `HistogramRange` / `HistogramStatus` 型別與序列/render_model
  範式；並經其 PUBLIC 連結傳遞 E1-03 `AlphaProfile` / `AlphaMode` 合成描述）。
- 測試：`tests/e4/test_e4_29.cpp`（23 個 gtest 案例，`add_test(NAME e4_29)`）。
