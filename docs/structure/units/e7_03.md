# 結構註記 — E7-03 段落變數

- 層級：engine(平台中立純邏輯)；描述子系統的**變數段落層**（相依已合併的 E7-02 → E7-01）。
- 目錄位置：`engine/format/e7_03/`
  - `section_vars.hpp` / `section_vars.cpp` — 實作
  - `CMakeLists.txt` — `add_library(e7_03)` + `target_link_libraries(e7_03 PUBLIC e7_02)`（消費上游）
    + `test_e7_03`（`tests/e7/test_e7_03.cpp`）+ `add_test(NAME e7_03)`
- 測試：`tests/e7/test_e7_03.cpp`（gtest，25 案例）
- 對外介面（`namespace ds::format`）：把**宣告於文件自身**的變數段落抽出、展開。
  - `kDefaultVarsKey`（`"vars"`）；`ExpandOptions{ vars_key, strip_vars, parent }`。
  - `build_scope(section, scope, err)`：由段落（須為 Map）填入 `VariableScope`；非 Map → false + err。
  - `expand(const Value&, opts)` → `ResolveResult`；`expand(const Document&, opts)` → `DocumentResolveResult`
    （`format_version` 原樣保留）。抽出頂層 `vars_key` 段落建作用域（鏈接 `opts.parent`），委派
    E7-02 `resolve()` 展開其餘（或全部，視 `strip_vars`）內容。
  - **段落非映射 / 未定義 / 循環 / 未終止 `${` / 容器內嵌字串化一律明確回報、不靜默**（NFR-04）。
- 定位：E7-02 是替換「引擎」（外部建 scope）；本單元是其上的「文件內宣告」層，讓變數可完全在
  單一宣告式文件裡「宣告一次、處處引用」。替換 / 型別保留 / 巢狀 / 循環偵測全數委派 E7-02，不重造。
  平台中立、無 `#ifdef`。
