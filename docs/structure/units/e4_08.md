# 結構註記 — E4-08 圖層合成

- 單元：E4-08（engine 層 / render / phase 1 / Risk: low，depends_on=[E4-02, E4-06]）
- 目錄位置：`engine/render/e4_08/`（平台中立引擎邏輯，換平台一行不動）
- 測試：`tests/e4/test_e4_08.cpp`（CTest 名 `e4_08`）

## 放了什麼

- `layer_compositor.hpp`：`BlendMode`（Normal/Multiply/Screen/Overlay）、`CompositeStatus`
  （Ok/Invalid/NotFound）、`LayerEntry`（單層描述）、`CompositionPlan`（合成計畫描述）、
  `LayerCompositor` —— 多圖層合成的計畫產出器。
- `layer_compositor.cpp`：`LayerCompositor` 各方法實作（具名鍵線性尋找，同 E4-06 慣例）。
- `CMakeLists.txt`：`add_library(e4_08)` + `PUBLIC` 連 `e4_02` `e4_06` + `test_e4_08` +
  `add_test(NAME e4_08)`。

## 對外介面（一句話）

`ds::render::LayerCompositor(SurfaceSwitcher&)`：`add_layer(surface_id, blend_mode, opacity)`
（surface 須先經 E4-06 `SurfaceSwitcher::has()` 定址存在，否則 `NotFound`；空 id / 非有限
透明度 / 未知混合模式 / 重複加入回 `Invalid`）/ `remove_layer(surface_id)`（未知回
`NotFound`）/ `has_layer` / `layer_count` / `layer_order()`（依加入順序的具名清單）/
`compose()`（產出依具名圖層順序排列的 `CompositionPlan`，純描述、不做真實像素合成）——
全程具名 id + 具名混合模式，不對外暴露任何數字索引 / z-order（NFR-02）。
