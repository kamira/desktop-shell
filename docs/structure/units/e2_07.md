# 結構註記 — E2-07 儲存 IO 吞吐與佇列

- 層級：module(平台無關指標提供者)／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_07/`
  - `disk_io.hpp` / `disk_io.cpp` — 差分演算法 + 抽象/注入式來源 + 值模型 + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_07)` **PUBLIC 連上游 `e2_01` `e2_02`**；`test_e2_07`
    (`tests/e2/test_e2_07.cpp`) + `add_test(NAME e2_07)`
- 測試：`tests/e2/test_e2_07.cpp`（gtest，36 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`）＋ E2-02 採集頻率分級
  （`engine/metrics/e2_02`），皆可讀不可改——消費 `MetricProvider`／`MetricRegistry`／
  `InMemoryMetric` 契約與 `SamplingTier` 分級，不自造指標模型或排程器。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「磁碟 IO 指標」（讀/寫
  吞吐率 bytes/sec、讀/寫 IOPS、佇列深度）透過 **E2-01 的 `MetricProvider`** 掛成**五個**指標，
  每個以**每顆磁碟**為可列舉實例，並以 **E2-02 的頻率分級**決定採樣節奏，支援多磁碟。
  - 值模型：`DiskIoCounters`（單顆磁碟累積 read/write bytes、累積 read/write ops + 瞬時
    queue_depth）、`DiskIoSnapshot`（磁碟身分 + 計數）、`DiskIoSample`（時間戳 + 全磁碟累積
    快照）、`DiskIoRates`（已差分四速率 + 瞬時佇列）、`DiskIoReading` / `DiskIoUsageSample`
    （身分 + 速率的列舉輸出 + valid）。
  - 差分演算法（自由函式，獨立可測）：`counter_rate(prev,curr,dt)`＝currΔ/dt（防 dt<=0 /
    計數重置）；`rates_from_delta(prev,curr,dt)`＝四速率 + 佇列瞬時原樣帶出；
    `usage_from_delta(prev,curr)`＝dt 為兩份時間戳差、每磁碟以共同數對齊逐顆差分、身分取當前
    快照，共同磁碟數 0 → 無讀值。**吞吐率 / IOPS 有量綱，差分需時間差**（與 CPU tick 比率
    不同）。
  - 累積計數來源：抽象 `IoStatSource::read()→DiskIoSample`（列舉磁碟 + 每磁碟累積計數 +
    時間戳）；`NullIoStatSource`（相位 1 null/假來源，注入累積計數序列，列盡回最後一份）。
  - 速率來源：抽象 `IoRateSource::sample()→DiskIoUsageSample`（提供者只依賴此）；
    `NullIoRateSource`（直接速率注入，繞過差分）；`DifferencingIoRateSource`（把累積計數來源
    以「兩次取樣差分」轉成速率來源，首次回未知——差分至少需兩份）。
  - `DiskIoProvider : ds::metrics::MetricProvider`：`register_metrics()` 掛上五指標
    `disk.io.read_bytes`(B/s)、`disk.io.write_bytes`(B/s)、`disk.io.read_iops`(IOPS)、
    `disk.io.write_iops`(IOPS)、`disk.io.queue`(unit "")，皆 range=`at_least(0)`（上無界），
    每個以每磁碟為可列舉實例（instance_id = 磁碟識別碼，各保留歷史環）；`sample()` 重新讀
    來源更新各磁碟實例（速率推入歷史，新磁碟於五指標動態新增、下線者設未知不污染）；
    `sampling_tier()` 回建議採集分級（預設 Normal），供 `SamplingScheduler::add_demand`。
  - 核心性質：相位 1（Mac/null 期）平台中立、**無 `#ifdef` / IOKit / /proc/diskstats /
    mach / win32 / cocoa** 等真實 IO API；無讀值時以 valid==false（未知）誠實表達、不謊報 0；
    消費者只透過 E2-01 抽象介面走訪，新增此組指標掛件一行不動。
