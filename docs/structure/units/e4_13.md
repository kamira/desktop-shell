# 結構註記 — E4-13 文字流內嵌物件

- 單元：E4-13（module 層 / elements / phase 1 / Risk: low，depends_on=[E4-01, E4-02]）
- 目錄位置：`modules/elements/e4_13/`（平台中立元件邏輯，換平台一行不動）
- 測試：`tests/e4/test_e4_13.cpp`（CTest 名 `e4_13`）

## 放了什麼

- `inline_flow_element.hpp`：`InlineFlowStatus`（Ok/Invalid）、`FlowGlyph`（文字字符相對
  佈局）、`FlowObject`（內嵌物件相對佈局，攜帶 E4-02 `ImageRenderModel`）、`FlowLine`（行盒，
  含逐行有效行高）、`InlineFlowResult`（完整混排渲染描述）、`InlineFlowElement`（文字流
  內嵌物件元件）。
- `inline_flow_element.cpp`：`InlineFlowElement` 各方法實作——`add_text`/`add_inline_object`
  累積內容，`render_model` 對混合 token 序列重跑一份與 E4-01 等價的貪婪詞界換行 + 對齊 +
  省略號演算法。
- `CMakeLists.txt`：`add_library(e4_13)` + `PUBLIC` 連 `e4_01` `e4_02` + `test_e4_13` +
  `add_test(NAME e4_13)`。

## 對外介面（一句話）

`ds::elements::InlineFlowElement(FontMetrics&, SurfaceId)`：`add_text(utf8)`（非法 UTF-8 →
`std::invalid_argument`）/ `add_inline_object(ImageRenderModel, Size)`（物件無來源或尺寸
非正/非有限 → `Invalid`，不加入；成功則佔一個排版位）/ `clear()` / `empty()` /
`object_count()` / `render_model(LayoutConstraints)`（重用 E4-01 換行/對齊約束，產出文字 +
內嵌物件混排的 `InlineFlowResult`：逐行相對佈局、內嵌物件與文字一起換行對齊、行高隨較高
物件放大）——全程相對佈局 + 具名 surface，不對外暴露絕對座標 / 數字 z-order（NFR-02）。
