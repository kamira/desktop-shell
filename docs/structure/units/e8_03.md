# 結構註記 — E8-03 表現控制指令集

- 層級：engine(平台中立純邏輯)；描述子系統的**表現 / 演出控制指令層**（相依已合併的
  E8-02 對話腳本直譯器、E4-06 Surface 定址切換、E6-01 命令匯流排與分派）。
- 目錄位置：`engine/script/e8_03/`
  - `presentation_commands.hpp` / `presentation_commands.cpp` — 實作
  - `CMakeLists.txt` — `add_library(e8_03)` +
    `target_link_libraries(e8_03 PUBLIC e8_02 e4_06 e6_01)`（消費上游）
    + `test_e8_03`（`tests/e8/test_e8_03.cpp`）+ `add_test(NAME e8_03)`
- 測試：`tests/e8/test_e8_03.cpp`（gtest，25 案例）
- 對外介面（`namespace ds::script`）：一組控制表現 / 演出的高階具名指令，供 E8-02 腳本
  編排視覺，phase 1 為描述 / 分派，不做真實繪製。
  - `presentation_commands::{kShow,kHide,kSwitchSurface,kTransition,kWait}`：五個具名
    命令 id（`ds::script.` 前綴），一律經 E6-01 `CommandBus` 註冊 / 分派。
  - `TransitionRecord{kind, from, to, duration_seconds}`；`WaitRecord{seconds}`。
  - `PresentationController(SurfaceSwitcher&, CommandBus&)`：註冊五指令到 bus；
    `switch_surface` 委派 E4-06 `SurfaceSwitcher::switch_to`；show/hide/transition/wait
    為 phase 1 純記憶體描述。`ready()` / `registration_error()`（id 衝突不靜默）；
    `is_visible()` / `visible_count()` / `transitions()` / `waits()` / `surfaces()`；
    解構時 unregister 自己成功註冊過的命令。
  - `PresentationSink : ds::script::OutputSink`：E8-02 整合點。`emit(text)` 把 `say`
    產生的一行文字（`show <target>` / `hide <target>` / `switch_surface <target>` /
    `transition <kind> <from> <to> <duration>` / `wait <seconds>`）解析為具名命令並經
    bus 分派；未知指令名稱組出未註冊 id，沿用 `CommandBus` 既有「未知命令 → NotFound」
    契約。`results()` / `all_ok()` / `failure_count()` / `count()` / `clear()`。
- 定位：不擴充 / 不修改 E8-02 的 opcode（`set`/`say`/`if`/`goto`/`label`），改以其既有
  `OutputSink` 擴充點疊加表現層語意；`switch_surface` 是唯一觸及 E4-06 的指令，其餘
  四個為 phase 1 記憶體描述，不綁真實後端。
- **未知指令（不在五個之列）與無效參數（缺參數 / 空字串目標 / 非有限或負值秒數 /
  未知 surface）一律經 `CommandResult`（`NotFound` / `Failed`）明確回報、不套用、不
  靜默**（NFR-04 精神）；`PresentationSink::results()` 忠實記錄每行分派結果，不吞任何
  錯誤。全程具名字串（surface id / 元件 target / 轉場 kind），無絕對座標 / 數字
  z-order（NFR-02）。平台中立、無 `#ifdef`。
