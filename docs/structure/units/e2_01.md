# 結構註記 — E2-01 統一指標介面（擴充點 1 契約）

- 層級：engine（平台中立純邏輯）／子系統 metrics
- 目錄位置：`engine/metrics/e2_01/`
  - `metric.hpp` / `metric.cpp` — 契約介面 + 記憶體內實作
  - `CMakeLists.txt` — `add_library(e2_01)` + `test_e2_01`（`tests/e2/test_e2_01.cpp`）+ `add_test(NAME e2_01)`
- 測試：`tests/e2/test_e2_01.cpp`（gtest，31 案例）
- 對外介面（`namespace ds::metrics`）：**平台五個擴充點的第一個**。統一指標契約，六要素為
  名稱 / 值 / 單位 / 範圍 / 歷史 / 可列舉實例。
  - 值型別：`MetricValue`（數值 + 可選文字 + valid）、`MetricRange`（min/max 可無界 +
    `normalized()` 正規化到 [0,1]）、`MetricHistory`（固定容量環狀，0=最舊…size-1=最新）。
  - 抽象契約：`MetricInstance`（單一可讀實例：id/label/value/history）、`Metric`（指標身分 +
    單位 + 範圍 + 列舉實例）、`MetricProvider`（提供者掛上一個或多個指標）、`MetricRegistry`
    （註冊 / 查詢 / 移除 / 註冊順序列舉；消費者唯一入口）。
  - 記憶體內實作：`InMemoryMetric` / `InMemoryMetricInstance`（相位 1 假感測器與測試用）。
  - 核心性質：消費者只依賴上述介面、**不依賴任何具體感測器**——新增指標 = 新增
    `MetricProvider`，掛件一行不動。純邏輯、無平台分支。
