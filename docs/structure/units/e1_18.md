# 結構註記 — E1-18 具名螢幕與每螢幕實例

- 層級：platform（相位 1 = Mac / null 期，僅介面 + null 後端）／子系統 kernel
- 目錄位置：`src/kernel/e1_18/`
  - `named_screens.hpp` / `named_screens.cpp` — 平台中立介面 + null 後端（內嵌單一具名主螢幕）
  - `CMakeLists.txt` — `add_library(e1_18)`（可選 link e1_17）+ `test_e1_18`（`tests/e1/test_e1_18.cpp`）+ `add_test(NAME e1_18)`
- 測試：`tests/e1/test_e1_18.cpp`（gtest，12 案例）
- 對外介面（`namespace ds::kernel`）：以**具名 ScreenId**（非數字索引）列舉螢幕，每螢幕有獨立狀態。
  - `Screen`{ id, description, role, anchor }；幾何以具名 `ScreenRole`（Primary/Secondary，取代
    數字 z-order）+ 具名 `ScreenAnchor`（Center/Left/Right/Above/Below，取代絕對座標）表達（NFR-02）。
  - `ScreenRegistry`：`defaults()`（null 期單一主螢幕）/ 由宣告建構；`is_known` / `find` / `ids`
    （具名列舉）/ `primary` / `is_primary` / `anchor_of`；未知螢幕一律保守（nullptr / false / Center）。
  - `PerScreen<T>`（樣板）：以具名 ScreenId 為鍵的每螢幕獨立實例狀態；可與 E1-17 每螢幕縮放
    搭配（`PerScreen<double>` 存各螢幕 scale_factor）。未知螢幕保守回 nullptr / fallback。
  - 相位 1 約束：無平台分支、無真實後端、無絕對座標 / 數字 z-order。
