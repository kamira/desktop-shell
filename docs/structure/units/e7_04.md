# 結構註記 — E7-04 動態變數與執行期重算

- 層級：engine(平台中立純邏輯)；描述子系統的**反應式變數層**（相依已合併的 E7-02）。
- 目錄位置：`engine/format/e7_04/`
  - `reactive.hpp` / `reactive.cpp` — 實作
  - `CMakeLists.txt` — `add_library(e7_04)` + `target_link_libraries(e7_04 PUBLIC e7_02)`（消費上游）
    + `test_e7_04`（`tests/e7/test_e7_04.cpp`）+ `add_test(NAME e7_04)`
- 測試：`tests/e7/test_e7_04.cpp`（gtest，24 案例）
- 對外介面（`namespace ds::format`）：把 E7-02 的靜態變數推進為執行期可變、相依者自動重算的反應式變數。
  - `ReactiveScope`：`set(name, value)`（來源變數，執行期可變）、
    `define_derived(name, deps, compute)`（衍生變數，值由 compute 依 deps 算出）、
    `get(name)`（含髒衍生的延遲重算）、`has` / `is_derived` / `names`（建立序）/ `size`、
    `on_change(cb)`（變更訂閱）。
  - `DerivedInputs`：傳給 compute 的唯讀輸入，只允許讀**已宣告的** deps（讀未宣告名 → throw）。
  - `ComputeFn` / `ChangeCallback`；`ReactiveError{message, variable}`；`ReactiveResult`（Value / error）。
  - 機制：相依圖（正向 deps / 反向 dependents）+ 髒標記傳播 + 拓撲重算（`ensure_computed` 遞迴）。
    `set` 來源時沿反向邊標髒下游、以拓撲序**只重算受影響者**（菱形相依只算一次）；
    值實際改變者依建立序（來源優先）觸發 `on_change`。
  - **循環相依於 `define_derived` 當下明確報錯、狀態不變（不靜默、不無限遞迴）**；
    另有執行期 `computing_` 堆疊防禦性守衛。未知變數 / 對衍生 set / 相依不存在一律明確回報（NFR-04 精神）。
- 定位：消費 E7-02 的變數概念與 E7-01 的 `Value`，為其上的**執行期反應式**層；設定 / profile /
  內容可先解析、再以本層讓值於執行期可變且衍生者自動重算。平台中立、無 `#ifdef`。
