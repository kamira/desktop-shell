# 結構註記 — E4-04 按鈕三態

- 目錄位置：`modules/elements/e4_04/`（module 層 / 子系統 elements / phase 1 / risk=low /
  平台中立純邏輯）。
- 內容：`button_element.hpp|cpp`（`ButtonStatus{Ok,Invalid}`；`ButtonState{Normal,Hover,
  Pressed}`（顯示優先序 Pressed>Hover>Normal）；`ButtonRenderModel{state, ImageRenderModel
  visual}`；`ClickCallback`；`ButtonElement`：`set_visual/visual`（各態視覺，值複製 E4-02
  `ImageElement`）、`set_on_click`、`attach/detach/handle_hover_event`（登記 / 訂閱 E5-02
  `HoverTracker`，轉譯 Enter/Leave/Move 為 hover 態）、`press/release`（以 E1-04 `HitTester`
  對按鈕自身本地形狀做命中判定，切換 pressed 態並條件式觸發 `on_click`）、
  `is_hovered/is_pressed/state`、`render_model()`），`CMakeLists.txt`（`add_library(e4_04)`
  PUBLIC 連 `e4_02 e1_04 e5_02` + `test_e4_04`，根層自動 glob 收入）。
- 對外介面：命名空間 `ds::elements`；按鈕三態元件——依互動狀態（常態/懸停/按下）切換外觀：
  用上游 E5-02 懸停事件切 hover 態、上游 E1-04 命中 + 按下/放開動作切 pressed 態，各態顯示
  對應上游 E4-02 圖片/樣式，`render_model()` 產出當前態渲染描述，並於「按下後於按鈕範圍內
  放開」時觸發 `on_click` 回呼。相位 1 不綁任何真實滑鼠 / 視窗系統事件，懸停與按下皆由
  呼叫端 / 測試注入驅動。
- NFR-02（無絕對座標 / 無數字 z-order）：id 為具名 `ds::kernel::SurfaceId`（字串）；圖層為
  具名 `ds::kernel::SurfaceLayer`；座標沿用 E1-04 `LocalPoint`（本地 / 相對）；渲染描述沿用
  E4-02 `ImageRenderModel`（具名目標 / 正規化裁切 / 比例透明度）。本單元不新增任何 (x,y)
  螢幕位置或疊放層級欄位。
- 不靜默：建構子空 id → 擲 `std::invalid_argument`；`set_visual`/`visual` 遇無效
  `ButtonState`（超出三個合法值）→ `Invalid`/`nullptr`；`press`/`release` 遇非有限座標或
  按鈕自身形狀無效 → `Invalid`，不改變任何狀態、不觸發 `on_click`（「放開於按鈕範圍外」則
  屬正常取消點擊，非錯誤，與此明確區分）。
- 依賴：E4-02（各態視覺 `ImageElement`/`ImageRenderModel`）、E1-04（`HitTester`/`Shape`/
  `LocalPoint` 命中判定）、E5-02（`HoverTracker`/`HoverEvent` 懸停事件）。
- 測試：`tests/e4/test_e4_04.cpp`（24 個 gtest 案例，`add_test(NAME e4_04)`）。
