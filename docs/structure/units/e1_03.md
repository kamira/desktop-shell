# 結構註記 — E1-03 逐像素 alpha surface

- 層級：platform（相位 1 = Mac / null 期）／子系統 kernel／單元 e1_03
- 目錄位置：`src/kernel/e1_03/`（根 CMakeLists 以層級 GLOB `src/*/*/CMakeLists.txt` 深度 2 自動收入）
  - `alpha_surface.hpp` — 介面擴充：能力鍵 `kPerPixelAlphaCapability`（`"surface.per_pixel_alpha"`）、
    型別 `AlphaMode`{Opaque, PerPixel} / `AlphaProfile`{mode, opacity∈[0,1]} / `AlphaStatus`{Ok,
    Unsupported, Invalid}、服務 `AlphaSurfaceService`、能力矩陣輔助 `alpha_capable_matrix()` /
    `alpha_incapable_matrix()`
  - `alpha_surface.cpp` — 能力閘控 + null 記憶體模擬實作
  - `CMakeLists.txt` — `add_library(e1_03 STATIC alpha_surface.cpp)` +
    `target_link_libraries(e1_03 PUBLIC e1_21 backend_null)` + `test_e1_03`
    （`tests/e1/test_e1_03.cpp`）+ `add_test(NAME e1_03)`
- 測試：`tests/e1/test_e1_03.cpp`（gtest，13 案例）
- 上游相依（可讀不可改）：E1-24 `KernelBackend` / `NullKernelBackend` / `SurfaceId` /
  `SurfaceProfile`（surface 模型）；E1-21 `CapabilityMatrix`（能力鍵 / `has()` 閘控來源）。
- 對外介面（`namespace ds::kernel`）：逐像素 alpha 透明 surface 的**能力閘控服務層**。
  - `AlphaSurfaceService`（組合持有 `KernelBackend&`）：`supported()`（= 後端 `has(kPerPixelAlphaCapability)`，
    所有變更操作的閘門，NFR-03）；建立 / 銷毀 `create_alpha_surface` / `destroy_alpha_surface`
    （實體 surface 委由後端 K1 原語，alpha 狀態另存記憶體）；查詢 `has_alpha_surface` /
    `alpha_surface_count` / `alpha_profile` / `is_per_pixel`；設定 `set_alpha` / `set_mode` /
    `set_opacity`（opacity clamp [0,1]、非有限值拒絕）。
  - 能力表述：per-pixel alpha 為**可選能力**；上游 `CapabilityMatrix::defaults()` 未宣告該鍵
    （保守回不可用），`alpha_capable_matrix()` 追加宣告為可用以模擬「支援」平台——**不修改** E1-21。
  - 相位 1 約束：無平台分支（無 `#ifdef`）、無真實 OS / 繪圖 API、無 `src/kernel/backend/win32|cocoa/`；
    surface 具名指涉、alpha 以具名模式 + 正規化不透明度表達（無絕對座標 / 數字 z-order，NFR-02）；
    能力查詢一律經 `has()`（NFR-03）並附降級路徑；alpha 狀態全存記憶體（null 模擬）。
