# 結構註記 — E10-05 獨立行程 widget 宿主

- 單元：E10-05（engine 層 / ipc / Risk: low）
- 目錄位置：`engine/ipc/e10_05/`（平台中立引擎邏輯，換平台一行不動）
- 測試：`tests/e10/test_e10_05.cpp`（CTest 名 `e10_05`）
- 相依：
  - E10-01 本機 IPC 訊息投遞（`target_link_libraries(e10_05 PUBLIC e10_01)`）——宿主與
    主程式的通訊通道（`MessageChannel`）。
  - E1-03 逐像素 alpha surface（`target_link_libraries(e10_05 PUBLIC e1_03)`）——widget

## 放了什麼
- `widget_host.hpp`：獨立行程 widget 宿主契約——`WidgetSpec`（啟動規格）、`ProcessLauncher`
  （可注入行程宿主抽象：spawn/terminate/is_alive）、`NullProcessLauncher`（相位 1 記憶體
  模擬 + `simulate_crash()` 測試鉤子）、`ProcessState` / `WidgetHostStatus` 列舉、宿主事件
  訊息型別常數、`WidgetHost`（生命週期管理 + 崩潰偵測 + surface 橋接 + 經 E10-01 通道通訊）。
  相位 1 不含任何真實 fork/exec/win32 CreateProcess 等行程 API，僅注入式抽象。
- `widget_host.cpp`：`widget_host_contract_version()`（"e10_05/1.0.0"；因與 E10-01 同
  `ds::ipc` 命名空間 `contract_version()` 撞名而改名，沿用 E10-02/E10-04 前綴慣例）；
  `NullProcessLauncher` 三原語實作；`WidgetHost` 生命週期 / 崩潰偵測 / surface 橋接 /
  宿主事件廣播邏輯。
- `CMakeLists.txt`：`add_library(e10_05)` + `PUBLIC e10_01 e1_03` + `test_e10_05` +
  `add_test(NAME e10_05)`。

## 對外介面（一句話）
`ds::ipc::WidgetHost` 以注入的 `ProcessLauncher`（相位 1 為 `NullProcessLauncher`）管理單一
widget 行程的生命週期（`start` / `stop` / `restart` / `state` / `is_alive` /
`poll_crash`+`on_crash`），經注入的 E1-03 `AlphaSurfaceService` 橋接 widget 的具名 surface，
並透過 E10-01 `MessageChannel`（`channel()`）廣播宿主事件與供呼叫端直接收發；無效 spec /
能力不可用一律回傳明確的 `WidgetHostStatus`，不留孤兒行程、不靜默吞錯。
