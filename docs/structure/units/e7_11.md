# 結構註記 — E7-11 群組與批次操作

- 層級：engine（平台中立純邏輯）；建於描述子系統根契約 E7-01 + 命令匯流排 E6-01 之上。
- 目錄位置：`engine/format/e7_11/`
  - `group.hpp` / `group.cpp` — 實作（`namespace ds::format`）
  - `CMakeLists.txt` — `add_library(e7_11)` + `target_link_libraries(e7_11 PUBLIC e7_01 e6_01)`
    + `test_e7_11`（`tests/e7/test_e7_11.cpp`）+ `add_test(NAME e7_11)`
- 測試：`tests/e7/test_e7_11.cpp`（gtest，21 案例 / 87 檢查）
- 對外介面（`namespace ds::format`）：讓宣告式格式定義項目群組並對整組批次施加操作。
  - `Selector`：從 `Value` 樹挑選 Map 節點的述詞包裝——`tagged(value,key="group")` / `has(key)` /
    `where(pred,label)`；只對 Map 節點求值，帶診斷 `label()`。
  - `select(root, selector) -> Group`：前序遍歷樹，收集命中的 Map 節點為 `Group`。
    每個 `GroupMember{path,label,node}` 帶樹中唯一路徑（如 `/layers/1`）、友善標籤（取自 `id`/`name`
    欄位，退化為 path）與指入來源樹的非擁有指標。
  - `apply_to_group(bus, group, command, args)` / `(bus, group, command, make_args)`：對每個成員經
    **E6-01 CommandBus** 分派具名命令，回 `GroupResult{per_member[]}`；`make_args` 版本可依成員節點客製參數。
    未知命令 → 該成員 NotFound；處理器失敗 → Failed。**部分失敗逐成員回報、不靜默**（NFR-04 精神）。
  - `apply_attributes(group, changes) -> GroupAttributeResult{per_member[]}`：對整組套用共同屬性變更，
    為每個 Map 成員產出**新副本**（既有鍵保序覆寫、新鍵附加；**不改來源樹**）；非 Map 成員逐一回報原因。
- 定位：批次操作層——把 Value 樹中一組項目視為群組，統一經動作擴充點（E6-01）發令或套用屬性。
  平台中立、無 `#ifdef`；不含能力閘控呼叫（純格式 / 分派邏輯）。
