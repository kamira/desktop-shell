# 結構註記 — E7-13 階層式項目結構（描述子系統 / E7-01 的應用）

- 單元：E7-13（engine 層 / format / Risk: low / 相依 E7-01）
- 目錄位置：`engine/format/e7_13/`（平台中立引擎邏輯，換平台一行不動）
- 測試：`tests/e7/test_e7_13.cpp`（CTest 名 `e7_13`）

## 放了什麼
- `item_tree.hpp` / `item_tree.cpp`：消費 E7-01 的 `Value` / `Document` 契約，提供與領域無關的
  階層式項目樹（供啟動器選單樹、對話本、清單等共用）——
  - `Item`：`id` / `label` / `value`（附帶酬載，任意 `Value`）/ 有序 `children`（遞迴）；
    查詢 `is_leaf` / `child_count` / `size` / `depth`；程式化建構 `set_label` / `set_value` /
    `add_child`；深層 `operator==`。
  - `find(id)` / `contains(id)`：依 id 尋址（前序、含自身；id 唯一）。
  - `for_each_preorder(root, visit(node, depth))`：前序遍歷。
  - `build_item(Value / Document)` / `build_forest(list)`：從宣告式文件建構（單根 / 多根森林），
    契約違反回傳帶可定位訊息的 `BuildError`（`ItemResult` / `ForestResult`）。
- `CMakeLists.txt`：`add_library(e7_13 STATIC item_tree.cpp)` +
  `target_link_libraries(e7_13 PUBLIC e7_01)` + `test_e7_13` + `add_test(NAME e7_13)`。
  不改根 CMakeLists、不自造格式模型。

## 對外介面（一句話）
`ds::format`：以 `build_item(doc)` 從宣告式文件建出 `Item` 樹（每項目保留鍵 `id`/`label`/`value`/
`children`），`for_each_preorder` 遍歷、`find("editor")` 依 id 尋址；建構契約違反（非 Map / 缺·空·
非字串·重複 id / 型別錯 / 未知鍵）一律回傳可定位的 `BuildError`，不靜默失敗。
