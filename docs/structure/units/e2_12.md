# 結構註記 — E2-12 系統靜態資訊

- 層級：module(平台無關指標提供者)／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_12/`
  - `system_info.hpp` / `system_info.cpp` — 介面 + null 後端 + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_12)` **PUBLIC 連上游 `e2_01`**；`test_e2_12`
    (`tests/e2/test_e2_12.cpp`) + `add_test(NAME e2_12)`
- 測試：`tests/e2/test_e2_12.cpp`（gtest，16 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`，可讀不可改）——消費 `MetricProvider`
  契約、不自造指標模型。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「系統靜態資訊」
  （OS 名稱/版本、主機名、CPU 型號、核心數等，隨選查詢、非高頻）透過 **E2-01 的
  `MetricProvider`** 掛成指標 `system.static`。
  - `SysInfoField`（key/label/text/number）、`SysInfoSource`（抽象後端 `query()`）、
    `NullSysInfoSource`（相位 1 null 後端：不查系統，回空欄位集或注入的假資料）。
  - `SystemInfoProvider : ds::metrics::MetricProvider`：`register_metrics()` 把每個
    靜態欄位建成一個 `MetricInstance`（欄位集=列舉實例、欄位數=`instance_count()`；
    純文字欄位讀 text、數值欄位如核心數同時承載 number+text；history_capacity=0）。
  - 核心性質：相位 1（Mac/null 期）平台中立、無 `#ifdef` / win32 / cocoa / 真實 OS 查詢；
    消費者只透過 E2-01 抽象介面走訪，新增此指標掛件一行不動。
