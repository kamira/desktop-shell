# 結構註記 — E1-06 命中與繪製層序

- 層級：platform（相位 1 = Mac / null 期）／子系統 kernel／單元 e1_06
- 目錄位置：`src/kernel/e1_06/`（根 CMakeLists 以層級 GLOB `src/*/*/CMakeLists.txt` 深度 2 自動收入）
  - `paint_hit_order.hpp` — 介面：`PaintHitOrder`（`set_paint_order` / `paint_order` / `size` /
    `hit_topmost`），全部型別（`HitSurface` / `LocalPoint` / `HitStatus` / `TopmostHit` 等）
    直接複用上游 E1-04，不新增。
  - `paint_hit_order.cpp` — 實作：依繪製反序走訪、逐一呼叫 E1-04 `HitTester::hit_test_alpha`，
    純序列邏輯，不重新實作任何幾何 / alpha 判定。
  - `CMakeLists.txt` — `add_library(e1_06 STATIC paint_hit_order.cpp)` +
    `target_link_libraries(e1_06 PUBLIC e1_04)` + `test_e1_06`（`tests/e1/test_e1_06.cpp`）
    + `add_test(NAME e1_06)`
- 測試：`tests/e1/test_e1_06.cpp`（gtest，11 案例）
- 上游相依（可讀不可改）：E1-04 `src/kernel/e1_04/hit_test.hpp`（`HitTester` / `HitSurface` /
  `LocalPoint` / `HitStatus` / `TopmostHit`）；經其傳遞取得 E1-03（`AlphaMode` / `AlphaProfile`）
  與 E1-24（`SurfaceId` / `SurfaceLayer` / `HitPolicy`）的 include 目錄。
- 對外介面（`namespace ds::kernel`）：**命中層序與繪製層序一致**——給定具名 surface 的繪製
  順序（陣列宣告順序即繪製順序，末端為視覺最上層），命中測試依**繪製反序**（最上層先）判定，
  保證視覺最上者即互動最上者。
  - `PaintHitOrder`：`set_paint_order(surfaces)`（設定 / 覆蓋目前繪製順序）；
    `paint_order()` / `size()`（唯讀查詢目前繪製順序）；`hit_topmost(point)`（依繪製反序逐一
    以 E1-04 `hit_test_alpha` 判定，第一個命中者即結果；任一 surface 無效 → `HitStatus::Invalid`
    報錯不靜默；無命中 → `hit=false`）。
  - 相位 1 約束：純序列邏輯 + 複用 E1-04 幾何 / alpha 判定，無真實視窗系統；無平台分支
    （無 `#ifdef`）、無真實 OS / 繪圖 API、無 `src/kernel/backend/win32|cocoa/`；繪製順序以
    陣列宣告順序表達（無數字 z-order，NFR-02）；`SurfaceLayer` 為 surface 屬性，不作為本單元
    排序依據。
