# 結構註記 — E2-20 網路連通性

- 層級：module（平台無關指標提供者）／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_20/`
  - `connectivity.hpp` / `connectivity.cpp` — 值模型 + 純邏輯自由函式 + 抽象/注入式來源
    + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_20)` **PUBLIC 連上游 `e2_01` `e2_02`**；`test_e2_20`
    (`tests/e2/test_e2_20.cpp`) + `add_test(NAME e2_20)`
- 測試：`tests/e2/test_e2_20.cpp`（gtest，27 案例 / 101 檢查）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`）＋ E2-02 採集頻率分級
  （`engine/metrics/e2_02`），皆可讀不可改——消費 `MetricProvider` 契約與 `SamplingTier`
  分級，不自造指標模型或排程器（範式與 E2-08 網路流量、E2-03 CPU 負載一致）。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「網路連通性」（是否
  連上網際網路、延遲/ping ms、封包遺失率 %、對特定目標可達性、DNS 可解析）透過 **E2-01
  的 `MetricProvider`** 掛成**五個**指標，並以 **E2-02 的頻率分級**決定採樣節奏。
  - 值模型：`ConnectivityTarget`（單目標 reachable / latency_ms / loss_pct /
    dns_resolvable，各帶獨立 valid 旗標）、`ConnectivitySample`（整體 online + online_valid、
    各目標讀值、整體 valid；`find(name)`、`unknown()`）。
  - 純邏輯自由函式（獨立可測、純算術）：`loss_pct_from_counts(sent,received)`＝
    (sent-received)/sent*100，防護 sent==0→0、received>=sent→0；`online_from_targets(sample)`
    ＝任一目標有效可達即 online，無任一有效可達性讀值回 `{valid=false}`（不謊報）。
  - 連通性來源：抽象 `ConnectivitySource::sample()→ConnectivitySample`；
    `NullConnectivitySource`（相位 1 null/假來源，**永不含平台探測**）——支援**固定**
    （`set_sample` / `set_online` / `set_target`，單元素快照重複回同一份）與**序列**
    （`set_sequence` / `push_sample`，逐份推進、列盡回最後一份）兩種注入；空列預設無讀值。
  - `ConnectivityProvider : ds::metrics::MetricProvider`：`register_metrics()` 掛上五個
    指標——`net.connectivity.online`（**單一實例** "internet"、range bounded(0,1)）、
    `net.connectivity.reachable`(bounded(0,1))、`net.connectivity.latency`(unit "ms"、
    at_least(0))、`net.connectivity.loss`(unit "%"、bounded(0,100))、`net.connectivity.dns`
    (bounded(0,1))；後四者以**每探測目標**為可列舉實例（同名、首見序、各保留歷史環）；
    `sample()` 重新讀來源更新各實例（有效值推入歷史，新目標動態新增實例、消失者設未知）；
    `sampling_tier()` 回建議採集分級（預設 Normal），供 `SamplingScheduler::add_demand`。
    bool 面向以 1.0 / 0.0 表達（配合 bounded(0,1) 可正規化）。
  - 核心性質：相位 1（Mac/null 期）平台中立、**無 `#ifdef` / socket / ping / getaddrinfo /
    win32 / cocoa** 等真實網路探測（原始碼僅於註解敘明「不含」）；各面向 / 整體無讀值皆以
    valid==false 誠實表達（不謊報 0 / 不謊報 online）；消費者只透過 E2-01 抽象介面走訪，
    新增此指標掛件一行不動。
- 指標 id 命名空間 `net.connectivity.*` 與既有 `net.*`（E2-08 網路流量）無碰撞。
