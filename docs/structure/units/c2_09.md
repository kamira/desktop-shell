## 放了什麼

- `calendar_todo_widget.hpp` / `.cpp`：**組裝型**單元（非新引擎邏輯）——把四個已合併的擴充點
  組成「行事曆 / 待辦」桌面 widget：
  - C1-01 `SkinProfile`：本 widget 的桌面殼層基底（圖層 / 定位 / 拖曳），透過 `shell()` 暴露，
    由呼叫端直接驅動（`shell().load_skin(...)` / `place` / `begin_drag` 等）。
  - E7-13 `Item` / `build_forest`：以樹狀結構表達「日期分組（頂層）→ 事項（子層）」；事項
    `value` 為 `{done: bool}` 附帶酬載。
  - E7-12 `serialize`：`save()` 把目前森林重建為 E7-01 `Value` 樹並序列化回文字。
  - E4-01 `TextLayout`：`render_model()` 把行事曆 / 待辦清單排版為文字渲染描述（標題行 + 各
    事項 `[x]`/`[ ]` 前綴行），排版目標 surface 綁定本 widget 的具名 id。
- `CMakeLists.txt`：`add_library(c2_09)` + `target_link_libraries(c2_09 PUBLIC c1_01 e4_01 e7_12
  e7_13)` + `test_c2_09`（`tests/c2/test_c2_09.cpp`）+ `add_test(NAME c2_09)`。
