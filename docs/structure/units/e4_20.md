# 結構註記 — E4-20 向量圖形

- 目錄位置：`modules/elements/e4_20/`（module 層 / 子系統 elements / phase 1 / 平台中立純邏輯）。
- 內容：`vector_graphic.hpp|cpp`（`VectorPath`：路徑指令累積 `move_to/line_to/curve_to/close`；
  `Shape{Rect,Circle,Polygon,Line}` + `build_shape_path()` 把基本形狀轉為路徑指令序列；
  `VectorGraphic`：持有路徑 + `StrokeStyle`/`FillStyle`，`set_stroke/set_fill/render_model()`
  產出 `VectorRenderModel`），`CMakeLists.txt`（`add_library(e4_20)` PUBLIC 連 `e1_03` +
  `test_e4_20`，根層自動 glob 收入）。
- 對外介面：命名空間 `ds::elements`；向量圖形元件——路徑(moveto/lineto/curveto)、基本形狀
  (矩形/圓/多邊形/線段)、描邊/填色屬性，`render_model()` 產出向量渲染描述(路徑指令序列 +
  樣式)。相位 1 不做真實繪製。頂點/控制點皆為元件本地座標系（NFR-02：非螢幕像素、無數字
  z-order）。無效路徑操作（未 `move_to` 先 `line_to`/`curve_to`/`close`）與退化形狀（零/負
  寬高矩形、零/負半徑圓、<3 頂點多邊形、零長度線段）皆回 `VectorStatus::Invalid`，不靜默。
- 依賴：E1-03（`AlphaProfile`/`AlphaMode`，描邊/填色的合成描述）。
- 測試：`tests/e4/test_e4_20.cpp`（25 個 gtest 案例，`add_test(NAME e4_20)`）。
