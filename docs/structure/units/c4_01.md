# 結構註記 — C4-01 鍵位速查

- 單元：C4-01（artifact 層 / apps / 組裝型 / Risk: low）
- 目錄位置：`apps/c4_01/`
- 測試：`tests/c4/test_c4_01.cpp`（CTest 名 `c4_01`，26 個 gtest 案例）

## 放了什麼
- `shortcut_cheat_sheet.hpp` / `.cpp`：**組裝型**單元（非新引擎邏輯）——把兩個已合併的
  擴充點組成「鍵位速查」（keyboard shortcut cheat sheet）應用 + 行為：
  - C1-04 `OsdOverlayProfile`：面板顯隱生命週期基底（以參考持有，不取得所有權）——
    `show(ttl)` / `hide()` 委派其 `show(message, ttl)` / `dismiss()`。
  - E4-01 `TextLayout` / `FontMetrics`：把可見鍵位清單排版成 `LayoutResult`（每個可見
    鍵位一行，全相對偏移）。
- `CMakeLists.txt`：`add_library(c4_01)` + `target_link_libraries(c4_01 PUBLIC c1_04
  e4_01)` + `test_c4_01`（`tests/c4/test_c4_01.cpp`）+ `add_test(NAME c4_01)`。

## 對外介面（一句話）
`ds::apps::ShortcutCheatSheetApp`：`load_shortcuts(vector<ShortcutEntry>) ->
LoadStatus`（載入鍵位清單，整批驗證，成功時若面板顯示中即時刷新）/
`filter(query)`（大小寫不敏感子字串篩選鍵位或說明，`visible_shortcuts()` 讀結果，同樣
即時刷新顯示中的面板）/ `layout(constraints={}) -> LayoutResult`（對目前可見鍵位排版，
純函式，與顯示狀態無關）/ `show(ttl)` `hide() -> bool`（委派 C1-04 面板顯隱）。相位 1：
純資料 / 文字排版組裝，無真實 GUI 繪製、無真實鍵盤 hook（`keys` 僅顯示用字串）；無平台
分支（無 `#ifdef` / win32 / cocoa）、無絕對座標 / 數字 z-order（NFR-02）。
