# 結構註記 — E2-23 檔案系統列舉

- 層級：module(平台無關指標提供者)／子系統 sysinfo
- 目錄位置：`modules/sysinfo/e2_23/`
  - `fs_enum.hpp` / `fs_enum.cpp` — 抽象後端 + 記憶體內假來源 + 提供者實作
  - `CMakeLists.txt` — `add_library(e2_23)` **PUBLIC 連上游 `e2_01`**；`test_e2_23`
    （`tests/e2/test_e2_23.cpp`）+ `add_test(NAME e2_23)`
- 測試：`tests/e2/test_e2_23.cpp`（gtest，26 案例）
- 上游相依：E2-01 統一指標介面（`engine/metrics/e2_01`，可讀不可改）——消費 `MetricProvider`
  契約、不自造指標模型。
- 對外介面（`namespace ds::sysinfo`）：一個 sysinfo 指標提供者，把「某路徑下的目錄項目
  清單／數量」透過 **E2-01 的 `MetricProvider`** 隨選掛成指標 `fs.entries`。
  - `DirEntry`（name/type/size/mtime）、`DirEntryType`（File/Directory/Other）、
    `FsError` + `ListResult`/`StatResult`（錯誤不靜默）。
  - `FileSystemSource`（抽象後端 `list(path)` / `stat(path)`）、`NullFileSystemSource`
    （相位 1 記憶體目錄樹假來源：**絕不接真實檔案系統**，`add_file`/`add_dir`/
    `set_permission_denied`/`clear`）。
  - `FileSystemEnumProvider : ds::metrics::MetricProvider`：`register_metrics()` 把目標路徑
    下每個子項目建成一個 `MetricInstance`（清單=列舉實例、數量=`instance_count()`；
    列舉錯誤以 `last_error()` 明確回報、不崩）。
  - 核心性質：相位 1（Mac/null 期）平台中立、無 `#ifdef` / win32 / cocoa /
    `<filesystem>` 實體存取 / `opendir`；消費者只透過 E2-01 抽象介面走訪，新增此指標掛件
    一行不動。
