# 結構註記 — E1-09 邊緣吸附

- 層級：platform（相位 1 = Mac / null 期）／子系統 kernel／單元 e1_09
- 目錄位置：`src/kernel/e1_09/`（根 CMakeLists 以層級 GLOB `src/*/*/CMakeLists.txt` 深度 2 自動收入）
  - `edge_snapping.hpp` — 介面：`SnapStatus`{Ok, Invalid}；具名 `Edge`{Left,Right,Top,Bottom}；
    `AxisSnap`{None,ScreenStart,ScreenEnd,Surface}；`SnapConfig`（threshold 正規化分數 / to_screen /
    to_surfaces / `from_spacing`）；`SnapResult`；`SnapTarget`；`SurfaceTarget`；自由函式
    `screen_edge_of` / `snap_rect` / `snap`；服務 `EdgeSnapping`；E1-08 整合 `snap_surface`
  - `edge_snapping.cpp` — 純幾何最近邊吸附 + 宣告式再表達（round-trip）+ E1-08 便利層實作
  - `CMakeLists.txt` — `add_library(e1_09 STATIC edge_snapping.cpp)` +
    `target_link_libraries(e1_09 PUBLIC e1_07 e1_08)` + `test_e1_09`（`tests/e1/test_e1_09.cpp`）+
    `add_test(NAME e1_09)`
- 測試：`tests/e1/test_e1_09.cpp`（gtest，18 案例）
- 上游相依（可讀不可改）：
  - E1-07（`PUBLIC` 連結）→ `AnchorSpec` / `Offset` / `Size` / `ResolvedPlacement` / `resolve` /
    `is_valid_anchor` / `is_finite_size` / `Spacing` / `spacing_fraction`：吸附後位置的宣告式表達與落地。
  - E1-08（`PUBLIC` 連結）→ `DraggableSurface::live_position` / `SurfaceId`：`snap_surface` 便利層讀取
    拖曳中 surface 的實時位置並對其他具名 surface 的實時位置吸附（唯讀，不改拖曳狀態）。
- 對外介面（`namespace ds::kernel`）：**邊緣吸附**——拖曳中 surface 對螢幕（容器）邊 / 其他 surface 邊
  的自動吸附對齊，結果以 E1-07 宣告式定位承載（NFR-02）。
  - 純幾何核心：`snap_rect(dragged_rect, target_rects, container, config, out)`——逐軸求「夠近
    （|delta| ≤ threshold·容器邊長）且最近」的對齊（螢幕起 / 末端邊、各 target 左-左 / 右-右 /
    左-右 / 右-左），套用位移；`SnapResult` 帶吸附後矩形與逐軸 `AxisSnap`。
  - 宣告式：`snap(dragged_spec, element, targets, container, config, out)`——`resolve` 落地 →
    `snap_rect` → 再表達為 `AnchorSpec`（吸螢幕末端邊 → 末端錨 + 零偏移「隨容器縮放恆貼齊」；其餘軸 →
    起始錨 + 正規化偏移精確承載；round-trip 回同一矩形）。
  - 設定：`SnapConfig`（閾值為容器尺寸正規化分數，逐軸換算；`from_spacing` 用 E1-07 具名間距；
    `to_screen` / `to_surfaces` 分別開關）；服務 `EdgeSnapping` 持一組設定。
  - E1-08 整合：`snap_surface(snapping, DraggableSurface, dragged_id, element, surface_targets,
    container, out)`——讀實時位置吸附（含自己 → 略過、目標無實時位置 → 略過；被吸附者無實時位置 →
    Invalid）。
  - NFR-02：閾值為相對分數；吸附後位置全為 E1-07 `AnchorSpec`（具名錨點 + 正規化偏移）；邊以具名
    `Edge` / `AxisSnap` 表達。核心 API **無**絕對像素座標 / 數字 z-order；具體像素只在 `snap_rect` 的
    `ResolvedPlacement` 邊界（呼叫端提供尺寸）出現。
  - 錯誤：越界 anchor / 非有限 / 負尺寸 / 非有限 / 負閾值 / 非正容器 / 無效目標 / 無實時位置 →
    `SnapStatus::Invalid` 且不觸碰 out。一律結構化回報，不靜默、不崩潰。
  - 相位 1 約束：無平台分支（無 `#ifdef`）、無真實 OS / 視窗 / 繪圖 API、無
    `src/kernel/backend/win32|cocoa/`；純幾何 + 純資料，`EdgeSnapping` 無自有可變狀態。
