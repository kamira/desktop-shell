# 結構註記 — E5-09 機率排程器

- 層級：engine（平台中立純邏輯）／子系統 events
- 目錄位置：`engine/events/e5_09/`
  - `random_source.hpp` — 可注入亂數來源介面 `RandomSource` + 預設 `SeededRandomSource`（SplitMix64，固定種子決定性）。
  - `probabilistic_scheduler.hpp` / `probabilistic_scheduler.cpp` — 機率排程器介面 + 實作。
  - `CMakeLists.txt` — `add_library(e5_09)` + `target_link_libraries(e5_09 PUBLIC e5_04)` + `test_e5_09`（`tests/e5/test_e5_09.cpp`）+ `add_test(NAME e5_09)`。
- 相依：`e5_04`（心跳；PUBLIC，介面上使用其 `Tick` / `SubscriptionId` / `HeartbeatSource`）。
- 測試：`tests/e5/test_e5_09.cpp`（gtest，13 案例）。
- 對外介面（`namespace ds::events`）：以機率在邏輯時間推進中偶發觸發事件，供桌面角色隨機行為（隨機閒置動作）。
  - `schedule(interval, probability, cb)`：每 interval（tick）為一次評估機會，每次評估抽一個可注入亂數，
    抽值 < probability 即觸發 `cb`；`interval==0` 拒絕回 0，probability 夾至 [0,1]。
  - `cancel(id)` / `advance(dt)`（回傳本次總觸發數）/ `tick()` / `now()` / `task_count()` / `set_random_source()`。
  - 時間推進委派 E5-04 `HeartbeatSource`（每任務掛一心跳訂閱作為評估來源）。
  - 核心性質：**RNG 可注入 / 可替換、不使用全域 `rand()`**，固定種子下觸發序列完全決定性可重現；
    每次評估固定抽一個亂數使消耗次序穩定。純邏輯、無平台分支、無真實時鐘 / 熵。
