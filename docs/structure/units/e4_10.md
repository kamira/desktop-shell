# 結構註記 — E4-10 閒置自動動畫觸發

- 目錄位置：`modules/elements/e4_10/`（module 層 / elements 子系統 / 平台無關純邏輯）。
- 內容：`idle_animation_trigger.hpp|cpp`（`IdleAnimationTrigger`：以注入式 tick 累計「距上次
  活動已過多久」的閒置計時；`set_idle_threshold`/`idle_threshold()` 設定 / 查詢閒置門檻；
  `register_animation(FrameAnimationElement&, eval_interval, probability)` 登記候選閒置動畫
  （回傳 `RegistrationId`，內部即一枚 E5-09 排程任務）/`unregister_animation`/
  `animation_count()`；`notify_activity()` 重置閒置計時；`advance(dt)` 推進——未達閒置門檻
  前完全不推進內部 E5-09 排程器（不消耗亂數），達門檻後才轉呼其 `advance` 評估各登記動畫，
  機率命中即對該動畫 `reset()`+`play()`；`idle_elapsed()`/`is_idle()`/`total_trigger_count()`
  查詢）、`CMakeLists.txt`（`add_library(e4_10)` +
  `target_link_libraries(e4_10 PUBLIC e4_07 e5_09)` + `test_e4_10`，根層自動 glob 收入）。
- 相依：上游 E4-07 幀序列動畫（`modules/elements/e4_07/`，可讀不可改；提供
  `FrameAnimationElement` 供觸發時 `reset()`+`play()`）、上游 E5-09 機率排程器
  （`engine/events/e5_09/`，可讀不可改；提供決定性機率觸發邏輯，內部以 `ProbabilisticScheduler`
  成員形式持有）。
- 對外介面：命名空間 `ds::elements`；呼叫端注入邏輯時間（`advance`）與活動通知
  （`notify_activity`）驅動「該不該觸發登記動畫」的決定；**不**自行推進動畫逐幀進度（那是
  `FrameAnimationElement` 本身 / 其與 E4-09 動畫驅動源的接線責任），**不**偵測真實輸入裝置。
  因內部排程回呼閉包參照 `this`，本類別刪除複製 / 搬移。
- 測試：`tests/e4/test_e4_10.cpp`（13 個 gtest 案例，`add_test(NAME e4_10)`）。
