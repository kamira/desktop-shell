# 結構註記 — E7-12 設定值寫回（描述子系統 / E7-01 的應用）

- 單元：E7-12（engine 層 / format / Risk: low / 相依 E7-01）
- 目錄位置：`engine/format/e7_12/`（平台中立引擎邏輯，換平台一行不動）
- 測試：`tests/e7/test_e7_12.cpp`（CTest 名 `e7_12`）

## 放了什麼
- `writeback.hpp` / `writeback.cpp`：消費 E7-01 的 `Value` / `Document` / `FormatVersion` 契約，
  提供設定持久化的「寫」方向——
  - `Path` / `PathSegment`（Key / Index）+ `parse_path("a.b[0].c")`：以路徑 / 鍵定位。
  - `set_value(root, path, value)`：純函式重建，更新既有值或新增鍵 / 附加元素（回傳新樹，不改原樹）。
  - `serialize_value` / `serialize(Document)` / `serialize(root, version)`：序列化回 E7-01 文字格式。
- `CMakeLists.txt`：`add_library(e7_12 STATIC writeback.cpp)` + `target_link_libraries(e7_12 PUBLIC e7_01)`
  + `test_e7_12` + `add_test(NAME e7_12)`。不改根 CMakeLists、不自造格式模型。

## 對外介面（一句話）
`ds::format`：以 `set_value(root, "window.width", Value::integer(1280))` 就路徑更新 / 新增設定值，
再以 `serialize(root, version)` 序列化回 E7-01 可再解析的文字——round-trip（parse→改值→序列化→
再 parse）一致；契約違反（型別不符 / 索引越界 / 路徑錯）一律 throw，不靜默失敗。
